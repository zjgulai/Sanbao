## 2. 方案概述

第二批 20 张工单按**消融优先**的验证哲学组织：先让「会降级 + 会红灯」成为被证明的事实，
再把静态守卫（消费面判据、spec 接线）补到盲区上。分六个批次（A 运行时耦合 / B 消融矩阵 /
C 可达性 / D 效率 / E 欠账 / F 卡位），工单文件已全部落盘，本 spec 只定**执行顺序与阶段门**，
不复述工单内容。

**接缝选择**：全部复用现有接缝——`node scripts/gate.mjs` 退出码（判据面）、
`lifecycle-events/startup.jsonl`（启动权威读数）、`sync-profile --check --loadpoint`（装载点）、
CDP 会话（实机 DOM）。不新建观测通道。
