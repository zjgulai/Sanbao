# 026 后置只读呈现组：四族的"只印什么、绝印什么"

> 决策与规则见 [ADR-0208](../../../adr/ADR-0208.md)。

## Problem

工单 026 的验收三条全是禁令（不得有更新入口、不得由工具数量/连接成功推导可用、知识无写入口），
而"后置页面族"本身没有 provider 清单——知识库、成员/范围、更新能力在本版都不存在。
所以本票的真问题不是"接什么查询"，而是**每一族能诚实印出什么**，以及缺席时说什么。

## Decision

- **可见范围**（US-129/130）：只印已读到的组织（实例策略 `organizationId`）与事项主责
  （`matter.responsiblePartyRoleRef`）；缺席分别 `policy-unreadable` / `projection-absent` 并配固定句；
  卡片零控件（无邀请、无协作管理人、无范围变更）。
- **知识与引用**（US-131~133）：知识库 provider 不存在 → 明写"未接线 · 无 provider"，并与
  "没有知识条目可列"分开讲；引用条目（013 的记录）只读呈现来源/版本/可达性；取用留在能力页。
- **插件与扩展**（US-134~136）：行 = 运行时清单的安装时 identity/version/artifact 摘要；
  "本次启动的一次观察"（loader active / boot / 世代）单独一块；两块不合结论（ADR-0167/0168）；
  清单缺席 → 未核验+原因码，不写停用。
- **关于与诊断**（US-137~139）：版本/协议/世代/manifest 摘要只取自 Host 快照（ready 过 pin 校验才有），
  `manifestVerified` 仅活跃快照为真；数据根取启动解析的 `paths.root`；无更新入口。
- 分类器 `src/main/sage-readout.ts` 是唯一的合成点，且它只搬运；界面有恒定免责句。

## Alternatives considered

- 插件显示"已挂载/未挂载"两态：安装时 attestation 不证明挂载，否决。
- 可见范围列成员：无 provider，且"出现某人≠有读取权"，否决。
- 诊断导出按钮：脱敏边界未定，本族只显示不导出，否决。
- 知识条目渲染成空列表：会被读成"确实没有条目"，否决。
- 版本号由 renderer 常量提供：US-139 明文禁止，且会出现第二个家，否决。

## Consequences

- 面板内零控件由文档切片断言守着；"未核验/未接线"各有固定说法。
- 诊断块与 001 的命令槽共用同一份 `lastCommand`（provider 传入），命令事实仍一个家。
- 已知未闭：知识/成员/更新三类 provider 不存在（工单备注：接入后另开票）；真机端到端未跑。
