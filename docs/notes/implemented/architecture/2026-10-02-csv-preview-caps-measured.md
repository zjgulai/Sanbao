# 016 CSV 预览容量定标：本机实测与所选上限

> 决策与规则见 [ADR-0219](../../../adr/ADR-0219.md)。

- 命令：`cd apps/sage-shell && npx tsc && node scripts/measure-csv.mjs`（用出货解析器 `lib/main/csv.js`）
- 环境：darwin arm64、Node v24.18.0、2026-10-02

## 所选上限与依据

- 预算：预览打开保持可交互 ⇒ 解析＋建表合计 ≤ ~50ms（本机实测口径）。
- `maxRows = 2000`、`maxColumns = 64`、`maxCellCharacters = 200`：
  - 上限内最重的可读形状 2000 × 64 × 12 实测 **38.47ms**（≤ 50ms），且其 1,701,397 字节低于读取页
    的 byte 上限（基座默认 2MiB），页能完整送达解析器；
  - 50,000 × 32 实测 **1255.51ms**（34× 预算）⇒ 明确排除在解析范围外；
  - 2000 × 16 × 200 实测 **149.90ms** 且输入 6.4MB 已超出读取页上限 ⇒ 200 字符做**显示截断**、
    超长输入由读取层的 too-large 明确拒绝（两条都不是静默截断）。
- 这些数字来自本仓实测，不是照抄基座默认值（基座默认仅提供读取页边界事实：2MiB/32MiB/5000 行）。
