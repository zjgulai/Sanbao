# 020 显示偏好：单一权威值、状态分开、失败回退

> 决策与规则见 [ADR-0214](../../../adr/ADR-0214.md)。

## Problem

020 要三项显示偏好单一权威值持久化、两处入口共用，并禁止快捷键/语音/布局入口与"内置浏览器"开关；
US-110 还要求把"保存请求／已保存版本／实际生效"分开，"立即保存"不能冒充已持久化。

## Decision

- 本设备一条密封记录（与草案同族 `createDeviceSealer`）；外观页与用户菜单只读 `state.preferences`、只写
  `/.sage/preferences`。
- 记录只存 `requested` 与 `savedAt`；`effectiveTheme` 由 main 用 `nativeTheme` 观察解析（无观察即 null →
  界面"未核验"）；"已保存到本设备"只挂在 `savedAt` 上。
- 写入失败＝refused → 两处入口重写回已保存值 + "保存失败：显示值已回退"（本地提示门防轮询覆盖）。
- 禁令进卡片正文；外观卡放**个人资料**面板（后置只读面板保持零控件）。

## Alternatives considered

- 两处各存一份：US-108 禁止，否决。
- 不记 savedAt：无法区分"已保存版本"，否决。
- renderer 读 matchMedia：与 US-111（main 观察）冲突，否决。
- 无观察兜底浅色：把未核验写成结论，否决。
- 外观卡放后置只读面板：被 026 的零控件断言当场判红，位置改到个人资料，否决原位置。

## Consequences

- 三条验收各有断言（两入口同值同变、独一路由、savedAt 语法、失败回退、未观察未核验、无禁用控件）。
- 已知未闭：真机 Electron 未跑（观察以注入值证明）；八项外观清单其余五项等 047。
