# 031 运行监控四轴与只读运行日志

> 决策与规则见 [ADR-0228](../../../adr/ADR-0228.md)。

## Problem

FW-032/US-159~164：四轴分开、不合成单一状态；折叠/关闭面板不取消运行、详情与列表同一投影
（R12）；设备离线≠取消≠接管；用量三态（预留/消耗/账单）分开、未知≠零；上下文与压缩只读、
显式提示、不泄漏私有侧聊；运行日志只读、不进对话同步、导出独立核权（P14）。基座无用量/预算/
设备/压缩读数；S5 可读工作区日志文件（版本令牌不透明、含 mtime）。

## Decision

- `main/run-monitor.ts`：步骤=会话同一投影；预算三态=分开 unknown（禁 0 冒充）；设备/后台=各自
  reason；视图无 overall/runStatus/total；生产两槽同源一读。
- 面板开合=本地 hidden（零请求）；渲染断言开合后 requests 为空且刷新保持。
- 上下文/压缩只读＋无触发入口＋不外泄文案（沿 024 分别投影）。
- `main/run-logs.ts`（S5）：游标式有界只读——≤200 行/页、单行>2000 截断计数；**追加不失效
  游标**（旋转判定=文件变小，因 mtime 使每次追加都变版本）；变小=file-rotated 置空游标提示
  从头；缺文件自码；活会话作用域；不触会话/转录；无导出入口。
- 路由 `/.sage/run-log`（精确体 2–5 键）；槽 `runMonitor`（fallback unavailable 各轴保留 reason）。

## Alternatives considered

合成单一状态（R12 教训）、0 冒充未知（D-031 点名）、另建事件缓存（US-160 点名同投影）、
定时 tail（首版按需有界读）、版本变化判旋转（追加即误报）、导出入口（D-033/059 后置）。

## Consequences

- 验收两条机器断言：四轴形状钉住＋压缩只读零控件；折叠零请求零取消。
- S5 真字节：分页/追加/变小轮转/超长截断/缺文件≠空日志。
- 已知未闭：四轴中三个读数未接线（如实 unknown）；同尺寸重写不可检测；真机未跑。
