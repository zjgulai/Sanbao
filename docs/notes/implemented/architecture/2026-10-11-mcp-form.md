# 自定义 MCP 表单（本地草稿，提交 fail closed）

## Problem

Loop-Q R8：O08 十二行（自定义 MCP 表单族）此前零实现。Sage 无 MCP 配置写 provider；T10 禁止本类票安装/启用/批准。观察行均为表单形状事实，可在不触治理链的前提下装配。

## Decision

按 [ADR-0306](../../../adr/ADR-0306.md) 实施：`McpForm` 本地草稿域 + 观察形状逐条装配（空表单、STDIO/HTTP/SSE 字段集、动态行、JSON 示例、名称预览、放弃确认）；提交/导入 fail closed（T10 未接通具名拒绝）；扩展页升级为扩展管理页。

## Alternatives considered

见 ADR-0306 备选表（真实写 route、空表单禁用、自绘高亮、跨传输清空——逐条否决）。

## Consequences

- O08 组 11 叶 + 伞行迁 implementing（35→47、163→151 pending）。
- 视觉验收、替换预览等未观察叶、原生菜单微差登记。
