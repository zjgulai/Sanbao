# 「三无 · Agent全栈专家」：从一条压缩 preset 到十四节点的全栈派活链

- 日期：2026-09-16
- 生命周期：implemented
- 分类：capability
- 对应 ADR：[ADR-0091](../../../adr/ADR-0091.md)
- 相关：[ADR-0023](../../../adr/ADR-0023.md)（删除被会话引用的 preset）、
  [ADR-0083](../../../adr/ADR-0083.md)（技能开关写在 SKILL.md frontmatter）、
  [ADR-0090](../../../adr/ADR-0090.md)（品牌资产判据的诚实划界）、
  总账 P-02 / P-03 / P-04 / P-07

## Problem

`创造模式（压缩加固）`（`lute-cordis`）只解决一件事：长中文会话的上下文压缩。它**没有角色** ——
模型不知道自己该按什么链路干活，技能目录仍是全量 1700+ 条，输入框里选中它只换来一个更省 token 的压缩后端。

要求是把它变成一个有名字、有执业准则、有派活链的全栈专家，并指名两个外部来源。于是有三件事必须同时成立：

1. **人格**要可执行，不是形容词堆；
2. **技能目录**要收窄到这条链用得上的那一批；
3. **页面**的组织方式要与人格里那张派活表**同轴** —— 否则模型说「走 M09」，人在页面上找不到 M09。

### 调研阶段被实测推翻的四处自述

动手前我按记忆写了四条「已知事实」，逐条核对后**四条都错**，全部更正（这是本 Note 里最该留下的部分）：
`retro` 的 README 里 `STUB` 出现 **0 次**（它不是桩）；`implement-spec` 不是 `write-spec` 的重复
（它是 2043 字节的编排技能）；42 个 `commands/*.md` 合计 **175,587 字节**、其中 `ship-check` 是调用 4 个命令的编排器，
所以「折进技能正文」这个方案作废、改为整体存档；节点/白名单/技能数实为 **14 / 89 / 138**，不是 13 / 80 / 152。
还有一处是运行中自己抓出来的：派给分类 subagent 的清单漏了 `analyze-feature-requests`，
它主动对账顶了出来。

### 人格层的腐烂是**不可见**的

人格写错、写空、被截断，**加载、日志、页面读数全部正常**，只有行为变了 —— 而「行为变了」没有读数。
`persona` 行又是 `agent.cordis.yml` 中间的一个块标量，人不会去读它。

### 全栈线的分组头像此前一条判据都没有

`verify_static.mjs` 查了出海线与通用线的分组头像，**全栈线没有**。而
`build_preset_catalog.py` 在 `category-icons-fs.json` 缺某个键时会回落到 `cat_svg['agent-tools']` ——
那是出海线「工具管家」的头像，**不是空值**，所以「这一行有没有图」这条判据看不见这个回落：
14 个节点会一起顶着同一张脸。

## Decision

### 1. 人格：`SOUL.md` 是家，persona 行是渲染副本，门禁用同一个渲染函数复核

正文写在仓库内 `packages/capabilities/dsh-overseas-skills/presets/agent-fullstack/SOUL.md`（4224 字符），
`sync-fullstack-persona.mjs` 渲染进 persona 行，`verify-agent-fullstack.mjs` 复算比对。
渲染函数**只此一处**并被门禁 import —— 门禁自带一份「等价实现」会漂移，而漂移的那一份仍然报绿。

人格正文分六节：三无（把「无谄媚附和 / 无编造未验证 / 无越权承诺」写成可判定的行为，来源是
`Constraint/cursor_rules/anti-sycophancy.mdc` 的证据分层与自检触发器）、风险分级与人类责任
（R0–R3 + Delegate/Review/Own，来源是 `docs/workflow.md` 的 Full-stack Coding Agent Contract 与
`08-AI-Native-SDLC控制面规范.md` 的责任级别）、M00–M13 派活表、开工/实现/调试/收工固定动作、
语言与表达、上下文与工具。节点级打法**不进**人格：常驻文本只留路由表。

### 2. 门禁不只比字节

`verify-agent-fullstack.mjs` 第 6 层独立断言：三无三条逐条在文、M00–M13 逐条在文、
`{{model}}`/`{{cwd}}` 仍在、长度不低于下限、不是 P1 留下的骨架占位。
理由是**逐字比对挡不住「源与副本一起被删」** —— 那种改法两边一致，字节判据一样绿。

11 条突变自测（`scripts/gates/agent-fullstack.test.mjs`）证明它**能说不**，其中两条是要点：
M1 用**同长度**的单字符替换（打掉「只比长度」的退化实现）、M4 源与副本一起删掉 M09 那行后
同源仍成立而派活链断点仍判红（证明 6b–6d 不是 6a 的附庸）。

### 3. 全栈目录：8 个做法类 → 14 个交付节点

节点键与标题的唯一事实源是 `scripts/build-fullstack-catalog.mjs` 的 `NODES`，派生三份产物：
`fullstack-mapping.json` 的 `categories`（同时也是 `assign_lute_icons.py` 取头像 id 的依据）、
`manifest/fullstack-skills.json`（页面读的那一份）、`manifest/taxonomy-v3.json` 的 `fullstackNames`。
`--check` 供门禁，且先证明「零改动往返逐字节相同」。

`verify_static.mjs` 的新判据一律与事实源对账、**不写数字**，并补了那条此前缺失的分组头像判据
（存在 + **互不相同**）。

### 4. `lute-cordis` 保留目录、只标退役

实测引用面 **329 个会话**（302 subagent + 27 顶层；顶层里 16 个有人类用户消息、1709 条用户消息、400MB）。
`remove-preset.mjs` 拒绝执行是**对的**。改动只落在 `preset.yml`：名字加「· 已退役」、描述写清被谁取代与
保留原因、`order: 9900` 排到最后。平台没有 `hidden` 字段（`@deepseek-ai/dsh-agent-presets` 的 schema 只有
`name`/`description`/`order`/`icon`），所以「藏起来但仍可解析」这条路不存在。

## Alternatives considered

- **`--force` 归档**：字面满足「归档」，代价是打断 329 个会话。用户 2026-09-16 明确选择保留。
- **先改会话里的 preset 引用再删**：要动 zstd 压缩的用户会话 JSONL，且 302 个子会话的父方未必都拿得到。
- **13 组（M01–M13，M00 不进页面）**：M00 的 4 条技能仍要落点，白名单与人格也都是 14 个节点。用户选了 14。
- **沿用 8 组、在标题里加 M 编号**：一个技能只落一个组，两套轴不可能靠改标题重合。
- **把节点打法塞进人格**：人格是每次请求都注入的常驻文本，那是渐进式披露该承担的东西。
- **给 68 条新技能各做一枚头像**：14 枚节点分组头像已能让每行都有图（回落语义是产物里烘死的），
  68 枚的技能头像不在本轮范围；回落名单由脚本打印点名。

## Consequences

**读数（每条都有真实命令输出）。**

| 项 | 前 | 后 |
| --- | --- | --- |
| 人格 | P1 骨架占位 174 字符 | SOUL.md 4224 字符，同源=是，节点 14/14 |
| 全栈分组 | 8 组（做法类） | 14 组（M00–M13） |
| 全栈行数 | 70 | 138（M00:5 M01:8 M02:10 M03:17 M04:22 M05:10 M06:3 M07:11 M08:5 M09:12 M10:6 M11:4 M12:12 M13:13） |
| 分组头像 | 8 枚，无判据 | 14 枚且互不相同，新增判据 |
| `verify_static` | 绿（全栈线无判据） | 绿（FS 14 组 / 223+138 行 / 图标 199 枚 6911 个 paint 全合法） |
| 包内测试 | 71 | 72 全绿 |
| 门禁 quick | 59/59 | 63/63 |

**负控（判据必须能说不）。**

- 人格层 11 条突变自测全过；对**真** preset 注入同长度单字符替换 → 门禁红并点名两条，
  同步器拉回后 `sha256` 与注入前**逐字节相同**。
- README 组数 14→15 → `doc-counts` 红；还原复绿。
- 新 FS 判据在改造前**真实红过**四条（分组轴不符、行数 70≠138、行挂未知分组、名单漂移），
  这正是它「不是空转」的证据。

**代价与诚实划界。**

- 人格 4224 字符进每次请求的 system prompt。取舍：这份 preset 的用途就是全栈交付，
  这些规则是它存在的理由；节点级细节已下沉到 skill。
- **页面生效需重启 DSH**：宿主在插件装载时 `import` 了 `lib/catalog.js`，本会话内改文件不热更新。
  本 Note 写就时「设置 → AI全栈」仍显示旧的 8 组 —— **运行层验收未做**，不是通过。
- **14 枚新头像未做像素级验收**（本会话的模型不支持读图，也没有截图工具）。已做的是结构判据：
  品牌 9 条不变量（viewBox / 品牌绿描边 2.2 / 三档渐变 / 外框圆角 18 / 成人脸 80% 占比 / 底部投影）、
  每枚的徽章图形确实画上（与「不写 emblem」的基线逐字节不同）、与按 catalog 重算逐字节相同。
  `assets/preview-*.html` 仍是 310 枚旧版。
- 68 条新技能无专属头像，回落到所属节点头像。
- `lute-cordis` 仍在抽屉里（标着已退役）。
- 本机 `~/.dsh/skills/lute-brand-icons` 不在 git 下，310 → 324 枚的追加只由 `catalog.js` 同步追加保证；
  **没有跑 `scripts/build.js`**（它会整体重写清单，有把 310 枚已验收头像重算成不同字节的风险，
  而那些字节被隔壁包逐字节断言着）。
- 三处被 subagent 纠正的事实，照实记：合法 `emblem` 不是 17 个而是 **45 个**（我先前取的是源码前 17 个）；
  `assets/manifest.json` 那一行必然出现在 diff 的修改侧，「0 行修改」只对 310 枚 SVG 成立；
  预览页未重跑。
