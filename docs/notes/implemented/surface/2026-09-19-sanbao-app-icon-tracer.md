# 005 图标示踪弹：受管 squircle、形状判据与安全重放

关联决策：[ADR-0133 D3](../../../adr/ADR-0133.md)、[ADR-0135 D5](../../../adr/ADR-0135.md)、[ADR-0136 D5](../../../adr/ADR-0136.md)。
工单与验收回执：[005 示踪弹 B](../../../../.scratch/sanbao-reskin/tickets/005-示踪弹-B.md)。

## Problem

旧 app 图标构建依赖未入仓的 preview 副本或仓外头像引擎；门禁只看 IHDR 尺寸，尺寸正确的 RGB 方块也会通过。Finder 的 icns 与 Dock/托盘 PNG 是两条不同供给路径，仅检查其中一条不能证明装机品牌一致。

## Decision

- 使用显式标注 `placeholder` 的中性几何 SVG，由仓内生成器产出 power-5 superellipse icns 和运行时 PNG，输入及输出纳入既有 pin 校验；这些图标是本仓自制派生物，不伪称为供体原文件。
- `brand-icons` 读取实际 PNG 像素，守住 alpha、透明边角区域、可见主体与 app 深底，设置解压上限；反例及可复现构建测试进入既有 selftest。
- 资产集合与 `ICON_PAIRS` 同片更换；装配逐项检查必备资产，缺件中止。重放测试覆盖 icns 与运行时 PNG 的写入、幂等及拒写前后字节相等。
- 真机执行暴露仓内 icns 未透传、备份晚于写入以及备份目录只认旧布局的问题；改为显式 `BRAND_ICON_ASSET`，签名身份预检和双布局备份前置，备份失败立即退出。保持“应用运行中拒绝改 bundle”的既有闸门。
- 用户裁决 005 只做图标：不改显示名、bundle 路径、可执行文件、bundle id 或用户数据路径；正式图形字母标仍归 T1。

## Alternatives considered

- 直接换一份二进制：无法复现，下次更新继续依赖人工。
- 只看 `hasAlpha` 或四个角点：RGBA 硬边图、只挖四点的方块仍能冒充合格，已用反例验证。
- 顺便把 `DSH Desktop.app` 改为 `Sanbao.app`：超出图标工单，且改变既定寻址边界，用户明确选择不在本票做。
- 修改豁免或覆盖其他会话的 profile 装载点来获得全绿：不采用，按基线 §2.4 留原始门禁结果与归因。

## Consequences

图标可以从受管输入重建，装机双通道与缺件失败路径具备回归测试。生成仍依赖 macOS `sips`/`iconutil`，逐字节复现证据限定当前工具链，不宣称任意 OS 版本都会产出同一编码。

真机外观由用户目视确认；本会话录屏权限为 false，未生成截图，不以文件哈希冒充视觉证据。原始验证结果、共享环境未通过项、装机首轮失败和重试结果统一记录在工单回执，不在此复制数字。
