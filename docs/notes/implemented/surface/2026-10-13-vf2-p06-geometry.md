# VF-2 P06 设置族几何精修（ADR-0337）

对应决策：[ADR-0337](../../../adr/ADR-0337.md)。对应票据：[视觉保真票](../../../plans/2026-10-12-qoder-visual-fidelity-tickets.md)（VF-2）

## Problem

VF-1 后颜色锚定 Qoder，但 P06 设置族几何仍是自造：卡片带 1px 边框、分组标签在卡内、行无分隔线、弹窗轻阴影——与真机截图（`assets/qoder-reference/screenshots/base-20261013/`）对照错位明显。

## Decision

按 [ADR-0337](../../../adr/ADR-0337.md) 实施：像素测量（逐像素扫描截图像素）→ 几何换形。分组容器改「标签卡外 + ul=白卡无边框 + surface ring」；行间改发丝分隔线（新 token `divider-hairline`，light `#f0f7f4` / dark `#262624`，进唯一家+锚定表）；页标题 24px、组距 24px、行 padding 10px；弹窗 backdrop 改 surface 72% 水洗 + blur(18px)、卡片无边框白底。零行为改动（h3 加 class 之外无 DOM/aria 变化）。图标方块（26×26 tinted tile）独立小批。

## Alternatives considered

见 ADR-0337 备选表（分隔线写死踩零字面色合同——实测被 desktop-page spec 拦下后 token 化；图标方块混入拖批；纯色遮罩失真）。

## Consequences

- P06 设置族与真机肉眼接近；VF-3 验收管线可先在此族试跑。
- `divider-hairline` = 第 20 色 token，后续族复用。
- 弹窗遮罩为常开形态；「模糊与玻璃效果」开关接线随 T13 偏好子批。

## Verification

真实运行（2026-10-13）：

- tsc 0 错；主题射程 31 文件 319/319（settings 4 spec + theme-tokens + display-theme + desktop-page 含零字面色合同）。
- `pnpm run gate` 32/32。
- 过程拦截记录：分隔线初版写死 `#f0f7f4` 被「CSS 零字面色」合同拦下 → token 化正路；弹窗阴影初版带 rgba 同被拦 → 收敛回 token 阴影。
