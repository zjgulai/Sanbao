# 全站三主题统一

- 日期：2026-09-20
- 状态：实施中，未完成全站三主题验收
- ADR：[ADR-0145](../../../adr/ADR-0145.md)
- 规格：[全站三主题与统一排版](../../../specs/2026-09-20-qoder-visual-language.md)

## Problem

界面存在旧颜色持久化回灌、局部配色和独立文档主题断链。主题包扩展变量的亮态只写在 root，而官方同名变量定义在 body；root 继承无法覆盖 body 自有声明。仅改默认值或增加粉色预设不能消除混色。

用户明确要求所有页面和子页面按亮色、暗色、暖粉白三种风格一致，并批准一次性实施；旧的双主题局部计划不足以交付。

## Decision

采用 [ADR-0145](../../../adr/ADR-0145.md) 的三主题身份、Host 权威设置与语义色板单一源。保留字体和字号偏好，关闭任意旧配色写入口，按实际渲染环境适配并逐叶验收。

颜色与排版分工独立，四个字体字段为共同接口；不得通过颜色重置更改用户排版。开发在隔离工作树中进行，未经协调不改实际装载点或重启应用。

## Alternatives considered

仅改默认值无法影响有效旧记录；增加主题预设无法阻止任意配色；逐页面写颜色会造成多源；全屏滤镜会污染文档和状态。均不采用。

## Consequences

核心模型、同文档面、独立文档可以逐任务测试，但完整交付依赖全页面三主题矩阵闭合。系统控件及用户文档保持内容边界，未测试面和不可访问面必须显式记录，不能算通过。

实施与全站三主题验收仍未完成；验收遵循[规格 §0（含 §0.3 排版验收）](../../../specs/2026-09-20-qoder-visual-language.md#0-已确认的扩展范围)。具体命令、原始输出与阶段进度由[同计划](../../../plans/2026-09-20-qoder-visual-language.md)的 progress 记录保管；该记录位于 gitignored 临时目录，不作为永久证据链接，本 Note 不复写临时进度数字或预写成功。
