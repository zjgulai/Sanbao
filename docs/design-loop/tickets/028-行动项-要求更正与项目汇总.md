# 028 · 行动项、要求更正与项目汇总

**Blocked by**: 002
**覆盖需求**: US-146, US-147, US-148, US-149
**接缝**: S1 / S8

## 目标

MECE补漏：事项内行动项可分派跟踪并回看执行记录；“另补要求更正”以关联消息+生效回执表达；项目视图只做归属与汇总。

## 涉及层

- [ ] 数据层：行动项与其归属事项、执行记录、更正关联
- [ ] 逻辑层：行动项不等同交付项/待办请求/工具调用/一次运行；更正不覆盖原要求、不重放未知结果
- [ ] UI层：行动项列表与详情；项目汇总视图不显示未获授权的事实变化
- [ ] 测试：行动项语义区分有断言；项目归属变化不自动改主责或可见范围

## 验收标准（须给真实证据，未跑就写“未运行”）

- 要求更正可追溯到原要求与生效回执
- 项目汇总不自动共享或改变主责（有断言）

## 明确不做

不做跨项目批量改属；不做项目级权限继承
