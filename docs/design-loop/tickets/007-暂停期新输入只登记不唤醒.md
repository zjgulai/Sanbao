# 007 · 暂停期新输入只登记不唤醒

**Blocked by**: 006
**覆盖需求**: US-020, US-021
**接缝**: S1 / S2

## 目标

暂停态下发送新内容只保存为待继续并反馈“已收到，尚未执行”；查看/编辑/移除也不唤醒执行。

## 涉及层

- [ ] 数据层：待继续清单追加
- [ ] 逻辑层：记录消息与派发prompt分离，暂停态不调用会唤醒Agent的prompt
- [ ] UI层：保持暂停态并显示独立继续入口
- [ ] 测试：断言暂停态发送不产生派发调用；继续后按序派发

## 验收标准（须给真实证据，未跑就写“未运行”）

- 暂停态发送后无Agent唤醒调用（有断言）
- 发送与继续并发时按队列版本对账，不悄悄把未含内容送入执行

## 明确不做

不定义旧输入合并/顺序细则（留实现合同）
