# 042 · 模型排队、就绪与重试三态

**Blocked by**: 005
**覆盖需求**: US-200, US-201, US-202
**接缝**: S1 / S2 / S8

## 目标

状态级补漏：排队中/就绪/重试三态来自服务事实并与错误三态不混用；排队与重试不重复提交。

## 涉及层

- [ ] 数据层：排队状态、就绪时点与请求标识
- [ ] 逻辑层：就绪不由界面计时器推断；超时归入结果未知
- [ ] UI层：三态文案与错误三态分开，不合并为“请重试”
- [ ] 测试：重试用同一请求标识不并行发起（有断言）

## 验收标准（须给真实证据，未跑就写“未运行”）

- 排队期间不产生重复提交（有断言）
- 超时显示结果未知并只给核对入口（有断言）
- 就绪提示可追溯到服务事实来源

## 明确不做

不做排队优先级设置、不做跨账号配额调度、不做模型自动故障切换
