# 037 · 回复操作与后续建议

**Blocked by**: 005
**覆盖需求**: US-188
**接缝**: S1 / S8

## 目标

状态级补漏：回复操作区只呈现已核实动作，后续建议点击只填入输入区。

## 涉及层

- [ ] 数据层：可用动作清单来自投影事实（复制/引用/重试仅确定失败）
- [ ] 逻辑层：建议点击不自动发送；重试沿用确定失败判据
- [ ] UI层：不显示无后端依据的动作按钮
- [ ] 测试：确定失败以外不出现重试（有断言）

## 验收标准（须给真实证据，未跑就写“未运行”）

- 未知态不出现“重试”按钮，只出现核对入口（有断言）
- 点击建议后输入区有内容但未发送

## 明确不做

不做自定义回复模板、不做回复评分反馈、不做建议的自动追问
