# 029 · 归档、重命名与逐项批量

**Blocked by**: 002, 022
**覆盖需求**: US-150, US-151, US-152, US-153, US-154
**接缝**: S1 / S8

## 目标

MECE补漏：归档按D-029落地，重命名经服务裁决回读实际值，批量逐项返回结果与权限结论。

## 涉及层

- [ ] 数据层：归档状态与可恢复性、重命名的版本化变更
- [ ] 逻辑层：批量逐项裁决，不对无权项静默跳过
- [ ] UI层：隐藏/归档/停止三者分开；归档项在筛选或后续视图可见
- [ ] 测试：归档不停执行、不解责任、不删保留数据（有断言）

## 验收标准（须给真实证据，未跑就写“未运行”）

- 归档后仍可恢复且事实与回执保留
- 批量结果逐项可核对，无“整体成功”伪报
- 重命名回读显示实际生效值

## 明确不做

不做批量审批或批量授权；不做删除与保留策略
