# 048 · 反馈入口与结构化诊断

**Blocked by**: 001
**覆盖需求**: US-223, US-224
**接缝**: S1 / S2

## 目标

状态级补漏：反馈只提交用户文本与结构化诊断，回执区分已接收与结果未知。

## 涉及层

- [ ] 数据层：反馈载荷限定为文本 + code/stage/correlation
- [ ] 逻辑层：不自动附日志/堆栈/机器路径/凭据；重复提交按同一请求标识核对
- [ ] UI层：未知态只给核对同一提交入口
- [ ] 测试：载荷脱敏边界有断言

## 验收标准（须给真实证据，未跑就写“未运行”）

- 反馈载荷不含凭据、机器路径与原始堆栈（有断言）
- 结果未知不重复提交（有断言）

## 明确不做

不做日志上传、不做崩溃自动上报、不做反馈的工单系统集成

**备注**：来源：O13 反馈（FW-040；US-223~224）
