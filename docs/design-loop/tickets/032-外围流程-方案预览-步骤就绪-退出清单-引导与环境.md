# 032 · 外围流程：方案预览、步骤就绪、退出清单、引导与环境

**Blocked by**: 005, 025
**覆盖需求**: US-165, US-166, US-167, US-168, US-169, US-170, US-171
**接缝**: S1 / S2 / S8

## 目标

MECE补漏：把方案作为交付呈现（接受≠执行），步骤按动作前提显示就绪/未就绪，退出前给影响清单，引导只读讲解，环境只读显示来源。

## 涉及层

- [ ] 数据层：方案交付记录、动作前提与就绪事实、退出影响清单来源
- [ ] 逻辑层：未知呈现为阻断而非失败；退出成功不等于远端效果已知
- [ ] UI层：未保存提示绑定真实未保存内容；引导不自动改配置；实验不直通生产
- [ ] 测试：退出清单逐项后果可见；环境页无装配/远端执行入口

## 验收标准（须给真实证据，未跑就写“未运行”）

- 接受方案不触发执行（有断言）
- 不就绪项不被派发；未知呈现为阻断
- 引导不写入任何配置或授权

## 明确不做

不做环境装配、跨设备占用与远端执行；不做实验直通生产
