## 读法

- 目录约定：本集合按用户指定落在仓外设计目录 `docs/tickets/`，不写入源仓 `.scratch/`；粒度与阻塞关系由用户批准（“26 票直接写入”；组级 MECE 补漏增 027～033；状态级核对后按用户“全部补成 US 进首版”决定增 034～049，三批均未引入新的前置票）。
- 顺序执行：按编号从上到下，阻塞者先做。
- 并行执行：下表按 Blocked by 计算，同一波内各票的前置都已落在更早的波次，可并行开工；波次是依赖深度，不是排期承诺。
