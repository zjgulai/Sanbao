# 011 · 事项↔工作区关联（具名建立与解除）

**Blocked by**: 002, 010
**覆盖需求**: US-065, US-066, US-067, US-068, US-069, US-070
**接缝**: S1 / S8

## 目标

事项侧显式从获准工作区列表添加关联、显式解除；默认只列已关联项；解除不删内容、不静默换源。

## 涉及层

- [ ] 数据层：事项与多工作区关联记录及具名操作留痕（Sage自建）
- [ ] 逻辑层：默认执行环境作为偏好保存，每次派发前逐次重验条件
- [ ] UI层：添加/解除入口在事项侧；不隐式产生关联；无工作区详情反向列表
- [ ] 测试：多关联不触发资源扫描或权限合并；解除后既有引用仍指向原来源版本

## 验收标准（须给真实证据，未跑就写“未运行”）

- 关联建立/解除均产生可追溯操作记录
- 关联动作不读取、不上传任何资料内容（有断言）
- 默认环境不可用时阻断并提示，不静默换环境

## 明确不做

不做反向关联列表；不做工作区共享与可见性管理；不合并多工作区权限
