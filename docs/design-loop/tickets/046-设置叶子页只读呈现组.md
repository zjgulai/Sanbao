# 046 · 设置叶子页只读呈现组

**Blocked by**: 020, 026
**覆盖需求**: US-209, US-210, US-211, US-212, US-213, US-214, US-215, US-216, US-217, US-218, US-219
**接缝**: S1 / S3 / S4 / S8

## 目标

状态级补漏：桌面宠物/记忆/数据导入/钩子/电脑操控/移动端/连接/安全/网络/工作区索引/任务监控共 11 张叶子页首版只读呈现来源与不可用原因。

## 涉及层

- [ ] 数据层：每页条目来源可追溯到挂载观察、配置事实或本地记录
- [ ] 逻辑层：写操作一律无入口；触发重建、发起连接、启用开关等不实现
- [ ] UI层：不可配置项显示原因，不留“看起来能改”的控件；未挂载不说成已停用
- [ ] 测试：凭据与 raw subject 不出现在任何页面（有断言）

## 验收标准（须给真实证据，未跑就写“未运行”）

- 11 张页面均只读且有来源标注（逐页断言）
- 任何写操作入口缺位且给出原因（有断言）
- 工作区索引页不触发全量扫描（有断言，与 D-090 一致）

## 明确不做

不做上述任一页面的启用、启停、导入、连接、策略与索引重建；治理写面保持 §7 后置
