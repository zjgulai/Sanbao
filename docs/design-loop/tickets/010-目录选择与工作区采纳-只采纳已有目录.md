# 010 · 目录选择与工作区采纳（只采纳已有目录）

**Blocked by**: 001
**覆盖需求**: US-057, US-058, US-059, US-060, US-061, US-062
**接缝**: S1 / S4

## 目标

通过系统目录选择器指定已存在目录并幂等采纳为工作区；各类失败与取消都有如实反馈。

## 涉及层

- [ ] 数据层：工作区采纳记录（来自workspace.create）
- [ ] 逻辑层：directoryPicker.pick经Host窄桥；invalid-path/name-conflict/unavailable分别投影
- [ ] UI层：无新建空目录入口；取消选择无副作用
- [ ] 测试：幂等采纳（重复同目录返回原工作区）；Host无能力时显示不可用而非静默降级

## 验收标准（须给真实证据，未跑就写“未运行”）

- 同一目录重复采纳不产生第二个工作区（有断言）
- 取消pick不落任何记录
- 首版不调用createDirectory

## 明确不做

不做新建空目录、不做越界路径引导、不做工作区内浏览器的创建操作
