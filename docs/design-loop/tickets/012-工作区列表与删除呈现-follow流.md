# 012 · 工作区列表与删除呈现（follow流）

**Blocked by**: 010
**覆盖需求**: US-063, US-064
**接缝**: S1 / S4 / S8

## 目标

工作区列表接基座follow的baseline+increment维护，重连以baseline对账；删除工作区与删除目录内容在UI上明确区分。

## 涉及层

- [ ] 数据层：列表投影与增量合并
- [ ] 逻辑层：rename/delete/insertBefore经Application Service，不绕过受信边界
- [ ] UI层：重命名/删除/排序反馈；删除不宣称删除内容
- [ ] 测试：断线重连后与baseline一致；增量乱序不产生幽灵项

## 验收标准（须给真实证据，未跑就写“未运行”）

- 重连后列表与baseline完全对账（有断言）
- 删除后目录仍在磁盘上，UI不把两者混为一谈

## 明确不做

不做工作区内容批量扫描；不做反向关联列表
