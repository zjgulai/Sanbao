# 003 · 建项结果未知与失败的恢复入口

**Blocked by**: 002
**覆盖需求**: US-005, US-006, US-119
**接缝**: S1 / S2

## 目标

创建中、失败或结果未知时，输入保留并与同次请求关联；未知走“核对同一操作”，不重复建项。

## 涉及层

- [ ] 数据层：同次请求关联与结果记录
- [ ] 逻辑层：核对查询 + 幂等；失败可回原工作面修正
- [ ] UI层：三态各自的入口（修正/核对/继续等待），取消未提交返回草案编辑
- [ ] 测试：注入未知→核对→已生效路径；断言刷新不重复转换、不自动启动运行

## 验收标准（须给真实证据，未跑就写“未运行”）

- 未知态下界面无“重试建项”，只有核对
- 核对得已生效后列表只出现一个事项
- 取消未提交确认回到草案且内容不丢

## 明确不做

不做批量建项；不做跨设备接续
