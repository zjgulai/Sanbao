# 031 · 运行监控、用量与运行日志（只读）

**Blocked by**: 005, 022
**覆盖需求**: US-159, US-160, US-161, US-162, US-163, US-164
**接缝**: S5 / S8

## 目标

MECE补漏：监控按步骤/预算/设备/后台四轴分别呈现，面板折叠或关闭不取消运行；用量区分预留/消耗/账单；上下文压缩只读并显式提示。

## 涉及层

- [ ] 数据层：四轴状态来自同一投影，不建本地副本
- [ ] 逻辑层：设备离线与运行取消/接管分开；压缩不外传、不泄漏私有侧聊
- [ ] UI层：详情与列表读同一投影，避免“已停/运行中”并存；用量归集到事项；运行日志只读呈现且导出不携带未脱敏内容
- [ ] 测试：折叠面板不取消运行（有断言）；重试与子执行不重复占用预算

## 验收标准（须给真实证据，未跑就写“未运行”）

- 四轴各自独立显示，无合成单一状态
- 压缩前后差异与提示可见，未确认不压缩

## 明确不做

不做预算预留与结算合同、不做后台执行主体、不做设备接管协议；日志不进入普通对话同步
