# 030 · 能力目录、市场与Agent配置只读

**Blocked by**: 001
**覆盖需求**: US-155, US-156, US-157, US-158
**接缝**: S1 / S3 / S4 / S8

## 目标

MECE补漏（discovery/extensions 页面族最大缺口）：能力目录与市场只读浏览，已配置/已启用/可用三者分开显示，写操作入口缺位。

## 涉及层

- [ ] 数据层：目录条目与已配置项的只读投影
- [ ] 逻辑层：不以目录存在或自报推导兼容/授权/可用
- [ ] UI层：安装/更新/启用/撤销无入口；Agent配置只读展示候选与分工声明
- [ ] 测试：三态分开显示的断言；无委派/子执行/预算关系建立

## 验收标准（须给真实证据，未跑就写“未运行”）

- “已配置”不等于“已启用/可用”（有断言）
- 界面无安装与启用写操作
- 未挂载不说成已停用

## 明确不做

不做安装、更新、启用、停用、撤销与授权；不做委派/子执行/预算配置
