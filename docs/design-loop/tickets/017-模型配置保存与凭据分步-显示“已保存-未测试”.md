# 017 · 模型配置保存与凭据分步（显示“已保存、未测试”）

**Blocked by**: 001
**覆盖需求**: US-043, US-044, US-047
**接缝**: S1 / S4

## 目标

模型条目结构校验通过后可保存并回读为“已保存、未测试”；配置与凭据两步分开，部分失败如实回报。

## 涉及层

- [ ] 数据层：配置条目与凭据状态分离记录
- [ ] 逻辑层：settings/credentials适配 + expectedRevision冲突核对
- [ ] UI层：不暴露全量settings编辑器；只显示已配置/缺失/失败
- [ ] 测试：保存不触发任何供应商请求（有断言）；凭据写入不回显秘密

## 验收标准（须给真实证据，未跑就写“未运行”）

- 保存成功与可调用状态在界面上是两个字段
- 部分失败不显示整项完成
- 凭据值不出现在日志/投影中

## 明确不做

不做真实连接测试（见018）；不做密钥存储机制改造
