# 004 · 建项责任字段的真实身份默认值

**Blocked by**: 002
**覆盖需求**: US-008
**接缝**: S1

## 目标

责任字段默认填入当前已认证身份，且UI自报身份不作为授权依据。

## 涉及层

- [ ] 数据层：identity handle引用
- [ ] 逻辑层：读取真实认证态填默认值
- [ ] UI层：显示并可改；无真实身份时不伪造默认值
- [ ] 测试：signed-out与signed-in两态断言

## 验收标准（须给真实证据，未跑就写“未运行”）

- 未认证时责任字段为空且提示缺失，不用占位身份填充
- 改责任值不改变任何权限判定
