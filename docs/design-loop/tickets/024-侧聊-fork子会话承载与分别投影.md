# 024 · 侧聊：fork子会话承载与分别投影

**Blocked by**: 005
**覆盖需求**: US-102, US-103, US-104, US-105, US-106
**接缝**: S1 / S4 / S8

## 目标

侧聊以基座fork派生子会话，独立上下文与历史；事项只关联主对话，侧聊作为派生记录单独列出可回看。

## 涉及层

- [ ] 数据层：父子会话关系与事项归属
- [ ] 逻辑层：fork适配；回主对话需显式动作并沿用候选交付合同
- [ ] UI层：侧聊不混排进主对话流；可见范围分别投影
- [ ] 测试：侧聊内容不默认进入主对话或向协作者开放（有断言）

## 验收标准（须给真实证据，未跑就写“未运行”）

- 打开侧聊不改变主对话历史
- 无“自动合并”路径；合并只能显式动作

## 明确不做

不做侧聊与主对话的自动同步；不做协作者可见范围管理

**备注**：**核验项**：在途运行中能否fork、atSeq截断位置
