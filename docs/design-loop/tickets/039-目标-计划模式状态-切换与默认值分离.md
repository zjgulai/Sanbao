# 039 · 目标/计划模式状态、切换与默认值分离

**Blocked by**: 005, 017
**覆盖需求**: US-192, US-193, US-194
**接缝**: S1 / S2 / S4 / S8

## 目标

状态级补漏：模式状态来自服务投影，切换是具名请求，事项内切换不写全局默认；计划模式输出进入方案预览。

## 涉及层

- [ ] 数据层：当前模式事实、模式默认值与事项内选择分开记录
- [ ] 逻辑层：复用 FW-006 同构实现——不写默认值的会话级切换；默认只在设置页明确修改
- [ ] UI层：回执前不显示为已切换；退出计划不留下“已执行”暗示
- [ ] 测试：模式保存失败不伪报成功（有断言）

## 验收标准（须给真实证据，未跑就写“未运行”）

- 事项A切换模式不影响新事项默认（有断言）
- 切换回执三态可区分；未生效显示当前实际模式
- 计划模式方案进入 US-165 呈现，接受方案不等于执行

## 明确不做

不做模式级审批、不做模式的团队策略下发、不做计划模式下的自动执行
