# 035 · 会话锚点定位与短预览

**Blocked by**: 009, 015
**覆盖需求**: US-183, US-184
**接缝**: S1 / S8

## 目标

状态级补漏：点击会话锚点定位到该消息并显示短预览，不整段载入历史、不激活执行；目标不可读时如实缺失。

## 涉及层

- [ ] 数据层：锚点指向消息与其所属运行的引用
- [ ] 逻辑层：定位只走纯读取接点；短预览按所需最小正文读取
- [ ] UI层：目标缺失显示不可读原因，不显示空白成功
- [ ] 测试：定位不促发 Agent（有断言）

## 验收标准（须给真实证据，未跑就写“未运行”）

- 点击锚点只定位与预览，不产生 prompt/follow（有断言）
- 锚点所属运行不可读时显示缺失并保持现场，不回落为空白（有断言）

## 明确不做

不做锚点收藏/分享、不做跨事项锚点跳转、不做全文检索式定位
