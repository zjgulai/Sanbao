# 013 · 本地引用：候选、实时读取与版本重核

**Blocked by**: 010
**覆盖需求**: US-077, US-078, US-079, US-080, US-081, US-082, US-084
**接缝**: S1 / S5

## 目标

从已采纳工作区内选择文件形成候选引用，实际使用时经workspaceFiles实时读取并重核版本；源变更即阻断并提示失效。

## 涉及层

- [ ] 数据层：引用记录（来源+stat版本token）
- [ ] 逻辑层：内容读取端口S5；引用不触发读取或扫描
- [ ] UI层：候选→确认关联；失效提示且不换源；历史仍指当时来源版本
- [ ] 测试：改文件后重核失败并阻断；不因引用自动上传或发送内容

## 验收标准（须给真实证据，未跑就写“未运行”）

- 引用创建时不读取文件正文（有断言）
- 源变更后取用被阻断且提示具体失效原因
- 工作区外路径不出现在候选中

## 明确不做

不做D-093受控本地快照；不做工作区外路径引用；不宣称源文件已删除

**备注**：核验项：version为opaque token的失效判据与成本上限，须实测后定产品承诺
