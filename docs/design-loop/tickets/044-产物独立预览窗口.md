# 044 · 产物独立预览窗口

**Blocked by**: 015
**覆盖需求**: US-205
**接缝**: S1 / S5 / S7

## 目标

状态级补漏：独立窗口只在显式动作下打开，与侧面容器共用同一版本引用；迟到结果不覆盖、关闭不取消运行。

## 涉及层

- [ ] 数据层：窗口与产物版本引用一对一
- [ ] 逻辑层：打开请求绑定准确版本；迟到加载结果按选择丢弃
- [ ] UI层：关闭独立窗口回原工作面，不改产物记录
- [ ] 测试：同版本重开不重跑生成（有断言）

## 验收标准（须给真实证据，未跑就写“未运行”）

- 显式动作前不创建窗口（有断言）
- 窗口与侧面板同时存在时不出现两份权威版本值

## 明确不做

不做多窗口标签管理、不做窗口内编辑与回写、不做窗口级权限策略

**备注**：来源：P12（FW-037；US-205）
