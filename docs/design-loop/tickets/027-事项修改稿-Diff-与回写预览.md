# 027 · 事项修改稿、Diff 与回写预览

**Blocked by**: 013, 015
**覆盖需求**: US-140, US-141, US-142, US-143, US-144, US-145
**接缝**: S1 / S5 / S7

## 目标

MECE补漏：在已采纳工作区的文件上生成事项修改稿，直接查看它与所依据版本的Diff；回写作为独立具名动作出现，首版不自动回写，Git写操作无入口。

## 涉及层

- [ ] 数据层：修改稿记录绑定源文件与版本、生成来源与状态
- [ ] 逻辑层：Diff 由内容端口按版本比较得出，不依赖Git；回写动作需单独确认并预览影响
- [ ] UI层：修改稿不称“共享文件已更新”；下载/导出不产生回写；文件修改类工具活动只显示受控修改信息与目标版本
- [ ] 测试：版本比较可回溯到所依据版本；回写需显式确认；原始payload 不透传（有断言）

## 验收标准（须给真实证据，未跑就写“未运行”）

- 修改稿生成后源文件保持未变（有断言）
- 回写确认卡显示目标版本与影响，未确认不写入
- 界面无 Git 提交/推送/分支入口

## 明确不做

不做 Git 真实接线与 Worktree 写操作；不做自动回写；不做 Office 原格式预览
