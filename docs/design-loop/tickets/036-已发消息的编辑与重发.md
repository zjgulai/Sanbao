# 036 · 已发消息的编辑与重发

**Blocked by**: 005
**覆盖需求**: US-185, US-186, US-187
**接缝**: S1 / S2 / S8

## 目标

状态级补漏：编辑已发送消息产生新内容与版本并保留原版本；重发只针对编辑后内容，未知先核对。

## 涉及层

- [ ] 数据层：消息版本与提交关系记录，原版本不被覆盖
- [ ] 逻辑层：重发走同一命令入口与请求标识；已消费消息不重复派发
- [ ] UI层：编辑不显示为历史已改写；未知态只给核对同一操作
- [ ] 测试：重复点击不并行发起（有断言）

## 验收标准（须给真实证据，未跑就写“未运行”）

- 编辑后原版本与提交关系仍可回看（有断言）
- 重发不重复派发已消费内容（有断言）
- 结果未知不自动重试、不直接放回可重发队列

## 明确不做

不做历史消息删除、不做他人消息编辑、不做编辑后自动继续执行
