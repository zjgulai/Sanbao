# 014 · 附件上传链（候选→流式上传→receipt→随消息发送）

**Blocked by**: 005, 010
**覆盖需求**: US-071, US-072, US-073, US-074, US-075, US-076, US-083
**接缝**: S1 / S6

## 目标

选择文件只产生候选，确认后经main流式上传取得receipt，随消息发送并在历史消息内展示实际状态。

## 涉及层

- [ ] 数据层：附件记录与事项范围绑定；receipt
- [ ] 逻辑层：uploadStream有界分块与取消；部分失败续传同一封存版本
- [ ] UI层：传输中/完整性核验/关联生效分别显示；无事项附件列表面板
- [ ] 测试：源内容在选取与上传间变化需重选；重开不重跑上传；上传成功不等于模型已读取

## 验收标准（须给真实证据，未跑就写“未运行”）

- 上传成功回执不显示为已读取或已使用
- 部分失败可续传同一版本而不重新生成内容
- 机器路径不进入跨端数据（有断言）

## 明确不做

不做独立事项附件列表；不做跨消息复用；不做模型传输政策核验界面

**备注**：核验项：receipt的同一会话绑定与事项隔离方式
