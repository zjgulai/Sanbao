# 043 · 工作台集成终端只读呈现

**Blocked by**: 031
**覆盖需求**: US-203, US-204
**接缝**: S1 / S5 / S7 / S8

## 目标

状态级补漏：终端只在工作台侧面板内提供，输出作为运行观察只读呈现；无可用终端时显示未就绪。

## 涉及层

- [ ] 数据层：终端会话与所属运行的关联
- [ ] 逻辑层：打开/关闭不取消运行；输出不进对话历史、不作产物
- [ ] UI层：终端不接收权威动作输入；未就绪显示缺项
- [ ] 测试：关闭面板后运行状态不变（有断言）

## 验收标准（须给真实证据，未跑就写“未运行”）

- 无终端能力时显示 unavailable 与缺项，不显示空终端（有断言）
- 终端输出不出现在事项对话同步与产物列表（有断言）

## 明确不做

不做终端内命令执行授权扩面、不做终端会话持久化与导出、不做真实 shell 包装的产品承诺
