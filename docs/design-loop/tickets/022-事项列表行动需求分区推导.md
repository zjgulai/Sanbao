# 022 · 事项列表行动需求分区推导

**Blocked by**: 002, 006
**覆盖需求**: US-090, US-091, US-092, US-093, US-094, US-095, US-096
**接缝**: S1 / S8

## 目标

由Application Service从attempt、待验收artifact、就绪blocked/unknown与待继续输入推导“待我处理/进行中/待验收”分区，分区内按最近更新排序。

## 涉及层

- [ ] 数据层：无新状态存储（分区是呈现组织）
- [ ] 逻辑层：推导规则落地且可追溯；renderer不自判
- [ ] UI层：默认不展开归档/完成，可筛选
- [ ] 测试：事实变化后分区随投影更新；无authority时保持unavailable-first

## 验收标准（须给真实证据，未跑就写“未运行”）

- 每个“待我处理”项能指出触发事实（有断言）
- 待验收只显示计数，不定义整体完成语义
- 不用fixture冒充列表数据

## 明确不做

不定义分项验收与整体完成语义（D-015/016未收口）；不做持久自定义顺序
