# 034 · 澄清问答闭环：卡片、回答、自定义与停止

**Blocked by**: 005
**覆盖需求**: US-177, US-178, US-179, US-180, US-181, US-182
**接缝**: S1 / S2 / S4 / S8

## 目标

状态级补漏：Agent 提出的澄清问题在工作面内成卡、回答后按回执推进，等待期间停止即转待继续，重开只读历史。

## 涉及层

- [ ] 数据层：澄清问题/答案与所属运行绑定，答案进入历史后只读
- [ ] 逻辑层：答案经命令管线提交所属会话；回答前不派发依赖该答案的步骤；模式切换的确认按当前有效模式生效
- [ ] UI层：候选项与自定义答案同权；未确认前不显示“已回答”；AI 整理不自动写成交付或责任字段
- [ ] 测试：停止时卡片转待继续且不自动续跑；重开不重复提交（有断言）

## 验收标准（须给真实证据，未跑就写“未运行”）

- 澄清等待中点击停止：卡片进入待继续，不出现自动继续（有断言）
- 回答回执三态可区分；结果未知只给核对入口，不给重试
- 同一答案重复点击/刷新不重复派发（有断言）
- 重开事项沿历史回看澄清，不调用促发路径（沿用 US-024 判据）

## 明确不做

不做澄清答案晋级为事项事实、不做多轮澄清的审批化流程、不做跨事项复用澄清模板
