# 015 · 产物卡与侧面预览（首批常见格式）

**Blocked by**: 005
**覆盖需求**: US-031, US-032, US-033, US-034, US-035, US-036, US-037, US-038, US-040, US-042
**接缝**: S1 / S5 / S7

## 目标

产物版本就绪后仅更新卡片；点击才由内容端口取得该版本并由main加载侧面预览；HTML走离线交互容器与帧禁用不变量。

## 涉及层

- [ ] 数据层：产物记录与版本就绪事件
- [ ] 逻辑层：内容端口按版本取内容；同版本重试不重跑生成
- [ ] UI层：不自动展开、不抢焦点；迟到结果不覆盖当前选择、不重开已关闭预览；Office格式仍是文件卡+导出
- [ ] 测试：连续点击不同产物的时序用例；内容失效显示失败而非切最新版

## 验收标准（须给真实证据，未跑就写“未运行”）

- 卡片出现时未创建预览容器（有断言）
- 关闭预览后对话与输入保留、执行未受影响
- 不把可下载说成可预览

## 明确不做

不做DOCX/XLSX/PPTX内置预览；不做自动转换与Office编辑
