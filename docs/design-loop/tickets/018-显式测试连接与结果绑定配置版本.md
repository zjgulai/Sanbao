# 018 · 显式测试连接与结果绑定配置版本

**Blocked by**: 017
**覆盖需求**: US-045, US-046, US-048, US-049, US-050
**接缝**: S1 / S2

## 目标

只有明确点击才发起测试，结果单列并绑定当次配置+凭据版本；改配置后旧成功只留历史。

## 涉及层

- [ ] 数据层：测试记录含配置/凭据版本、目标模型与范围
- [ ] 逻辑层：真实测试端口核定后接入；测试用最小非业务样本
- [ ] UI层：测试中/成功/失败/待核对；不并行重复测试；超时不伪报
- [ ] 测试：修改配置后旧结果不套用；迟到结果不覆盖当前状态

## 验收标准（须给真实证据，未跑就写“未运行”）

- 测试不携带事项对话或附件（有断言）
- 测试失败保留配置
- 成功文案只说明本次所测能力

## 明确不做

不做“测试通过才能添加”的门槛；不用业务内容做隐藏试调用

**备注**：**核验项**：真实测试端口存在性未证明，未证明前本票不得开工
