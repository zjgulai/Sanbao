# 033 · 成果与工具结果呈现补全（图表/链接/图片/typed 结果）

**Blocked by**: 015
**覆盖需求**: US-172, US-173, US-174, US-175, US-176
**接缝**: S5 / S7

## 目标

MECE补漏：图表全屏与链接预览走离线资源与受控外链；图片缩放平移；网页成果目录只读；typed 工具结果由Sage组件呈现且不支持类型明确拒绝。

## 涉及层

- [ ] 数据层：成果条目与同源版本、访问限制
- [ ] 逻辑层：链接不自动联网；结果内不执行脚本、不接受权威动作输入
- [ ] UI层：全屏退出恢复焦点；详情脱敏、结果图片按权限加载；不支持类型明确拒绝
- [ ] 测试：raw payload 不透传（有断言）；上线状态与托管交付不混同

## 验收标准（须给真实证据，未跑就写“未运行”）

- 外链仅在显式动作下打开
- 网页成果目录不把已托管说成已上线
- 批注入口缺位

## 明确不做

不做图片批注、不做真实发布与站点上线、不做完整图表编辑
