# 009 · 冷历史与运行历史（读取不激活执行）

**Blocked by**: 005
**覆盖需求**: US-024, US-097, US-098, US-099, US-100, US-101
**接缝**: S1 / S4 / S8

## 目标

重开事项时以纯历史接点倒序列出全部运行、分页读取，默认只展开最新；点开旧运行才读详情，旧运行不可读保持缺失。

## 涉及层

- [ ] 数据层：运行记录与实际模型/版本快照
- [ ] 逻辑层：page类读取接点与follow冷激活路径严格分开
- [ ] UI层：倒序列表+默认展开最新；历史实际模型与当前选择分开显示
- [ ] 测试：断言打开历史不促发Agent；旧运行不可读不显示空白成功

## 验收标准（须给真实证据，未跑就写“未运行”）

- 打开历史事项后无Agent被激活（有断言）
- 历史运行显示当时实际模型，不被当前默认改写
- 重开不重复发送、不重跑上传

## 明确不做

不做两运行/产物版本对照（依赖D-015/016收口）
