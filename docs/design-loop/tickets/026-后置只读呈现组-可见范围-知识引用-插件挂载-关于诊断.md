# 026 · 后置只读呈现组：可见范围/知识引用/插件挂载/关于诊断

**Blocked by**: 001, 010
**覆盖需求**: US-129, US-130, US-131, US-132, US-133, US-134, US-135, US-136, US-137, US-138, US-139
**接缝**: S1 / S5 / S8

## 目标

把四个后置页面族限定为只读呈现：当前可见范围事实、知识/引用条目与来源版本、插件与扩展的实际挂载状态、可信版本与结构化诊断信息。

## 涉及层

- [ ] 数据层：无写入
- [ ] 逻辑层：只读取既有投影；自报与局部观察不合成权威结论
- [ ] UI层：无邀请/启用/安装/发布/更新入口；未挂载不说成已停用；知识只读且点开才按需读取重核
- [ ] 测试：断言写操作入口不存在；版本标识取自可核验来源

## 验收标准（须给真实证据，未跑就写“未运行”）

- 界面不出现“检查更新/立即更新”
- 插件页不显示由工具数量或连接成功推导的可用结论
- 知识条目无创建/编辑/发布/退役入口

## 明确不做

不做协作成员管理、知识发布与退役、Registry启用授权、Sage发布链与自动更新

**备注**：各子项依赖真实provider或治理裁决，接入后需另开票
