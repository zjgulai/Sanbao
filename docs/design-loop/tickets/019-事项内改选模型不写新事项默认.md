# 019 · 事项内改选模型不写新事项默认

**Blocked by**: 005, 017
**覆盖需求**: US-051, US-052, US-053, US-054, US-055, US-056
**接缝**: S1 / S4

## 目标

事项选择与默认值分开写入：事项内改选只影响当前事项；默认值只在设置页明确修改。

## 涉及层

- [ ] 数据层：事项选择记录 / 默认值记录 / 运行实际模型快照分开
- [ ] 逻辑层：会话级不写默认值的受支持接点（须核定）；禁止先改默认再还原
- [ ] UI层：保存/待后续运行应用/实际使用三态分别显示
- [ ] 测试：事项A改选→默认不变→新建事项仍用原默认；默认保存失败不伪报成功

## 验收标准（须给真实证据，未跑就写“未运行”）

- 改选后默认值未变（有断言）
- 运行中改选遵守D-017收口，不覆盖旧运行快照
- 新模型不可用时提示替代，不静默换回默认

## 明确不做

不做供应商级模型目录改造；不做跨事项批量改选

**备注**：**核验项**：公开请求无saveDefault开关；未证明受支持接点前不能以包装原接口充数
