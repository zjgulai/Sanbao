# 041 · 权限申请与外部授权等待

**Blocked by**: 025
**覆盖需求**: US-197, US-198, US-199
**接缝**: S1 / S2 / S8

## 目标

状态级补漏：外部授权以待确认态显示范围与来源，未获授权不派发依赖动作；设备离线或过期使等待失效。

## 涉及层

- [ ] 数据层：授权请求、请求范围、来源与当前等待状态
- [ ] 逻辑层：依赖未兑现授权的动作保持阻断；旧等待不自动兑现
- [ ] UI层：显示等待原因与撤回入口，不显示为失败或已批准
- [ ] 测试：离线不伪造已批准（有断言）

## 验收标准（须给真实证据，未跑就写“未运行”）

- 未获授权时依赖动作不派发且界面为阻断态（有断言）
- 授权过期/设备离线后旧等待失效并需重新申请
- 撤回是具名动作且有回执

## 明确不做

不做多级审批与授权策略下发（§7.1/§7.3）；不做凭据读取

**备注**：来源：S03（FW-037；US-197~199）
