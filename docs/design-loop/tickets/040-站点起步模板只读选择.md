# 040 · 站点起步模板只读选择

**Blocked by**: 005
**覆盖需求**: US-195, US-196
**接缝**: S1 / S8

## 目标

状态级补漏：起步模板只读列出名称与来源，选择只产生本次草案输入，不建站点、不写配置。

## 涉及层

- [ ] 数据层：模板条目与来源、版本
- [ ] 逻辑层：选择只写入草案；不触发远端创建
- [ ] UI层：不把“选了模板”显示为“已建站/已发布”
- [ ] 测试：无任何远端副作用（有断言）

## 验收标准（须给真实证据，未跑就写“未运行”）

- 选择模板后无站点创建请求发出（有断言）
- 模板不可用时显示不可用原因，不静默替换

## 明确不做

不做站点创建、发布、域名与上线核验（§7.8）；不做模板的市场写操作

**备注**：来源：O02.sites.templates.open（FW-036；US-195~196）
