# 047 · 外观项持久化清单扩围

**Blocked by**: 020
**覆盖需求**: US-220, US-221, US-222
**接缝**: S1 / S8 / S9

## 目标

在 FW-016 的三项之上把可持久化外观项扩为八项（主题/语言/密度缩放/字体风格/内容宽度/终端主题/文件图标/图标外观），仍由同一偏好端口持有。

## 涉及层

- [ ] 数据层：S9 偏好端口承载八项，单一权威值
- [ ] 逻辑层：设置页与快捷菜单读写同值并订阅变更
- [ ] UI层：清单外项（快捷键/语音/监控布局）显式标注不可配置
- [ ] 测试：任一处保存失败不显示已生效（有断言）

## 验收标准（须给真实证据，未跑就写“未运行”）

- 八项在两入口读写同值（逐项断言）
- 重启后实际生效值与投影一致（有断言）
- 清单外项不出现可交互控件或出现即标注不可用

## 明确不做

不做主题 token 全量审计与无障碍对比度验收（§7.10）；不做快捷键/语音/监控布局偏好

**备注**：来源：P06 外观六个下拉 + OBS04 快捷外观（FW-039；US-220~222）
