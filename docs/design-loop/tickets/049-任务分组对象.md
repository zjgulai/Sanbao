# 049 · 任务分组对象

**Blocked by**: 029
**覆盖需求**: US-225, US-226
**接缝**: S1 / S2 / S8

## 目标

状态级补漏：分组是 Sage 自有组织对象，建立/改名/移除为具名命令并逐项回执，只改变列表组织。

## 涉及层

- [ ] 数据层：分组对象与事项归属记录
- [ ] 逻辑层：分组不改变事实、可见范围、责任或权限
- [ ] UI层：批量操作逐项结果，不显示整体成功
- [ ] 测试：分组变化不触发权限推断（有断言）

## 验收标准（须给真实证据，未跑就写“未运行”）

- 分组建立/改名/移除各有回执与回读（有断言）
- 分组不改变可见范围与责任（有断言）

## 明确不做

不做分组的共享与协作语义、不做按分组批量授权、不做跨设备分组同步
