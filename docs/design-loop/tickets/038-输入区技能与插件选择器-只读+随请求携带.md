# 038 · 输入区技能与插件选择器（只读+随请求携带）

**Blocked by**: 005, 030
**覆盖需求**: US-189, US-190, US-191
**接缝**: S1 / S3 / S4 / S8

## 目标

状态级补漏：技能与插件列表只读来自挂载观察，选择只对本次请求携带引用，不改变启用状态。

## 涉及层

- [ ] 数据层：可选技能/插件条目与来源、可用性来自同一投影
- [ ] 逻辑层：选择只写入本次请求上下文；未挂载显示不可用与缺项
- [ ] UI层：选择插件不显示为“已启用”；自报不作权威
- [ ] 测试：无 authority 时 unavailable-first（有断言）

## 验收标准（须给真实证据，未跑就写“未运行”）

- 列表来源为挂载观察，未挂载不说成已停用（有断言）
- 选择结果只影响本次请求，不影响其他事项（有断言）

## 明确不做

不做技能/插件的启用、安装、授权与配置写操作（§7.5）；不做技能市场跳转
