# 025 · 动作级执行前确认单卡

**Blocked by**: 005
**覆盖需求**: US-124, US-125, US-126, US-127, US-128
**接缝**: S1 / S2

## 目标

对会产生外部效果的动作给出单张确认卡（对象/动作/资源/范围/时间/前提+可得的费用影响预估），确认兑现该次派发必要条件，派发前逐次重验。

## 涉及层

- [ ] 数据层：确认记录与所依据的意图版本
- [ ] 逻辑层：前提/版本变化使旧确认失效；确认≠效果已发生
- [ ] UI层：确认卡与结果三态衔接（复用001）
- [ ] 测试：变化后旧确认被拒并需重新确认；重复点击不派发两次

## 验收标准（须给真实证据，未跑就写“未运行”）

- 范围外动作无法用旧确认放行（有断言）
- 确认卡不伪装成审批流程，也不产生多级路由

## 明确不做

不做多级审批、代理审批与审批队列
