# 006 · 停止与待继续保留

**Blocked by**: 005
**覆盖需求**: US-014, US-015, US-016, US-017, US-018, US-019, US-022, US-023
**接缝**: S1 / S2 / S4

## 目标

点停止后取消可取消工作、阻止后续输入自动进入执行，未执行输入成为可查看/编辑/移除的待继续项；明确继续才恢复派发。

## 涉及层

- [ ] 数据层：待处理输入持久记录 + 暂停状态（尚未派发/已提交/已消费/结果待核对）
- [ ] 逻辑层：Sage执行协调层不得先把输入送入会自动唤醒的inbox；继续请求与恢复执行分离
- [ ] UI层：待继续清单与继续入口；已有回复与产物保留展示
- [ ] 测试：竞态用例（停止与已提交输入消费）断言无法确认的输入不回到可重发队列；重复点击不重复派发

## 验收标准（须给真实证据，未跑就写“未运行”）

- 停止后无后续输入被自动执行（有测试证据）
- 切页/重连/重开应用不自动续跑
- 编辑待继续项不改写已消费输入

## 明确不做

不做跨事项联动；不做定时自动化

**备注**：本票含矩阵登记的“cancel keepInbox与kick续跑竞态”核验项，须给实测证据
