# ADR-0001 · HTML产物允许离线交互，不开放网络或宿主能力

- 日期：2026-10-01
- 状态：accepted-design-only（用户已确认产品方向；未实施，未验收）
- 决策归属：本轮仓外接线设计，编号不属于Sage仓ADR序列。
- 讨论入口：[D-034](../discussion.md#d-034--html产物允许离线交互禁止联网)
- 现行容器依据：[Sage ADR-0178](../../adr/ADR-0178.md)

## Problem

HTML图表、报告和原型需要筛选、折叠等交互，但生成内容不是可信的产品代码。静态预览会损失交互；把产物放进特权主界面或默认开放联网，则会扩大内容访问、外传和调用宿主能力的风险。

## Decision

首版允许HTML产物在隔离容器中执行离线交互，只访问该产物明确包含且经受控加载的资源；不开放网络、任意本机文件、Sage工具或登录凭据。

容器沿用Sage ADR-0178：独立非特权WebContentsView、独立session、无preload、无特权IPC；不在privileged renderer内嵌iframe。容器归属已由现行ADR决定，本记录不重新批准或改变该合同。

预览失败或所需资源不受支持时明确提示，不通过放开网络、宿主文件或工具权限来恢复。产物预览本身不构成业务动作授权、成果接受或发布。

## Alternatives considered

- 仅静态预览：安全与验证范围更集中，但交互图表、动态报告与应用原型无法完整呈现。用户选择保留离线交互。
- 默认联网或给予宿主能力：不在本次批准范围；离线预览不能因页面内按钮、脚本或链接请求而自行升级权限。

## Consequences

需要独立的产物资源范围、受控加载、导航/弹窗/下载限制、预览进程失效处理和关闭回收合同。实施验证还须覆盖网络尝试、跨产物访问、路径越界、宿主桥访问、卡死与撤销后访问；不能以“没有Node权限”或单条CSP作为全部安全证据。

本决定不确定资源URL方案、脚本引擎配置、容量预算或所有文件格式支持，也不授权联网抓取依赖。源码、配置、真实产物、GUI及负向验证均未运行；源仓保持不变，正式归档与实施另行确认。
