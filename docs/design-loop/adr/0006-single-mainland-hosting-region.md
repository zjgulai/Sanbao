# ADR-0006 · 首版在中国内地单一托管数据区起步

- 日期：2026-10-01
- 状态：accepted-design-only；未选云厂商/城市，未部署、迁移或处理真实数据。
- 编号范围：本轮仓外设计，不占Sage正式ADR编号。
- 用户决定：[讨论工作稿](../discussion.md) D-074、D-075。
- 前序：[ADR-0005](0005-all-formal-matters-hosted.md)。
- 后续细化：讨论工作稿D-076已选择首版云端模型仅支持经核验的中国内地处理/留存服务；下文“境外模型未决定”保留为本ADR形成时的历史状态，具体供应商、语音/附件处理方式及保留规则仍未定。

## Problem

正式事项统一托管和跨设备协作已确定，但未明确首版地域产品要求。若首版同时提供多个组织可选数据区，需要分别处理服务发现、租户路由、隔离、升级、备份恢复和将来的迁移；仅选择服务器位置又不足以说明资料实际流向。

## Decision

首版在中国内地的一个明确托管数据区起步，不同时提供组织选区。组织开通前告知数据区及适用边界，不能满足该地域要求的组织暂不接入。具体云厂商、城市、可用区和数据库后续核定；单一区域不等于单机或单可用区，不豁免备份及故障恢复责任。

该选择限定正式记录与托管内容的存储设计方向，不自动证明模型、解析、转写、日志、备份及运维访问全部留在境内。各数据流、来源/组织政策、处理目的、服务条款及地域仍须分别核验；境外模型服务是否进入首版候选尚未决定，D-073的范围授权和逐次核验继续有效。

## Alternatives considered

- 首版按组织选择多个数据区：适配更多客户地域要求，但多区隔离、路由与运维复杂度更高；首版不采用。
- 以中国香港或新加坡作为首个数据区：用户在明确地区边界后选择中国内地，不将其他地区视作同一区域或默认备份位置。

## Consequences

登录/组织开通、隐私及模型设置、附件/成果同步和服务运维合同都须明确数据区及各自的数据流。增加新区域或迁移既有组织时另立合同，不能静默搬移资料或让两区同时成为同一事项的正式裁决点。

这是产品部署目标，不是已经通过的合规结论或“数据绝不出境”承诺。保留、删除、legal hold、备份与运维访问仍需确认，真实数据生产门未解除。本决定不授权开通云资源、配置网络/凭据、部署、迁移或改写当前Sage源码及正式ADR。
