**Goal:** 把 Sage 薄壳的内核（seed 41 依赖 = 38 个 `@deepseek-ai/dsh-*` + cordis 族 3 个 + 壳 devDeps 的 `@deepseek-ai/*`）从 0.1.5-rc.2 一次性换装到 0.2.0-rc.2，完成协议自有权收口、fixtures/goldens 重锚、隔离端到端验收与隐私默认审计，全程不改变 Sage 骨架形态。

**Spec:** [docs/superpowers/specs/2026-10-02-harness-0.2.0-upgrade-design.md](../specs/2026-10-02-harness-0.2.0-upgrade-design.md)（executor 必须同时读 spec 与 [research/20 差异总账](../../research/20-harness-0.2.0-rc.2-delta.md)）。
**Tech Stack:** pnpm 11.7.0 / Node `^22.19.0 || >=24.0.0` / TypeScript strict / node:test via `node scripts/test.mjs run` / Sage gate（`pnpm run gate`）。
