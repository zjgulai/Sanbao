# ADR-0294 · Host 生命周期失效接线：启动观测只服务于同一活跃 epoch

- 状态：accepted（2026-10-11）
- 日期：2026-10-11
- 决策者：用户（lute：继续执行）＋ agent（取证与实施）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-11-host-epoch-currency.md)
- 相关：[ADR-0284](ADR-0284.md)、[ADR-0286](ADR-0286.md)、[ADR-0289](ADR-0289.md)（三处登记的 host-lifecycle 后续票）、[ADR-0168](ADR-0168.md)（Host live projection 一次 boot 观测）

## 背景

runtime inventory 观测在启动时组合一次（`runtimeInventoryResult`），此后持续喂给准入链（compatibility 及其上游 target 的 provenance）。`runtime-invalidated` 时宿主把快照转为 `unavailable` 并把 `runtimeGeneration` 自增、清空 `runtimeEffective`——但主进程的观测闭包此前只检查 `kind === 'available'`，宿主 epoch 死亡或移动后仍会把旧 epoch 的事实继续喂链。三张 ADR（0284/0286/0289）均登记该失效接线为后续票。

## 决策

1. **货币性检查单一纯函数**：`isInventoryObservationCurrent(evidence, snapshot)` = 快照 `kind === 'active'` 且 `bootId` 与 `runtimeGeneration` 与观测证据逐字段相等。
2. **接线在观测闭包**：`runtimeInventoryObservation` 在返回证据前调用该检查（读活快照 `host.readSnapshot()`）；不匹配即 `undefined`——链步骤按自身语义 fail closed，绝不评估死 epoch 的事实。
3. **机制理由**：检查按请求求值而非事件订阅——不做事件竞态补救，`invalidateSnapshot` 已经自增 generation，纯比较即完整判据。
4. **范围**：本刀覆盖审计准链面（观测闭包）。插件分类等 UI 投影面仍直接消费启动结果（陈旧行属 UI 面，登记后续）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 事件订阅失效（invalidation event → 清空结果） | 否决：事件与请求竞态；按请求比较已是完备判据（generation 自增是官方失效信号）。 |
| 宿主重连时自动重组合观测 | 登记（重组合成本 50–200s，属重观测票）；本刀先保证诚实 fail closed。 |
| 把检查放进各链步骤端口 | 否决：单一闭包是唯一出口，收入口最窄。 |

## 后果

- 宿主 epoch 死亡/移动后，准入链的观测立即失效；配合活的 `runtimeEffective` 检查，整条链要么用同一 epoch 的完整事实，要么诚实不可用。
- UI 插件投影的陈旧行为登记未闭。
