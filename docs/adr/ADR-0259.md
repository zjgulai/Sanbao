# ADR-0259 · UI-01A：工作台外壳视觉收口（dense + calm 首切片）

- 状态：accepted（2026-10-04）
- 日期：2026-10-04
- 决策者：用户（lute，指示视觉／CSS 层优先推进，并委派本票由 Qoder 会话执行）
- 决策记录：[Note](../notes/implemented/surface/2026-10-04-workbench-visual-tone-batch-12.md)
- 相关：[ADR-0254](ADR-0254.md)、[ADR-0257](ADR-0257.md)、[ADR-0258](ADR-0258.md)、[UI 一致性合同](../specs/2026-09-27-sanbao-to-sage-ui-consistency-contract.md)

## 背景

一致性合同冻结的产品语气是 `dense + calm + evidence-first + operational`：不使用大面积 hero、装饰性渐变，或把功能说明写进页面代替清晰控件。UI-01 最小切片（三栏工作台、六态 fixture、token owner、零业务写入）已由批次 7–11 交付，但首屏仍保留展示级排版：matter 面板标题真实窗口 computed 为 53.6px、事项目标 41.6px，Overview 面板仍带 hero 文案区与旋转式"经营网络"装饰卡，工作台主卡还留有一条实现说明句。这些正是被点名的"hero、大标题、装饰性宣传卡"，会削弱密集、安静的操作型工具感。

## 决策

1. Overview 面板退役 hero 文案区与 `sage-network-card` 装饰卡（含 orbit 结构与相关 CSS）；保留 RUNTIME 状态卡、当前事项卡与 MATTER TRACE 说明条，`data-view-target="matter"` 入口由事项卡链接保留。
2. 六个面板标题（matter/capability/governance/profile/readout/settings）与事项目标改用运营级标度（1.35rem / 1.3rem，weight 620，letter-spacing -.01em）；删除全部展示级 `clamp()`（4.2rem / 3.35rem / 2.6rem / 2.2rem）。层级改由字重、色阶与结构表达。
3. 工作台主卡移除解释性整句（"当前事项是工作台的主对象…"）；fail-closed 诚实标记全部保留（fixture 徽标、阶段轨道说明、只读 composer 说明、总览不合成进度说明）。
4. 清理死 CSS：`.sage-hero*`、`.sage-network*`（含 orbit）、`.sage-trace-list`、`.sage-matter-layout`、`.sage-matter-main`；面板 padding 与 section 间距小幅收紧。不改任何行为、路由、provider、token 语义或业务断言。
5. 完成证据分三层：源合同 spec（`test/ui-shell-visual.spec.ts`）、真实 Electron computed 标度与节点缺席断言（窗口探针新增），以及 1440 双视图人工回看截图；对旧构建先取得具名红再实施。
6. 本批不引入 React/dependency/package/lockfile，不改左侧 nav 六项目标、支持卡长文案与 UI-DECISION-01 技术栈决策；完整 Qoder UI/UX 复刻仍未完成。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 直接复制 Qoder / Sanbao CSS 或资产 | 否决：合同只允许语义迁移，外部 CSS 不进 Sage。 |
| 保留 hero 仅缩小字号 | 否决：合同点名去掉 hero 与装饰卡；保留只会延续宣传型首屏。 |
| 以 viewport 或媒体查询条件性保留展示标题 | 否决：同一页面两套语气，不构成单一产品事实。 |
| 顺带调整左侧导航集或支持卡长文案 | 后置：属 UI-01B 与 UI-DECISION-01 范围。 |
| 只用 Fake DOM / 字符串断言验收 | 否决：标度与节点缺席必须在真实窗口 computed 路径验证。 |

## 后果

- Sage 六个面板标题与事项目标统一到运营级标度；Overview 成为密集状态视图；工作台首屏信息密度提升。
- 新增回归守护：源合同 spec 的负空间扫描（hero/network/clamp/死 CSS/解释句）+ 真实 Electron 探针（computed ≤24px、display chrome 节点数 0、overview 无 h1）。
- 未决：左侧 nav 六项目标、支持卡文案收敛、UI-DECISION-01、完整 Qoder UI/UX 复刻、真实业务 mutation/provider。
- 改动写入 `main` 工作区，未 stage、未 commit、未 push（等待用户处置）。
