# ADR-0193 · Sage 组合隐私默认：上游会话日志贡献的显式关断与遥测面登记

- 状态：accepted（2026-10-02）
- 日期：2026-10-02
- 决策者：用户（lute）+ agent（K7 执行与实测）
- 决策记录：[Sage 组合隐私默认](../notes/implemented/security/2026-10-02-sage-privacy-defaults.md)
- 相关：[ADR-0192](ADR-0192.md)（0.2.0-rc.2 内核换装）、[ADR-0159](ADR-0159.md)（产品边界与数据隔离）、[research/20 §5](../research/20-harness-0.2.0-rc.2-delta.md)

## 背景

0.2.0-rc.2 把 `dsh-session-log-deepseek` 的上传贡献改为**默认开启**（实测 `lib/index.js:18`：`enabled: z.boolean().default(true).volatile()`）——符合条件的官方 DeepSeek API 请求会携带 canonical 会话日志后缀（含 message 文本、工具参数与结果、workspace 路径）。同批还新增 OTel 与产品分析面：`desktop-product-telemetry`（`dsh-host-product-telemetry-otel`）与 `product-analytics`（`dsh-client-product-analytics`）由 web-app 以 `disabled: !!js "ctx.get('profileContext')?.name !== 'desktop'"` 门控；`session-telemetry-otel` 以 `mode: FEEDBACK_ONLY` 运行（仅在显式用户反馈后释放会话日志前缀）。Sage 的凭据/隐私纪律要求「默认不出网、需要时显式开启」。

## 决策

1. **D1 session-log 贡献显式关断**：Sage overlay（`config/shell.cordis.patch.yml`）新增 `- id: session-log-deepseek` 行、`config.enabled: false`——组合层单一动作，不改上游包本身；需要该贡献的实例在本地 patch 层（ADR-0162）按用途重新开启，且这属于显式变更。
2. **D2 产品遥测/分析维持零动作 + 登记门控条件**：两条行依赖 `profileContext.name === 'desktop'`，Sage 自组 launcher 不提供 `profileContext`（证据：组合探针下两行自动关闭；同时端点还要求 `DSH_PRODUCT_ANALYTICS_OTLP_URL`）——**`profileContext.name === 'desktop'` 不得在 Sage 启动器出现**；若未来引入该值，必须重审本 ADR。
3. **D3 session-telemetry-otel 维持 FEEDBACK_ONLY**：无反馈入口时不可被普通活动触发；不额外 disable（避免无行为差异的上游偏离）。**未来若 Sage 引入任何消息反馈面，必须重审本 ADR**（届时 FEEDBACK_ONLY 将被真实触发）。
4. **D4 证据方法**：组合探针（临时脚本，跑完即弃）对已物化 profile 的 composed entries 断言 `session-log-deepseek` 的 config；smoke 全链以零告警为旁证；本 ADR 与 Note 记录探针读数。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 修改上游包默认值 | 否决；改基座（ADR-0008 精神），且升级即丢。 |
| 依赖「不配置 DeepSeek API 就不会触发」 | 否决；默认值是上游合同的一部分，P-02 类「靠现状不触发」的守卫会静默腐烂。 |
| 连 session-telemetry-otel 一并 disable | 否决；FEEDBACK_ONLY + 无反馈入口已等价关闭，disable 只增偏离面；改由「引入反馈面须重审」登记守。 |
| 把探针脚本落仓 | 否决；一次性组合检查，读数进 Note；系统性断言留给后续需要时独立立项。 |

## 后果

- **读数（2026-10-02，隔离根 `tmp.fEaCVwelL9`）**：overlay 变更后同根第二代重物化（generation `7592e8d0`）：smoke **16/16 PASS**、零告警；composed-entries 探针 **11/11 OK**——含 `session-log-deepseek config.enabled=false {"enabled":false}`，其余 10 项（7 disable 行、2 insert、connection inject）保持。提交 `babcbc9`。
- **行为面**：Sage 组合对官方 DeepSeek API 的请求不再携带会话日志后缀；需要时实例可显式重新开启（默认关是产品姿态，不是能力删除）。
- **边界**：不改上游包、不新增机制；`DSH_TELEMETRY_OTLP_URL`/`DSH_PRODUCT_ANALYTICS_OTLP_URL` 等 env 覆盖面登记（未设置时相关 exporter 不动作）。
- **遗留**：反馈面/新出网默认的任何引入须重审本 ADR；设置面（0.2.0 起 profile 级配置）未来若承载用户可见的隐私开关，其与 overlay 默认的优先级关系届时单独决定。
