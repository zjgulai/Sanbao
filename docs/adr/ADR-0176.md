# ADR-0176 · Electron 43.3 IPC/preload caller-binding 预检与 WT-02D.0.1 阻断

- 状态：accepted（2026-09-30）
- 日期：2026-09-30
- 决策者：用户（lute）
- 决策记录：[Note](../notes/proposed/architecture/2026-09-30-electron-ipc-caller-binding.md)
- 相关：[ADR-0174](ADR-0174.md)、[ADR-0175](ADR-0175.md)

## 背景

[ADR-0174](ADR-0174.md) 要求未来 Electron-main Application Service 只接受由 renderer 不能自报的 transport / sender 事实建立的 caller binding，并在 privileged boundary 前重新核验 caller 生命周期。[ADR-0175](ADR-0175.md) 已证明当前 browser-fetch / custom protocol 候选不能满足这一合同，WT-02D.0.1 因而保持 blocked。

WT-02D.0.1-IPC-PREFLIGHT revision 39 独立验证固定 Electron 43.3.0 下的窄 IPC/preload 候选：sandboxed preload 只公开具名 read / action / cancel 方法；main 以 `IpcMainInvokeEvent.sender`、`senderFrame`、expected WebContents / Session、current main frame、exact origin 与 main-owned navigation generation 建立 binding，并在模拟 durable dispatch 前重新核验。本 ADR 只决定预检结果与后续分支，不实现 production preload、route、Application Service 或业务动作。

## 决策

1. **revision 39 的结论为 NO-GO。** 真实 Electron browser-process probe 以 `outcome=no-go`、`passed=false`、exit 2 结束。具名 read / action / cancel、direct child-frame IPC、其他 WebContents、different partition、other / opaque origin、forged payload、cross-document / same-document navigation、WebContents destruction、renderer-process-gone、sender-scoped explicit cancel 与 post-dispatch `outcome-unknown` 均取得预期读数，但这些局部通过不构成完整 caller binding。
2. **同源 child 可以借用 top-frame bridge。** 在普通 `nodeIntegrationInSubFrames=false` 页面中，same-origin child 能调用 `top.sageIpcProbe.beginOperation()`；Electron main 收到的事件通过 expected WebContents / Session、current main frame、exact origin、process ID / frame ID 与 liveness 全部校验，并创建 pending operation。换言之，`event.senderFrame` 能证明实际发送 IPC 的 top preload frame，却不能证明触发该公开方法的 JavaScript 来自 top document 而非可访问它的同源 descendant。
3. **preload 的 `process.isMainFrame` guard 与 main 的 direct sender-frame guard 不足以关闭该缺口。** 它们能让 child 自身没有公开 bridge，并拒绝 probe-only child raw IPC；但无法阻止 same-origin child 调用 top main world 已公开的函数。不得把 direct child rejection 写成 main-frame-only authority 已成立。
4. **WT-02D.0.1、`.1` 与 `.2` 继续 blocked。** 当前 Host-owned `GET /.sage/state` / `POST /.sage/actions` 保持不变；不得迁移 production route、增加 production preload / IPC handler、连接 Host narrow port、Application Service、provider、store、Adapter、UI action 或真实副作用。
5. **绿色测试只表示 NO-GO 证据可重复。** 外层 test 独立断言 raw child exit 2、三条 exact failure、完整正负事件矩阵、pre-dispatch effect count、post-dispatch state 与 cleanup；`harness-fatal` 仍独立编码为 exit 1。测试通过不表示 IPC/preload candidate 通过或 production guard 已上线。
6. **下一种候选必须另票决定。** 将 same-origin descendant 明确认作与 top 相同 caller principal、禁止 production 同源 frame、改变 renderer embedding / bridge contract、采用其他 main-owned transport或升级 Electron pin，都会改变架构、安全或 UX 边界，必须另建 Birdview 计划、决策与用户确认，revision 39 不自动选择。
7. **本批只保留预检证据与治理记录。** 射程严格为三份 test-only IPC/preload 文件、本 ADR、对应 Note、ADR 索引、派生 ledger 与执行计划；production `src/**`、package / lockfile、Electron pin、vendor、legacy 与 release 均不修改，也不暂存、不提交、不推送。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 只验证 child 自己没有 bridge，并忽略 `top` 借用 | 否决；同源 child 已真实调用 top bridge，并被 main 误判为合格 main-frame caller。 |
| 将 same-origin child 与 top 视为同一个 caller principal | 本票不采纳；这会改变 ADR-0174 的 main-frame-only caller 合同与未来 embedding 安全边界，必须另票决定。 |
| 假设 production 永不出现同源 frame | 本票不采纳；需要由 production CSP、导航图、frame policy 与回归门共同保证，不能从当前 test-only probe 推断。 |
| preload 暴露 raw `ipcRenderer` 或通用 `send` / `invoke` | 否决；扩大 renderer 权限面，也不能解决同源 descendant 借用 top API。 |
| 只在 IPC 入口验证 sender，不在 durable boundary 前重验 | 否决；navigation、destroy、crash 与 cancel 仍要求 main-owned lifecycle recheck。 |
| 回到 browser-fetch / `protocol.handle()` | 否决；ADR-0175 已记录 caller lifecycle NO-GO，不重开同一机制。 |
| 本批升级 Electron pin或直接实现 production route | 不执行；dependency 与 production ownership 变更必须独立决策、验证与回滚。 |

## 后果

- revision 39 证明 Electron IPC event 可以为 direct sender 提供比 browser-fetch 更强的平台事实，也证明 main-owned lifecycle / cancellation state machine 在已测场景可行；这些均是局部证据。
- 同源 child 借 top bridge 的反例阻断当前 candidate。不得用 direct child raw IPC 被拒绝、其他 case 通过或外层测试绿色覆盖该反例。
- ADR-0174 继续拥有 Application Service 总体合同；ADR-0175 继续拥有 browser-fetch revision 38 NO-GO；本 ADR 只拥有 IPC/preload revision 39 NO-GO 与下一票边界。
- probe 使用 synthetic durable-effect counter，只证明 transport / state-machine 语义；没有证明真实 Adapter cancel、receipt、reconciliation、outcome recovery 或 production authorization。
- production runtime、当前 route、Host、UI、provider、Adapter、store、真实数据和外部动作保持原状。
