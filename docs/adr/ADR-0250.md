# ADR-0250 · UI 接线第三批：显式事项选择与 session-family authority 收口

- 状态：accepted（2026-10-03）
- 日期：2026-10-03
- 决策者：agent（用户确认下一批并开始执行）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-03-active-matter-selection-and-session-family-admission-batch-3.md)
- 相关：[ADR-0249](ADR-0249.md)、[ADR-0174](ADR-0174.md)、[ADR-0163](ADR-0163.md)、[ADR-0164](ADR-0164.md)

## 背景

第二批留下一个 main-owned 但默认 inactive 的 ActiveContext，并只将 send/stop/resume 三条 session route 接入异步 admission。产品仍缺明确事项选择入口，pending/queue/clarification/edits/plan-mode/approval 写路由仍绕过 authority；旧 context 也没有在每次 effect 前同时重核 identity session、current revision、default link、fresh workspace 与 frame。

## 决策

1. 新增 `POST /.sage/context/select`，candidate 只含 `matterId + expectedContextGeneration`；只有显式点击可调用，GET/send/link/draft recency 不得隐式激活。
2. selection 按 identity session → 独立 matter read authorization → current revision → default workspace → fresh workspace fold → FramePolicy → CAS 顺序运行。identity session 只提供 session ref；actor scope 只来自 read authorization。
3. production 暂无真实 matter read-policy provider，因此 selection 稳定 unavailable；route/kernel/UI 接线完成不等于产品选择可用。
4. admitted session effect 每次重新核对 vault session、current revision、default link、fresh workspace/path 与 frame；logout、frame contamination、当前 workspace 删除或默认 link 改绑使 context 失效。
5. pending、queue、clarification、edits、plan-mode、approval 七组写 route 进入 protected admission；连同 send/stop/resume 共 10 条。完整后续 authority 缺失时 raw provider 调用数为零。
6. route truth 更新为 58 条：13 read-only、5 local-preference、38 protected-effect、2 unsupported；protected 中 2 runCommand、10 admitted、1 context-selection、25 bypass violation。视觉/IA、dependency/lockfile 与 Qoder 018/019 写入口不在本批。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 用 GET、send、link 或最新 draft 激活 | 否决：把读取/其他动作变成隐式 context 写，且 recency 不是 authority。 |
| identity handle 直接作为 actor scope | 否决：认证不是事项读取授权。 |
| renderer 提交 revision/session/root | 否决：candidate 不能自报可信事实。 |
| 继续直调 session raw providers | 否决：provider present 不能替代完整 authority、preflight、persistence 与 dispatch。 |
| 同批视觉换壳 | 否决：UI-01 前置未完成，本批只做最小明确选择 affordance。 |

## 后果

- 明确选择 route 与 main-owned CAS 已建立，但真实 read policy 未接，production 选择保持 unavailable-first。
- protected bypass 从 32 降至 25；10 条 admitted route 仍因后续 authority 缺失而不可执行。
- CTX-02 仅关闭 admitted session-family 的 fresh context/root 核对；其他路径与 draft-recency read owner 继续留在 backlog。
- renderer 不获得 actor、session、trusted root 或 authority；selected 后必须重新读取 state。
