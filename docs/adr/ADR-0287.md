# ADR-0287 · 第 8 步 preflight：fresh availability、实时 epoch 读与判词边界

- 状态：accepted（2026-10-10）
- 日期：2026-10-10
- 决策者：用户（lute：同意下一批顺位、失败语义裁决延续）＋ agent（取证与实施）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-10-session-prompt-preflight-step.md)
- 相关：[ADR-0249](ADR-0249.md)（十步链序）、[ADR-0286](ADR-0286.md)（registry 步）、[ADR-0169](ADR-0169.md)（C2C availability/preflight 合同，外部能力专用）、[ADR-0284](ADR-0284.md)（observedAt 纪律）

## 背景

边界文档（2026-09-30 application-service-boundary 第 7 项）给第 8 步的语义是 **fresh availability / no-side-effect preflight**：`approved`（Registry）≠ `compatible`（Matrix）≠ `authorized`（Identity/Policy）≠ `available`。落地侦察：C2C.4 的 availability/preflight 内核绑定外部 descriptor/provenance/host/connection 代，对 first-party 会话通道是范畴错误；行级断言（default preset 未 broken、pinned preset 在 roster）的等值关系在仓内无定义（requirement 钉 `preset:set` 集合身份，live roster 是成员行）；唯一真实、live、无副作用的可用性面是 **Host epoch 的 runtime-effective 观测**（protocol v5，逐请求读取，epoch 消失即 undefined），且 inventory 生产者在 boot 已确立其读法三件套。

## 决策

1. **D1 端口与语义**：新端口 `createSessionPromptPreflightPort`（`src/main/session-prompt-preflight.ts`）。v1 检查面 = 实时 runtime-effective 观测的三步读法：形状经 `isRuntimeEffectiveObservation` 校验、`kind === 'observed'`、其余一律 `unavailable`；坏链（bundle 失败 / 无声明 requirement / mappingRef 形态非法）在触 Host 之前拒绝——不可用的链永不读 Host。**无副作用**：纯读 + 一个确定性域分隔摘要，无时钟。
2. **D2 判词集（裁决延续）**：preflight **永不 denied、永不 stale**；运行时缺失不是拒绝（延续 ADR-0286 的失败语义）。`denied`/`stale` 留待 persistence/dispatch 的「紧邻写入/派发前再核验」（边界文档第 9/10 项）与撤销运营。`preflightRef = urnDigest('urn:sage:preflight:v1:', [targetRef, mappingRef, requirementDigest, 实时读数规范形])`——roster 移动即 ref 移动。
3. **D3 v1 边界声明（不得冒充完成）**：不宣称「操作 preflight 完成」。boot 静态一致（default ∈ preset members）由 inventory 生产者在 boot 证明、此处不重证；availability ≠ execution authority（dispatch 仍 absent）；roster 漂移只表达为 ref 移动，Host 生命周期失效与逐请求重观测属 ADR-0284/0286 登记项。
4. **D4 接线**：options-gated 合并（requirementBundle + runtimeEffective 齐备才现身）；复用 index 既有 main-owned 验证闭包（Ticket 030：`isRuntimeEffectiveObservation` 先行校验），不新增读面。
5. **D5 门禁**：route-authority 新增 preflight 事实组六项（gated 接线、index 验证闭包、live 形状校验、非 observed→unavailable、mappingRef 预检、判词集为空、ref 域）＋六条具名突变；note 句 preflight 移出 absent 名单（stops at the absent persistence / dispatch steps）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 复用 C2C.4 availability/preflight 内核 | 否决：内核绑定 external descriptor/provenance/host/connection 代；first-party 是范畴错误，且其 actionability 恒 blocked 会误导。 |
| 行级断言（default preset 未 broken / pinned preset 在 roster） | 否决：会话实际使用的 preset 与 live default 的等值关系仓内无定义——断言即发明。 |
| 收敛型再核验（重读 context/frame/revision/session 并比对） | 否决归位：那是 persistence/dispatch「紧邻写入/派发前再核验」的职责；放 step 8 会重复且挤占第 9/10 步语义。 |
| 只读 boot 证据（不触 Host） | 否决：那不是 fresh——fail 面只剩 registry 已证过的旧事实，新鲜度无从表达。 |

## 后果

- 十步链真实推进到第 8 步：窗口内 `session.send` 过 preflight 后停在 persistence；路由级仍 `protected-effect-unavailable`（信封不含 stage）。
- availability 与 approved 正交落地：Host epoch 不在 = unavailable，绝不被读成拒绝；ref 随实时读数移动，freshness 可观测。
- 未闭：persistence（第 9 步，含 durable evidence 与再核验）、dispatch（第 10 步，窄 Adapter port）、Host 生命周期失效接线、撤销运营。
