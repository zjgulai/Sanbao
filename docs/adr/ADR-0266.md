# ADR-0266 · 本机系统入口：GET /.sage/bootstrap 与 local-system 类别

- 状态：accepted（2026-10-05）
- 日期：2026-10-05
- 决策者：用户（批准 T02 精确范围：bootstrap 本机读取分类与 route-authority 门禁扩展）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-05-local-system-bootstrap-read.md)
- 相关：[ADR-0265](ADR-0265.md)、[Application Service 边界](../notes/proposed/architecture/2026-09-30-application-service-boundary.md)

## 背景

默认桌面需要一条在任何登录与事项语境之前就能读取的设备入口：身份状态、运行时状态枚举、以及初始显示用 theme/density。既有读取面全部绑业务语境：`/.sage/state` 走 projection-read admission（要求 session+matter+读策略），local-preference 面（`/.sage/preferences` POST）没有未登录读入口；CB1 只验 exact app URL / origin / 未污染 frame，其缺失维度含 frame-ready（门禁锁死，不得把公共维语义提升）。因此需要一条新的、窄的、可门禁登记的 local-system 路由，而不是放宽既有读取策略。

## 决策

1. 新增 `GET /.sage/bootstrap`，是唯一 local-system 类别路由（route-authority 58→59）；响应为封闭 DTO：`{runtime:{status},auth:{status},display:{theme,density}}`，不携带姓名、凭据、session 引用、配置值、工作区或业务内容。
2. main 组装专属 runner（`createLocalSystemBootstrapRunner`）：verifyCaller（请求级 callerBinding）→ verifyFrame（ready 且未污染，锁定 frame generation）→ read（vault 状态 + 已保存显示偏好）→ post-read freshness（frame generation 未动）→ 读中身份状态不得变化；任一步失败统一回 `bootstrap-unavailable`（防枚举）。无 runner 时组合返回同一稳定拒绝；无 caller 在路由层 403 且不触 provider。
3. 门禁登记为逐行事实：矩阵新增 `localSystemAdmission` 位；检查器对 main 装配做精确针（kernel 导入、装配行、runner 内 caller/读前帧/读后帧/身份移动四条语句）＋负向检查（不得出现 displayName/matterRef/workspaceRoot）；自测含四个具名突变。
4. renderer 侧解析同样封闭（exactKeys＋枚举校验），不显示未分类字段；账号菜单的登录只由显式点击触发，logout 确认后立即重读 state 与 bootstrap 撤回本地旧状态。
5. bootstrap 不是业务读取通行证：state/search 等路由的 admission 不变，未登录仍拒绝。

## 备选方案

| 方案 | 取舍 |
| --- | --- |
| 扩展 CB1 加 frame-ready 并让既有面承担入口 | 不采用；CB1 是全部 59 条的公共维，提升其语义等于扩大既有面；入口 DTO 也会混入业务读取。 |
| 放宽 projection-read 以在未登录时读 state | 不采用；违反 READ-01A（认证≠读权）与既有 unavailable-first 策略。 |
| 复用 local-preference 面 | 不采用；它没有读入口且语义是设备偏好而非身份状态。 |

## 后果

默认桌面在任何语境前可显示真实身份/运行时/显示事实；本机外泄面收窄为一个封闭 DTO 与单一拒码。T05/T06 的真实消息链与 T03 read-policy 不变；登录完成路径（OIDC）与其后的业务能力仍按各自后续票验收。
