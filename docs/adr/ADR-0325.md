# ADR-0325 · 桥终局契约修正：`bridge-result` 必须 resolve 声明契约对象

- 状态：accepted（2026-10-12）
- 日期：2026-10-12
- 决策者：用户（2026-10-12 授权继续排障并修复）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-12-bridge-result-contract-and-bootstrap-followups.md)
- 相关：[ADR-0324](ADR-0324.md)（设备聚合读）、ADR-0206（有界流读）、Ticket 010/012（工作区接入与折叠）

## 背景

v6 装机实测：`/.sage/state` 放行（ADR-0324）后名册可读；工作区折叠恒 `unavailable`，`接入工作区` 恒 `workspace-adoption-failed`。装版探针读数：

- 折叠：帧正常到达（`{"type":"baseline",...}`），终局值却是 `{"frames":1}`；
- 接入：`directory/pick` 抛 `bridge-provider-failed`。

代码链：Host 处理器返回整包 `{ok:true,result}`；shell 客户端 `host-process.ts` 的 `bridge-result` 处理器把**整包剥成 `message.result`** 再 resolve。全仓 20 个工作区/会话/附件/产物等消费者模块（`asAnswer` 家族）都按**整包**解析 → 一律落入 `bridge-answer-unrecognised`。凡走 bridge 的请求面（折叠、接入、会话通道、附件……）在生产冷启动路径上从未工作过——既往走查全部落在 fixture/空根断言之后，从未触达这批路径。

`directory/pick` 的 `bridge-provider-failed` 另有其一环：shell overlay 禁用 base 原生 directory-picker、插入 browse 后端（overlay 首行注释：「in-app browsing until its native picker bridge exists」）；controller 的 `pick()` 要求 `native` 能力 → 无 native 后端即抛。这是已登记的设计取舍，不是本 ADR 修复对象；走查环境改走种子（见 Note）。

## 决策

1. **D1 声明契约对象 resolve**：`host-process.ts` 的 `bridge-result` 对 `ok:true` 改为 `pending.resolve({ ok: true, result: message.result })`——消费者侧的声明形态（`BridgeAnswer = {ok:true,result} | {ok:false,code}`，`workspace-adoption.ts` 等 20 个模块的 `asAnswer` 家族）；`ok:false` 维持 reject（`BridgeCallError` 带 code）。消费者契约不变，修复在传输层单点。
2. **D2 不散点改消费者**：不改 20 个消费者模块；不为兼容保留第二形态（不做双形态解析）。
3. **D3 门禁**：`sage-route-authority` 新增 pin——`resolve({ ok: true, result: … })` 必须存在、`resolve(message.result)` 不得回。
4. **D4 走查环境**：原生 picker bridge 面属「尚未接通」（overlay 既定）；走查种子脚本扩展为补齐**已转化草案**（名册行来源）与**base 工作区存储条目**（折叠来源），与既有事项种子同一方法论。walkthrough 手册同步修正第 16 步措辞（原生弹窗改记「尚未接通」）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 逐个把消费者改成剥包后形态 | 否决：20 处散点、契约方向反了（Host 的整包才是协议形态）；agent 单点改动最易腐烂。 |
| 双形态兼容解析 | 否决：两个家会分叉；错误形态应判红而非容忍。 |
| 顺带实现 native picker bridge | 否决：超批范围；原面属 overlay 显式取舍。 |

## 后果

- 凡走 bridge 的请求面恢复契约一致：折叠、接入后续、会话通道、附件、产物等（各自既有测试已按整包写）。
- 走查依赖：工作区由种子写入 base 存储（`<root>/harness/storages/workspace.json`），事项由同名脚本种子；「接入工作区」按既定设计记「尚未接通」。
- v7 DMG 承载本修复 + ADR-0324 组装面修复（composition scopedOr）。
