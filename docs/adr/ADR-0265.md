# ADR-0265 · Sanbao 复刻桌面成为 Sage 默认主界面

- 状态：accepted（2026-10-05）
- 日期：2026-10-05
- 决策者：用户（确认现有 Sanbao 原型用于替代原 DSH Desktop 桌面 UI，并授权完整 Spec/tickets 和接入开发验收）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-05-sanbao-default-desktop-t01.md)
- 相关：[ADR-0261](ADR-0261.md)、[ADR-0264](ADR-0264.md)、[Application Service 边界](../notes/proposed/architecture/2026-09-30-application-service-boundary.md)、[UI 一致性合同](../specs/2026-09-27-sanbao-to-sage-ui-consistency-contract.md)

## 背景

Sanbao 复刻原型的用途是替换桌面 UI，而不是提供额外的原型目录窗口。此前的第二窗口与 206 状态挂载证据不能证明默认主界面替换或后端接通。用户已明确要求直接复用现有原型，将界面与真实 Sage 服务连起来。

原型的 product 分支为简化演示，完整桌面结构位于 QoderResearchSidebar、QoderResearchHomePage 与完整 Composer。复用该结构时，必须移除研究导航、虚构业务数据、按 observation 驱动的模拟状态和发送后立即清空的行为。

## 决策

1. Sage 保留既有 `dsh-app://app/index.html`、`createSageWindow` 和 FramePolicy，默认文档改由 Electron main 提供；不再从默认启动路径打开 Sanbao 辅助窗口。CSP、sandbox、业务路由和授权顺序不放宽。
2. 将已核验 Sanbao `b861d04` 的桌面结构与 SVG 几何受控复用于 Sage 本地源码。原型仓不作运行时依赖；研究目录、示例账号/额度/会话/文件和模拟成功不纳入产品。palette 继续由 Sage theme-tokens 独占。
3. 新桌面构建输出为 `lib/main/desktop-bundle.js`；保留既有旧 renderer 的未提交工作与构建，不覆盖、不回滚。空 desktop bundle 必须在 Host 启动和窗口创建前失败；非精确资产路径在 main 终止，编码别名不得回落旧文档。
4. T01 只接既有 `GET /.sage/state` 的实际响应。200 denial 不是成功投影；有效服务响应只提取本片所需 runtime 状态，丢弃原始消息和敏感数据。请求/响应体超时与损坏响应保持不可用。
5. Composer 草稿由父组件持有，读取、拒绝、重复点击和页面切换不清空输入。成功发送尚未接通，本片不调用未完成授权装配的写入口，也不伪造会话或受理回执。
6. dev:debug 默认使用真实服务响应，不注入 fixture 或辅助窗变量，并移除 GUI 子进程的 `ELECTRON_RUN_AS_NODE`。测试和 Host 的 Node 执行模式不变。
7. 完成度按主界面、具体服务操作和实际结果分账。T01 不关闭真实消息发送、流式输出、停止/恢复、206 状态全接通或发布验收；这些保留在依赖明确的后续工单。

## 备选方案

| 方案 | 取舍 |
| --- | --- |
| 将原型作为第二窗口 | 不满足用户要求；仅保留历史承载实验的证据。 |
| 原样运行完整原型 App 并隐藏目录 | 会连带带入模拟业务驱动与 fixture 回退，不作为正式产品实现。 |
| 重新设计一套首页 | 不采用；复用已有复刻结构，改动集中于数据与调用边界。 |
| 为让聊天成功直接调用 Host prompt | 不采用；不得绕过独立读取策略、custody 与 protected dispatch。 |

## 后果

展示方向替代 UI-00 的“原型仅作证据、不复用组件”限制及旧默认事项卡首页选择；业务状态所有权、权限、数据治理、兼容性与发布资产审批要求保持。新主窗自足运行，后端能力缺口仍然可见。旧未提交代码不再默认显示，但原始字节与索引状态保持不变。
