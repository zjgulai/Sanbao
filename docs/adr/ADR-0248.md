# ADR-0248 · UI 接线第一批：冻结 Qoder 来源、57-route authority 真值与 matter payload 驱动 DOM

- 状态：accepted（2026-10-03）
- 日期：2026-10-03
- 决策者：agent（用户确认启动第一批）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-03-ui-wiring-convergence-batch-1.md)
- 相关：[ADR-0184](ADR-0184.md)（main 唯一终止 `/.sage/*`）、[ADR-0174](ADR-0174.md)（Application Service 唯一产品编排入口）、[UI 一致性合同](../specs/2026-09-27-sanbao-to-sage-ui-consistency-contract.md)

## 背景

Qoder 接线结果同时存在已推提交、本地提交与继续漂移的 018/019 混合 dirty tree；不能把三者当成同一来源。`eeff896` 又存在两条未闭线：57 条 route 中只有 2 条 protected route 进入统一 command authority，且 renderer 没有把 main 已提供的 nested `matter` 投影绑定回事项 DOM，静态 fixture 反而让测试假绿。

## 决策

1. Qoder 原 worktree 保持只读；以 `eeff896` 建 integration。committed、local、dirty-observed 四层分开，dirty 只保存双采样证据与 hash，不自动应用。
2. 建立 57-route authority truth matrix 与独立 gate。13 read-only、5 local-preference、37 protected-effect、2 unsupported；仅 `/.sage/actions` 与 `/.sage/draft/convert` 记为实际 `runCommand`，其余 35 条 protected bypass 必须保持 violation。
3. `CB1` 只记 partial；Origin-required、frame-ready、active-session、read-policy 缺项不得由 gate 绿色掩盖。
4. renderer 只接受 exact nested `{ service, matter, runtime, ... }` envelope。production 初始事项为 unavailable；`matter` 的 null/fixture/live/malformed 分支分别渲染并清除旧值，旧 flat/off payload 退场。
5. 动态事项 action 只生成只读 preview，不产生 button、POST 或 `ActionIntent`；Electron probe 必须等 route payload 真正驱动 DOM。
6. 第一批不做 AUTH-02、不接真实 provider、不吸收 Ticket 018/019 dirty、不新增 UI dependency，也不宣称完成 Sanbao 视觉/IA 迁移。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 复制 Qoder dirty tree | 否决：018/019 交叉且仍漂移，无法保持票据与字节来源。 |
| 将已知 35 条 violation 直接作为永久 gate failure | 否决：truth drift 与行为迁移是两种信号；AUTH-02 另票执行。 |
| 把 direct provider route 标为 compliant | 否决：main-owned/provider present 不等于 action-scoped authority。 |
| 保留 flat/off + nested 双协议 | 否决：违背 main 唯一 route owner，并继续掩盖 envelope 漂移。 |
| 默认渲染 fixture 或先铺视觉壳 | 否决：会把不可用包装成可用，并重现预烘焙假绿。 |

## 后果

- 默认 Sage gate 新增 `sage-route-authority` 与 selftest，总项数由 25 增至 27；绿色只代表矩阵/源码一致。
- 35 protected bypass、13 read-only 的 read policy 缺口与 partial CB1 保持显式未完成，进入 AUTH-02/后续 read-policy 批次。
- renderer 合法输入收窄为 exact nested envelope；测试夹具必须同步提供 `matter`，production 不再预烘焙 fixture。
- Qoder dirty 中同名未跟踪 `ADR-0248.md` 只是冻结 observation；Ticket 019 重建时须按当时最新索引重新编号。
- 本批只完成 CONV-01/02、AUTH-01、UI-WIRE-01；视觉栈与三栏 IA 仍受 UI-01 前置约束。
