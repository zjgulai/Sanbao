# ADR-0256 · UI-FIXTURE-01：六阶段只读 fixture 与当前阶段轨道

- 状态：accepted（2026-10-04）
- 日期：2026-10-04
- 决策者：用户（lute，确认执行 UI-FIXTURE-01）
- 决策记录：[Note](../notes/implemented/surface/2026-10-04-six-stage-fixture-workbench-batch-9.md)
- 相关：[ADR-0174](ADR-0174.md)、[ADR-0248](ADR-0248.md)、[ADR-0254](ADR-0254.md)、[UI 一致性合同](../specs/2026-09-27-sanbao-to-sage-ui-consistency-contract.md)

## 背景

Sage 的三栏事项工作台已经能消费 strict `sage.matter-view.v1`，但本地 fixture 只有 clarification 单态，其他阶段无法经 production wire 重复驱动；界面也没有只标记当前 token 的阶段轨道。真实窗口进一步暴露出：合法的 `projection-read-unavailable / read-policy` route denial 会被 renderer 误写成 malformed invalid。

## 决策

1. 冻结 `created / evidence / clarification / running / artifact-receipt / failed-retry` 六个 exact fixture token；所有 fixture 共享 `sage.matter-view.v1`，保持 `projectionSource=fixture`、顶层及 actions 全部 `blocked / fixture-only`、deep-frozen，并排除 snapshot、matrix、digest、locator、机器路径与 authority record。
2. main 只有在 `SAGE_FIXTURE_PROJECTION=1` 时读取 `SAGE_FIXTURE_STAGE`；缺省为 clarification，空串、空白、大小写别名和未知 token fail closed。URL、hash、query、localStorage 与 renderer 不拥有 stage 选择权。
3. 工作台增加六项只读阶段轨道，只允许 current / idle；不渲染 completed。六态、null、malformed 与 live 连续重绘必须清除旧 current marker、澄清、trace rows 和 action previews。
4. artifact-receipt 保留 succeeded attempt + artifact、空 receipt 与 undefined conclusion；failed-retry 保留两个不同 ID 的 failed attempt。artifact、attempt 或回复结束都不得推导事项 completed。
5. exact non-aggregate `projection-read-unavailable / read-policy` typed denial 显示 unavailable；真正 malformed、缺字段 aggregate 与退休 flat payload仍显示 invalid。真实 Electron 必须覆盖 1440、760 drawer/focus、200% zoom、query 隔离、trace 同源、截图像素证据、zero-write 与写入负控。
6. 本批不新增真实 mutation / ActionIntent / provider / Host bridge / persistence，不修改 dependency、package 或 lockfile，不声明真实事项流程、production E2E 或完整 Qoder UI/UX 复刻完成。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 复制或嵌入 Qoder / Sanbao 六张页面 | 否决：外部原型是证据输入，不是 Sage runtime dependency。 |
| 用 query / hash 选择业务阶段 | 否决：产品 URL 不拥有业务状态，未知 token 必须 fail closed。 |
| 阶段轨道把左侧项画成已完成 | 否决：失败、澄清、重试与回执不是单向进度条。 |
| artifact 出现即设置 completed | 否决：artifact 不等于 acceptance receipt 或 matter conclusion。 |
| 所有非 aggregate response 一律显示 unavailable | 否决：malformed 必须与合法 typed denial 区分。 |
| 只跑 Fake DOM | 否决：真实 wire、viewport、drawer、focus、zoom 与像素证据需要 Electron。 |

## 后果

- 六个 deterministic local fixture 可经 main-owned exact selector、Application Service route 和真实 renderer 重复呈现。
- 阶段轨道只高亮当前 stage；trace 与 action previews 与同次 wire 同源，null / malformed / live 不残留旧态。
- production/no-fixture 与 unknown token 仍 unavailable-first；typed denial 不再被误报为 schema invalid。
- 六态继续只读且 zero-write；真实 authority/provider、dispatch、持久化与 production E2E 仍显式未完成。
- 本 ADR 不授权 commit、push、merge 或发布。
