# ADR-0318 · R17-A 设置壳批：观测导航 + 四默认页结构复刻

- 日期：2026-10-12

- 决策记录：[Note](../notes/implemented/surface/2026-10-12-r17a-settings-shell-batch.md)
- 相关：[ADR-0315](ADR-0315.md)（纯壳口径）、[ADR-0316](ADR-0316.md)（R16 成例）、[ADR-0313](ADR-0313.md)（壳批成例）、T13（tickets 计划）

## 背景

P06 设置族是矩阵最大 pending 块（40 行：18 入口 + 四默认页 + shortcuts/voice/models 子簇）。观测证据在仓内副本齐备（QB7-01 个人资料、QB15-01 常规、QB15-02 模式配置、QB16-01 任务监控）。R17 侦察后分四波：A 设置壳+四默认页（本 ADR）、C 快捷键+语音、B 模型编辑器（BYO API Key 凭证面待裁决）、D 杂项薄观测行。

## 决策

1. **D1 壳形状**：设置面 = 观测导航（返回应用 / 搜索设置 / 导航项）＋内容面板；波一只渲染已有页面的入口（后续波随页面加入各自入口）——不存在「导航指向假页」。
2. **D2 默认面板本地规则**：落地默认面板保持「外观与显示」，偏离观测默认（`#/settings?section=profile`）。理由：保护既有验收落点（DMG-06 / 走查 / 既有 spec 都以外观页为默认态）；偏离记录在案，后续波可再裁。
3. **D3 结构逐字 + 未接线态**：四个默认页按观测结构复刻（组/行名/说明逐字取自 capture）；无 Sage 机器的行给诚实「未接线」态与禁用控件——**不显示伪造读数、不提供动作入口**（沿用 R16 读回面口径）。
4. **D4 profile 真事实**：个人资料页只接真身份事实（身份会话状态 + 真 login/logout 动作，复用既有 account 控制器）；计量/订阅/编辑/分享/成就墙/清除凭证具名未接线。
5. **D5 写路径独立成批**：本地偏好写入属 local-preference 类，不 spin protected-effect admission 批；保存与应用分离（T13 子批），本批零写入。
6. **D6 矩阵迁移**：7 行 pending→implementing（四默认页 + profile/general/mode 入口行），evidenceRefs 挂 tracked-test（countsAsVerification:false），blockers 按四要素改写；route currentAuthority 与 violation 计数零改动（ADR-0315 D1）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 渲染全部 24 观测入口（指向未建页） | 否决：导航指向假页即伪造可达性；后续波随页面加入入口。 |
| 默认面板改为个人资料（照观测） | 否决（本批）：击穿既有验收落点；偏离记录留待后续裁定。 |
| 显示观测默认值（排队/on 等）为本机值 | 否决：Qoder 默认值不是 Sage 事实；伪造读数比空态更糟。 |
| 本批直接接通用设置写路径 | 否决：超出壳批口径；保存与应用分离有 T13 明文。 |

## 后果

- 设置壳落地：导航+搜索+返回应用，五面板（外观既有 + 四新）；矩阵 111→118，pending 40→33。
- 余量具名：shortcuts/voice（波 C）、models（波 B，凭证裁决前置）、杂项入口（波 D）、24 入口全展开（scope 行）。
- `账号与设置` 页的既有外观验收不受影响（默认面板与控件不变）。
