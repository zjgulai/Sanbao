# ADR-0306 · 弹层族第二刀：自定义 MCP 表单（本地草稿，提交 fail closed）

- 状态：accepted（2026-10-11）
- 日期：2026-10-11
- 决策者：用户（lute：同意 Loop-Q R8，并指示可并行处并行）＋ agent（盘点与实施）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-11-mcp-form.md)
- 相关：[ADR-0305](ADR-0305.md)（弹层族第一刀）、T10 票据纪律（安装/启用/授权分离）

## 背景

Loop-Q R8：O08 的 12 行（自定义 MCP 表单族）。盘点：Sage 无 MCP 配置写 provider；T10 明文禁止本类票「顺便安装、启用或批准插件」。观察行全部是**表单形状事实**（空表单/字段集/动态行/JSON 示例/名称预览/放弃确认）——可在不触碰治理链的前提下装配；提交与导入必须 fail closed。

## 决策

1. **D1 本地草稿域**：新增 `McpForm`（desktop），状态全部本地未保存；观察的每个形状逐条装配：空表单（名称占位「例如 github-search」、传输未选、取消/添加 MCP/关闭）、传输选择（STDIO/HTTP/SSE 顺序）、HTTP/SSE 字段集（URL 占位 + 不在 URL 放 token 提示；HTTP 有 Header 区、SSE 无——依观察）、STDIO 字段集（命令/参数/工作目录/环境变量 + 绝对路径提示）、动态行（添加后行号命名与移除、添加按钮保持焦点）、JSON 标签（观察的示例 + 预览导入按钮）、名称预览（唯一观察映射 `-`→`_`，完整规范化算法**不发明**）、放弃确认（未保存时取消→「放弃未保存的修改？」，继续编辑初始获焦，放弃修改红字，无关闭按钮）。
2. **D2 提交 fail closed**：「添加 MCP」「预览导入」点击 → 明确「尚未接通：能力治理链未建立（T10）；本次修改不会保存或导入」；不写配置、不安装、不授权。空表单**不**断言禁用（观察明确未能推断空表单校验）。
3. **D3 未验证项不装**：跨传输切换保留字段（观察未验证）→ 实现保留但**不作断言**并登记；灰色预高亮（原生菜单微差）与凭据遮蔽不装/不断言。
4. **D4 落点**：「扩展」页从占位升级为扩展管理页（连接器区 + 添加 MCP + 表单）；`outstanding` 映射移除「扩展」。
5. **D5 迁移**：O08 十一叶迁 `ui` `pending→implementing`；O08.scope.unexpanded 依伞行核验侦察判据（组内 11/11 implementing）同迁。summary 生成器重算（35→47 implementing、163→151 pending——含伞行 1 条）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 提交接一个真实写 route | 否决：MCP 配置写入属 T10 治理（descriptor provenance/审批/registry），无真实 authority 前不得开写路径。 |
| 空表单禁用「添加 MCP」 | 否决：观察明确不能推断空表单校验——不发明校验语义。 |
| 自绘下拉复刻灰色预高亮 | 否决：select 即原生菜单；微差登记 blocker。 |
| 跨传输字段清空 | 否决：观察未验证保留或清空——保留 + 不作断言 + 登记。 |

## 后果

- 弹层族最大 pending 群（12 行）收口；O08 组全叶 implementing。
- 提交/导入真实行为、替换预览等未观察叶登记；视觉验收待走查。
