# ADR-0155 · ResearchView 首片拆分：内部 hooks 与展示分离，行为和验收边界不变

- 状态：accepted（2026-09-21）
- 日期：2026-09-21
- 决策者：用户（lute），本轮明确批准 DA-07 首片及五模块拆分方案
- 决策记录：[Note](../notes/implemented/surface/2026-09-21-research-view-separation.md)

## 背景

ResearchView 同时承载资料库、路由、异步状态机协调及工作区展示，难以独立验证生命周期。
本轮只拆一个源文件；行为、构建前置与保留的已知问题见决策记录，不扩展到 wanzh/investigation/gate。

## 决策

采用已批准的五模块边界：资料库 hook、工作区 hook、纯 view model、工作区展示、composer。
ResearchView 保留资料库与卡片/删除对话框。报告剪贴板副作用用工作区 hook 模块中的 pane-scoped
useReportExport 承载，维持原挂载时机；纯导出字符串归 model，原有 HTML 行为不变。

公开调用面、effect dependencies、计时值、时间戳比较语义与 mutation 错误保留均不改。
新增 hook 行为测试先红后绿，原视觉断言扩展到所有被拆出的展示源。
本 ADR 接受的是拆分决策，不是整张 DA-07 或 DSH 集成验收完成声明。
后续用户批准的产物同步、HTML/删除依赖/层级修复由 [ADR-0156](ADR-0156.md) 单列；
以下「原样」「不修」「唯一配置」约束只描述本拆分片，不限制该明确批准的行为变更。
