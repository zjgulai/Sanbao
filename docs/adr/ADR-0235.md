# ADR-0235 · 消息锚点：轮次跳点、本地短预览与保留现场的缺失

- 状态：accepted（2026-10-03）
- 日期：2026-10-03
- 决策者：agent（取证并实施；FW-035、US-183/184 已定方向）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-03-message-anchors.md)
- 相关：[ADR-0233](ADR-0233.md)（009 纯历史接点与 runsOfRecords）、[ADR-0213](ADR-0213.md)（006 停止）、[ADR-0234](ADR-0234.md)（034 澄清问答）

## 背景

工单 035（FW-035，US-183/184）：会话锚点（轮次跳点）点击后**定位到该消息并显示其短预览**，
**不因此加载整段历史正文或激活执行**；锚点目标所属运行**不可读时保持缺失提示，不显示空白
成功**（与 US-100 同判据）。产品证据（Sanbao P01.anchor.preview + M01.message-anchor，N05）：
锚点=会话底部的轮次定位钮，hover/点击出**短预览弹层**（预览文本 + 「定位到此轮消息」+
关闭），**hover 不应提交命令**；基座侧 `turn/start`（而非 user/message）是每轮的锚。
本仓 009 已把纯历史接点（`session/page`＋`runsOfRecords`）立成判据；035 在这条接点上做跳点。

## 决策

1. **D1 锚点=轮次引用＋有界短预览**：`main/session-anchors.ts` 的 `read` 只调一次有界
   `session/page`（`maxMessages: 400`），由 `runsOfRecords` 组轮（`turn/start` 为锚），
   每条 `{runSeq, turn, promptPreview}`——预览取该轮**第一条用户消息**、截断 ≤140 字；
   newest-first、`MAX_ANCHORS=50`；`no-session` 绝不建会话；页读失败=`unavailable+code`。
   短预览**随列表随行**：点预览不需再读一次桥（整段正文永不过界）。
2. **D2 定位=一次有界窗口读**：`locate({matterRef, runSeq})` 调一次
   `session/page{throughSeq:-1, beforeSeq: runSeq, maxMessages:400}`，找到该轮后返回
   `{state:'located', runSeq, turn, promptPreview≤300}`；页读失败或轮不在窗口=
   `{state:'missing', runSeq, code}`——**US-184 的"不可读"在这里可判定**（不回落空白）。
3. **D3 渲染面（S8）**：D3 卡内「消息锚点」区——`[读取锚点（最近轮次）]`＋逐行
   `运行 @N·第K轮 — 预览：… [锚点预览]`；点击锚点开**本地短预览弹层**（问题文本＋
   `[定位到此轮消息]`＋`[关闭预览]`，**零桥调用**）；点定位发**恰一条** `action:'locate'`；
   hover **无监听、零命令**；`located` 标记随投影重建（**保持现场**：刷新与定位失败都不清场景）；
   未接线/无会话/失败各有具名句（不以空列表冒充）。
4. **D4 共核 009 不另起炉灶**：`runsOfRecords` 增 `firstUserText`（加法字段，轮分组仍只有
   一个家）；短预览由该轮自身文本现算，不复制日志解析逻辑。
5. **D5 首版不做**：锚点收藏/分享、跨事项锚点跳转、全文检索式定位。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 引入 `dsh-session-turn-outline` 服务做锚点源 | 否决（首版）：该服务是客户端 rail 投影；本仓 009 的纯历史页读已能给出同构数据（turn/start 锚＋有界 prompt 预览），免新增 host 服务面。 |
| 点预览时再读一次桥取预览文本 | 否决：短预览本就按"所需最小正文"随列表截断返回；点击必须零调用可断言。 |
| hover 也触发读取/定位 | 否决：N05 明令 hover 不提交命令；悬念留给显式点击。 |
| 定位失败即清空锚点区 | 否决：US-184 要与 US-100 同判据——缺失自报、**保现场**，不显示空白成功。 |

## 后果

- 验收两条机器断言：① 读/定位只调 `session/page`（hover 与预览点击零请求、定位恰一条，
  无 prompt/follow/其它路径）；② 目标不可读=`missing+code` 具名句且锚点行与预览仍在。
- 路由 `/.sage/session/anchors`（`{action:'read'}` 1 键 / `{action:'locate', runSeq}` 2 键精确体）；
  端口名册 +2（sessionAnchorsRead/sessionAnchorLocate）；033 装配守护 +1 族；
  `runsOfRecords` 加法字段（009 消费方不受影响）。
- §1.6：真产物两页——锚点行（@12·第 2 轮/@0·第 1 轮＋有界预览）＋打开的短预览弹层；
  真实 Chrome DOM 读数：定位恰一条读、缺失句「运行 @12 不可读（history-run-not-in-page）：
  保持缺失（不显示空白成功）——现场保留，不回落为空白。」与行数/预览保持。
- 已知未闭：收藏/分享、跨事项跳转、检索式定位后置；真机 Electron 未跑。
