# ADR-0307 · 知识/站点页壳第一批：诚实不可用而非空列表

- 状态：accepted（2026-10-11）
- 日期：2026-10-11
- 决策者：用户（lute：同意 Loop-Q R9 双线并行）＋ agent（侦察＋实施）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-11-knowledge-sites-shell.md)
- 相关：[并行侦察记录](../notes/implemented/process/2026-10-11-scope-and-knowledge-sites-recon.md)、T12 票据

## 背景

OBS02 知识中心（13 行）与 OBS03 站点（4 行）此前为占位通知。侦察结论：无知识库/Repo Wiki/站点存储 provider；**「无 provider」不能冒充「空列表」**——观察空态文案（「还没有知识库」「还没有站点」）语义为「有存储、空列表」，缺失 provider 时必须显示「provider 未接通 + 具名 reason」。

## 决策

1. **D1 页壳装配**：「知识中心」「站点」从 outstanding 占位升级为实页，形态依观察：知识中心双 tab（知识库 | Repo Wiki）+ 视图切换（卡片/列表）+ Repo Wiki 筛选（全部/已生成）与搜索输入；站点双 tab（我的站点 | 共享给我的）。
2. **D2 诚实数据区**：知识数据区 =「知识库服务未接通（{reason}）」——reason 优先取 state 信封 `readout.knowledge`（新增 `readoutKnowledge` 宽容槽；真实 service 的 fallbackReadout 自然携带 `not-wired`），槽缺失时 fallback 具名常量；**绝不出现空列表/无匹配文案**。站点同形（`sites-store-unavailable`）。搜索框可输入且查询保留——无来源可搜 ≠ 无匹配。
3. **D3 不放假入口**：两页无创建/提交/生成动作按钮（「生成」属受保护 effect，须等 provider + 显式授权）。
4. **D4 范围**：本批 7 行（entry×2、empty×2、shared.empty、generated.empty、search.empty）；`sites.loading`（无 provider 时骨架即假声明）与 `repo-wiki.knowledge-cards.wide`（依赖配置视图）留 pending。7 行迁 `ui` `pending→implementing`；summary 生成器重算（59→66 implementing、139→132 pending）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 显示观察到的「还没有知识库」空态 | 否决：无 provider 时该文案是假声明（有存储才有空列表）。 |
| 搜索框 readOnly | 否决：观察里查询可输入；改为可输入+查询保留+具名未接通。 |
| 骨架 loading 件本批装入 | 否决：无触发链的骨架即装饰性假象；留待 provider。 |
| 携带真实 fallbackReadout 直接展示空态 | 否决：fallbackReadout 的语义就是 not-wired，如实呈现。 |

## 后果

- 两页壳与诚实不可用上线；知识/站点余量（表单族 6 行、配置/生成族 2 行、loading/wide 2 行）登记。
- 真实 provider 落地前，行关闭（applicationService/hostIntegration/visual）保持 pending。
