# ADR-0300 · 执行模块第二刀：产物卡右栏与受控预览接线

- 状态：accepted（2026-10-11）
- 日期：2026-10-11
- 决策者：用户（lute：同意 Loop-Q R2）＋ agent（取证与实施）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-11-artifact-rail-and-preview.md)
- 相关：[ADR-0298](ADR-0298.md)（R1 活流）、[ADR-0178](ADR-0178.md) D3（受控预览容器）、Ticket 015/033/044

## 背景

Loop-Q R2 两行：`QDR.A02.output.html`（HTML 产物卡、更多文件操作、选择打开方式、右侧产出项；T09）与 `QDR.P14.preview.html`（右侧浏览器工作面、地址栏与两层标签、显示本地清单 HTML；T06）。盘点：Sage 预览容器早已存在（main-owned `WebContentsView`，512px 右侧、`PREVIEW_PANEL_TOPBAR` 起点、受控离线文档、无导航 chrome——ADR-0178 D3）；状态信封已带 `artifacts` 槽（cards + preview）；desktop 线不消费。缺口 = desktop 侧消费与动作接线。

## 决策

1. **D1 desktop 消费 artifacts 槽**：client 严格闭合解析（malformed 槽整体省略）；卡片字段全显示面（name/kind/bytes/state），无机器路径。
2. **D2 右栏产物 rail**：`.session-layout` 内新增 `artifact-rail`（卡片 + 「更多操作」details 菜单：面板打开/独立窗口）；预览打开时 rail 保留（让位于左侧），状态块按 preview 状态给出 正在打开 / 已打开（关闭预览、全屏查看、独立窗口开关）/ 打开失败（重试）。
3. **D3 面板避让单一常量**：`SAGE_PREVIEW_PANEL_WIDTH = 512` 上移 `src/product/contracts.ts`（一个家：main 的 WebContentsView 布点与 renderer 的布局避让共用）；preview opening/ready 时 `.session-layout.preview-open { padding-right }`。
4. **D4 动作薄封装**：`desktop/artifacts.ts` 五个既有路由的 POST 封装（open/retry/close/fullscreen/window），零本地事实；动作后经 `refreshNow`（后台读）拉新投影。
5. **D5 诚实差异登记**：Qoder 的「地址栏、浏览器与页面两层标签」**不复刻**——受控容器无导航面（ADR-0178 D3）；行迁移 blocker 显式写明。两行 `ui` `pending→implementing`（tracked-test refs，`countsAsVerification:false`）；summary 生成器重算（20→22 implementing、178→176 pending、verified 8 不变）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| desktop 自渲染预览文档（iframe/React） | 否决：受控预览容器是既有安全边界（独立非特权 WebContentsView），不可绕开另开渲染面。 |
| 地址栏/两层标签照搬 | 否决：导航面与受控容器合同冲突；诚实登记差异。 |
| rail 常驻 512px 与面板并排 | 否决：面板固定覆盖右缘；rail 保留在避让后的内容区即可。 |
| 动作后 foreground refresh | 否决：清屏闪烁；后台读足够且与轮询一致。 |

## 后果

- 执行面获得产物卡与预览的全链接线（观察 feed → 卡片 → 受控面板）。
- 两行迁 implementing；「地址栏/两层标签」差异与真机视觉验收登记 blocker。
- 真实 HTML 产物验证依赖真实会话链（走查）。
