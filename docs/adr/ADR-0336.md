# ADR-0336 · VF-1 主题重定值：token 锚定 Qoder 0.4.4 实测，合同改复刻锚定 + 偏离清单

## 背景

Sage 原 19 token 是自造绿色系；VF-0 完成 Qoder 0.4.4 静态提取 + 27 张真机截图后，VF-1 把 light/dark 重定值为 Qoder mint 系实测。落值即冲突：Qoder 的分隔线/三级文字/主按钮白字本身低于 Sage 既有全矩阵对比度合同（≥4.5/≥3）。复刻与可访问性 gate 二选一。

## 决策

1. **D1 值锚定实测**：light=mint-light 真机读数（画布 `#f9f9f9`、侧栏 `#dff1ea`、brand `#4fa98f`；侧栏/选中面是 accent 叠白派生的固化字面值）；dark=mint-dark 实测 + 结构推导。19 token 名单不动，唯一 palette 家不动（ADR-0257 保持）。
2. **D2 合同改锚定**：全矩阵对比度断言废除；新断言 (a) 15×2 token == 锚定值（防漂移）；(b) 对比度仪器保留，断言偏离集合 == 已知集合（值动集合动，强制同提交改账本）。
3. **D3 偏离透明**：全部 WCAG 偏离（分隔线 1.x:1、三级文字 2.8–4.4:1、主按钮白字 2.79:1 等）为 Qoder 原样继承，清单入 Note；VF-4「超越」批以逐用法分析决定修正。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| A 调值保合同（换 Qoder 同族更深档） | 否决（用户裁决）：像素偏离即复刻失败；VF-2/3 失去基线意义。 |
| 静默放宽阈值 | 否决：无机制的放宽即绿灯漂移（pitfalls）。D2 锚定+集合断言是机制。 |

## 后果

- 视觉基线 = Qoder 0.4.4 mint 系，VF-2/3 由此出发。
- 可访问性责任移交偏离清单；VF-4 收口时逐项裁决。
- 锚定值只随显式基线升级批变动；锚定断言拒绝随手改值。
