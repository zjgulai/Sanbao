# ADR-0237 · 回复操作与后续建议：投影动作清单、确定失败判据与只填不发的建议

- 状态：accepted（2026-10-03）
- 日期：2026-10-03
- 决策者：agent（取证并实施；FW-035、US-188 已定方向）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-03-reply-actions-and-suggestions.md)
- 相关：[ADR-0212](ADR-0212.md)（005 会话通道）、[ADR-0213](ADR-0213.md)（006 停止）、[ADR-0236](ADR-0236.md)（036 编辑重发）、[ADR-0229](ADR-0229.md)（032 方案投影）

## 背景

工单 037（FW-035，US-188）：**回复操作区只提供已核实动作**（复制、引用、**仅确定失败时
重试**）；**「后续建议」点击只填入输入区，不自动发送**。产品证据 M01.reply.actions（原型
含复制/评价/分支与三条建议 chips；评价与分支不在本票）。**取证中发现一个跨票真实缺陷**：
基座的 `turn/end` 以**对象**写入原因（`dsh-agent-loop`：`{kind: 'completed'|'blocked'|
'max-tokens'|'aborted'|'error', …}`），而 005 的 fold 与 009 的 history 只认字符串（
`typeof data.reason === 'string' ? … : 'ended'`）——真实运行恒落 `'ended'` 兜底，fakes 喂字符串
故测试全绿（与 034 的 queue-edit 同类假绿）。037 的「确定失败」正需要该词表，本票一并修。

## 决策

1. **D1 原因归一词表（跨票修复）**：导出 `turnEndKind(data)`——字符串原样（旧证据/假件
   兼容）、对象取 `kind`、其余 `'ended'`；005 fold、009 history detail、031 监控与侧聊沿用
   同一词表。`lastTurnEnd ∈ {completed, blocked, max-tokens, aborted, error, ended}`。
2. **D2 动作清单＝投影事实**：`SessionChannelStatus.reply = {text, endKind, failed, actions}`；
   `actions` 在无回复文本时为空，有文本时恒含 `copy`、`quote`，**`retry` 仅当
   `endKind === 'error'`**（确定失败）；渲染面只画清单里的按钮（不本地自判）。
3. **D3 未知只给核对**：流断（`streamBroken`）不撤 `copy/quote` 但**撤回 `retry`**，
   改给「核对（重新读取会话）」——核对＝只刷新，零写调用；成功发送的判定「受理≠执行」
   文案照旧（与 005 同判据）。
4. **D4 重试＝同一发送入口**：点击 `retry` 取**最近一条用户行文本**走 `/.sage/session/send`
   （普通发送路径，新身份由通道铸造）；回执 accepted（受理≠执行）/deferred（暂停只登记）/
   refused（未确认送达→只给核对，不自动重试）；在途按钮禁用（不并行）。
5. **D5 后续建议＝方案投影可推进步骤**：取最新方案 `steps` 中 `readiness==='ready'` 者（≤3）
   为 chips；点击**只填输入区**（零请求、不自动发送）；方案未接线/无可推进步骤各有具名
   负空间句（不以固定文案冒充建议）。
6. **D6 首版不做**：自定义回复模板、回复评分反馈、建议的自动追问（工单边界）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 保留字符串 reason 解析不动 | 否决：真实运行恒 `'ended'`，「确定失败」不可判——本票验收需要该事实。 |
| 渲染面本地判断失败/未知 | 否决：动作清单必须来自投影事实（不显示无后端依据的按钮）。 |
| 流断时连 copy/quote 一起撤 | 否决：文本已读到的事实不因流断作废；撤的只是需要"确定"的重试。 |
| 未知后自动重试/直接恢复重试钮 | 否决：US-187/021 三态纪律——核对后才可能回到可重试。 |
| 建议用静态固定文案 | 否决：UI 层禁"无后端依据"；宁缺（具名负空间）不演。 |

## 后果

- 验收两条机器断言：① 未知（流断）态不出现「重试」按钮、只出现核对入口；② 点击建议后
  输入区有内容且**零请求**（未发送）。
- 跨票修复随行：005 fold / 009 history / 031 监控 / 侧聊统一经 `turnEndKind` 取 kind；
  005 spec deliberate 增补（send 身份断言与 messageRef 已在 036，此处新增 reply 事实不破）。
- §1.6：真产物两页——确定失败态（[复制回复][引用][重试上一轮（确定失败）]＋引用句）
  ＋后续建议（2 chips「建议：按渠道部口径生成拆分表/输出对外说明的一页摘要」）；真实 Chrome
  DOM 读数：引用填入输入区且**跨轮询保留**（本地反馈守护）、建议点击只填不发（标题/零请求）、
  流断态 `retry[absent] audit[present]` 与「只给核对入口，不给重试。」句。
- 已知未闭：评价/分支（原型其余动作）与建议的模型来源后置；真机 Electron 未跑。
