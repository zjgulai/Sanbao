# ADR-0258 · RUNTIME-03B：权威 density root、semantic geometry 与重启恢复

- 状态：accepted（2026-10-04）
- 日期：2026-10-04
- 决策者：用户（lute，确认执行 Batch 11）
- 决策记录：[Note](../notes/implemented/surface/2026-10-04-display-density-application-batch-11.md)
- 相关：[ADR-0257](ADR-0257.md)、[UI 一致性合同](../specs/2026-09-27-sanbao-to-sage-ui-consistency-contract.md)

## 背景

Batch 10 已完成 display theme 的持久化、Electron 应用、root observation 与 restart，但 density 仍只被保存，未驱动产品。Sage 需要一个用户可见、framework-neutral 的窄切片：把 `comfortable | compact` 接到权威 root 与 computed geometry，同时继续守住 unknown、fail-closed、只读工作台和零业务写入边界。

## 决策

1. `product/theme-tokens.ts` 在唯一 token owner 内新增独立的 `--sage-density-*` geometry 轴，exact roles 为 nav item padding、main padding、card padding、row gap 与 control minimum height；不得混入 theme palette、typography 或第二份 spacing owner。
2. comfortable 精确保留 Batch 10 当前值；compact 只收缩列明 geometry，不改变字号、行高、文案、信息层级、可见事实、focus 顺序、actionability 或 authority。
3. renderer 只把权威 `preferences.requested.density` 写成 root `data-sage-density=comfortable|compact`；malformed、missing、`null` 或 unavailable 写 `unknown` 并清旧值。unknown/missing 只使用 comfortable 视觉 fallback，不回写、不新增 effective density。
4. 保存成功后设置页、快捷菜单、root 与 computed layout 同步；保存失败必须重读存量 projection 并回退。theme 与 density 可即时应用，其余六项继续只保存。
5. 完成证据必须来自真实 Electron：light/dark 的 comfortable→compact→comfortable computed cycle、1440、760 drawer、约 320 CSS px reflow、keyboard/focus/Escape、第二进程 compact restart、六态/production-null、blocked ActionPreview 与零业务写入；Fake DOM、字符串或 PNG hash不能单独形成完成结论。
6. 本批不实现其余六项 display preference，不引入 React/Vite/dependency/package/lockfile，不新增组件、ActionIntent、route/provider/Host/persistence 或真实业务 mutation，也不声明完整 Qoder UI/UX 或 production 已完成。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| renderer 内单独维护 density 常量 | 否决：产生第二个 geometry 事实家。 |
| viewport 自动决定 density | 否决：响应式布局不能替用户 requested preference。 |
| unknown 直接投 comfortable | 否决：把视觉 fallback 冒充权威状态。 |
| 顺带改变字号、内容宽度或 IA | 否决：超出 density-only，分别留给完整 RUNTIME-03 与 UI-DECISION-01。 |
| 复制 Qoder / Sanbao CSS 或 runtime | 否决：原型仅作只读交互证据。 |
| 同批引入 React 或真实业务写链 | 否决：混淆显示偏好闭环与技术栈/授权决策。 |

## 后果

- RUNTIME-03B 的 persisted density → projection → root → semantic geometry → restart 子链本地闭环。
- compact 提供真实高密度工作台；comfortable 与 Batch 10 视觉基线一致，非法/未知 projection 不会留下 stale compact 或假权威值。
- 完整 RUNTIME-03、UI-DECISION-01、真实事项 ActionIntent/provider、production E2E 与完整 Qoder UI/UX 复刻仍未完成。
- 改动仍在 `main` 工作区，未 stage、未 commit、未 push、未 merge、未发布。
