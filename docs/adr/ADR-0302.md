# ADR-0302 · 执行模块第四刀：变更摘要与差异审阅

- 状态：accepted（2026-10-11）
- 日期：2026-10-11
- 决策者：用户（lute：同意 Loop-Q R4）＋ agent（取证与实施）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-11-diff-review.md)
- 相关：[ADR-0301](ADR-0301.md)（turnProcess 基线）、[ADR-0296](ADR-0296.md)（D2 diff 面登记）

## 背景

Loop-Q R4 三行：`QDR.A01.changes.created`（本轮修改摘要：文件数 · +A/-R · 撤销/审阅/文件入口）、`QDR.A01.diff.created`（差异面板：文件列表/行号/绿色新增/复制路径）、`QDR.A01.diff.modified`（红绿替换行、折叠未改动行）。盘点基座 `tool-fs`：编辑工具把展示用 diff 写进 `tool/result.meta`（`{diffs:[{path,oldText,newText}]}`，持久入日志——"persisted so a UI bridge reproduces the card on replay"）；`write` 创建时 meta.diffs 为空（`operation:'create'`），但 `tool/call.arguments.content` 携带全文。Sage 缺口：fold 不读 meta。

## 决策

1. **D1 fold 读 meta（durable 唯一源）**：`tool/result.meta.diffs` 提取为有界 hunk（≤4 hunk/项、60 行/侧，超限补「…」），added/removed 按行计；全空 diffs 视为「无 diff 事实」；`write` 创建回退 = call 侧 `arguments.content` 作为纯插入。basename 规则不变（机器路径不过投影）。`meta` 只在 `isError !== true` 时采信。
2. **D2 契约与解析**：`turnProcess.fileWrites[]` 增 `added/removed/hunks[{old,new}]`（null/空为未知，绝不猜）；desktop 宽容解析逐片校验。
3. **D3 renderer**：footer 增「本轮文件修改摘要：N 个文件 · +A/-R」+「审阅」按钮（与「执行过程（N）」共享展开态）；列表项增 +A/-R 与嵌套「查看本次修改」（hunks 以 `-`/`+` 前缀行渲染，red=`--sage-danger`、green=`--sage-success` 语义 token 低透明度底色）。这同时**闭合 ADR-0301 登记的 M02 入口 blocker**（blocker 已改写）。
4. **D4 未装面显式登记**：审阅面为**回合流内联**（非右侧独立面板）；「撤销」「复制路径」「文件树」入口不接线（写回与文件打开面未装配）——blocker 明写。三行迁 `ui` `pending→implementing`；summary 生成器重算（25→28 implementing、173→170 pending、verified 8 不变）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 审阅面板塞进受控预览容器 | 否决：预览容器按 artifact 版本守卫的文档面；diff 是回合过程事实，不abuse该machine。 |
| 右侧独立 diff 面板（Qoder 形） | 登记：需 rail/面板职责扩展设计；本刀内联面先行并如实登记差异。 |
| 折叠未改动行 | 采纳日志自身 hunk 粒度（patch 上下文折叠由基座完成）；renderer 不重算。 |
| 显示完整路径 | 否决：basename 规则（ADR-0301）不变。 |

## 后果

- 变更摘要与红绿差异可复现（重开可读）；M02「查看本次修改」入口闭合。
- A01 三行迁 implementing；撤销/复制路径/文件树/右侧面板登记 blocker。
