# ADR-0179 · WT-02D.0.1 main-owned `/.sage/*` route skeleton

- 状态：accepted（2026-10-01）
- 日期：2026-10-01
- 决策者：用户（lute）
- 决策记录：[WT-02D.0.1 main-owned /.sage/* route skeleton 落地](../notes/implemented/architecture/2026-10-01-wt02d01-main-sage-route-skeleton.md)
- 相关：[ADR-0174](ADR-0174.md)、[ADR-0177](ADR-0177.md)、[ADR-0178](ADR-0178.md)

## 背景

ADR-0174（revision 37）确定 Electron main 独占 Application Service，但源码未动：`/.sage/state` 与 `/.sage/actions` 仍由 Host 子进程响应，projection-read 与 action 都在受信边界之外。WT-02D.0.1 是唯一编排边的第一笔源码，目标是在不引入任何真实 provider 的前提下，把 route 精确截在 main、以 unavailable-first 骨架启动、并用机器可判定的方式守住进程边界。设计 spec（五裁决 A/A/A/A/A）与五任务实施（T1–T5）已全部落地，本 ADR 记录其架构决定。

## 决策

1. **main 精确截获 + 环境开关回退（D1）。** `main/index.ts` 的 `protocol.handle` 对 `/.sage/*` 先于 `host.fetch` 分流；`SAGE_APP_SERVICE=off` 为显式维护态，`/.sage/*` 原样转发 Host 旧路径（Host handler 0.1 期间暂留，删除属 WT-02D.1）。开关启动时读一次，运行中不变。
2. **纯函数内核 + 注入 ports（D2）。** 新目录 `apps/sage-shell/src/appservice/`（route-skeleton / composition / errors / contracts）零 Electron import；`main/index.ts` 只做接线。单测走 sage-shell 现有 `node --test` runner。
3. **state 双字段合同（D3）。** state 响应在 P0-2 runtime availability 字段之外内嵌 `service` 字段（`unavailable` + 可枚举 reason + opaque correlation）；renderer 现有消费不破。
4. **caller binding 接线位（D4）。** `main/appservice-binding.ts` 的 `verifySageServiceCaller` 做 origin 校验 + FramePolicy generation 单帧事实检查，返回 opaque `CallerBinding`（不含 transport identity）；binding 失败 = 403，成功 → 继续到 unavailable 响应。完整逐步重验（command 顺序 1–10）属 0.2。
5. **import firewall 由门禁守住（D5）。** 静态 import 扫描（断言 `src/appservice/**/*.ts` 不 import electron/renderer 实现/Cordis/plugin/packages/vendor/node_modules，空射程判红）注册进 `pnpm run gate` 两项：`sage-appservice-import-firewall`（阻塞）+ `-selftest`（负例判红能力）。

Production composition 全程 unavailable-first：state 返回 `service.status='unavailable'` + `identity-unavailable`，dispatch 503 + 脱敏错误体（无 stack/message 键），无任何 fixture/placeholder 注入口；providers 只能由 main 接线注入真实 snapshot。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 直接切换、出事 git-revert 回滚 | 否决；回滚窗口内边界仍暴露且无运行时护栏，开关回退可审计。 |
| main 与 Host 双写 `/.sage/*` | 否决；违反唯一 owner（ADR-0174 第 1 条），双响应漂移出第二 authority。 |
| 内核写死 main（直接 import Electron） | 否决；无法静态守进程边界，内核退化为不可单测的 main 代码。 |
| appservice 独立子进程 | 否决；0.1 无 provider 可隔离，不预付接缝成本；0.2 再评估。 |
| binding 完整复刻 rev40 command 顺序 | 否决；无对手方可验，完整复刻只能 fixture 自证；骨架期 403/继续二值可真实断言。 |
| firewall 只写测试不进门禁 | 否决；「知道≠拦住」（pitfalls P-03），不进 gate 的检查会腐烂。 |

## 后果

- on 态 `/.sage/*` 不再进 `host.fetch`（fallback.spec 断言 + main/index.ts 唯一命中在非 `/.sage` 分支）；off 态是唯一回退通道，Host 旧 handler 删除前必须保持可回退。
- 缺 provider 全部 fail closed；command 顺序步骤 2–10（Identity/Policy 求值、strict rehydrate、Compatibility、Registry、idempotency/receipt）留 0.2，本票只有步骤 1 骨架与稳定拒绝。
- gate 23→25 项；既有全量测试 45 files / 417 tests 双态（on/off）全绿。
- 验收期发现既有物化缺陷（`HOST_LIB_FILES` 未登记 `product/component-renderer.js`，`7bf1d91` 引入）：当前任何 generation 无法 live 启动，off 态实弹冒烟受阻、退回 fallback.spec 断言并如实登记；修复另票，不混入本 ADR 票。
- 详见决策记录（Note）中的五条验收原始读数与遗留登记。
