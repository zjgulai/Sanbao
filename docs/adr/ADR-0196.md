# ADR-0196 · WT-02C.2E.3：Host protocol v5 运行态有效观测（ready 携带）+ E.2 默认标记并入

- 状态：accepted（2026-10-02）
- 日期：2026-10-02
- 决策者：用户（lute：三裁决——通道/观测面/并入范围均按推荐）+ agent（实施与实测）
- 决策记录：[WT-02C.2E.3 Note](../notes/implemented/architecture/2026-10-02-wt02c2e3-runtime-effective-observation.md)
- 相关：[ADR-0168](ADR-0168.md)（C2B 边界）、[ADR-0191](ADR-0191.md)（E.2）、[ADR-0192](ADR-0192.md)（0.2.0 换装）、[ADR-0195](ADR-0195.md)（帧名称面）、[设计](../superpowers/specs/2026-10-02-wt02c2e3-runtime-effective-observation-design.md)

## 背景

E.2 登记的遗留①「默认 preset 运行时判定」只能从 host 内 live dsh runtime 读取（registry `defaultId = selectedDefault ?? config.default`；`remoteExportList()` 已给出带 `isDefault` 的 roster）。本票执行「Host protocol 扩展」：让 main 观测运行态有效配置并把默认标记并入 stable descriptor；协议从 v4 升到 v5。

## 决策

1. **D1 通道 = ready 携带（协议 4→5）**：host 在 ready 前观测一次，`ready` 事件新增 `runtimeEffective` 字段；host 与 main 共用 protocol.ts 的类型与深校验（exact-keys、拒 Proxy/getter/多余键、长度上限）；绑定 boot、沿用现行 invalidation、零 renderer 可达面；旧 v4 generation fail-loud 拒配（须重物化）。
2. **D2 观测面 = defaultId + roster**：`{kind:'observed', defaultPresetId, presets:[{id,isDefault,broken?}]}`；`unavailable` 原因 ∈ `registry-service-absent|invalid-roster|observation-failed`；不变量=恰一条 isDefault 且等于 defaultPresetId（悬空默认 fail closed）；`broken` 仅观测、不并入 descriptor。
3. **D3 E.2 并入**：`preset.behaviorConfigurationDigest` / `agent.behaviorConfigurationDigest` 的 canonical 文档改为 `{defaultPresetId, members:[{id,trust,contractHex}]}`；新增第 8 个 unavailable code `runtime-effective-unavailable`；stable 对变更=预期矩阵键事件。
4. **D4 语义面**：观测实现内 `remoteExportList` 必须带接收者调用（本票首版脱挂 `this` 被真机 smoke 判红后修复）；`@deepseek-ai/dsh-agent-preset-registry` 保持非壳依赖（结构类型）。
5. **D5 matrix 重发登记**：无按稳定对键控的物理制品；重发义务登记给真实 Matrix Authority 发布票。
6. **D6 发现登记（非本票引入）**：`llm-deepseek` 等 4 条 host 面行因缺 peer 包（npm 存在但未入 profile）运行时导入失败，K 世代同病；后续票处置（seed peer 闭包 + 模型 route 功能探针）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| main→host 请求路由 / Node IPC 请求响应 | 用户裁决否决：新增 renderer 面堵点与 freshness/IPC 机制，成本大于 ready 携带。 |
| 观测面仅 defaultId | 否决：roster 与 defaultId 同源，代价近零且携带 broken 信号。 |
| descriptor 并入另票 | 否决：① 一次性收口（用户裁决）。 |
| 行级 enablement 全矩阵 | 否决（本票）：登记未来消费者。 |

## 后果

- **读数（2026-10-02）**：隔离根 `sage-e3-accept.qbcmtXWANV` 修复后 generation `4b8e7dfb`：smoke **19/19**（含 `default=standard presets=[standard,ptc,minimal,cordis]` 三条新断言）；套件 **621+1skip**；typecheck 0；三层 gate **25/25**。goldens：4 变 + 9 独立未变 + C2B canonical 重锚（探针实算后固化）。
- **教训**：跨边界方法必须带接收者调用；假 fixture 不用 `this` 即覆盖洞（真机 smoke 是唯一咬住该缺陷的仪器）。
- **遗留**：4 行 import 失败（peer 闭包缺口）处置票；行级 enablement 全矩阵；selectedDefault 运行时切换细粒度失效（引入壳内默认切换面时重审）；运行态 env 合并；matrix 物理重发。
