# ADR-0156 · Deep Research 出货产物同步与终审缺陷修复

- 状态：accepted（2026-09-21）
- 日期：2026-09-21
- 决策者：用户（lute），明确批准同步当前已提交源码，保留新入口/编辑/导出能力并修复终审缺陷
- 决策记录：[Note](../notes/implemented/surface/2026-09-21-deepresearch-artifact-sync.md)

## 背景

[ADR-0155](ADR-0155.md) 的源码职责拆分不能代表旧出货 bundle 的行为基线。补齐真实构建后，既有源码中的入口、编辑与导出能力以及 Host 守卫开始进入产物；终审同时暴露 HTML 注入、删除后依赖错位与 CSS 大整数精度缺陷。基线与各项处置以决策记录为准。

## 决策

把产物同步单列为用户批准的行为变更，不恢复旧 sidebar 注册来伪装保真。保留当前已提交源码的 optional deepresearch-workbench 与 overlay-only 注册、预算/来源选择、问题编辑及导出能力，只在包内修复三项缺陷。生成文件必须通过实际构建更新。
