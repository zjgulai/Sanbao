# ADR-0131 · 品牌收口：出货产品改名 WorldPilot，LUTE 退为内部标识，换皮射程 20 处含签名身份

- 状态：accepted（2026-09-19）
- 修订：射程落点数由初判 16 改判为实测 20（逐落点枚举后 tray 彩色档与模板档、安装器 app 与 install.sh 文案应各自独立计数）
- 取代：**本 ADR 的 D1 与 D2/D3 中「产品名 = WorldPilot」的部分已被 [ADR-0136](ADR-0136.md) 取代**——产品名定为 Sanbao / 三宝，WorldPilot 降为视觉语言供体。射程结构、签名身份纳入、泄漏清零、换皮不改承载四条决策继续有效。
- 决策者：用户（lute）+ WorldPilot 全维度换皮轮
- 素材源：`github.com/lillian-maker/WorldPilot`（`brand/logo/`、`digital-employees/`、`website/`）
- 相关：ADR-0008（基座只 pin 不改）、ADR-0009（一份事实一个家）、ADR-0012（包名不改）、ADR-0015（Note 纪律）、ADR-0019（官方 UI 改写锚禁止钉哈希）、ADR-0022（头像走官方 `icon` 字段，图标库是唯一事实之家）、ADR-0056/0057/0058（DMG 发布红线）、ADR-0130（面改乘官方 slot）；总账 P-07（一条事实多个家）

## 背景

现状是本仓库同时挂着**三套半品牌**：对外的 `LUTE Agentic System`、侧栏品牌座上的 `路特创新 / AgenticOS`、
boot 字标上语义为 `ROOT` 的 R∞T 图形，以及**从未被品牌化过的基座残留**——`manifest.webmanifest` 里
仍写着 `"name": "DeepSeek Harness"`、`"short_name": "DSH"`，`dsh-agent-team-gui-local/src/client/i18n.ts:85,87`
的用户可见文案仍是「请重启 DeepSeek Harness」。`brand-replay.sh` 的射程只覆盖 app bundle，改不到插件包，
所以这条泄漏一直活着。

同时，主色 `#58B848` 经全仓实测（排除 `node_modules`、`.app-cache`、`vendor`、`.dsh-types`）
命中 **33 个文件**，其分布是：**10 个源定义家**（`brand.tsx`、`shared/client/lute-tokens.ts:43`、
`newapp.module.css` Brand block、`theme-settings.ts`、`presets.ts`、`accent-swatches.ts`、
`skill-panel.module.css` 六处、`dsh-wanzh-hulian/lib/client.js` 四处、
`brand-payload-wordmark.txt`、官方 UI 补丁 `dsh-client-ui-agent-preset/lib/client.js.patch`）、
**6 个生成物副本**（各包 `lib/client.js`）、**7 个测试复述**
（`brand.test.tsx:12`、`layer-icons.spec.ts:61`、`theme-tokens.test.ts`、`accent-swatches.test.ts`、
`stylesheet.spec.ts:85`、`hero-fixture.ts`、`agent-fullstack.test.mjs:342`）、
**4 个校验器**（`verify-patches-v2.sh`、`verify-layer-icons.mjs`、`root-brand-live-anchors.mjs`、
`geometry-probe.mjs`）与 **3 个未跟踪本地文件**。其中 `verify-patches-v2.sh:105` 把
`#58B848` 当作**补丁锚文本**——它必须是字面量，因为补丁按精确文本匹配。
这正是总账 P-07 的形状，且规模远超「四个家」的直觉。

素材源仓的岗位数据经逐条比对与本仓 `role-catalog.json v2.0` **同源**：`workforce.json` 的 AGT-001…050
职责 50/50 命中（9 处差异仅拉丁词两侧空格的排版）、花名 50/50 全等、四平面×八责任域结构一致。
因此「换皮」在这里不是抄一个陌生品牌的皮，而是**把同一个产品的两套既有表达收口成一套**。

## 决策

**D1 单品牌收口：出货产品即 WorldPilot。** 对外只留一个名字，不存在「底座名 + 皮名」并存的中间态。
`路特创新`、`AgenticOS`、`ROOT`、`LUTE Agentic System` 作为对外表达全部退役。

**D2 LUTE 退为内部面，不可动锚保持不变。** npm 包名、目录名、`luteOrigin`/`luteOwner`/`lutePublish`
三元组、`/Applications/DSH Desktop.app` 路径、可执行文件名、`appId ai.deepseek.dsh.desktop` 一律不改
（ADR-0012、ADR-0008）。改名只发生在**显示面**，不发生在**寻址面**。

**D3 射程为 20 处出货可见面，含签名身份。** 完整清单与其现状/目标值见
`.scratch/worldpilot-reskin/surface-map.md`（本 ADR 的射程表，唯一权威）。签名身份一并改为
`WorldPilot Code Signing`：实测该证书由 `packaging/scripts/ensure-signing-identity.sh` **本机自签**
（无 Developer ID、无 notarization），而 TCC 授权与应用数据目录挂在 `appId` 与磁盘路径上、
不挂在签名身份上，故换身份的成本是重跑一次自签脚本，**不构成客户升级断链**。

**D4 品牌泄漏清零属于射程，且必须防新增。** 存量三处（`favicon.svg`、`manifest.webmanifest`、
`agent-team-gui` 的 i18n 文案）随本轮改完；改完后由门禁拦住「出货可见面里再次出现基座原名」，
不靠人记得。

**D5 换皮不改承载。** 只改表达（图形、颜色、图像、文字、材质、字体），不改 ADR-0130 定的
slot 挂载、事件通道与面板几何契约。`sidebar-row-axis` 的行轴、`--radius` 之外的布局轴、
零 z-index 约束（ADR-0128 D2）在换皮后必须与换皮前逐字节同形。

## 备选方案

| 方案 | 为什么未采用 |
|---|---|
| 双品牌分层：LUTE 是底座，WorldPilot 是 preset/profile 的一层可切换皮 | 契合 ADR-0061 的 profile 装配哲学，但会让每一条文案位都要回答「这句给谁看」，16 处射程表退化成 32 处，且 P-07 的「一条事实多个家」从 4 个家涨到 8 个。当前没有任何消费方需要第二套皮 |
| 只借视觉语言不借名字（保留 LUTE 名 + 采纳 WP 标与钛银） | 字母标是 W/P、名字是 LUTE，图形与文字互相否证，比现状更乱 |
| 射程不含签名身份 | 技术上更保守，但收益是零：证书自签、客户链本就不经过信任链，不改只会留下「内部面里唯一一个对外可见的身份」这种别扭状态 |
| 先改 UI 面、打包链留下一期 | 会出现「下载文件名与安装后界面不同名」的中间态，且 `dmg-layout-doc` 门禁的入口表要同时容纳两套名字 |

## 后果

- **正面**：对外品牌从三套半收敛为一套；主色十六进制有了借 D3 射程表收口的契机；
  102 位头像里**只有 52 位有实岗**：AGT-001…050 与本仓逐条同源可零映射直投，AGT-051 BoBo（管理员）
  与 AGT-052 筑程（全栈工程师）为素材源仓新增已配置岗；AGT-053…102 共 **50 位是纯占位**
  （`job: 待分配岗位`、`plane: 扩展成员`、`deliver: 待岗位配置后确定`），不可当作可用岗宣传。
- **负面 / 需跟进**：
  1. 签名身份变更后，`packaging/scripts/ensure-signing-identity.sh` 必须能生成新身份的证书，
     且旧身份证书是否保留决定老 bundle 能否复现构建——需在执行期单独裁决并登记。
  2. `dmg-layout-doc` 门禁的 `INSTALL-GUIDE.md` §2 入口表随 DMG 名/卷名变更必须同步，
     否则 R3（未列文件）/R4（幽灵条目）判红。
  3. 射程表是一份**新的事实**，它本身也会腐烂：必须有门禁或测试断言「出货可见面里不含
     退役名」，否则 D4 只做了一半。
  4. 本 ADR 不决定**怎么改**（token 落点、头像格式、门禁改造、分期），那些是后续 ADR 的射程。
