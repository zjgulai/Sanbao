# ADR-0304 · 执行模块第六刀：任务监控页与回顾卡（P16 收口）

- 状态：accepted（2026-10-11）
- 日期：2026-10-11
- 决策者：用户（lute：同意 Loop-Q R6）＋ agent（取证与实施）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-11-task-monitor.md)
- 相关：[ADR-0301](ADR-0301.md)（turnProcess）、[ADR-0303](ADR-0303.md)（P16 复盘登记）

## 背景

ADR-0303 复盘：`QDR.P16.review.summary`（任务监控区回顾卡）需要 desktop 线的任务监控面，登记为本轮。盘点：`runMonitor` 早已在 state 信封（`RunMonitorView`：steps 轴 + budget/device/background/context 未知轴，state 恰为「诚实未知」——预算与用量来自真实后端计数、无读数即 unknown）；desktop 的「运行模式」页此前是占位通知。

## 决策

1. **D1 监控页装配**：desktop「运行模式」页替换占位——`MonitorPage` 读 state 的 `runMonitor` 槽：步骤轴（执行中/空闲/不可读+reason）+ 四未知轴逐行如实（`未知（reason）`，绝不以零代替）。
2. **D2 回顾卡（P16）**：卡含标题、「更新于 {本地时间}」（来源 = fold 的 `turnProcess.endedAt`，日志自身毫秒戳——**新增上位**，非本地时钟）、展开入口（复用 `TurnProcessFooter`）、产出段（observed artifacts 列表或「暂无观察到产出」）、来源段（「来源读数未接通」——与观察一致的空态）、「更多操作」（最小：返回任务输入）。无已结束回合 → 诚实空态文案。
3. **D3 宽容解析**：`DesktopRunMonitor` 逐轴校验；非法轴退化为 `未知（fallback reason）`；整体畸形 → 槽省略。steps 非法 → 「不可读（monitor-not-read）」。
4. **D4**：P16 迁 `ui` `pending→implementing`（tracked-test refs，`countsAsVerification:false`；blocker 登记：更多操作最小化、真实读数、visualAcceptance）。summary 生成器重算（29→30 implementing、169→168 pending）。执行回流面（session 页 11 行）至此**全部完成迁移**。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 回顾卡塞进会话页 | 否决：行断言为「任务监控区」——独立页与占位页职责相符（原占位即「运行模式」页）。 |
| 「更新时间」用本地时钟换算 | 否决：无权威时间戳即「更新时间未知」；有戳则用日志自身毫秒值。 |
| budget 等轴显示 0 或占位数字 | 否决：T10 纪律——无真实计数即 unknown。 |
| 更多操作直放「取消任务」等未装动作 | 否决：不放假入口。 |

## 后果

- 任务监控页上线（占位退场）；回顾卡可复现且时间可核（日志戳）。
- P16 迁 implementing；执行回流面 11/11 完成。
