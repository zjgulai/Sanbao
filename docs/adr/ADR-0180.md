# ADR-0180 · HOST_LIB_FILES 补全与注册表对拍守卫

- 状态：accepted（2026-10-01）
- 日期：2026-10-01
- 决策者：用户（lute）
- 决策记录：[HOST_LIB_FILES 补全与 host live 启动恢复](../notes/implemented/architecture/2026-10-01-host-lib-files-completeness.md)
- 相关：[ADR-0167](ADR-0167.md)、[ADR-0179](ADR-0179.md)

## 背景

`src/profile/layout.ts` 的 `HOST_LIB_FILES` 注册表自 `7bf1d91` 起缺三个文件（`product/component-renderer.js` / `view-state.js` / `action-preview.js`）：`renderer.ts` 拆出 `component-renderer.ts` 时清单未同步，重新物化的 generation 缺文件、host 子进程启动即 `ERR_MODULE_NOT_FOUND`；盘上旧 generation 物化自旧 lib、发 protocol v3 `ready` 被当前 v4 lib 判 `invalid IPC event`。两态叠加使任何 generation 都无法 live 启动，WT-02D.0.1 的验收 2 实弹被迫退回 fallback.spec 断言（ADR-0179 后果节已登记）。注册表与编译输出之间无任何对拍机制，清单漂移静默发生（pitfalls P-04「写了但从没跑到」家族）。

## 决策

1. **补全注册表**：`HOST_LIB_FILES` 按依赖序补登 `product/view-state.js`、`product/action-preview.js`、`product/component-renderer.js`。
2. **对拍守卫转测试机制**：`test/layout.spec.ts` 新增守卫用例，递归枚举 `lib/{host,product,adapter}` 全部 `.js` 编译产物与 `HOST_LIB_FILES` 双向逐名对拍（漏登、多登均判红）；`profile/paths.js` 与 `protocol.js` 为显式白名单。守卫随 `node scripts/test.mjs run` 全量批执行，注册表漂移从此在提交面被拦。
3. **修清单 + 重新物化，不手补 generation**：generation 是不可变物化产物（manifest/digest 绑定 `runtime-artifact-attestation.json`），手补会破坏 attestation 绑定；正确路径是修清单、build、重新 materialize 出新 generation，指针原子切换。
4. **旧 generation 不清理**：`bee8a015` / `a20738b4` / `2d1b09f9` 留待 runtime-artifact-attestation 既有保留策略处置，本票不碰用户数据侧清理。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 只补清单不加守卫 | 否决；本次红证明清单会静默漂移，同型缺陷复发无拦（P-04 家族特征）。 |
| 守卫放 gate（mjs 层） | 否决；编译输出只在 sage-shell 构建后可预期存在，gate 层耦合构建状态；vitest 守卫与全量测试同批覆盖同一提交面。 |
| 手补三个文件进现有 generation | 否决；破坏 manifest/attestation digest 绑定。 |
| 顺带删旧 generation | 否决；超出本票射程，保留策略归 attestation 治理。 |

## 后果

- **host live 启动恢复**：新 generation `d73e1195` smoke 18/18 全 PASS（protocol v4 ready、generation/manifest digest 绑定、`/.sage/state` / `/.sage/actions` 实弹、路径遍历 403、干净关停 exit 0）——ADR-0179 验收 2 的退回理由消除，on/off 两态实弹通道打通。
- 全量测试 46 files / 421 tests 绿（守卫 +1）；typecheck 0 error。
- `layout.spec.ts` 守卫依赖真实 `lib/` 编译产物存在（先 `npm run build`）；全新 clone 未构建时会红并提示先 build——与 smoke/dev 同前置，接受。
- 用户数据侧：active profile 指针切至 `d73e1195`（2026-10-01T05:06Z），旧 generation 未删。
