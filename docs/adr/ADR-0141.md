## 背景

初始实现的右侧侧边栏存在以下问题：

1. **视觉凌乱** - 7 个图标平铺占据过大面积
2. **缺乏质感** - 缺少精致的边框和立体效果
3. **空间浪费** - 图标尺寸过大，排列拥挤
4. **交互单一** - 没有分组折叠，所有功能常驻显示

用户参考 Qoder CN 的设计风格，提出需要：
- 折叠分组减少视觉噪音
- 双层边框 + 微渐变 + 柔和阴影的质感设计
- 更紧凑的尺寸和间距
- 优雅的激活状态反馈

## 决策

### 1. 布局策略：折叠分组设计

采用**折叠分组**而非单列或双列布局：

| 方案 | 取舍 |
|---|---|
| 折叠分组设计（推荐） | 按功能分组，默认只显示组标题，点击展开子项，节省空间 |
| 单列垂直排列 | 每个图标独占一行，清晰但占用过多垂直空间 |
| 双列网格布局 | 更紧凑但可能显得拥挤，不利于扩展 |

**决策依据**：
- 符合现代 UI 设计规范（类似 VS Code、WebStorm）
- 大幅减少初始加载时的视觉噪音
- 保持所有功能的可访问性
- 与 Qoder CN 设计风格一致

### 2. 分组方案

建议分为**3 个逻辑组**：

```
📁 工作区 ▾
  ├── 📋 待办任务
  └──  环境信息

📁 工具 ▾
  ├── ⚡ 技能和 MCP
  ├── 🔍 网页查阅
  └── ⚙️ 后台进程

📁 信息 ▾
  ├── 📦 产出
  └── 📚 来源
```

**分组原则**：
- **工作区**：高频操作，日常开发核心
- **工具**：中频辅助，按需使用
- **信息**：低频查看，被动获取

### 3. 尺寸规范

```css
/* 图标尺寸 */
icon-size: 24x24px;

/* 间距 */
group-padding: 8px;    /* 组内图标间距 */
section-margin: 16px;  /* 组间间距 */

/* 容器 */
border-radius: 8px;    /* 圆角 */
width: auto;           /* 自适应宽度 */
```

**设计依据**：
- 24x24px 是标准图标尺寸，清晰可点且不过大
- 8px 组内间距保证视觉呼吸感
- 16px 组间间距明确分组边界

### 4. 视觉风格：Qoder CN 风格

#### 双层边框
```css
border: 1px solid rgba(255, 255, 255, 0.1);          /* 外层细线 */
border: 1px solid rgba(255, 255, 255, 0.2) inset;   /* 内层高光 */
```

#### 微渐变
```css
background: linear-gradient(135deg, 
  rgba(255, 255, 255, 0.05) 0%, 
  rgba(255, 255, 255, 0.02) 100%
);
```

#### 柔和阴影
```css
box-shadow: 0 4px 6px rgba(0, 0, 0, 0.1),
            0 2px 4px rgba(0, 0, 0, 0.06);
```

#### 玻璃态背景
```css
background: rgba(30, 30, 30, 0.7);
backdrop-filter: blur(10px);
```

### 5. 激活状态

当某个模块面板打开时：

```css
/* 高亮背景色 */
background: rgba(88, 184, 72, 0.15);  /* 品牌绿 tint */

/* 发光边框 */
box-shadow: 0 0 0 2px var(--lute-brand),
            0 4px 6px rgba(88, 184, 72, 0.3);

/* 图标变色 */
color: var(--lute-brand);
```

## 备选方案

| 方案 | 取舍 |
|---|---|
| 极简单线边框 | 扁平化，但缺乏深度感和质感 |
| 玻璃态毛玻璃 | 现代感强，但性能开销较大 |
| 纯颜色填充 | 简单直接，但不够精致 |

## 后果

### 正面：
- **视觉清爽** - 折叠分组大幅减少初始视觉噪音
- **质感提升** - 双层边框 + 渐变营造立体感
- **空间优化** - 紧凑尺寸节省垂直空间
- **交互优雅** - 平滑动画过渡提升体验

### 负面：
- **实现成本** - 需要重写 CSS 样式和分组逻辑
- **学习成本** - 用户需要适应折叠交互模式
- **代码复杂度** - 增加状态管理和动画逻辑
