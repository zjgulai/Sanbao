# ADR-0191 · WT-02C.2E.2 RuntimeInventoryProvider 组合：stable descriptor + full inventory evidence

- 状态：accepted（2026-10-02）
- 日期：2026-10-02
- 决策者：用户（lute）
- 决策记录：[WT-02C.2E.2 RuntimeInventoryProvider 组合](../notes/implemented/architecture/2026-10-02-wt02c2e2-runtime-inventory-composition.md)
- 相关：[ADR-0165](ADR-0165.md)、[ADR-0166](ADR-0166.md)、[ADR-0167](ADR-0167.md)、[ADR-0168](ADR-0168.md)、[ADR-0184](ADR-0184.md)、[ADR-0187](ADR-0187.md)、[Compatibility Authority](../notes/proposed/architecture/2026-09-28-compatibility-authority.md)

## 背景

Wave 22 的 C2E 切片要求由 Electron main 汇合 C2A/B/C/D、PMAP、trusted clock 与 instance authority，**同时产出 stable runtime descriptor 与 full inventory evidence**。E.0（ADR-0187）交付 PMAP 合同与静态 producers；V2 生产者合同（解析与 `compute*DigestV2`）已在 `compatibility.ts` 冻结；C2B 投影完整。但七个 provenance 字段（receipt / materializationInstance / instanceAuthority / mainObservationProvenance / health / liveness / registrySnapshot）与三个顶层 policy digest（protocol / launch / overlay）在全仓无生产者、无定义；C2D.2A registry 与 C2C.5 外部能力未落地——组合层必须先定义这些事实的 canonical 形态并给出具体生产者。

用户四裁决（2026-10-02）：生产 main 接线 + 恒 unavailable（deps 到位即活）；health/liveness 本票定义最小语义（仅 provenance 陈述，resolver 不据此放行）；观测窗口复用 C2B 窗口；registry 必需端口、缺席即 unavailable（不构造空 capabilities 冒充）。

## 决策

1. **D1 组合形态与固定顺序**：新模块 `src/main/runtime-inventory-provider.ts`（main-owned、端口全注入、零模块级 I/O、内核零改动）。固定顺序 C2B → readActiveProfile（漂移即 `active-profile-unavailable`）→ PMAP（按面表完备性）→ policy 文档 → registry → capabilities → 组装 → compute* → 绑定自验 → deep freeze；7 个具名 code，任一缺项 unavailable，永不 placeholder。
2. **D2 四个 policy 文档 + 七个 provenance 摘要本票定义**：全部 `sha256:` + 64 hex、canonical JSON（显式键序）；四文档与七摘要以手写 golden 冻结（稳定对共 13 个字面量）。host.version 取协议主版本正式 SemVer 形 `4.0.0`；overlayPolicy 必须覆盖 local patch 存在性与内容；health/liveness 为最小 provenance 语义（不据以放行）。
3. **D3 六组件映射与 capabilities 派生**：PMAP urn → sha256 同 hex 换形不重算；model 三面 provider 委托；agent.behavior = preset 组件同值（roster 派生）；preset 聚合按 id 排序不敏感 + 包身份另读；capabilities 自 registry 快照派生（approved ∧ 以投影 observedAt 评估 effective；V2 文法；verified/c2c5；behavior/registryDescriptor/adapterMapping 三摘要）。
4. **D4 接线、证据与仪器**：main 单次 read + 一行稳定 stdout；`runtimeInventory` options 透传槽（无消费者，登记）；成对反例（瞬态仅 full 变、语义两者变）与变异 M1–M4 守约束；V2 resolver 消费测试（equivalent/过期/篡改）；真实 generation 集成为显式 opt-in（全树扫描 45–200s）；smoke 的 `/.sage` 断言对齐现行合同（Host 拒面，main 唯一 owner per ADR-0184）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| registry 缺席时构造空 capabilities 冒充 | 否决（用户裁决）；掩盖 C2D/C2C.5 缺项，等同伪造完整证据。 |
| host.version 直接用 `'4'` | 否决；不合 V2 version 文法；`'4.0.0'` 为协议主版本的正式形。 |
| agent.behavior / model 面自模型行推导或省略 | 否决；面表要求 + 权威口径＝模型随 provider 包分发、agent 行为由 roster 派生。 |
| overlay 摘要忽略 local patch | 否决；同 digest 掩盖行为差异；M3 变异证明测试咬住。 |
| 消费测试与真实集成放默认套件 | 否决（实现层）；真实全树扫描负载敏感，默认显式 skip + opt-in 命令，不静默假绿。 |
| smoke 旧 `/.sage` 断言延后修 | 否决；仪器与现行合同矛盾时永红＝无验收；即刻对齐 ADR-0184 语义并给旧 Note 挂更正指针。 |

## 后果

- **读数（2026-10-02）**：611 tests + 1 opt-in skip 全过；typecheck 0；tsc 构建通过；smoke PASS（修复后 16/16）；gate 25/25。golden 13 字面量（四文档独立复算后冻结）；变异四组全红还原；V2 消费 equivalent/过期/篡改三态；真实 generation 终局 `pmap-incomplete`（settings 文档缺失在前——如实读数）；live stdout 一行 `unavailable (pmap-incomplete)`。
- **行为面**：本票后生产 inventory 恒 unavailable（registry 端口不存在）；稳定对已可按固定字段产生并通过 V2 内核自验；C2D.2A/C2C.5 到位即在同一 provider 内放行后续阶段。
- **边界**：C2D.2A/C2C.5/resolver 编排/matrix 发布/Host protocol 扩展/v1 一律不做；内核、C2B、PMAP 零改动；零持久化/零日志/零网络新增。
- **遗留**：默认 preset 运行时判定（Host protocol 票，agent.behavior roster 派生届时并入属正常语义变更）；host/harness 分包 artifact 树粒度；policy 文档与常量同步靠 golden 守；`preset:set` 复合语义；capability 投影与 C2D.1 digest 收敛；health/liveness 待 C2C.4/C2C.5 增强；`runtimeInventory` 槽无消费者；registrySnapshotDigest 换形不重算；smoke 仪器与活动 generation 同代教训入 Note。
