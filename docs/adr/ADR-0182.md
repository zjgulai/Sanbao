# ADR-0182 · WT-02B.2B-pre OIDC 验证纯内核：fail-closed 校验链先于真实 adapter

- 状态：accepted（2026-10-01）
- 日期：2026-10-01
- 决策者：用户（lute）
- 决策记录：[OIDC 验证纯内核收口（变异验证 + 全量回归）](../notes/implemented/security/2026-10-01-oidc-verification-kernel.md)
- 相关：[ADR-0163](ADR-0163.md)、[ADR-0164](ADR-0164.md)、[ADR-0174](ADR-0174.md)

## 背景

WT-02B.2B（真实 OIDC adapter + system-browser callback + vault + session）的硬前置——真实 issuer / client / redirect / audience / scopes——尚未到位。按治理红线「真实登录等待期间只允许纯 kernel、fixture / blocked projection 与 inventory 开发」（[ADR-0164](ADR-0164.md)），验证链（compact JWS 解析、JWKS 选 key、RS256/ES256 验签、ID token claims、provider metadata 精确比对、callback state 一次性 + PKCE S256）若与 adapter 的网络 / 浏览器 / 持久化耦合交付，参数缺位期既无法运行也无法变异验证。设计 spec `docs/superpowers/specs/2026-10-01-oidc-verification-kernel-design.md`（切片 A）确定先落纯内核；Task 1–4（commits `7754172` / `853a5d1` / `f0bca37` / `57e8cbb`）交付 `apps/sage-shell/src/security/oidc/` 四模块，本 ADR 收口其决策。

## 决策

1. **D1 纯内核切片，不冒充登录**：四模块（`jws.ts` / `id-token.ts` / `metadata.ts` / `callback.ts`）为无 I/O 纯函数，互不 import、不进 composition、不接 main / renderer；密钥 fixture 测试内本地生成，不入库不落盘。无网络请求、无浏览器唤起、无 token 交换、无 session / vault。参数到位后 2B adapter 叠加其上，内核接口零返工。
2. **D2 精确相等无规范化 + strict base64url**：issuer / endpoint / nonce / state 全部字符串精确相等（拒绝尾部斜杠等 URL 归一）；base64url 解码 = charset 检查 + re-encode roundtrip 相等——预检实测 `Buffer.from(str,'base64url')` 对非规范形静默产出垃圾字节（如 `bXwwe`、`Buffer.from('a!b@c','base64url')`），roundtrip 比对是唯一拦截层。
3. **D3 ES256 走 node 原生 p1363**：签名与验签均用 `node:crypto` 的 `dsaEncoding: 'ieee-p1363'` 原生承载 raw `r||s`（64 字节）语义，否决 spec 原案的手写 DER↔raw 转换（原生支持存在、手写是 bug 面）；内核保留显式 `signature.length !== 64` 拒绝作为自身契约声明（变异验证实测该检查黑盒不可区分——node 对错误长度自抛错——登记为纵深防御）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 引入 jose / jws 等验签库 | 否决；零新依赖纪律，且库的宽容解析面与 strict 契约相反。 |
| ES256 手写 DER↔raw 转换（spec 原案） | 否决；node 原生 p1363 已覆盖双向语义，手写字节转换是 bug 面。 |
| mock 验签（只测 claims 逻辑） | 否决；真实密码学咬合是验收立足点，tampered / unknown key / DER / 错误长度负例必须打在真 crypto 上。 |
| 验证链与 2B adapter 一起交付 | 否决；参数缺位期无法收口，耦合让变异验证无法隔离到单条校验。 |

## 后果

- 变异验证（2026-10-01）：11 项点名校验逐条「注释实现行 → spec 红 → git 恢复（终态 diff 为空）」，**10 红 + 1 存活有据**（`signature.length !== 64`：node 26 对错误长度 p1363 自抛 `ERR_CRYPTO_OPERATION_FAILED`，探针实测；检查保留为纵深防御）。逐条记录见 `.superpowers/sdd/2026-10-01-oidc-verification-kernel/task-5-report.md`。
- 全量回归（2026-10-01，真实数字）：sage-shell 52 files / 488 tests 全绿（10.07s）；typecheck 0 error；仓根 gate 25/25 通过。
- brief 三处测试数据 bug（`bXww`→`bXwwe`、`aa`→`YWJj`、replayed 用例字面量）在 Task 1/2/4 修正并披露——测试侧最小修数据、实现零改动；后续计划手写密码学测试数据应附 roundtrip 自检。
- 2B adapter 零返工衔接：内核五接口（`verifyCompactJws` / `verifyIdToken` / `verifyProviderMetadata` / `verifyAuthorizationCallback` / `verifyPkceS256`）即 2B 验证合同；真实 provider 接线、浏览器回调、token 交换、session / vault 归 2B 另票。本 ADR 落档不等于真实登录、产品接线或产品验收完成；ADR-0163/0164 fail closed 与 ADR-0174 unavailable-first 边界继续成立。
