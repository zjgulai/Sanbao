# ADR-0218 · 产物卡与侧面预览：线索经 stat 核验成卡、一次打开一个非特权容器、版本冻结与迟到守卫

- 状态：accepted（2026-10-02）
- 日期：2026-10-02
- 决策者：agent（取证并实施；容器落地与失败语义是取舍）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-02-artifact-cards-and-side-preview.md)
- 相关：[ADR-0178](ADR-0178.md)（嵌内容必须走独立非特权 WebContentsView）、[ADR-0207](ADR-0207.md)（文件读 scope 由活会话解析）、设计仓 ADR-0001（`Sage-ui-wiring-design/docs/adr/0001-offline-interactive-html-preview.md`，仓外稿件，离线交互、不开网络与宿主能力）

## 背景

工单 015（FW-004/005，US-031~038/040/042）要求：产物版本就绪后**只更新卡片**；用户点击才由内容端口按
准确版本取内容、由 main 在侧面加载预览；HTML 走离线交互容器与帧禁用不变量；连续点击迟到结果不覆盖、
关闭不被迟到结果重新打开；内容失效显示失败与**同版本重试**，不静默切最新、不重跑生成；首批预览支持
纯文本/Markdown/代码/PNG/JPEG/离线 HTML/PDF（CSV 表格化属 016）；Office 原格式预览后置、仍是文件卡。

基座声明取证（逐字，ADR-0205）：`workspaceFiles`（`@deepseek-ai/dsh-api-workspace-files`）提供
`read`（行页、非 UTF-8/NUL 即 not-text）、`readBytes`（字节窗，`{offset,length}`）、`readAll`（整文件，
超 `maxFileBytes` 拒绝而非截断）、`stat`（opaque `version` token）、`changes`（**观测不是增量**：
"Only instrumented filesystem operations report here; the OS is not watched"）。ADR-0178 D3 已把
"未来 HTML 预览必须走独立非特权 WebContentsView"定为合同；本票是该合同指名的"具体 UI 票"。

## 决策

1. **D1 卡片＝线索核验产物（US-031/034）**：`workspaceFiles.changes` 的每帧只是**线索**；`observe`
   逐条 `stat` 核验——仅当 stat 版本与线索版本一致才写 `ready（版本已核验）`；不一致=未能核验、
   缺失=观察时不存在（保留上一版本）、目录不产卡、dotfile 不产卡；投影只带 name/kind/bytes/version/
   state，**机器路径零出现**。卡片措辞是"运行观察候选"，**不是交付验收结论**；turn-end 边沿触发一次
   有界观察（非计时器、非 OS 监听）。
2. **D2 内容端口按版本（US-035/038）**：桥新增 `workspaceFiles/readBytes`（窗键 `{offset,length}`，
   与 `read` 的 `{offset,limit}` 分开校验）与 `workspaceFiles/readAll`；`readAll` 超限即 `too-large`
   明确失败（不截断、不做容量承诺——US-041 属 016 实测）。HTML/PDF/图片都以整文件或窗读取，
   读取层永不写、永不转换。
3. **D3 一次打开一个非特权容器（US-032/033/042）**：`createArtifactPreview` 持状态机，Electron 容器
   （`preview-window.ts`）落地 ADR-0178 D3/设计 ADR-0001：独立非持久 session、无 preload、无特权
   IPC、`sandbox/contextIsolation` 开启；**只有内存 `sage-preview://` 方案可读**（加载时填、关闭时清），
   其余请求一律取消（无网络、无本机文件）；导航与 window.open 拒绝；HTML 产物页在其内**离线交互**运行。
   **容器只在通过的 open 里创建**（`createContainer` 仅 open 调用、close 销毁——"卡片出现不创建容器"有
   断言）；close 只回收预览（视图销毁+映射清空），不停止执行、不动对话与输入（US-037）。
4. **D4 生成号守卫（US-036）**：每次 open 领一代；stat/read/load 之后各验代——被超越的迟到结果一律
   `artifact-superseded` 丢弃，close 先代++再销毁，迟到结果**永不复活已关闭预览**、永不覆盖新选择。
5. **D5 版本冻结（US-035）**：打开只读**卡片版本**；stat 或 read 任一报出他版本=失败
   `artifact-version-changed`（retryable），**重试仍是同一记录同一版本**——不静默切最新版本；
   任何路径都不重跑生成（生成不在 Sage 手里）。
6. **D6 Office 与二进制是卡不是预览（US-040）**：`office` 打开即拒（`artifact-format-deferred`）且
   卡片显式写"本版无内置预览（不自动转换；**不把可下载写成可预览**）"；`binary` 拒
   （`artifact-format-unsupported`）并标"本版不支持该格式"。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 把每个 `changes` 帧直接当产物卡（不 stat 核验） | 否决：帧是观测不是就绪；版本未经核验的"就绪"是谎报（US-031/034）。 |
| 用 privileged renderer 内 iframe 显示 HTML | 否决：ADR-0178 D3 明禁；嵌内容只能进独立非特权容器的合同。 |
| 预览直接用 `file://` 或 data: 载入 | 否决：`file://` 给预览页本机文件可达面；data: 无法承载受控资源与大小，且不受控。 |
| close 只隐藏容器、复用之 | 否决：合同要求"关闭回收资源"；且隐藏容器会让迟到页继续存活。 |
| 重试时自动读取 stat 的最新版本 | 否决：US-035 点名"同版本重试、不静默切最新"。 |
| 在 015 就接 HTML 相对资源闭包（readRelated） | 否决（本票）：资源 URL 方案未定（设计 ADR-0001），自包含文档之外的引用在容器内自然加载不到（离线）；闭包留待专票。 |

## 后果

- 五条验收各有机器断言：卡片出现零容器创建（工厂计数 0）、迟到结果不覆盖/不复活、close 回收、
  版本变化失败+同版本重试、Office 无预览声明（词表）。
- 桥面 21→24 端点；预览容器为 Electron 侧新增 `preview-window.ts`（本 loop 不启动 app，容器行为由
  注入替身全测、真实视图留待真机）。
- 已知未闭：真机 Electron 未跑（容器、导航/弹窗拒绝、`sage-preview://` 服务为接线代码+替身验证）；
  CSV 表格化属 016；HTML 相对资源闭包与容量承诺（US-041）属 016/专票；MCP/预览进程失效恢复合同
  （设计 ADR-0001 后果项）仍待。
