# ADR-0194 · WT-02C.2E-PMAP.1：preset/provider/model 源面随 0.2.0-rc.2 换代（声明行 + 层叠行模型；preset:set 源包迁移）

- 状态：accepted（2026-10-02）
- 日期：2026-10-02
- 决策者：用户（lute）+ agent（PMAP.1 执行与实测）
- 决策记录：[WT-02C.2E-PMAP.1 Note](../notes/implemented/architecture/2026-10-02-wt02c2e-pmap-row-layer-adaptation.md)
- 相关：[ADR-0187](ADR-0187.md)（E.0 合同）、[ADR-0191](ADR-0191.md)（E.2 组合）、[ADR-0192](ADR-0192.md)（0.2.0-rc.2 换装）、[PMAP 设计](../superpowers/specs/2026-10-02-wt02c2e-pmap-runtime-inventory-design.md)、[E.2 设计](../superpowers/specs/2026-10-02-wt02c2e2-runtime-inventory-composition-design.md)

## 背景

0.2.0-rc.2 删除/改写了 E.0 PMAP 静态层的全部既有来源：`dsh-agent-presets` 包整体删除（presets 换代为层内**声明行** `name: '@deepseek-ai/dsh-agent-preset'` + `config.id`，registry 不扫描目录、不收 preset 路径）；`settings.yaml` 被运行时一次性导入改名（model 选择落在 `agent-default-model` 行的层叠 `config`）；provider 路由不再是 `dsh-llm-<route>` 公式（路由为 llm 包内 `PROVIDER` 常量）。换装票（ADR-0192）只登记不改 PMAP；E.2 的 `preset:set` 面还引用已删的 `dsh-agent-presets`——真实 0.2.0 generation 上 provider 会恒 `pmap-incomplete`，而 E.2 fixture 写同名伪造包，套件呈现假绿。

## 决策

1. **D1 preset 面 = 声明行模型**：层序 = 各 bundle `dsh.bundle.patch` 文件（system）→ profile `cordis.patch.yml`（user，缺文件=合法空层）→ shell overlay（user，必需）；行提取为缩进文本切块（不引 YAML 引擎、不执行 `!!js`）；同 `config.id` 冲突首条 `observed`、后续 `broken`（`preset-id-collision`，镜像 registry 拒绝语义）；零声明=合法空 roster。
2. **D2 provider/model 面 = `agent-default-model` 层叠行配置**：沿层序浅合并（后者覆盖）；路由→包名走静态校准表（`deepseek-official`/`deepseek-account` → `dsh-llm-deepseek-api-key`/`-account`）；原因码 `patch-layer-unresolved` / `preset-row-unparsable` / `preset-id-collision` / `model-selection-unparsable` / `model-selection-incomplete` / `model-selection-row-missing`；`settings.yaml` 不再是选择源。
3. **D3 `preset:set` 源包迁移**：`dsh-agent-presets` → 后继 `dsh-agent-preset-registry`（E.2 provider 与设计 §3 同步修订）；不迁移则生产恒 `pmap-incomplete`。
4. **D4 overlay 为组成必需层**：缺 overlay → PMAP 三面 broken（`patch-layer-unresolved`），E.2 呈现 `pmap-incomplete`（早于 policy 阶段）；「读取被拒」仍是 `policy-document-unavailable`——两态分阶段表达。
5. **D5 证据纪律保持**：层标签 path-free；白名单字段（非白名单 key 不进 evidence）；hostile `!!js` 不执行；digest 公式逐面冻结、goldens 全字面量重锚。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 保留目录扫描（迁到新包 presets/） | 否决；0.2.0 registry 不扫描目录，会观测到永不生效的「影子 roster」。 |
| 引 YAML 引擎静态解析 | 否决；依赖面扩大 + 块内 `!!js` 求值风险；文本切片足够。 |
| settings 与行模型双读 | 否决；settings 已一次性导入 profile patch，双读=双真源。 |
| `preset:set` 留旧包只登记 | 否决；包不存在，生产恒 pmap-incomplete。 |
| 只改 fixture 不查真实 generation | 否决；真实根探针正是暴露源包缺口的手段。 |

## 后果

- **读数（2026-10-02）**：真实 generation `7592e8d0` 双跑 7 行全 observed（4 条 `standard/ptc/minimal/cordis@system` + `deepseek-official/deepseek-flash` + agent `@0.2.0-rc.2`），逐位确定、零写入；同隔离根第三世代 `56302c51`（重建 lib 后重物化）smoke **16/16 PASS**、PMAP 探针 7 行全 observed 零写入；全量 **613 pass + 1 skip（62 文件）**、typecheck 0 错；E.2/pmap goldens 以真实生产者重锚（探针实算后固化，探针已撤）。
- **插件体检（只读盘点）**：0.2.0 `evaluatePluginCompatibility` 对 dsh 族 peerDependencies 逐轴核 runtime 版本；27 个 in-repo bundle 包中 7 个有 dsh 族 peer，当前全部 legacy 隔离、**零 Sage 影响**；4 包区间排除 0.2.0（`dsh-deepresearch-local`/`dsh-loopx-plugin`/`dsh-auto-compact-local`/`dsh-agent-team-gui-local`），未来装入 0.2.0 系 profile 需改区间或 exact-version exemption。
- **遗留**：运行态 effective（默认 preset 标记、enablement 求值）与 Host protocol 扩展另票（E.0 §2 不变）；K7 其余四项按 spec §8 索引。
