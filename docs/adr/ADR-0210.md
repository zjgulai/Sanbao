# ADR-0210 · 事项↔工作区关联：留痕即存储，链接待审、默认环境逐次重验、解除不换源

- 状态：accepted（2026-10-02）
- 日期：2026-10-02
- 决策者：agent（取证并实施；"留痕即存储"与"重验放在哪一步"是取舍）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-02-matter-workspace-links.md)
- 相关：[ADR-0201](ADR-0201.md)（建项走托管）、[ADR-0209](ADR-0209.md)（草案与回执）、[ADR-0190](ADR-0190.md)（授权步骤不放宽）

## 背景

工单 011 要求事项侧显式建立/解除与工作区的关联，并给出三条硬验收：**建立/解除都要有可追溯操作记录**、
**关联动作不读取不上传任何资料内容**、**默认环境不可用时阻断提示、不静默换环境**。既有事实：工作区列表
来自基座 follow 流（012）；引用（013）自带 `workspaceRoot` 与创建时的版本；派发流水线的步骤 3–10
是 fail-closed 且**不允许放宽**（ADR-0190）。

## 决策

1. **D1 留痕即存储**：关联状态不是另一张可变的表，而是**只追加的 JSONL 留痕**（`matter-links/trail.jsonl`，
   0600），当前关联集与默认环境都由**折叠**得出。每条记录有 `linkId`、时刻、动作、事项、工作区与
   **actorRef**（main 按会话状态记 `session:verified` / `session:anonymous`）。损坏的留痕整条判不可读，
   不做半读——半边历史会被折叠成一个"悄悄少了一条"的现状。
2. **D2 链接待审**：`link` 之前必须先读到**实时折叠**里的该工作区（元数据读取，`workspace/follow`）；
   读不到就不落记录。因此"关联动作不读取、不上传任何资料内容"是结构事实：该路径只有 follow 流，
   没有任何 `workspaceFiles/*` 调用（判据对 store 与 wiring 两处源码各有一条断言）。
3. **D3 默认只能来自已链**：`set-default` 只有当目标当前处于已链状态才生效；`unlink` 掉默认所在的工作区
   会**同时清掉默认**（不让"默认"漂到另一个工作区）；`set-default` 不带 workspace 即清除默认。
4. **D4 逐次重验在派发前、流水线之前**：每次 `/.sage/actions` 派发前，main 用**实时折叠**重验该事项
   （`matterId`）的默认环境是否仍在；不在 → 以 `environment-unavailable`（stage `environment`、
   `retryable: true`）阻断，**流水线一步都不跑**（有计数断言：`resolveIdentityPolicy` 未被调用）。
   该码归"未就绪"类（补环境后可重发同一次动作），界面文案明说"不会自动换到别的工作区"。
   没有默认环境时不拦（无事可验），也不为它新造一个审批步骤。
5. **D5 解除不动既有事实**：`unlink` 只追加一条解除记录；已存在的本地引用（013）保持其 `workspaceRoot`
   与创建时版本不变（断言：解除前后引用记录逐字段相等）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 可变表 + 另一张审计表 | 否决：两个家会分叉；留痕折叠成现状只有一个真源。 |
| 关联时校验工作区"可用"（调用能力预检） | 否决：那会把关联变成一次能力裁决（ADR-0165~0171 的边界），本票只验"在已采纳列表里"。 |
| 把重验塞进流水线新的一步 | 否决：会改动 ADR-0190 冻结的步骤序列；放在派发前是对既有步骤的零改动。 |
| 默认环境不可用时自动挑一个可用工作区 | 否决：正是工单禁止的"静默换环境"。 |
| actorRef 由 renderer 自报 | 否决：谁在操作是 main 侧事实，不是页面自报。 |

## 后果

- 三条验收各有机器断言：留痕（逐条 action/actor）、零内容读取（源码级 + 路由载荷断言）、
  阻断且不换源（计数断言 + 文案断言）。
- 关联面新增 1 条路由、1 个端口、1 个状态槽与 1 张卡；命令侧只新增一个错误码（进"未就绪"类），
  没有新增审批步骤，也没有改动流水线。
- 已知未闭：真机端到端未跑（不启动 Host）；关联的**权限侧**（谁能关联、可见性治理）按工单"明确不做"
  继续留给治理线；`defaultOf` 目前按 `matterId` 字符串匹配（formal matter 的 ref 形态待托管方定型）。
