# ADR-0319 · R17-C 快捷键/语音壳批：结构复刻 + 真实本地搜索与弹窗壳

- 状态：accepted（2026-10-12）
- 日期：2026-10-12
- 决策者：用户（2026-10-12 确认 R17 波次计划）＋ agent（装配设计）
- 决策记录：[Note](../notes/implemented/surface/2026-10-12-r17c-shortcuts-voice-batch.md)
- 相关：[ADR-0318](ADR-0318.md)（R17-A 成例）、[ADR-0315](ADR-0315.md)（纯壳口径）、T13（tickets 计划）

## 背景

R17 波 C：shortcuts 5 行 + voice 7 行 + 两入口行 = 14 行 pending；观测齐备（QB17-01/B18 快捷键十六命令五组、搜索两态、发送菜单、编辑弹窗；QB18-05/B19 语音四组十三行、音色/速度/时长/设备菜单、快捷键编辑弹窗、常用词草稿）。

## 决策

1. **D1 结构复刻口径延用 R17-A**：命令/字段与说明逐字；绑定值与开关值不给伪造读数——全部「未接线」态。
2. **D2 真实本地交互三件**（观测即合同，零伪造）：快捷键本地搜索（过滤 + 无匹配文案 + 清空恢复，QB18-01/02）；编辑弹窗壳（打开/取消/Escape 真实，录制与保存禁用并具名，QB18-04/B19-02）；常用词草稿输入（本地键入，添加禁用——观测从未添加，QB19-03）。
3. **D3 菜单态不渲染**：音色/速度/时长/输入设备/发送菜单五态只登记观测枚举，不渲染菜单（无本地偏好 store；具名 blocker）——避免不可保存的假选择面。
4. **D4 铅笔范围**：非发送命令行挂铅笔（打开同一弹窗壳）；发送消息行无铅笔（其观测交互是组合菜单，非弹窗）。
5. **D5 写路径独立成批**：快捷键/语音偏好 store 属本地偏好类（T13 子批 4：保存与应用分离）；本波零写入。
6. **D6 迁移**：14 行 pending→implementing（含两入口行），evidenceRefs 挂 tracked-test；route 权威维度零改动。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 渲染键帽作为 Sage 当前绑定 | 否决：伪造读数且制造无效快捷键面（Sage 无快捷键系统）。 |
| 五个菜单全部渲染为可选面 | 否决：无 store 的可选面=假选择；录入观测枚举+具名。 |
| 弹窗渲染为完整录制器 | 否决：超出壳批口径；录制/校验/冲突/保存独立成批。 |
| 常用词输入直连添加（本地 store） | 否决：观测从未添加；新增 store 属 T13 子批。 |

## 后果

- 快捷键/语音两页落地；矩阵 118→132，pending 33→19（P06 剩 9 入口 + models 10 + 两占位）。
- 余量具名：models 编辑器（波 B，凭证裁决前置）、P06 剩余入口（波 D）、五菜单与偏好 store（T13 子批）。
