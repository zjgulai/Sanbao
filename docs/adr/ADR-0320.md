# ADR-0320 · L1-A 事项治理 admission 家族：五步面 + matter-admin 四 op 收口

- 状态：accepted（2026-10-12）
- 日期：2026-10-12
- 决策者：用户（2026-10-12 确认 L1 侦察与实施方案 a「家族步面」）＋ agent（装配设计）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-12-matter-governance-admission-batch.md)
- 相关：[ADR-0315](ADR-0315.md) D2（预告「须先扩 protected-effect-admission family」）、[ADR-0317](ADR-0317.md)（B 批成例）、[ADR-0174](ADR-0174.md)（appsvc 边界）

## 背景

22 条违规路由中 matter 家族是核心功能缺口：providers 已在 main、路由直连（direct-provider-bypass）、UI 零动作入口。新链 kernel 为 `family: 'session-core'` 字面类型、十步固定序、缺 port 即 unavailable；matter 写入是 local-write，target/compat/registry/preflight 对本地写无意义——为其造 always-allow port 即权威谎言。

## 决策

1. **D1 家族面按纯函数扩展（方案 a 的实现形态）**：新模块 `matter-governance-admission.ts` = 家族五步面（verifyCaller→resolveActiveContext→matchCandidate→resolveIdentityPolicy→dispatch），共享 kernel 的 checkStep/守卫/事实校验器（单一家；kernel 仅加性导出）。session-core 十步 kernel 零改动（其门禁钉原样）。
2. **D2 配对校验同 kernel**：intent.candidate 为 kind:matter 时必须等于活动 context.matterRef（否则 stale at candidate-match）；active-session 类豁免——renderer 的 matterRef 永远是候选而非权威。
3. **D3 收据随 detail**：四种 kind（matter-archived/restored/batch/renamed）各带 provider 自有读回 status；kernel 守卫 shape 校验（status.state ∈ read/unavailable + 各 kind 必填字段）；路由做身份配对（matterRef/ground/title/operation 相等），错配→保守 outcome-unknown。
4. **D4 dispatch 纪律照 B 批**：per-op payload 守卫（ground 枚举、batch ≤100 targets、title ≤500 等）恒 not-dispatched；live 复检子集（context 全等 + identity session + frame）漂移即 not-dispatched；provider 拒绝透传 code；抛错→outcome-unknown。
5. **D5 本家族暂无独立 intent 册**：本地写的耐久记录=dispatch 作者的事项域事件本身；per-op intent ledger 登记为后续（batch 记录具名）。
6. **D6 门禁事实翻转（有意编辑）**：matter-admin violation→compliant（22→21 bypasses、16→15 direct-bypass、13→14 admitted），checker 家族识别扩展（两族 helper），新增两枚家族钉（路由走家族 admission；配对字面量）；selftest 夹具同步。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 为 matter 造十真 port（方案 b） | 否决：无意义面=权威谎言。 |
| 改造 session-core kernel 为表驱动步面 | 否决（本批）：kernel 被门禁重钉、回归风险大；纯函数家族模块等价且零侵入。 |
| 家族独立 intent 持久册 | 推迟：域事件本身即耐久记录；独立册无 doctrine 强制。 |
| batch 逐 target 配权 | 推迟：store 自有 known-item 门；per-target 政策属 store 层后续。 |

## 后果

- 第二 protected-effect 家族存在；matter-admin 四 op 全链收口（表四行 scope matter.admin local-write）；路由路线级事实经真 policy 验证（grant/denied/未登录三态）。
- 矩阵 route 面：matter-admin 转 compliant；余 21 bypasses（groups 四 op = L1-B；草稿/编辑稿/side-chats/workspace/plans/action-items 后续波同型）。
- UI 动作入口（archive/restore/rename 真按钮；batch 选择态）排 L1-A.2。
- 全量 2059 passed | 1 skipped；gate 32/32。
