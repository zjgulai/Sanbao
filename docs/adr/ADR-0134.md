# ADR-0134 · 命名射程判据：只改品牌位，功能面板名保留；品牌名不翻译，描述语用中文叙述句

- 状态：accepted（2026-09-19）
- 决策者：用户（lute）+ WorldPilot 全维度换皮轮
- 取代：本 ADR 的 D2（品牌名不翻译）与 D3（hero/badge 用素材源仓中文叙述句）已被 [ADR-0136](ADR-0136.md) D3/D4 取代；D1（品牌位/功能位判据）、D4（启动屏删文本字标）、D5（泄漏清零取产品名）继续有效
- 相关：ADR-0009（文档消费者与语言策略：主脊柱中文单语）、ADR-0012（包名不改）、ADR-0131（单品牌收口与 16 处射程）、ADR-0133（图形落位）

## 背景

「全维度换皮」容易被执行成「凡是文字都改」。本仓库有六个功能面板名
（岗位矩阵 / 扩展中心 / 新应用 / 能力中枢 / 算法技能库 / 外观）与一批空态、错误、操作提示文案，
它们承担的是**功能可供性**（用户靠它找到东西），不是品牌表达。

同时存在两个改名成本被误判的风险：

1. `live-presets` 门禁的 `rowIdentitySha256` 哈希的是 `agent.cordis.yml` 每行的
   `stableId\0name\0kind`（56 preset / 1788 行），而 **`preset.yml` 的显示名与 `locales.ts` 的
   面板标签都不在这个哈希里**。所以「改面板名会不会触发重采样」取决于改的是哪一层，不能一概而论。
2. 本仓库自己的计划里写着一条排序铁律
   （`docs/plans/2026-09-19-capability-hub.md`）：「反序会让用户在迁移期『哪都找不到入口』」。

品牌位上还有一句现存文案本身是缺陷：`Artificial Business Intelligence Agentic`
是三个名词堆叠加一个悬空的 `Agentic`，语法不成立，且在盘上有 **4 个家**
（`brand.tsx:93`、`brand.test.tsx:24`、`test/helpers/hero-fixture.ts:28`、
`scripts/acceptance/root-brand-live-anchors.mjs:210`）。

## 决策

**D1 品牌位与功能位用一条判据分开：一个名字若同时承担「让用户找到功能」的职责，它是功能位，
不在换皮射程；只有纯粹表明「这是谁的产品」的名字才是品牌位。** 据此五个功能面板名及其副标题、
空态、错误与操作提示**一律保留现状**；品牌座、启动屏、hero、窗口标题、`CFBundleName`/`DisplayName`、
DMG 名、卷名、安装器名、签名身份、客户文档标题进入射程。

**D2 品牌名不翻译。** 全程只用拉丁字标 `WorldPilot`，中文只出现在描述位。
现状的「中文主体名 `路特创新` + 英文 badge `AgenticOS`」两行结构退役——它正是 ADR-0131 要消掉的
多品牌并存形状。

**D3 品牌位描述语照抄素材源仓的中文叙述句**：hero 行用 `AI Native 经营决策与运营执行平台`，
badge/eyebrow 用 `面向跨境电商与出海品牌`。**不采用本 ADR 提案的 mono 元标签替代方案**。
后果照实登记：`面向跨境电商与出海品牌` 是一条**关于客户群的定位断言**——若出货对象不是
跨境电商与出海品牌，这句在启动界面上即为假；该风险由射程表与验收读数承担，不靠改文案规避。

**D4 启动屏不再放独立文本字标。** 现状 boot 字标是「SVG 图形 + 文本 `ROOT`」两段，
改判为只留 `stacked` 形态——其 SVG 已把 `WorldPilot` 字标转为路径（`brand/logo/README.md:3`），
因此文本段成为重复事实，删除。`brand-replay.sh` 的语义锚 `this.wordmark=…(…wordmark,"ROOT")`
随之重切。代码内的 `ROOT` 命名族（`dsh-root-brand-local`、`RootMark`、`HeroRootBrand`、`.dsh-rb-*`）
属内部面，按 ADR-0131 D2 不改。

**D5 品牌泄漏清零后的目标串取产品名本身**：`请重启 DeepSeek Harness` → `请重启 WorldPilot`
（含英文镜像 `Restart WorldPilot`），`manifest.webmanifest` 的 `name` 取 `WorldPilot`、
`short_name` 取 `WP`，`<title>` 取 `WorldPilot`。

## 备选方案

| 方案 | 为什么未采用 |
|---|---|
| 五个面板名一并换成素材源仓语汇（岗位矩阵→数字员工 等） | 用户「哪都找不到入口」，且要重跑 live-presets 采样与大量 locales 断言；而素材源仓的业务学轴（7 价值流）已在 ADR-0132 D6 / ADR-0133 D6 被否，搬它的词等于搬一套本仓不渲染的本体 |
| 面板名保留但副标题/空态改成问答式调性 | 调性换到了也不破坏导航，但文案位数量大（五份 `locales.ts`）且逐条需人审，收益是审美一致性而非正确性；留作后续独立一轮 |
| 造一个中文名（世界领航）中英并列 | 素材源仓没有中文名，造一个即超出素材范围自创，且产生「中文名片标是拉丁」的第四套并存 |
| hero/badge 走 mono 元标签（`.tiny` 大写）而非中文叙述句 | 与钛银调性更一致、避免把营销语搬进空会话态，但用户裁决取素材源仓逐字文案优先。已按 D3 登记其定位断言风险 |
| DMG 名与卷名保留 `DSH Desktop` 前缀只换 LUTE | 与不可动的 bundle 路径一致、客户升级不困惑，但对外名字里继续混着基座名，与 ADR-0131 D4 泄漏清零冲突 |

## 后果

- **正面**：改名射程有了可判真的判据，「哪些名字归换皮」不再靠逐条争论；
  一句语法不成立且住在四个家的品牌文案被删除而非再复制一份。
- **负面 / 需跟进**：
  1. `面向跨境电商与出海品牌` 的**客户群适配性**成为出货内容的真实风险，需在售卖口径上确认。
  2. 删除 boot 文本字标要重切 `brand-replay.sh` 的语义锚，属 `patch-anchors` 射程，必须与门禁同一次提交。
  3. 功能面板名保留意味着**产品内叙述与官网叙述存在语体落差**（官网讲价值流/场景/经营链，
     产品讲平面/责任域/岗位）。这是 ADR-0132 D6 与 ADR-0133 D6 的必然结果，不是新缺陷，
     但必须在内容轮把本体口径统一后才能消掉。
  4. `short_name: WP` 是本 ADR 首次为品牌定缩写，需与 app-icons 的 `worldpilot-*` 命名保持一致。
