# ADR-0136 · 名字与视觉语言解耦：产品名定为 Sanbao / 三宝，WorldPilot 降为视觉语言供体；启动加载动画显式保留

- 状态：accepted（2026-09-19）
- 决策者：用户（lute）+ WorldPilot 全维度换皮轮
- 取代：ADR-0131 D1/D2/D3 中「产品名 = WorldPilot」的部分；ADR-0134 D2（品牌名不翻译）、D3（hero/badge 用素材源仓中文叙述句）
- 相关：ADR-0009（一份事实一个家）、ADR-0012、ADR-0131～0135；总账 P-07

## 背景

ADR-0131 把收口目标定为「产品即 WorldPilot」，ADR-0134 进一步定了「品牌名不翻译，全程只用拉丁字标」。
本轮拷问完成后用户补充：产品名要改为 **Sanbao**（中文 **三宝**），并给出 slogan——
中文「三宝出海，货通四方」、英文「Sanbao — Your AI Fleet to Global Markets」，且明确改名是**后置待办**。

这暴露了前面 22 条决策里一个未被检查的耦合：**把「视觉语言」和「产品名」当成了同一件事**。
拆开看，素材源仓里真正有价值且与名字无关的部分约占本轮的 60%：

- 全部色板（暗/亮中性阶、accent、good、on-accent、radius）
- `--metal-*` 材质系统、`--ux-*` 动效系统
- `.tiny` / `.eyebrow` 排印签名与标题字距规范
- **102 位 2.5D 数字员工头像**（AGT 编号与本仓 `role-catalog v2.0` 同源，与品牌名零关系）
- 双轨 token 机制、`theme-tokens` 命名空间扩列、`brand-icons` 形状判据、泄漏判据、锚值==源值断言、33 处单一源收口

而**绑死在名字上**的约占 40%：17 个 logo SVG 里有 8 个把 `WorldPilot` 钉成了矢量路径
（`lockup` / `stacked` × 4 色道）、`WP` 连笔字母标本体、squircle 生成器所画的字母、`favicon.svg`、
`short_name: WP`、DMG 名、卷名、签名身份、品牌座两行文案、`vendor/worldpilot.pin`。

若不处理这个耦合，改名 = 重做两个切片的一半，而且**恰恰在「名字」这一条上没做到刚建立的「一处一家」**。

同时用户要求保留启动加载屏动画。实测其本体在
`.dsh-types/dsh-client-web/lib/boot-page.module.css`：`.spinner` 为 20×20 圆环、
`animation: spin 0.8s linear infinite`，`::after` 用
`conic-gradient(var(--dsw-alias-brand-primary, var(--dsh-boot-brand)) var(--dsh-boot-arc, 72deg), transparent 0)`
经 `radial-gradient` mask 成环。**它的弧色正好取自 ADR-0132 D4 覆写的 `--dsw-alias-brand-primary`**——
即动画会自动跟随换皮，无需改动。另实测 `brand.tsx:180-186` 的运动抑制作用域是
`[data-plugin="dsh-root-brand"] *`、只压 `transition` 不压 `animation`、且仅在
`prefers-reduced-motion` 下生效，**碰不到 boot spinner**。

## 决策

**D1 产品名定为 Sanbao / 三宝；WorldPilot 降为「视觉语言供体」，不再是产品名。**
素材源仓的角色从「我们要成为的品牌」改为「我们采纳其色彩/材质/排印/图像/动效契约的上游」。

**D2 名字参数化：新增唯一「品牌名源」，所有含名字的产物由它生成。**
源字段至少含 `nameLatin`（`Sanbao`）、`nameZh`（`三宝`）、`shortName`、`sloganZh`（`三宝出海，货通四方`）、
`sloganEn`（`Sanbao — Your AI Fleet to Global Markets`）、`signingIdentity`、`bundleDisplayName`。
派生物覆盖：`stacked`/`lockup` 字标 SVG、`favicon`、app icon 上的字母、`short_name`、DMG 文件名、卷名、
签名身份、品牌座两行、`<title>`、`CFBundleName`/`DisplayName`、客户文档标题。
**改名 = 改一个源 + 重跑生成**，不得在 12 个落点各改各的。
字标转路径复用素材源仓现成配方（`sources/trace.json` + `sources/Inter-SemiBold.ttf`，授权见
`licenses/Inter-OFL-1.1.txt`）。

**D3 字顺分工：拉丁管图形与文件名，中文管描述。**
`Sanbao` 用于一切图形字标、app 图标、favicon、DMG 文件名、卷名、签名身份、`short_name`、
`CFBundleName`/`DisplayName`；`三宝` 用于描述语、文档标题与中文文案位。
理由：汉字转路径需中文字体子集且字重/字距体系与拉丁完全不同；文件名含汉字会引入编码与
`machine-path-baseline`（39 条只减不增）风险。**本条取代 ADR-0134 D2**——品牌确有汉字形态，
「不翻译」不再成立，但两个字形是同一名字的两种书写，不是两个名字。

**D4 本轮名字源初值直接填 Sanbao，不先发 WorldPilot 版。**
既然 ADR-0135 D7 定了不灰度、整体替换，中间不发版，那么生成一套只活几天的 WorldPilot 字标与全套
app-icons 是纯浪费。**本条取代 ADR-0134 D3**：hero/badge 不再用素材源仓的
「AI Native 经营决策与运营执行平台」/「面向跨境电商与出海品牌」，改用 D2 的 `sloganZh`/`sloganEn`。
这同时消掉了 ADR-0134 登记的 R3 风险——「三宝出海，货通四方」是**愿景式口号**而非
「面向 X 客户群」的**可证伪断言**。

**D5 图形字母标另立一轮，本轮字标用文字版。**
`WP` 连笔标对 Sanbao 无意义；本轮 `stacked`/`lockup` 的字标部分用 Inter SemiBold 排 `Sanbao` 转路径，
字母标位先用**中性几何占位**（不含 W/P 语义），图形字母标设计作为后置待办。

**D6 启动加载屏动画显式列为必须保留项。** 不改动 `dsh-client-web` 的 boot 页（基座只 pin 不改），
其弧色经 `--dsw-alias-brand-primary` 自动跟皮。新增一条断言：换皮后 boot spinner 的
`animation-name` 仍为 `spin`、`animation-duration` 仍为 `0.8s`、且 `::after` 的 conic 弧色
解析值等于品牌源 accent。**不得**以「简化启动屏」为由删除动画。

## 备选方案

| 方案 | 为什么未采用 |
|---|---|
| 照原计划出 WorldPilot 全套名字资产，改名时整体重做 S2/S4/S5 | 最快看到成品，但约 40% 重做，且刚花 22 条决策建立的「一处一家」在名字这条上直接失守 |
| 名字源先填 WorldPilot 并真的发一版 | 换皮成果立刻可用，但多一次完整发布周期，且 8 个钉了路径的字标 SVG 与全套 app-icons 要重出两遍 |
| 填 Sanbao 但不发版、等图形字母标定稿 | 只发一次且品牌完整，但换皮周期被字母标设计卡住，S1–S5 成果长期停留在未验收状态 |
| 中文为主（显示名一律「三宝」） | 界面与口语完全一致，但 DMG 文件名与签名身份含中文带来编码与 CI 风险，app icon 放汉字需另做设计 |
| 双语并列「Sanbao 三宝」 | 一次建立两形态，但侧栏仅 264px，并列会挤成两行或缩字，且「哪个是主名」无权威答案 |

## 后果

- **正面**：本轮 60% 的成果（色板、材质、排印、头像、机制、门禁）与名字彻底解耦；
  改名从「重做两个切片」降为「改一个源 + 重跑生成」；ADR-0134 的 R3 定位断言风险被 slogan 消掉；
  启动动画从「隐式幸存」变成「有断言守着」。
- **负面 / 需跟进**：
  1. **本轮字标是文字版，不是设计过的字母标**——出货观感会弱于素材源仓的 WP 标。这是主动接受的代价，
     图形字母标为后置待办。
  2. 字标转路径生成器是本仓新增能力（现状只有素材源仓的产物，没有生成它的脚本），要连字体授权一起入仓。
  3. ADR-0131 D1、ADR-0134 D2/D3 的正文仍写着 WorldPilot，已各自加「取代」指针；不得靠正文自证。
  4. `vendor/worldpilot.pin` 的语义从「品牌上游」变为「视觉语言上游」，pin 文件与射程表需同步改注释，
     否则未来读者会以为产品要长成 WorldPilot。
  5. slogan 的英文形态含破折号与品牌名（`Sanbao — Your AI Fleet to Global Markets`），
     在 `short_name`、卷名等**长度受限位**必须只用 `Sanbao`，不得整句塞入。
