# ADR-0245 · 反馈入口：文本＋结构化诊断的封闭载荷与「未知只核对、不重提交」

- 状态：accepted（2026-10-03）
- 日期：2026-10-03
- 决策者：agent（取证并实施；FW-040、US-223/224 已定方向）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-03-feedback-entry.md)
- 相关：[ADR-0219](ADR-0219.md)（007 三态回执先例）、[ADR-0224](ADR-0224.md)（021 检索先例）、[ADR-0198](ADR-0198.md)（host 消费登记——本票零新增）

## 背景

工单 048（FW-040，US-223/224）：**反馈只提交用户输入文本与结构化诊断（code/stage/
correlation），不自动附日志、原始堆栈、机器路径或凭据**；**回执区分已接收与结果未知；未知只给
核对同一提交的入口，不重复提交**。原产品证据：O13 反馈。Sage 侧无任何反馈接收端（无远端
sink、无工单系统），`service.correlation` 是既有服务事实（可作结构化诊断字段）。

## 决策

1. **D1 载荷封闭且可断言**（`main/feedback.ts`）：sink 收到的 payload 恰为
   `{requestId, at, text, diagnostics:{code, stage, correlation}}`——**键集由 spec 逐字断言**
   （`Object.keys…sort()` 相等 + 全量 deepEqual），任何自动附带的字段都无法悄悄加入；store
   不读日志/堆栈/路径/凭据（唯一输入=请求与注入 sink）；text≤4000、诊断字段≤128 且先验于派发。
2. **D2 回执三态＋缺项**：可读 ack=`accepted`（已接收）；ack 不可读或 sink 失败=`unknown`
   （记录在案，仅核对）；sink 具名拒绝=`refused`（**不记录**）；**生产未接线＝`unavailable`＋
   `feedback-sink-unavailable` 缺项句**（不伪报已提交、不记录）。
3. **D3 未知只核对、不重提交**（US-224）：`verify(requestId)` 只回读已记录回执，**零派发**
   （spec 断言 sink 调用数不变）；渲染面 unknown 回执只给 [核对同一提交]，核对走一条
   `{action:'verify'}` 且**绝不产生第二条 submit**；不存在的回执=`not-found`（核对不重派）。
4. **D4 入口位置与 027 守护的 deliberate 例外**：反馈块落于「关于与诊断」卡（O13 语义位）；
   027 的「只读卡零控件」spec 以**精确 id＋数量**钉住这一个例外（`feedback-submit` 恰 1 个、
   其余控件仍为 0），第二枚控件无法骑行走入。
5. **D5 首版不做**：日志上传、崩溃自动上报、反馈工单系统集成（工单边界）；真实远端 sink
   到位前生产恒缺项。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 自动附带诊断快照（版本/世代等） | 否决：US-223 明令只提交用户文本＋五个结构化字段；键集封闭可断言。 |
| 本地落盘做 sink | 否决：无授权的产品机制发明；端口留白、生产缺项。 |
| 未知态给「重试提交」 | 否决：US-224 只给核对同一提交；verify 零派发。 |
| sink 拒绝也记录回执 | 否决：未受理的提交无回执可核对（记录会暗示"提交过"）。 |
| 反馈块放 governance 面板 | 否决：O13 语义位在关于/帮助侧（关于与诊断卡）。 |

## 后果

- 验收两条机器断言：①载荷不含凭据、机器路径与原始堆栈（键集封闭＋deepEqual＋`environment`
  类注入突变的红）；②结果未知不重复提交（verify 后 sink 调用数不变、渲染面未知只给核对）。
- 面/装配：`FeedbackStatus` 状态槽＋`feedbackSubmit`/`feedbackVerify` 两端点（route
  `/.sage/feedback`）；名册 +2；033 装配守护 +1；027 守护 deliberate 更新（例外钉 id+数量）。
- §1.6：真产物两宽（1440/660）亲看——关于与诊断卡内「反馈（只提交你写的文本与结构化诊断
  code/stage/correlation；不自动附日志、堆栈、机器路径或凭据）」＋诊断码/阶段输入＋
  [提交反馈（文本＋结构化诊断）]＋注记句；flow 页点击后 DOM 恰一条
  `POST {"action":"submit","text":…,"code":"E-102","stage":"draft-save","correlation":"corr-048"}`
  ＋「已接收：反馈只含你写的文本与结构化诊断（不含日志、堆栈、机器路径或凭据）。」。
- 已知未闭：真实远端 sink 不存在（生产恒 `feedback-sink-unavailable` 缺项）；回执为进程内
  记录（持久化/去重跨重启后置）。
