# ADR-0323 · L1-C 草案保管 admission 家族：四命令收口

- 状态：accepted（2026-10-12）
- 日期：2026-10-12
- 决策者：用户（2026-10-12 确认 L1 波次计划并「开始」）＋ agent（装配设计）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-12-draft-custody-admission-batch.md)
- 相关：[ADR-0320](ADR-0320.md)/[ADR-0321](ADR-0321.md)（前两族成例）、[ADR-0315](ADR-0315.md)、T02/T05（票据）

## 背景

draft/create、update、cancel、reconcile 四路由直连（direct-provider-bypass 四条）。草案住 Sage 自有保管库；转换路（convert/prepare-confirm）属确认流水线另案（prepare-only 批 C2）。

## 决策

1. **D1 第三家族**：新 `draft-custody-admission.ts`（五步面同型）；四 op 表四行 scope `draft.custody` local-write；detail 四 kind（created/updated/canceled/reconciled）。
2. **D2 reconcile 裁决即收据**：custodian 的 settled/failed/unknown 三态是确定性答案，随 detail 携回（守卫校验 outcome.draftId === detail.draftId）；settled 落 commit 回写、failed 落 note——两者移入 dispatch（唯一真实调用点）。
3. **D3 convert 路留族外**：确认流水线（prepare → confirmation → command pipeline → convert 的 begin/note/commit 直连）不动；其 `draftCommitConversion`/`draftNoteAttempt` 选项保留为双职（转换路直连 + 本家族 dispatch 装配共用同一闭包）。
4. **D4 失败面形态**：DraftStatus 契约无 code 字段 → 一切非 dispatched 路径保持诚实 `{state:'unavailable',drafts:[]}`；reconcile 非 dispatched → `{state:'unknown',code:'reconcile-unavailable'}`（永不自settle）。
5. **D5 门禁翻转**：四路由 violation→compliant（16 bypasses / 10 direct / 19 admitted）；三族识别扩展；selftest 与矩阵 spec 同步。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 并入 matter-governance 家族 | 否决：草案非事项治理，语义混装；五步面复制成本低。 |
| convert 一并收口 | 否决：确认流水线（ADR-0224 卡流）与四命令不同族；prepare-only 独立批（C2）。 |
| reconcile 走 refused 错误码面 | 否决：unknown 是确定性答案非失败；收据携裁决才诚实。 |

## 后果

- 三家族并立（session-core / matter-governance / draft-custody）；direct 违规 14→10。
- 余量具名：C2 prepare-only 三路由（draft/prepare-confirm + actions/prepare + edit-drafts/prepare-writeback）；D2/E1 等在续波。
