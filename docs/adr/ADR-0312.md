# ADR-0312 · 设置叶区：十一叶真实机器上桌（导航批）

- 状态：accepted（2026-10-11）
- 日期：2026-10-11
- 决策者：用户（lute：指示继续无重叠独立线）＋ agent（实施）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-11-settings-leaf-region.md)
- 相关：Ticket 046（US-209~219 机器）、[ADR-0304](ADR-0304.md)（同为真实机器上桌）

## 背景

113 条 pending 侦察分级将「settings 叶导航」列为第四批备选：`SETTINGS_LEAF_IDS` 恰为 11 个叶（桌面宠物/记忆/数据导入/钩子/电脑操控/移动端/连接/安全/网络/工作区索引/任务监控），机器（`src/main/settings-leaves.ts`，Ticket 046）自 DMG-06 起在生产 live 读；矩阵对应 11 个 `QDR.P06.settings.*.entry` 行全部 pending。desktop 设置页此前只渲染 8 个外观 select，叶面未上桌。

## 决策

1. **D1 机器上桌**：`DesktopSettingsView` 新增「本机设置叶」区——11 行来自 state 信封 `settingsLeaves`（新槽，闭合解析；畸形整槽省略）。每行显示 title + state（已读/未核验）+ source + note 逐字——**机器说什么就显示什么**（如「以运行时清单页为准」「未核验：还没有读到实例策略」）。
2. **D2 零写入口**：机器 `writeEntry: null`；叶区无任何 button/input/select（spec 断言）。
3. **D3 槽省略语义**：`leaves` 缺省 → 无叶区（不渲染空壳）；信封畸形 → 槽省略。占位页 `outstanding` 与 8 select 区不动。
4. **D4 迁移**：11 个 entry 行迁 `ui` `pending→implementing`（tracked-test refs，`countsAsVerification:false`）；blocker 写明：叶区为只读读数上桌（每叶真实/未核验读数来自机器）、叶页导航（点击进入子页）不装、P06 伞行仍 pending（50 叶未装）。summary 生成器重算。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 自造叶页导航（点击进子页） | 否决：子页无机器；行断言为「入口」形态，读数上桌是当前可证半——导航登记 blocker。 |
| 把 8 select 与 11 叶混排 | 否决：8 select 是 device-preferences 机器（可写），11 叶是 Ticket 046 机器（只读）——一区两机器会模糊写入口边界。 |
| 叶区缺槽时显示「未核验」空壳 | 否决：无槽即无此面，空壳是假声明。 |

## 后果

- 叶读数（连接/安全/工作区索引 3 叶真实值）在生产 live 可见；8 叶诚实「未核验」。
- 矩阵 87→98 implementing（11 行）、111→100 pending。设置族余量聚焦 P06 主体 39 叶 + 伞行。
