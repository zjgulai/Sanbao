# ADR-0190 · WT-02D.2A 授权路径切片：intent→请求组装 + step-2 真接线 + retry 可用性语义 + route 开放

- 状态：accepted（2026-10-02）
- 日期：2026-10-02
- 决策者：用户（lute）
- 决策记录：[WT-02D.2A 授权路径切片](../notes/implemented/architecture/2026-10-02-wt02d2a-authorization-path.md)
- 相关：[ADR-0174](ADR-0174.md)、[ADR-0188](ADR-0188.md)、[Application Service 边界](../notes/proposed/architecture/2026-09-30-application-service-boundary.md)

## 背景

WT-02D.2（首个 production command path）的全量门（真实 Identity / Policy、WT-02B.3、C2/C3、Registry real entry、trusted clock、数据治理、idempotency/cancel/reconciliation）对当前源码复核后仍多处未闭合——**全量不可开**。2E 交付的 Authority Runtime 未接 pipeline；2E 显式登记「intent→请求组装 + step-2 端口接线属 WT-02D.2」。用户四裁决后按授权路径切片实施。

## 决策

1. **D1 动作表与组装内核**：`ACTION_AUTHORITY_TABLE`（冻结代码常量；v1 单条，锚定 fixture revision 域内 actionPolicies 与 2E instance-operator 角色；actionType 与 operation 形状解耦）+ `assembleAuthorizationRequest`（纯函数）：未登记动作 → `invalid`（不得进入求值）；无 session / 无线索 → `unavailable`；命中 → kernel 2D 请求五键。组织线索 = policy 文件 `organizationId`（生产组装下与 policy 同源，`policy-organization-mismatch` 不可达——登记遗留）。
2. **D2 retry 可用性语义与结果契约**：`checkAuthorizationAvailability`（active session ∧ 会话窗口 ∧ policy loaded ∧ 策略窗口；时效规则与 kernel `isActive` 同等，第二处拷贝登记）；pipeline retry 前置分支 → 健康返回新结果分支 `CommandAvailable {correlation, availability:'available'}`、否则 `identity-unavailable`（retryable）；旧「retry→invalid-intent」路径退场（序列断言）。`ServiceProviders.dispatch(intent)` 承接全形 intent。
3. **D3 接线与边界**：`createSageAppServiceProviders` 增 `options.authority`——真 step-2 端口与 availability 端口合并到 fail-closed 默认之上，**步骤 3–10 保持 fail-closed**；route 接受 `retry | SageActionIntentV2`；renderer retry 简化为「POST → refresh()」；B.3/C2D.2/C2E.1·2/C3/数据治理/idempotency/多 capability/UI 提交面一律不做。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 等 D.2 全量门全部闭合再开 | 否决；授权路径继续挂空、D 线停滞，切片不触碰任何被门项。 |
| 组装映射用配置文件 | 否决；v1 单动作不值得文件 schema + 校验面（升级路径保留）。 |
| retry 维持 fail-closed / 退场 | 否决；前者真 port 下误报，后者牵连现有 UI 流。 |
| route 维持 retry-only | 否决；真实求值结论需要产品面可达（fail-closed 之后零副作用）。 |

## 后果

- **读数（2026-10-02）**：596 tests 全 PASS；typecheck 0；tsc 构建通过；smoke PASS（窗口 probe 同装配）；gate 25/25；变异四组（放行未登记动作 / 漏会话窗口 / 删 retry 分支 / 硬编码线索）均红、还原后绿。
- **行为面**：真实登录 + 已供 policy 下产生真实求值（policy-denied / 步骤 2 通过后在 rehydrate 如实 fail-closed——本票真实前进量）；无 policy / 未登录一律 fail closed。
- **边界**：内核零改动；零持久化 / 零日志 / 零网络新增；步骤 3+ 与列名票据照旧。
- **遗留**：invalid→policy-denied 语义、intent actionScope 未参与组装、动作表升级形态、时效规则两处拷贝收敛、mismatch 不可达登记、可选 live 验收未运行。
