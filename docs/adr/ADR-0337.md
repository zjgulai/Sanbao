# ADR-0337 · VF-2 P06 设置族几何精修：白卡无边框容器 + 卡外分组标签 + 发丝分隔线 + 重模糊弹窗

- 状态：accepted（2026-10-13）
- 日期：2026-10-13
- 决策者：用户（2026-10-13「继续」批准 VF-2 按 P06 开工）＋ agent（像素测量与装配）
- 决策记录：[Note](../notes/implemented/surface/2026-10-13-vf2-p06-geometry.md)
- 相关：[ADR-0336](ADR-0336.md)（VF-1 token 锚定）、[视觉保真票](../plans/2026-10-12-qoder-visual-fidelity-tickets.md)（VF-2）、证据 `assets/qoder-reference/screenshots/base-20261013/`

## 背景

VF-1 后颜色已锚定 Qoder，但组件几何仍是自造（卡片带边框、分组标签在卡内、无行分隔线、弹窗轻阴影）。真机像素测量（2540×1838 @2x 截图逐像素扫描）得出 P06 设置族的精确几何：白卡 `#ffffff` 无边框、radius 12px、卡间距 24px、分组标签在卡**外**上方（12px quaternary 灰）、行分隔线 1px `#f0f7f4`（浅绿发丝线）、图标方块 26×26、页标题 24px、内容列 ~460px 居中、弹窗遮罩为重模糊 + 白色水洗（「模糊与玻璃效果」默认开）。

## 决策

1. **D1 卡片容器换形**：`settings-observed-group` 从「卡内含标签的带边框盒」改为「组=grid（标签+卡）」——`ul` 承担卡片（surface 白底、无边框、radius 12、surface ring 阴影），h3 移到卡外。settings-nav/settings-search 同步去 border 换 divider 发丝边。
2. **D2 新 token `divider-hairline`**：发丝分隔线是 Qoder 专属视觉件（浅绿 1px），进唯一 palette 家（light `#f0f7f4` / dark `#262624`），锚定表同步；styles.ts 零字面色合同保持全绿。
3. **D3 行节奏**：行间从 gap 改为分隔线 + 行 padding 10px；页标题 28→24px；组间距 16→24px。
4. **D4 弹窗对齐真机**：backdrop = surface 72% 水洗 + `backdrop-filter: blur(18px)`；卡片无边框白底。R17-B 模型弹窗与 R17-C 快捷键弹窗同享此形态。
5. **D5 零行为**：DOM 仅 h3 加 class（无 aria/结构变化）；不动任何交互合同；settings 4 spec + 主题 2 spec 全绿。
6. **D6 图标方块（26×26 tinted tile）暂缓**：需要为每个观测行配图标资产与语义映射，属内容决策——独立小批，不混入本几何批。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 分隔线色写死在 styles.ts | 否决：踩「CSS 零字面色」合同（desktop-page spec 实测拦下），正路是 token 化。 |
| 图标本方块本批一起做 | 否决：图标选择是内容决策（每行一个语义），混入会拖长几何批；独立小批跟进。 |
| 遮罩用纯色近似（不引 backdrop-filter） | 否决：真机观感的核心就是重模糊；Chromium 150 原生支持。 |

## 后果

- P06 设置族视觉与真机截图肉眼接近（颜色 VF-1 + 几何本批）；VF-3 视觉验收可用此族先行试跑验收管线。
- `divider-hairline` 成为第 20 个色 token；后续族（会话/工作区/市场）复用同一发丝线语义。
- 弹窗遮罩语义与「模糊与玻璃效果」开关尚未接线（常开形态）——开关接线随 T13 偏好子批。
