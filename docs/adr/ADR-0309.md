# ADR-0309 · 扩展管理重构、市场壳与侧面板入口（R11 双线）

- 状态：accepted（2026-10-11）
- 日期：2026-10-11
- 决策者：用户（lute：同意 Loop-Q R11，并指示可并行处并行）＋ agent（实施＋并行线）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-11-extensions-and-sidepanel.md)
- 相关：[ADR-0306](ADR-0306.md)（McpForm，保留于连接器标签）、[ADR-0307](ADR-0307.md)（同判据）

## 背景

R11 双线。线 A：P04 前 9 行（扩展管理四标签空态 + 插件/技能添加菜单 + 市场三默认页）此前零实现；观察行描述「有 store、列表空」语义。线 B：`QDR.P14.sidepanel.entry`（侧面板按钮可见；点击路径未核验）。

## 决策

1. **D1 扩展管理重构**：顶栏四标签（插件/技能/连接器/智能体）+ 各计数「—」（0 会冒充 store 已读数）+ 副标题与 市场/刷新/搜索 工具；插件/技能「添加」→ 观察的两项菜单（通过 Qoder 创建 / 上传 Plugin|Skill + 说明小字），任选项 → 具名拒绝（扩展安装治理链未建立）；智能体无添加入口（依观察）；连接器标签保留 ADR-0306 添加 MCP 与本地草稿表单。数据区具名「扩展服务未接通（extensions-store-unavailable）」——观察空态文案属 store 语义，不装。
2. **D2 市场壳**：市场/已安装本地切换；三标签标题副标题依观察原文（发现 Skills/Plugins/Connectors）；热门/最新排序对（默认热门）+「全部」类别 + 搜索（可输入）；数据区具名「市场服务未接通（market-provider-unavailable）」——**不渲染任何条目/卡片/推荐位/安装按钮**（24 条快照只作证据）；刷新按钮 → 具名拒绝 note（两处刷新同制，死控件不可接受）。
3. **D3 侧面板入口（线 B）**：会话页头「侧面板」按钮（可见入口）；本地开合 artifact rail——空态显示「尚无观察到产出物」。点击路径、面板类型/布局/标签均未核验（观察未记录），入 blocker。既有 rail 内容条件（有卡/预览）不变。
4. **D4 迁移**：9 P04 行 + P14.sidepanel.entry 迁 `ui` `pending→implementing`；summary 生成器重算（72→82 implementing、126→116 pending）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 计数显示 0 / 采用观察空态文案 | 否决：均属「有 store」语义——无 provider 时即假声明。 |
| 市场渲染 24 条快照条目 | 否决：取证快照是证据不是 fixture；伪造列表违红线。 |
| 刷新按钮保持死控件 | 否决：具名拒绝 note 是唯一诚实反馈（复验修正）。 |
| 侧面板按钮仅静态（无行为） | 否决：死入口；本地开合 rail 为真实最小行为。 |

## 后果

- P04 余 11 行（详情 ×6、search featured/latest/empty/match ×4? 计数以矩阵为准）+ loading/wide 等登记；P14 伞行依赖解除（sidepanel.entry 已装）。
- 计数「—」、具名拒绝、无假列表三条纪律在扩展/市场面落地。
