# ADR-0240 · 站点起步模板：只读目录、选择只填草案输入与「无站点创建请求面」

- 状态：accepted（2026-10-03）
- 日期：2026-10-03
- 决策者：agent（取证并实施；FW-036、US-195/196 已定方向）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-03-site-starting-templates.md)
- 相关：[ADR-0238](ADR-0238.md)（038 输入区只读清单先例）、[ADR-0231](ADR-0231.md)（007/002 草案区）、[ADR-0198](ADR-0198.md)（host 消费登记）

## 背景

工单 040（FW-036，US-195/196）：**起步模板只读列出名称与来源；选择只产生本次草案输入**
（不建站点、不写配置、不产生远端效果）；**模板不可用时显示不可用原因，不静默替换**；站点
创建与真实发布不在首版入口（§7.8），不做模板市场写操作。原产品证据（Sanbao Batch05
QB5-03）：输入区"站点"→ chip + "站点起步模板"面板（六分类/落地页十项，每项"使用提示词/
预览"）；但**提示词内容与选择行为在原产品未采集**，Sage 侧也没有任何站点能力（基座无
sites 服务；协议表无 site 端点）。矩阵留待项：模板来源与"替换用户输入及取消"另验。

## 决策

1. **D1 目录=可注入的 Sage 侧 provider 端口，生产未接线即诚实不可用**
   （`main/site-templates.ts`）：`catalog?: () => {entries:[…]} `；缺席=
   `unavailable('site-templates-provider-unavailable')`、抛错=`site-templates-failed`、形状不符=
   `site-templates-unreadable`——**空列表一律不冒充空目录**；条目带
   `templateId/name/source/version`（有界）与 `prompt|null`（超长/缺失→null=列出但不可插入，
   不静默截断）；≤50 条。
2. **D2 选择=仅本次草案输入的本地插入，零请求零副作用**：渲染面把条目 prompt 写入
   **草案输入框**（空→填入；非空→`\n\n` 追加，**不替换用户输入**——替换另验项取保守侧）；
   点击**不发任何 POST**（模块级无 bridge 调用者；结构性最强证据=**协议表不存在 site 端点**，
   由 spec 断言 `BRIDGE_ENDPOINTS` 无 `site` 键）；不写配置、不建站点、不触草案存储。
3. **D3 UI 文案不越权**：面板标"只读：名称与来源；选择只填入本次草案输入——不建站、不写
   配置、无远端效果"；插入回执句显式"**选模板不等于已建站或已发布**，也不写任何配置"；
   无 prompt 条目给"提示词未接线（本入口不可用；**不代表模板已失效**）"；`预览（未接线）`
   禁用（原产品预览结果未采集）；不可用态显示具名原因＋"不以空列表冒充，也不静默替换"。
4. **D4 首版不做**：站点创建、发布、域名与上线核验（§7.8）；模板市场写操作；把模板内容
   写入草案存储或随建项转换携带（版本化嵌入的持久语义留待模板来源确定后另议）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 把原产品观察的十个模板名烘焙为 Sage 内置目录 | 否决：模板来源未定（矩阵留待项）；名字可证但"使用提示词"内容未采集，烘名字=以观察冒充产品目录。 |
| 无 provider 时显示空列表 | 否决：空列表冒充空目录（"不可用显示原因"验收条款）。 |
| 选择经 main 写草案存储 | 否决：超范围——"只产生本次草案输入"=输入框内容；写存储会把未定语义固化。 |
| 选择时替换整段用户输入 | 否决：替换/取消语义未验（矩阵留待）；取追加的保守侧，不丢用户输入。 |
| 为站点另开预置创建接口 | 否决：§7.8 明确后置；本票"无站点创建请求"是结构要求。 |

## 后果

- 验收两条机器断言：①选择模板后**无站点创建请求**（点击零 POST + 协议表无 site 端点 +
  模块无 bridge 调用者）；②模板不可用**显示原因**（`site-templates-provider-unavailable`），
  不静默替换、不空列表冒充。
- 端口/装配：`SessionPlanModeStatus` 同族的只读槽 `siteTemplates`（SageServiceState＋
  composition 默认＋app-service 转发＋index 装配）；**无新桥端点、无新路由、无消费登记增量**
  （本票不接触宿主服务）。
- §1.6：真产物两宽（1440/660）亲看——面板两行（含来源/版本；一处「使用（填入草案输入）」、
  一处「提示词未接线（本入口不可用；不代表模板已失效）」＋两处「预览（未接线）」禁用）；
  flow 页点击后草案输入被填入 prompt（可编辑）＋回执句；不可用页只显原因句。DOM 读数：
  `POSTS ["/.sage/state"]`（仅轮询，**点击零 POST**）。
- 已知未闭：模板目录真源（原产品提示词内容未采集）——provider 留空，生产恒诚实不可用；
  替换/取消语义与版本化嵌入草案另验；真机 Electron 未跑。
