# ADR-0223 · 侧聊：fork 已完成轮派生子会话、主侧分别投影、带回主对话只走显式动作

- 状态：accepted（2026-10-02）
- 日期：2026-10-02
- 决策者：agent（取证并实施；派生子会话与显式带回是 FW-019 已定方向）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-02-side-chats.md)
- 相关：[ADR-0212](ADR-0212.md)（会话通道）、[ADR-0213](ADR-0213.md)（暂停语义）

## 背景

工单 024（FW-019，US-102~106）：侧聊以基座 `session.fork` 派生子会话（独立上下文/历史、不写入主
对话流）；事项仍只关联主对话，侧聊作为派生记录可单独回看；主侧分别投影；带回主对话需显式动作、
沿用候选交付既有合同、不新造合并机制。核验项：在途运行可否 fork、atSeq 截断位置。

基座取证（`dsh-api-session-controller/lib/index.js:660`）：`fork({sessionId, atSeq?})` 从**已完成轮
前缀**派生——无锚点截到最后一次 `turn/end`；锚点落在未完成轮（无 >= atSeq 的 turn/end）→
`session/fork-unavailable`；无任何完成轮同拒。子会话以该前缀事件为 seed、继承 cwd/preset、
meta.parentSession=源会话，父日志零回写。核验项就此收口：**在途运行可 fork（截到最后一个完成轮），
截断位置=已完成轮边界**。

## 决策

1. **D1 侧聊=子会话（US-102/106）**：桥加 `session/fork`（write）；主侧 `side-chats.ts` 以
   `ensureMainSession` 的主会话为源派生子会话并持久化记录（`sessions/side-chats.json`，0600）；
   侧聊内发送只 `session/prompt` 到**子会话**；`session/fork-unavailable` 原码透传。
2. **D2 事项只绑主对话、分别投影（US-103/104）**：记录按 matterRef 列出（可重启重载），主对话通道
   的读取与投影不含任何侧聊内容；测试断言派生/发送/回看全程 prompt/follow 的 sessionId 恒为子会话
   （主会话只作为 fork 源出现）。
3. **D3 带回主对话=显式动作（US-105）**：`returnToMain` 是唯一带回路径——把用户显式提交的文本经
   **主对话同一发送路径**（`sessionChannel.send`，ack≠执行、暂停语义、回显全沿既有合同）发出；
   侧聊历史不被触碰；页面无任何"合并/同步"控件（有断言）。完整候选交付合同仍后置，本票以"显式
   文本带回"落地其在侧聊面的最小形态。
4. **D4 暂停与边界**：事项暂停期侧聊发送拒绝（`side-chat-paused`，不静默改道待继续——那是主对话的
   记录）；文本边界同主对话（≤16384）；记录上限 16；存储损坏=整列表 `unavailable` 不造历史。
5. **D5 首版不做**：侧聊附件（receipt 按会话作用域，需子会话自有上传链，后置）；侧聊与主对话自动
   同步（点名不做）；协作者可见范围管理（点名不做）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 侧聊=主会话内另一个"线程" | 否决：FW-019 点名 fork 子会话、拥有独立上下文与历史。 |
| 侧聊内容自动回流/摘要进主对话 | 否决：US-105 只允许显式动作；页面无合并控件。 |
| 暂停期侧聊入待继续 | 否决：待继续是主对话的记录；侧聊拒绝更诚实。 |
| 重启后重新 fork | 否决：任务=回看既有派生记录；重 fork 会造出第二条子会话。 |

## 后果

- 验收两条各有断言：打开/发送/回看不触主对话（sessionId 恒为子会话）；无自动合并路径（唯一带回=
  显式按钮经同一主发送路径）。桥面 25 端点；消费登记不变（无新服务）。
- 已知未闭：真机未跑；侧聊附件、协作者可见范围、完整候选交付合同后置。
