# ADR-0221 · 事项列表行动需求分区：main 逐读推导、触发事实可追、待验收只计数、缺席不造行

- 状态：accepted（2026-10-02）
- 日期：2026-10-02
- 决策者：agent（取证并实施；推导规则落地是取舍）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-02-matter-list-partitions.md)
- 相关：[ADR-0201](ADR-0201.md)（建项尝试与回执）、[ADR-0213](ADR-0213.md)（待继续输入）、[ADR-0218](ADR-0218.md)（产物候选——"候选非交付"措辞纪律同源）

## 背景

工单 022（FW-015，US-090~096）要求：事项列表按**待我处理/进行中/待验收**分区、分区内按最近更新
排序；分区是**呈现组织**非新状态存储；归属由 Application Service 从既有事实推导（**当前 attempt、
待验收 artifact、就绪 blocked|unknown、待继续输入**），renderer 不自判；"待我处理"可追溯触发事实、
事实变化随投影更新；**待验收首版只呈现计数**（D-015/016 未收口）；归档/完成不在默认展开可筛选；
无真实 authority 时保持 unavailable-first、不用 fixture 冒充。FW-015 同时记录了 Sage 依据：既有
运行/就绪字段存在但没有单一"行动需求"字段——本票即补这个**纯推导投影**。

## 决策

1. **D1 推导四源落为本地真事实（US-092）**：`src/main/matter-list.ts` 逐读推导——
   attempt `unknown`→待我处理（"核对同一请求"）、`failed`→待我处理（修正后可重试）、`pending`→仍在
   形成（进行中）；待继续输入（006 存储 `state==='pending'`）计数>0→待我处理（count 作独立触发）；
   009/015 的观察产物候选计数>0 且无待办→**待验收**；其余有本地记录者→进行中。**优先级**：
   待办 > 待验收 > 进行中（记档）；无 attempt 且无 matterRef 的编辑中草案不列（草案卡处理）。
2. **D2 一项一车 + 最近更新（US-090）**：同一 matterRef 多草案合并为一项（新记录作标题/时间，
   任一草案上的开放 attempt 仍作触发——合并后再推导）；分区内 `updatedAt` 倒序；每分区上限 50。
3. **D3 触发事实逐项可追（US-093）**：待我处理项带 `triggers[{kind, ref, count?}]`（correlation 或
   matterRef 作 ref），渲染逐条成句；**推导不缓存**——每次读从存储重新 derive，事实变则分区跟着
   投影走（测试以同一实例两次读取、翻转事实验证）。
4. **D4 待验收只计数（US-094）**：分区只出计数与一句"分项验收与整体完成语义未收口，本版不定义"，
   **不列行**；计数=观察到的产物候选数（候选非交付的措辞纪律沿 015）。
5. **D5 默认不展开归档/完成（US-095）**：项带 `lifecycle: active|archived`、默认视图只显 active、
   筛选项可见 archived；**本版无任何事实产生 archived**（文档与界面都说明"暂无此类事实来源"），
   机制在、不造数据。
6. **D6 缺席不造行（US-096）**：记录门（草案存储 gate）不可读=整列表 `unavailable`+原因码，
   渲染"未核验…（不显示仿造行——fixture 不当列表数据）"；fixture 事项投影在场也不充当列表行（有断言）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| renderer 自己按字段拼分区 | 否决：US-092 点名不自判；视图只按 main 的 `partition` 字段分组。 |
| 把分区结果存成"行动需求"字段 | 否决：US-091 明说呈现组织、非新状态存储；逐读推导才随事实走。 |
| 待验收列出候选行 | 否决：US-094 只计数；D-015/016 未收口，列行即暗示验收语义。 |
| fixture 事项兜底列表 | 否决：US-096 点名不用 fixture 冒充。 |
| 把编辑中草案也列进列表 | 否决（本票）：无事项身份、草案卡已有专属工作面；列入会造出假事项。 |

## 后果

- 三条验收各有机器断言：每个待我处理项带触发事实；待验收只有计数行；fixture 在场不产生列表行。
- 状态槽 `matterList` 进 ViewState（读侧唯一家）；无新端口、无新存储。
- 已知未闭：真机未跑；归档/完成事实源不存在（机制在、数据待后续票）；命令级 blocked/unknown 的
  per-matter 归属沿 attempt 事实，独立 readiness 快照待专门票。
