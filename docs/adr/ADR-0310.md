# ADR-0310 · 新建工作区表单：复用真实接入链路的形状装配

- 状态：accepted（2026-10-11）
- 日期：2026-10-11
- 决策者：用户（lute：同意 Loop-Q R12，可并行处并行）＋ agent（并行线实施）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-11-workspace-create-form.md)
- 相关：[ADR-0309](ADR-0309.md)（同轮）、T03 票据（workspace/adopt）

## 背景

R12 线 A：`QDR.P13.create.empty` / `create.ready`（新建工作区表单：源文件夹/名称/图标/颜色；选目录后主要标签/自动名称/创建可用/保存瞬态）。Sage 已有真实 adopt 链路（`/.sage/workspace/adopt`，pick+创建一体，诚实三态）——**不复刻第二套创建路径**。

## 决策

1. **D1 形状装配**：WorkspacePage 新增「新建工作区」表单（空表单：未选择文件夹/名称空/图标三选项/颜色三选项/创建禁用；图标与颜色默认首项选中、选择纯本地）。
2. **D2 复用真实链路**：「选择文件夹」调既有 `adoptDesktopWorkspace()`（adopt.ts 零改动）；adopted → 目录行（title + 「主要」标签 + 路径）+ 名称自动 + 创建启用 + 具名 note；cancelled/refused → 表单不动、note 具名。
3. **D3 两段式差异显式登记**：观察为「先选目录、再点创建才保存」两段；一体路由下选目录即完成真实接入——「创建工作区」点击只结算本地草稿（瞬态「正在保存……」+ 结算 note），**不发第二次 adopt**（spec 断言请求次数恒 1）；差异进 blocker 与代码注释。
4. **D4 草稿状态上提**：表单 state 置于 WorkspacePage 顶层——`retry()` 的 transient loading 不丢用户已选（这是满足「选目录后名称自动填入」的必要实现，非额外发挥）。
5. **D5 迁移**：2 行迁 `ui` `pending→implementing`；blocker 登记：两段式差异、图标/颜色标签为本地占位（观察未记录清单）、选择不持久化、组内 edit/remote/archive 未装（P13 伞行保持 pending）。summary 生成器重算（83→85 implementing、115→113 pending）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 新建第二套 pick/create 路由 | 否决：adopt 是唯一已治理的创建链；平行第二路径违「一条事实一个家」。 |
| 图标/颜色列表照搬臆造清单 | 否决：观察未记录清单；用本地占位并登记。 |
| 创建点击再发一次 adopt 请求 | 否决：重复创建风险；spec 断言请求恒 1。 |
| 「正在保存」人造延时以可见 | 否决：不造人工时序；瞬态为同步置位，终值可断言。 |

## 后果

- 工作区创建面（形状 + 真实接入）上线；P13 伞行余 edit/remote/archive。
