# ADR-0094 · gate 结论统一记账，live preset row 身份以受控解析与 inventory 闭合

- 状态：accepted
- 日期：2026-09-16
- 决策者：用户（lute）+ agent
- 决策记录：[Note](../notes/implemented/contract/2026-09-16-gate-result-accounting-and-live-preset-inventory.md)
- 相关：ADR-0014（门禁硬门槛）、ADR-0075（空射程三态）、总账 P-02 / P-03

## 背景

总门禁已有 `passed`、`skipped`、`note` 等局部约定，但没有统一分母；必备文件缺失、可选环境缺失、
“环境存在却一个对象都没量到”仍可能长得一样。`live-presets` 又只识别“像路径的 name”，使裸包行
不进分母；未知 `!!js` 表达式还会被当成 disabled。结论即使为绿，也无法证明所有对象都被解释。

## 决策

1. 总门禁只消费一个 canonical result schema：`status`、`expected`、`discovered`、`checked`、
   `skipped`、`failed`、`typedSkips`、`reason`、`violations`。必须满足
   `expected = checked + skipped + failed`；空射程不得 pass，checker throw 与非法返回一律 fail-closed。
2. 旧 checker 只通过集中 adapter 映射为一个 gate 级测量单元；新 checker 不得同时返回 canonical
   与 legacy 两套含义。文本与 JSON 共用同一结果，`--require-no-skip` 遇任何 skip 返回非零。
3. 必备治理文件缺失是 fail；可选 profile、staging 或本机运行环境整体不存在是 typed skip；
   “环境已存在但没有对象”仍是 fail。各业务 checker 的完整对象覆盖由后续 QG-003/004/005 等卡继续闭合。
4. `live-presets` 不引入新 YAML dependency：按 pinned DSH composition 的 row 形态实现受控 indentation parser，
   只接受 top-level row 与 `group: true` 的 nested `config` row；解析不确定、错误缩进、重复 ID、缺文件、
   未知 dynamic expression 一律 fail。裸包、scoped package、相对/绝对/`file:`/`cordis:` 全进入分母。
5. 每条 row 产生 `presetId + rowPath + entryId` 稳定身份与 checked/disabled/failed 分类。仓库保存按 preset
   聚合的 row identity SHA-256 inventory，只绑定 stable ID、specifier 与类型，不保存用户 config 或凭证。
   删除、增加或替换一条仍可解析的 row 都会使 inventory 漂移并返回非零；经批准的结构变更必须只读重采、
   人工审查后再以 patch 更新 inventory。

## 备选方案

- 只把 `skip` 换一种颜色：没有分母与守恒，仍无法区分漏测，否决。
- 一次性重写所有业务 checker：会把 QG-001 与 QG-003/004/005 的判据变化混成一批，否决；采用集中 adapter 迁移。
- 直接在根包新增 YAML parser：现有根依赖没有该能力，且本卡只需宿主 composition 的窄子集，否决。
- 只比较当前 row 总数：删除一条再增加另一条可保持数字不变，否决；inventory 绑定逐 row 身份摘要。
- 把真实用户 preset 正文入库：会复制用户配置并扩大敏感信息面，否决；只存不可逆结构摘要。

## 后果

- 普通 gate 允许 typed skip 但不把它计作 pass；strict gate 会对当前平台明确 disabled 的 preset row 返回非零，
  这是 no-skip 语义而不是失败误报。
- inventory 把有意的 live preset 结构更新变成显式评审动作；直接改用户目录而不更新治理清单会被门禁拒绝。
- 受控 parser 不是通用 YAML parser；DSH composition 若引入新 row 形态，必须先扩契约与负例，不能 permissive fallback。
- 本轮只读扫描真实 preset；所有删除、替换、缺文件和缩进 mutation 都发生在临时目录，没有修改 `~/.dsh`。
- 并行启动多份全 gate 时，既有共享 fixture 曾使 `settings-shell-criteria-selftest` 瞬时失败；该聚合并发边界归
  QG-006B，本决策不把一次串行复绿冒充其已解决。
