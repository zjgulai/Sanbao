# ADR-0257 · UI-TOKEN-01 / RUNTIME-03A / UI-A11Y-01：唯一 semantic token、真实主题与可访问性

- 状态：accepted（2026-10-04）
- 日期：2026-10-04
- 决策者：用户（lute，确认执行 Batch 10）
- 决策记录：[Note](../notes/implemented/surface/2026-10-04-semantic-theme-accessibility-batch-10.md)
- 相关：[ADR-0254](ADR-0254.md)、[ADR-0256](ADR-0256.md)、[UI 一致性合同](../specs/2026-09-27-sanbao-to-sage-ui-consistency-contract.md)

## 背景

三栏 BusinessMatter 工作台与六阶段 fixture 已有真实 wire 证据，但 surface 仍固定 dark，palette 与组件 CSS 共居，undefined/fallback token 可隐藏断链；display theme 只持久化、不驱动 `nativeTheme`/DOM；Fake DOM 又把 Escape 直接投到预期 handler，无法证明真实 focus、AX、computed motion/focus 或 320 CSS px reflow。

## 决策

1. `product/theme-tokens.ts` 是 light/dark literal palette 与 semantic roles 的唯一 owner。renderer/component 只消费已声明的 `--sage-*`；禁止 owner 外 color literal、第二处 token 声明、fallback、`--sb-*`/`--sanbao-*`。brand 与 success/warning/danger 分离；normal text canonical contrast ≥4.5:1，focus/non-text ≥3:1。
2. Electron main 在 `BrowserWindow` 创建前恢复 persisted requested theme，并精确写 `nativeTheme.themeSource=system|light|dark`；保存失败不应用，保存成功后才应用并重读 main-owned system observation。built `product/theme-tokens.js` 必须进入 profile runtime 清单。
3. renderer 只把权威 preferences projection 投成 `data-sage-theme-requested` 与 `data-sage-theme-effective`；effective 缺失写 `unknown`。`prefers-color-scheme` 只提供视觉 fallback并触发 re-read，不拥有 effective fact。
4. Batch 10 只声明 theme 实时应用；其余七项 preference 仅保存。完整 RUNTIME-03 保持 open。
5. 一级导航使用 vertical tablist、单一 roving tab stop 与稳定 accessible names。user menu Escape 覆盖真实 trigger/panel focus path。trace rail wide 为 complementary；仅窄宽 open 时为 modal dialog，Tab/Shift+Tab containment、document Escape、close/Escape focus return 与 1440↔760 往返必须稳定。
6. 完成证据必须来自真实 Electron：Accessibility tree、activeElement、computed focus、CDP reduced-motion、light/dark/system、第二进程 restart、约 320 CSS px root/internal overflow allowlist与截图；Fake DOM/string/PNG hash 只能作为局部证据。
7. 本批不新增业务 ActionIntent、route、authority、provider、Host、domain persistence、dependency/package/lockfile 或最终 renderer 技术栈，不声明 production E2E 或完整 Qoder UI/UX 复刻完成。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| renderer 内保留 dark palette 并叠 light overrides | 否决：产生第二个事实家，无法守引用闭包。 |
| 复制 Qoder / Sanbao CSS、asset 或 runtime | 否决：外部原型只作证据输入。 |
| renderer 根据 matchMedia 自行决定 effective | 否决：system observation 属于 Electron main。 |
| 保存前先改 nativeTheme | 否决：持久化失败会造成运行态与回执分叉。 |
| 宣称八项 preference 都 live | 否决：只有 theme 已形成产品应用链。 |
| 继续向 panel 直接投 Escape、只查 CSS 字符串 | 否决：跳过真实 focus/event/computed behavior。 |
| 引入 React/CSS-in-JS/新 dependency | 否决：最终 UI 技术栈仍由 UI-DECISION-01 决定。 |

## 后果

- UI-TOKEN-01 与本批列明的 UI-A11Y-01 范围完成；Sage 拥有唯一 semantic palette、可验证双主题、稳定键盘/focus/modal/reflow。
- RUNTIME-03A 完成 theme 子链：persisted requested → Electron nativeTheme → Chromium preference → authoritative root attributes → restart；完整 RUNTIME-03 仍未完成。
- 未核验 theme effective 继续显示 unknown；system fallback、fixture、Host ready 或 screenshot 不能升级为业务 authority。
- 六阶段 fixture 继续 blocked / zero-write，production matter-null / unavailable-first 不变。
- 本 ADR 不授权 commit、push、merge 或发布。
