# ADR-0243 · 集成终端只读呈现：两读端点、缺项未就绪与「面板开关不触执行」

- 状态：accepted（2026-10-03）
- 日期：2026-10-03
- 决策者：agent（取证并实施；FW-037、US-203/204 已定方向）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-03-terminal-readonly.md)
- 相关：[ADR-0230](ADR-0230.md)（033 产物呈现与机器路径纪律）、[ADR-0238](ADR-0238.md)（038 只读清单先例）、[ADR-0198](ADR-0198.md)（host 消费登记）

## 背景

工单 043（FW-037，US-203/204）：**终端只在工作台侧面板内提供，打开/关闭不影响执行**；
**输出作为运行观察只读呈现**；**不进入事项对话历史、不作为交付产物、不接收权威动作输入**；
**无可用终端时显示未就绪与缺项**。原产品证据：P14.terminal.entry + M03 终端工具。基座事实
（pin 包 `dsh-terminal`）：`ctx.terminals`＝owner 作用域 PTY 注册表——`list(owner)` 出
`TerminalSessionSnapshot{sessionId,name?,type,pid?,status:running|exited(exitCode,signal)}`、
`read(owner,id,{offset?,count?})` 出**有界滚动页** `{text,totalLines,lineBegin,lineEnd,truncated}`；
写半边（spawn/kill/signal/send）存在但本票**一律不接**。

## 决策

1. **D1 只读桥两枚**：`session/terminals`（read：`agents.get`→`terminals.list`；行有界 ≤16、
   **裁掉 pid、无 cwd**，只留 identity/name/type/process status；提供者缺席=
   `bridge-provider-unavailable`、无活代理=`bridge-session-not-live`）与 `session/terminal-read`
   （read：`{sessionId,terminalId,offset?,count?}`→`terminals.read`→**text 上限 64KiB 截断标注**+
   分页元数据）。消费登记 +`terminals`；host 表 deliberate +2。
2. **D2 未就绪=缺项具名，绝无空终端**（验收 1）：无 terminals 服务→store `unavailable`+reason
   （`terminals-provider-unavailable`）；「有能力但零会话」与「无能力」分开成两句话——
   前者是合法空态（"当前没有终端会话：这里只作只读观察，不在此创建终端"），后者是缺项
   （"未就绪：终端能力不可用（…）——缺项未满足，不显示空终端"）。
3. **D3 只有清单内的会话可分页**（038 同纪律）：`read` 先对最近一次 list 投影校验，
   不在清单=`terminal-not-listed`（"不是已失效"）且零桥调用；offset/lines 双层校验
   （store＋route：offset≤1e6、lines 1–500）；`/paused` 与 terminal 无关（观察不写）。
4. **D4 面板开关不触执行（结构）**：无 spawn/kill/signal/send/cancel 任何写端点；打开=本地
   开关＋一条有界读页，关闭=**纯本地零请求**；调用表恰 `['session/terminals',
   'session/terminal-read']`（spec 断言）⇒「关闭面板后运行状态不变」「输出不进对话历史/产物
   列表」都是结构事实而非承诺；渲染面块内无 input/textarea/select（静态切片断言）。
5. **D5 首版不做**：终端内命令执行授权扩面、终端会话持久化与导出、真实 shell 包装的产品承诺
   （工单边界）；写半边桥面永不出现。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 接 spawn/kill 让 Sage 建/关终端 | 否决：US-203/204 只要求只读观察与入口；扩面违背工单边界。 |
| 无能力时渲染空终端壳 | 否决：验收 1 明令显示缺项、不显示空终端。 |
| 输出进对话历史或产物列表 | 否决：US-204 明令；且读路由只回观察页，无任何入史入列路径。 |
| 暴露 pid/cwd 便于核对 | 否决：033 机器路径纪律；pid 对只读观察无用户价值。 |
| 打开输出即长订阅流 | 否决：基座 read 是有界页；循环轮询会造第二推流面，首版不做。 |

## 后果

- 验收两条机器断言：①无终端能力→unavailable＋缺项句（不显示空终端）；②终端输出不出现在
  事项对话同步与产物列表（调用表恰两读＋transcript 容器不受影响＋文本只落 `#terminal-output`）。
- 桥面 +2 端点（均 read）；消费登记 +`terminals`；host 表 deliberate +2；端口名册 +1
  （terminalRead）；033 装配守护 +1 族；路由 +1（`/.sage/session/terminal-read`）。
- §1.6：真产物两宽（1440/660）亲看——标签＋「终端 2 项（只读运行观察；打开/关闭面板不影响
  执行）。」＋两行（构建·bash 运行中／本地服务·bash 已退出（exitCode 1）＋[打开输出（只读）]）；
  flow 页展开态：按钮变[关闭输出]＋输出页＋「只读运行观察（第 0–2 行 / 共 12 行）——不进对话
  历史、不作交付产物，也不接收操作输入。」；DOM 读数恰一条 POST `{terminalId:'t-1'}`。
- 已知未闭：真实 PTY 会话真机未跑（本机不装载 profile/不启 Host，store/bridge 全以替身驱动）；
  长输出滚动导航与历史终端会话（持久化）后置；真机 Electron 未跑；matter 投影生产恒 null。
