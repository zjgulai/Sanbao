# ADR-0308 · 知识/站点页壳第二批：创建弹窗与列表工具形状

- 状态：accepted（2026-10-11）
- 日期：2026-10-11
- 决策者：用户（lute：同意 Loop-Q R10）＋ agent（实施）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-11-knowledge-create-shell.md)
- 相关：[ADR-0307](ADR-0307.md)（第一批页壳）、[并行侦察记录](../notes/implemented/process/2026-10-11-scope-and-knowledge-sites-recon.md)

## 背景

第二批 6 行（create.open/workspace/ready、workspace-filter.open、repo-wiki.default/list）：表单/配置结构的形状观察，创建与生成仍是受保护动作（无 provider）。

## 决策

1. **D1 创建弹窗（形状）**：名称（placeholder「例如：工程手册」、maxLength 50、`N/50` 计数）；生效范围 radio 用户（选中，含观察说明文案）/工作区；工作区范围 = 「选择工作区」菜单（多选 toggle、Escape 只关菜单）+ 「至少选择一个可以使用此知识库的工作区」提示 + 已选 chips；创建禁用当名称空或工作区范围未选；就绪≠成功——点击创建 → 具名拒绝（T12 未接通），弹窗不关闭也不声称成功。
2. **D2 真实数据**：工作区菜单与 chips 使用真实 workspaces 槽的标题（观察的 paper-plane/qoder-ui-fixture 为原型虚构名，不复制）；列表级「全部工作区」筛选菜单同源。过滤语义（真实列表过滤）随 provider 登记。
3. **D3 Repo Wiki 默认形状**：标题文案、搜索、**三态**筛选（全部/已生成/未生成）、右侧卡片/列表切换；**不渲染零指标示例卡**（指标含义未核实）——数据区保持具名未接通；「去生成」入口不装。
4. **D4**：6 行迁 `ui` `pending→implementing`；blocker 登记未观察面（Escape/遮罩/焦点恢复、chip 移除、跨范围保留、列表布局）与 provider 依赖。summary 生成器重算（66→72 implementing、132→126 pending）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 渲染观察到的零指标示例卡 | 否决：指标含义未核实——显示 0 即冒充真实读数。 |
| 复制观察的虚构工作区名（paper-plane） | 否决：使用真实 workspaces 槽；虚构名只属于原型。 |
| 创建点击关闭弹窗并提示成功 | 否决：就绪≠成功；具名拒绝且不改变状态。 |
| 装「去生成」入口 | 否决：生成属受保护 effect，无 provider 前不放假入口。 |

## 后果

- 知识族余量收窄至 2 行（setup/knowledge-cards 生成族）+ loading/wide；创建链与过滤语义随 provider 票。
