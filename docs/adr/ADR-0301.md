# ADR-0301 · 执行模块第三刀：回合过程面（完成元信息与文件活动）

- 状态：accepted（2026-10-11）
- 日期：2026-10-11
- 决策者：用户（lute：同意 Loop-Q R3）＋ agent（取证与实施）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-11-turn-process.md)
- 相关：[ADR-0298](ADR-0298.md)（R1 活流）、[ADR-0300](ADR-0300.md)（R2 产物面）、基座 `ui-chat` TurnProcess 语义

## 背景

Loop-Q R3 三行：`QDR.M01.reply.completed`（回复显示成功、耗时与模型迭代信息；T06）、`QDR.M02.file.writing`（运行过程显示写入文件及计时；T09）、`QDR.M02.edit.expanded`（编辑文件完成项列表，关联文件与查看修改入口；T09）。盘点基座（vendor/dsh-desktop `ui-chat`）：`SessionFormatEvent` 携带 `seq` 与 `time`（毫秒纪元；`TurnProcessNodeView` 用 `turn.end.time - turn.start.time` 求耗时，`step/start` 计数迭代）；工具活动由 `tool/call`/`tool/result` 事件对承载，工具名 `write`/`edit`/`apply_patch` 为文件写入族，参数键 `file_path`/`path`。Sage 缺口：通道 fold 忽略这些事件。

## 决策

1. **D1 fold 扩展（durable 唯一源）**：`foldSessionFrames` 新增 `turnProcess` 累积——`turn/start` 重置并记 `startedAt`（`event.time` 毫秒，缺则 null）；`step/start` 计数（iterations）；`tool/call` 仅 `write/edit/apply_patch` 入列表（`callId` 关联、`file` 只取 basename——机器路径不过投影）；`tool/result` 按 `callId` 结项（`isError` → failed）；`turn/end` 记 `endedAt`。上限 12 项。耗时仅在两端都带毫秒戳时计算（**绝不猜**）。
2. **D2 契约**：`SessionChannelStatus.turnProcess = { durationMs, iterations, fileWrites[{name, file, state, durationMs}] }`（read/no-session/unavailable 三处构造齐；页面重放合并取 pageFold）。desktop 侧宽容解析（非法片段退化为 null/空，不致命）。
3. **D3 renderer**：执行中显示 live 行「正在写入/编辑 <basename>… · Ns」（计时自 Sage 观察到该调用起，本地 ticker——不是基座计时）；回合终态显示 footer「已完成/回合失败/已停止/本轮已结束 · 耗时 X · N 步」+ 可折叠「执行过程（N）」逐项列表（写入/编辑 文件 · 完成/失败 · 单项耗时）。error/aborted 不显示耗时（基座语义：取消与失败替换耗时）。
4. **D4 未装面显式登记**：编辑项的「查看本次修改」入口**不接线**——diff 面属 A01 行未装配；blocker 明写。三个行迁 `ui` `pending→implementing`（tracked-test refs，`countsAsVerification:false`）；summary 生成器重算（22→25 implementing、176→173 pending、verified 8 不变）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| live 工具事件走 SSE 增量 | 否决（本刀）：durable 轮询 ≤2s 已覆盖运行中显示；SSE 只运助手文本，面更窄。 |
| 展示完整文件路径 | 否决：机器路径不过投影（basename 规则，与 artifacts 一致）。 |
| 用 arrival 时间测耗时 | 否决：轮询批量下不可靠；只用日志自身的毫秒戳，缺则显示未知。 |
| 「查看本次修改」入口先放占位 | 否决：不放假入口；A01 diff 装配后接线。 |

## 后果

- 执行面获得完成态元信息与文件过程列表（durable，重开可复现）；live 行覆盖写入中状态。
- 三行迁 implementing；diff 入口依赖、真机边界（真实写入流）登记 blocker。
- `step/start`/`tool/*` 事件自此有 fold 消费者，为 A01/S10 行铺路。
