# ADR-0132 · 色彩与排印契约：钛银单主色、1 套品牌 × 明暗双色道、材质解禁、`--wp-*` 为源并纳入门禁

- 状态：accepted（2026-09-19）
- 决策者：用户（lute）+ WorldPilot 全维度换皮轮
- 取代：`docs/plans/2026-09-19-capability-hub.md` D3（主题预设「收缩到 3–4 套：codex/graphite/midnight + 1」）——本 ADR 改判为 1 套 × 2 色道
- 相关：ADR-0009（一份事实一个家）、ADR-0128 D4（`--lute-*` 命名空间与 theme-tokens 门禁射程）、ADR-0131（品牌收口与射程）；总账 P-07（一条事实多个家）、P-02（仪器假绿）

## 背景

素材源仓 `website/src/styles.css` 的第一行注释即其自我定位：
`Version 1 — one palette contract across every section and interaction.`
它是一份完整的中性阶 + 强调 + 语义 + 材质 + 动效契约，而不是一组十六进制。

现状的四处事实使换皮不能只做「替换色值」：

1. **主色有四个家**：`#58B848` 同时住在 `dsh-root-brand-local/src/client/brand.tsx:18`、
   `shared/client/lute-tokens.ts:43`、`dsh-newapp-local/src/client/newapp.module.css:64` 起的 Brand block、
   以及官方 UI 补丁 `dsh-client-ui-agent-preset/lib/client.js.patch:7`（作为 `patch-anchors` 门禁的**锚文本**）。
   另有三个校验器各自复述（`brand.test.tsx:12`、`layer-icons.spec.ts:61`、`agent-fullstack.test.mjs:342`）。
2. **一条美学断言的前提已被作废**：`brand-css.test.ts:51` 的测试名逐字是
   「品牌强调遵循 **Codex 视觉基线**，不使用渐变或装饰性辉光」，而 `codex` 正是被本 ADR 退役的绿系人格；
   同时 WorldPilot 的签名恰是材质（`--metal-fill: linear-gradient(145deg,…)`、`--metal-line`、`--metal-shadow`）。
3. **新命名空间对门禁隐形**：`scripts/gates/theme-tokens.mjs:57` 的
   `NAMESPACE = '--(?:dsw|ds|dsh)-'` 不含品牌自有前缀。该文件注释已预言后果——
   「门禁看不见、页面照走字面兜底，又是一个静默失败」。
4. **既有路线图的预设清单建立在「绿活着」的前提上**：S4 D3 的四个候选里 `codex` 的定义就是「绿系人格」，
   而 `midnight`（深蓝）与 `graphite`（中性）在换皮后与钛银阶 `#0b1521/#142332` 语义重叠。

对比度实测（WCAG，本 ADR 的取舍依据）：

| 读数 | 素材源仓 | 现状 |
| --- | --- | --- |
| 暗色 accent on bg | **11.72:1**（`#c4d0dc` on `#0b1521`） | 6.99:1（`#58B848` on `#171A17`） |
| 亮色 accent on bg | **7.62:1**（`#3d566e` on `#ffffff`） | 5.29:1（`#347A2F` on `#ffffff`） |
| 硬编码回退字面量在亮色底 | — | **2.33:1**（`#58b848` on `#F6F7F4`，低于 UI 组件 3:1 线） |
| accent 填充上的文字 | 10.14:1（`#122337` on `#c4d0dc`） | — |
| accent 与 muted 的色距 | ΔE\*ab **8.7**（暗）/ 8.6（亮） | 无同族冲突 |

即：换皮在可访问性上是**净改善**，唯一代价是 accent 与 muted 落在「并置可辨但不显眼」区间。

## 决策

**D1 全量照抄素材源仓 token 契约，钛银为唯一强调色。** 暗 `#c4d0dc` / 亮 `#3d566e`，
中性阶、语义 `--good`（`#8adac4` / `#176c57`）、`--radius 8px`、动效
（`160/260/520ms` + `cubic-bezier(.22,1,.36,1)`）一并采纳；`#58B848` 全面退役。
理由：ADR-0131 D1 既已选定单品牌收口，就不该在第一条 token 上推翻素材源仓自己的裁决
（「固定钛银主色，已移除主色筛选入口及蓝、绿两套品牌主色」）。

**D2 主题收敛为 1 套品牌 × 明暗双色道，取代 S4 D3 的四套清单。**
`codex`（绿）、`graphite`、`midnight` 全部降为 legacy：不进预设墙，分享串仍可解析但提示迁移。
派生引擎不动。理由：`midnight` 与 `graphite` 在换皮后与钛银阶重叠，留着等于让用户在三个
几乎一样的深色里选择；而素材源仓的契约本来就是「one palette contract」。

**D3 把混装断言拆成两条真实关切。** `brand-css.test.ts` 的渐变禁令一分为二：
材质渐变（`linear-gradient`）**合法化**——它是品牌签名；装饰性彩色辉光（带色相的 `box-shadow`）
**继续禁止**——那正是它原本要拦的东西（现状 `client.js.patch:7` 里那个绿光晕即此类）。
测试名改判为「遵循 WorldPilot 材质契约」。

**D4 双轨 token：`--wp-*` 为源，官方别名为派生，并把 `--wp-` 纳入门禁命名空间。**
可映射到官方别名的（accent / state）一律覆写 `--dsw-alias-*` 与 `--dsw-static-deepseek-*` scale，
让基座 UI 自动跟皮；品牌独有语义（`--metal-*` 材质、`--ux-*` 动效）住 `--wp-*`。
**硬规则：`--wp-*` 只做源、别名只做派生，同一条值不得在两处都写字面值。**
`theme-tokens.mjs` 的 `NAMESPACE` 扩为含 `wp`，并同步建立 `--wp-*` 的定义之家——
否则扩了命名空间会把全仓判红。

**D5 Inter 做默认 UI 字体，并采纳 mono 元标签原语。** `uiFont` 默认由 `system` 改 `inter`
（基座 bundle 已内置 `@fontsource-variable/inter` 的 6 个 woff2 子集，**零新资产**）；
把素材源仓的两个排印签名提为共享原语：`.tiny`（mono 11px / 字距 1.3px / 大写）与
`.eyebrow`（11px / 字距 2.5px / 650 / 主色 + 前导 27px 短横）；标题收紧字距
（h1 `-.055em`、h2 `-.045em`）。**不采纳官网的 `Arial` 字体栈**——那是
`website/README.md` 自陈的「无需安装前端依赖」妥协，不是品牌裁决；
品牌字标面住在 logo 包（`brand/logo/README.md:3`「字标使用产品已有的 Inter SemiBold」）。

**D6 不纳入 `--kg-*` 七色分类板。** 它的键是素材源仓的 7 条 `domains`（SP/IO/SA/AD/CO/OL/TP），
而本仓产品内实际渲染的是 8 条 `FLOW-01…08`，材料仓权威 `e2e-value-streams.json` v1.1.0 的
`mece_rule` 又声明 12 条（8 业务经营流 + 4 能力供应流）。三个口径互斥，色板无落点。

## 备选方案

| 方案 | 为什么未采用 |
|---|---|
| 钛银做品牌色 + 另留一个饱和交互色 | 可供性最强，但直接违背素材源仓「已移除绿主色」的裁决，且盘上多出一个「谁是主色」的家 |
| 交互态另立 derived token（选中/焦点走材质渐变与加粗边框） | 最贴「quiet surfaces, precise edges」原意，但新增 token 家族使 theme-tokens 射程与工作量显著上升。作为 **D1 实测不达标时的升级路径**保留，而非默认 |
| 复用 `--lute-*` 命名空间只换值 | 零门禁改动、零迁移，但 `--lute-brand` 里装着钛银，与 ADR-0131 D1「LUTE 退为内部标识」在代码层自相矛盾 |
| 全部表达为官方别名、不引入新命名空间 | 与基座同构、零新增之家，但官方只有 accent/state/radius/shadow/font 族，中性阶、材质、分类色**无槽位**，多余的值只能退回内联字面量——反而制造更多个家 |
| 保留 4 套预设、`codex` 原地改色 | 与已登记路线图零冲突，但 `codex` 这个名字不再指代它原本的东西（名字撞谎），且 4 套深色彼此难以区分 |
| 把七色当装饰色循环给 8 责任域上色 | 8 个域用 7 个色必然至少一色复用两次——两个不同域同色是分类色的致命缺陷，且 `--kg-SP` 不再指代 SP |

## 后果

- **正面**：主色从四个家收口为一个源 + 派生；可访问性净改善（亮色回退字面量从 2.33:1 升到 7.62:1）；
  主题面从 15 预设 × 8 色卡收敛为「一套品牌 × 明暗」，与 S4 的收缩方向同向且更彻底。
- **负面 / 需跟进**：
  1. **ΔE 8.7 是本 ADR 已知且接受的风险**。必须在真机验收里给出「选中态 vs 次要文字」的可辨性读数；
     不达标时走 D1 的升级路径（材质派生交互态），**不得**回退为「另留饱和色」。
  2. 扩 `NAMESPACE` 到 `wp` 会立刻把全仓未定义的 `--wp-*` 引用判红，因此**同一次提交**必须建好定义之家。
  3. `theme-tokens-baseline.json` 是只减不增清单，`exemptions.json` 当前为空——本 ADR 不为其开豁免；
     存量违规必须在换皮提交内清零。
  4. 改默认 `uiFont` 会改变字宽，`sidebar-row-axis` 门禁的列轴与 `TARGET_SIDEBAR_WIDTH=264`
     必须实测复核，不能推断为「应该没事」。
  5. `LEGACY_EDITORIAL_SIGNATURE`（`theme-settings.ts:126-131`）是**按十六进制字面量做解码期分支**的
     兼容逻辑；改默认值后必须验证它不会把新的钛银默认误判为旧 editorial 签名。
  6. 本 ADR 不决定 logo、头像、文案与门禁改造的形态（ADR-0133、ADR-0134）。
