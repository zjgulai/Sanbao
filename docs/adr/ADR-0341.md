- 日期：2026-10-13
- 决策者：用户（2026-10-13 五点裁决：命名「专家」/独立概念组合 Preset/3+50 为内容源/工具白名单只读 Registry/Fail-closed）＋ agent（逆向与映射设计）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-13-expert-system-research.md)
- 票据：[专家体系集成票](../plans/2026-10-13-expert-system-tickets.md)

## 背景

用户指令：把 Accio.app 的「智能体/专家」UI/UX 复刻到 Sage，Sage 侧语义 = Preset + 知识库的组合；内容源是 AI组织变革项目的 **3 MGT + 50 AGT 岗位体系**（role-catalog、soul.md、Role Playbook、Preset Blueprint——状态 design_only_not_importable、53 视觉身份含 webp 头像）。

逆向方法：REA 6.4.0 静态分析（Accio 0.24.1：8984 JS/855 模块/164 IPC）+ asar 静态提取 + 真机截图（0.24.1 智能体网格页、0.34.4 专家会话视图）。中文文案为运行时远程拉取，数据模型全部从主进程打包体逆向。

## 逆向发现（Accio 数据模型）

```
智能体/专家 = {
  name, avatar（像素头像）
  agentType（9 种内置 persona：coder/ecommerce/finance/product-manager/
            daily-assistant/reviewer/shopify-operator/dropshipper/main）
  model: { provider, name, reasoningEffort, displayName }
  systemPrompt: string
  soulMd: string          ← "# Soul 人格 + # Identity 身份" markdown（Accio 核心创新）
  allowedTools: string[]  ← 工具白名单
  mcpServers, defaultProject, runtime, agentInstanceId
}
0.34.4 增：专家团（teamId）、会话场景 tab（预设场景指令集）、内置专家注册表
         （带 id/version/name/description 的 persona 库）、tone 枚举
         （professional/friendly/creative/concise/casual/expert）
```

知识库 = 文件/文件夹上传 + folder 组织 + `<knowledge_base_refs>` 注入会话 + RAG；插件 = 自由市场安装（pluginId/pluginStatus 全生命周期）。

## 决策

1. **D1 命名「专家」**：Sage 侧新概念 Expert（专家）；UI 交互复刻 Accio（卡片网格 + 新建虚线卡 + 对话直通），文案走 Sage 治理调性，不逐字照搬 Accio 消费级文案。
2. **D2 独立概念、组合 Preset**：`ExpertProfile` = 身份（名称/头像/使命）+ prompt 面（来自岗位 soul.md/Role Playbook）+ model 配置（ADR-0339 的 model-config）+ 工具白名单（只读 Registry 已 approved 项）+ 默认工作区（custody）。Preset 保持纯粹；Expert 是 Preset 的**消费者与组合者**。
3. **D3 内容源 = 3+50 岗位体系**：50 AGT + 3 MGT 作为首批内置专家目录——role-catalog.json（50 岗位：mission/personality/principle/skills/boundary）+ souls/*.soul.md + preset-blueprints（identity/modes 面板）+ 视觉身份 webp（53 身份 318 资产，路径规范 `dist/assets/visual-identities/…/agt-xxx/light/list-64.webp`）。凭证红线：这些资产状态是 design_only_not_importable——ExpertProfile 只**消费其内容为配置数据**，不声明岗位已获生产授权（production_authorized=false 保持）。
4. **D4 工具白名单只读 Registry**：创建/编辑专家时，工具白名单 UI 只列 Capability Registry 已 `approved` 的能力；创建动作不产生新授权（fail-closed，ADR-0171 红线不破）。
5. **D5 第一期范围**：专家列表（卡片网格）+ 专家创建/编辑（身份+prompt+模型+工具白名单）+ 对话直通（走 `/.sage/session/send` 既有 admission）。**不含**：专家团（等 L1-B 分组成熟）、知识库绑定（等存储 provider 票 T12）、场景 tab（随 Preset 场景预设批）。
6. **D6 零伪造**：无 ExpertProfile 存储面之前，专家列表可以是设计资产只读投影（来自 AI组织变革项目的静态目录，标注来源与 design 状态）——与「未接线」语义一致；创建/编辑/对话按钮在存储面落地前具名禁用或走显式 fixture 开关。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 专家 = Preset 的别名/超集 | 否决（用户裁决）：Preset 保持纯粹，Expert 组合之。 |
| 工具白名单允许创建时申请新授权 | 否决：绕过 Registry 审批即破 ADR-0171。 |
| 知识库绑定入第一期 | 否决：存储 provider 缺位 + 敏感数据红线，UI 先行无意义。 |
| 复刻 Accio 自由插件市场 | 否决：Sage 是治理模型，市场浏览形态可复刻、安装必须走审批。 |
| 直接照搬 Accio 文案 | 否决：调性差异（消费级 vs 治理级）是产品差异，只复刻交互。 |

## 后果

- Expert 是 Sage 第一个「面向组织岗位」的产品概念——把 harness 的 preset 能力、Registry 的治理授权、matter custody 串成用户可见面。
- 3+50 岗位资产从设计文档升级为 Sage 的**内置内容源**（静态投影先行）——AI组织变革项目的 preset 设计资产获得第一个运行时消费者。
- 后续票链：ExpertProfile 存储面（applicationService 批）→ 卡片网格 UI 批 → 创建/编辑流批 → 对话直通批；每批独立验收。
