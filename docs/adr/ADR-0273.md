# ADR-0273 · legacy packages 解耦与减重（加载期脱离 quarantine 区）

- 状态：accepted（2026-10-07）
- 日期：2026-10-07
- 决策者：用户（「另列任务处理」授权：陈旧锁、LUTE 身份处置包、legacy packages 减重与解耦）
- 决策记录：[Note](../notes/implemented/process/2026-10-06-portable-cleanup-and-handoff.md)（见其「另列任务收据」节）
- 相关：[ADR-0160](ADR-0160.md)、[ADR-0166](ADR-0166.md)、[ADR-0272](ADR-0272.md)

## 背景

`packages/` 是隔离的 legacy 插件区，但 `scripts/gate.mjs` 在 scope 过滤**之前**静态 import 其中两个模块（`dsh-overseas-skills/scripts/verify-agent-fullstack.mjs`、`fullstack-contract.mjs`），`scripts/gates/role-brief-shape.mjs` 同样静态 import `dsh-role-matrix-local` 的两个 `.ts` 源——**模块不存在时整条 gate 连加载都做不到**，这正是「不能整目录删除」的根源。实测体积：`packages/` 共 1.91 GiB，其中 `node_modules` ≈ 1.8 GiB（30 个包各自带 `pnpm-lock.yaml`，可重装）；跟踪源码仅 ≈ 113 MB，且工作区与 HEAD 无差异。受影响检查（`agent-fullstack`、`fullstack-catalog`、`fullstack-whitelist`、`role-brief-shape` 及其 selftest）全部住在 **legacy scope**，Sage BASE 不运行它们。

## 决策

1. **加载解耦＝容错 TLA**：上述两处静态 import 改为 top-level `await import()` + try/catch 兜底为 `null`；受影响的 legacy 检查在运行期对 `null` **抛出具名错误**（fail-closed，含 `git checkout HEAD -- packages/` 恢复提示）。Sage 域检查集合、断言与行为零变化；`runGateChecks` 的同步契约不动。
2. **缺席消融有实证**：整目录临时移开后，`gate --scope sage --list`＝32 项、`--scope legacy --list`＝156 项均正常输出；role-brief 判定在缺源时给出恢复提示并非零退出；恢复后工作区对 `packages/` 零差异。
3. **减重只清可重装物**：删除 `packages/**/node_modules`（30 个）与 `eval/out`（1 个）等 ignored 重物；**保留全部跟踪源码**（含 `lib/**` 253 个 tracked 文件）；重装路径＝逐包 `pnpm install --frozen-lockfile`（30 份锁在库）。
4. **完整源码退役不在本轮**：若未来要整体移除 legacy 能力，必须同批处理：撤 `.gitignore` 三处 packages 白名单条目（否则 `gitignore-whitelist` ghost 判红）、退役或迁移 fullstack-* / role-brief / wanzh-hulian 等 legacy 检查与 selftest、审查 `scripts/acceptance/*` 对 packages 的引用面；不得单删目录。

## 备选方案

- **把被引用文件复制进 scripts/**：拒绝——同一事实两个家（P-07），且 legacy 判定失去唯一源；解耦加载即可。
- **让 runGateChecks 支持 async**：拒绝本轮——动验收仪器本体（32 项 + selftest 全依赖其同步契约），收益与风险不成比例；TLA 达到同一目的且零契约变化。
- **删除整个 packages/**：本轮拒绝——超过「减重」，等于退役 legacy 能力（含 156 项 legacy 检查的主体）；前提核对见决策 4。
- **保留 node_modules 原样**：拒绝——1.8 GiB 全部可从锁文件重装（清理器读数：被引用的是源码，不是这些缓存）。

## 后果

- 异机传输体积减少约 1.8 GiB；`packages/` 结构性降为 ≈ 113 MB 源码区。
- legacy 门禁与相关 selftest 在重装前 fail-closed（报恢复路径，不静默变绿）；`.dsh-types` 落在包内的类型链接随 node_modules 一并移除，重装后以 `node scripts/dsh-types.mjs --apply` 重建。
- Sage BASE 门禁从此对 `packages/` 的**存在性**零依赖（缺席消融已证）；对 `packages/` 源码内容的引用仍只存在于 legacy scope。
