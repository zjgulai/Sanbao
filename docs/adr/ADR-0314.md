# ADR-0314 · T09 产物与工具结果批：逆向放大装配（A03/A04/A05/M03/M05/P12）

- 状态：accepted（2026-10-11）
- 日期：2026-10-11
- 决策者：用户（lute：同意下一批＋裁定 1–5）＋ agent（RE 侦察＋实施）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-11-t09-artifact-tool-results-batch.md)
- 相关：[ADR-0300](ADR-0300.md)（产物 rail）、[ADR-0243](ADR-0243.md)（终端只读）、ADR-0310（adopt 装配成例）、用户指令 2026-10-11（逆向 Qoder.app + rea）

## 背景

R15 = 合成榜第 3 名「T09 产物与工具结果批」。用户新增常驻指令（2026-10-11）：复刻信息不足时直接逆向本机 Qoder.app（0.4.4）并应用 morluto/rea 核心能力。逆向侦察（rea 静态 Evidence + app.asar 全解包 → 四线合成）把五伞展开为 17 个叶候选；用户裁定五项：①维持 ADR-0243 只读终端口径；②M05 源头=session-log 半边（ruling 2a）；③A03 随批并入；④P12 多窗模型不迁（Sage 单窗）；⑤caller-binding 补全独立成批（本批不碰）。

## 决策

1. **D1 逆向证据政策**：Qoder 0.4.4 静态逆向（rea-agent Evidence + asar 解包）为**设计输入**——版本戳（Qoder 0.4.4 static-bundle）+ 文件/符号锚点；静态锚点不证运行可达；矩阵「observed」仍以真机观察为金标准。**安全模型的差异刻意不迁**：Qoder 预览窗=全权 renderer（挂全量 IPC 面）+ 多实例去重注册表；Sage 保持非特权容器（own partition、无 preload、无网络/文件系统可达）与单窗模型——差异登记，不照抄。
2. **D2 A03/A04**：office/binary 维持拒绝具名（artifact-format-deferred/-unsupported）且**卡上标签**（「原格式预览尚未接通／不支持预览」——评审确认 sage-shell 无系统打开路径，「可用系统应用打开」的承诺措辞已去除）；文本族 too-large 具名化为 artifact-too-large（不再泄漏 bridge 码，可重试与 image/pdf/html/csv 同口径）；8-格式描述符表仅作对照（Qoder 的 maxByteLength/allowEmpty 取值不作 Sage 契约）；批注流、缩略三形态无 provider——不装。
3. **D3 A05**：三态收口——打开失败码→句子映射（format-deferred/format-unsupported 显示同义句而非裸 code）；exact-version 双读校验与同版本重试为既有断言并入本伞证据；**不装通用版本历史**（逆向证伪：Qoder 0.4.4 自己也没有——决定性事实，非猜测）；文件更新通知（watch→刷新 pill）留自然条件。
4. **D4 M03**：desktop 终端只读面板（terminal 槽宽容解析 + 清单/状态行 + 打开输出 POST 精确 `{terminalId}` + 有界页与行号注记）；打开/关闭纯本地，不影响执行；**零写面**（区内无输入控件，spec 断言）。PTY 双向维持不装（ADR-0243，用户 2026-10-11 确认）。网络半边=工具名归一（TOOL_VERB 映射表扩展）——只对真实到达的 item 名生效，不预造条目。
5. **D5 M05（ruling 2a：session-log 半边）**：session-channel 折叠保留**非 write** 工具结果文本（callId→openToolCalls 有界登记 + result 文本 32 条/8192 字符有界截断带「已截断」标记；文本属**会话内容类**——与既有 assistant 正文同敏感级、同投影面，结构化字段的「机器路径不过投影」纪律不变）。评审确认求值序：`toolResults` 在 composition 中**位于 sessionChannel 之后**（同请求取折；修复前曾位于其前、仅靠 runMonitor 顺带读兜底——缺陷已修）→ sync `toolResultDeclarations(matterRef)` → `index.ts` 装配 `createToolResults({declarations, artifactRecord})` → composition 中 `toolResults` 在 `sessionChannel` **之后**求值（同请求取折，非前一 poll）；write 族不进 declarations（其事实家=turnProcess，一条事实一个家）；desktop 消费：工具结果区渲染 typed 字段（text/key-values/table/link/image + refused 具名 + unsupported 具名），image 仅经既有版本化 artifact open 打开；kernel 的「按名拒绝、refusal 不替代渲染」语义不动。
6. **D6 P12**：chrome 平台化——darwin `titleBarStyle:'hiddenInset'` + `trafficLightPosition {16,12}`（纯函数 `previewWindowChromeOptions(platform)` 可测）；Sage 自绘文档（text/image/csv）经 `withWindowHeaderReserve` 预留头空（仅 `</head>` 一处注入、仅 document kind）；**artifact 自身 HTML 与 PDF 查看器不注入**；多窗模型不迁（单窗）。
7. **D7 迁移**：A03/A04/A05/M03/M05/P12 六伞行迁 `ui` `pending→implementing`（tracked-test 证据并集，countsAsVerification:false）；`applicationService` 全部保持 blocked 不虚升（violation/unavailable-first 状态不因壳批翻转——沿用 ADR-0313 D6 先例）；blocker 逐伞具名（自然条件、不可迁项、独立批）。summary 重算（102→108）。
8. **D8 对抗评审（本批内）**：提交前四透镜对抗评审（fold 语义/装配纪律/UI 诚实/安全与准入）+ 逐条默认反驳 + 完备性批评；确认缺陷全部修复后才提交。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 照 Qoder 迁多窗注册表 + 全权 renderer 预览窗 | 否决：违反非特权容器红线（own partition/无 preload/无网络）；单窗是 Sage 既有模型。 |
| 装通用产物版本历史列表 | 否决：逆向证伪（Qoder 亦无）；Sage exact-version 卡片模型已覆盖且更严。 |
| M05 走插件 declarations 合同（c） | 否决（用户裁定）：需 Compatibility/Registry 链（ADR-0165/0171 边界），不属 T09。 |
| M05 走 base hostResult 合同（b） | 推迟为独立批：触 base 合同边界。 |
| 工具结果与 turnProcess 双写 | 否决：write 族事实家=turnProcess，重复即两个家。 |
| 本批顺手补 caller-binding | 否决（用户裁定 1/5）：admission 行为变化需独立 ADR/批，本批三 route 保持 partial。 |
| 终端装 PTY 双向 | 否决（用户裁定）：ADR-0243 只读口径维持。 |

## 后果

- 会话页获得工具结果与集成终端两个真实读数面；产物卡对 office/binary 具名不支持态；独立预览窗进入平台化 chrome。
- 矩阵 102→108 implementing。
- 余量具名：图片网格（READY image artifact 自然条件）、文件更新通知（watch）、caller-binding 补全批、A05 计划产物版本集合、Qoder 对照面（多窗/全权 renderer/外链 hover——差异登记不再装）。
- 真机验证项：工具结果自然到达、终端真实输出、独立窗口观感——走查手册第 17 步记录所见，visualAcceptance/electronAcceptance 保持 pending。
