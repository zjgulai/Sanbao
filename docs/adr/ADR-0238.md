# ADR-0238 · 输入区技能与插件选择器：挂载投影只读、选择随请求携带与「未挂载≠已停用」

- 状态：accepted（2026-10-03）
- 日期：2026-10-03
- 决策者：agent（取证并实施；FW-036、US-189~191 已定方向）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-03-input-area-selectors.md)
- 相关：[ADR-0212](ADR-0212.md)（005 会话发送入口）、[ADR-0229](ADR-0229.md)（032 方案投影）、[ADR-0198](ADR-0198.md)（host 消费登记）、[ADR-0236](ADR-0236.md)（036 随请求身份先例）

## 背景

工单 038（FW-036，US-189~191）：技能与插件列表**只读来自挂载观察**（名称、来源、可用性），
启用/安装/市场跳转不做；**选择只对本次请求生效并随请求携带所选引用**；**未挂载显示不可用与
缺项，不说成"已失效"**；**选择插件不改变启用状态、也不宣称已获得能力**；**无 authority 时
unavailable-first**。基座事实：`dsh-skill` 的 `SkillRegistry`（服务名 `skills`）暴露
`snapshot(options)→{skills:[{name,description,whenToUse?,invocation:{modelInvocable,userInvocable},
source,provider}], complete}` 与 `get(name)`——`complete:false` 明确表示"发现未完成"（不得当作
技能消失）；插件侧复用 026 已立在 `sage-readout` 的**同一组合 runtime inventory 投影**
（安装时 identity/version/digest）——不新开第二份挂载观察。

## 决策

1. **D1 技能清单=基座注册表快照（只读、有界、带完备性）**：桥面新增
   `skills/snapshot`（read；`ctx.get('skills').snapshot({})`）——映射有界摘要（name≤128/
   description≤200/source≤64/provider≤64/userInvocable/modelInvocable，≤100 条）＋`complete`；
   提供者缺席=`skills-unavailable`（unavailable-first，不以空列表冒充）；消费登记
   `sage-service-consumption.json` 增 `skills`。
2. **D2 插件清单=同一 runtime inventory 投影**：`main/input-selections.ts` 的插件行由 index
   以**与 readout 相同的 classifyPlugins 结果**喂入（identity/version/digestShort）；不可读=
   `未核验：挂载清单不可读（不以空列表冒充，也不说成已停用）`。
3. **D3 选择=经校验的本次请求引用**：`select({matterRef,kind,ref})` 校验＝技能须已读且
   **`userInvocable`**（未知=`selection-skill-not-listed`——自带"不是已失效"语义；
   model-only=`selection-skill-model-only`）、插件须在**当前挂载行**（缺席=
   `selection-plugin-not-mounted`）；每事项 ≤4、去重；`clear` 单项/整类；**全程零桥写、
   不碰任何启用状态**。
4. **D4 随请求携带且只随一次**：`carryPrefix`＝`[/skill:name] [/plugin:identity] ` 有界前缀，
   由 index 的发送装配（`sendWithSelections`）拼进**同一发送入口**的正文；请求
   accepted/deferred 后 `consume` 清空（refused 保留供重试）；事项间互不泄漏。
5. **D5 渲染面（S8）**：输入区只读清单（名称/来源/可用性；model-only 按钮禁用并显句；
   插件行标「已挂载（组合内实际存在）」）；选中 chips 文案**「（随下一次发送携带）」**且插件
   chip 显式「不改变启用状态，也不代表已获得能力」——**选择不显示为"已启用"**；未核验/
   不完整各有具名句；select/clear 各恰一条 `/.sage/session/selections` POST。
6. **D6 首版不做**：技能/插件启用、安装、授权与配置写（§7.5）、技能市场跳转（工单边界）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 直接读 profile 文件系统列技能 | 否决：挂载观察的唯一权威是基座注册表；文件存在≠载入。 |
| 为插件另开挂载观察 | 否决：026 的组合 inventory 就是同一事实；第二个家必漂。 |
| 选择写入技能/插件启用状态 | 否决：US-189/191 明令；写面在 §7.5，不在此入口。 |
| 选择跨请求保留 | 否决：US-190 "只对本次请求生效"；consumed 即清。 |
| `complete:false` 时隐藏未发现项并标"已失效" | 否决：不完整≠消失；具名句明说"不得当作已失效"。 |

## 后果

- 验收两条机器断言：①列表来源为挂载观察（快照端点＋同一投影；未挂载/未读如实，不写"已停用"）；
  ②选择只影响本次请求（同事项下一次请求无前缀；另一事项全程不受影响；accepted 后清空）。
- 桥面 +1 端点（`skills/snapshot`）；消费登记 +`skills`；host 表 deliberate +1；端口名册 +2
  （inputSelectionsSelect/Clear）；033 装配守护 +1 族。
- §1.6：真产物两页——技能三行（可选用/仅模型可调用（本入口不可选））＋插件两行（已挂载
  （组合内实际存在））＋不完整句＋已选 chip（随下一次发送携带／[清除]）；真实 Chrome DOM 读数：
  select 恰一条 `{"action":"select","kind":"skill","ref":"quarterly-review"}`、SKILLS 3/PLUGINS 2、
  model-only 按钮禁用、不完整句在页。
- 已知未闭：真实 broker/authority 下的挂载观察仍待真机（快照端点真实调用未跑）；技能/插件写面
  （启用/安装/授权）与市场跳转后置；真机 Electron 未跑。
