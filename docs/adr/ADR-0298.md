# ADR-0298 · 执行模块第一刀：活流式输出（SSE follow）与视区跟随

- 状态：accepted（2026-10-11）
- 日期：2026-10-11
- 决策者：用户（lute：同意 Loop-Q 下一批）＋ agent（取证与实施）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-11-live-session-stream.md)
- 相关：[ADR-0251](ADR-0251.md)（projection-read admission）、[ADR-0297](ADR-0297.md)（同族只读入口）、[ADR-0293](ADR-0293.md)（durable fold 为最终事实）

## 背景

Qoder 复刻矩阵执行回流面 11 行 pending 的第一行 `QDR.S01.session.streaming`（T06）：断言「Markdown 标题／列表逐步出现，视区随输出推进；停止按钮保持可用」。Sage 现状：会话呈现全部来自 durable fold（`assistant/message` 最终文本），live 帧（`assistant-stream`）被通道 fold 明确忽略（"Live presentation only"）；全仓无 Markdown 渲染器；renderer 与 main 之间只有 fetch 请求-响应（无 preload/IPC push 面）。

## 决策

1. **D1 活流原语**：`sessionChannel.followLive`（ADR-0298）——对既有 `session/follow` 有界流做显式重订阅循环：按 chunk index 去重（重订阅回放不重推）、`turn/start` 重置 index、首个 `turn/end`（含晚订阅 snapshot 里已含的终态）或 abort 即返回。不写、不成史。
2. **D2 SSE 只读路由**：`GET /.sage/session/stream`→ 操作名 `session.stream.follow`（封闭操作表第 18 项）→ 统一 projection-read admission（candidate = active-matter）；回调内建 `ReadableStream` SSE 响应；renderer abort 取消 body（进而 abort follow 循环）。走查 grants 草案增补该授权行。**协议层取消语义由真机走查验证**（jsdom 不可测）。
3. **D3 renderer 呈现**：execution === 'executing' 窗口内订阅（窗口结束即 abort 并清 live 文本）；live 文本渲染为「正在生成」气泡（纯文本），视区随更新滚动到底；停止按钮沿用既有的 executing 门。durable read 仍为最终事实；**不做**关闭后强制 refresh（轮询照旧）。
4. **D4 本行不迁移**：`QDR.S01.session.streaming` 断言含 Markdown 渲染面；全仓无 Markdown 渲染器，新增渲染依赖属治理决策——留待依赖裁决后另刀；本轮完成后行仍 pending，note 登记缺口。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| IPC push（webContents.send + preload） | 否决：Sage 主窗无 preload，renderer 全 fetch 架构；SSE over protocol.handle 同栈且可测。 |
| 轮询替代（2s 轮询 durable 呈现） | 否决：非「逐步出现」，行断言不满足，属假绿。 |
| 本批引入 Markdown 渲染库 | 否决（用户裁决留待）：零 runtime deps 的仓库，依赖新增是治理级决策。 |
| followLive 跨回合常开 | 保留：本刀以单回合为单位（turn/end 即返回）；同 execution 窗口内排队回合的联动流式留观察（真机走查登记）。 |

## 后果

- 执行模块获得第一块真实活流面；路由注册面 61→62、read-only 族 14→15、操作表 17→18。
- Markdown 渲染缺口显式登记（`QDR.S01.session.streaming` 未迁移的理由）。
- 协议取消语义、真机流式观感、同窗口多回合行为进真机走查清单。
