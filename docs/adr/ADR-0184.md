# ADR-0184 · WT-02D.1 fixture / blocked 只读 E2E 与 route 收口：main 唯一 owner 兑现 + matter 槽冻结

- 状态：accepted（2026-10-01）
- 日期：2026-10-01
- 决策者：用户（lute）
- 决策记录：[WT-02D.1 fixture / blocked 只读 E2E 与 route 收口](../notes/implemented/architecture/2026-10-01-wt02d1-fixture-projection-e2e.md)
- 相关：[ADR-0174](ADR-0174.md)、[ADR-0179](ADR-0179.md)、[ADR-0181](ADR-0181.md)

## 背景

WT-02D.0.1/0.2 已把 `/.sage/*` 截在 Electron main 并落地 typed 命令管道，但 0.1 明确移交的 Host 旧 `/.sage` handler 与 `SAGE_APP_SERVICE=off` 回退仍在（[ADR-0179](ADR-0179.md) 的 off 回退与 `src/adapter/` 三件套），构成双 owner 残留；Application Service 的 matter 投影槽（`SageMatterViewState`）从未进入公开 shape，UI-01 的「public shape 冻结」前置缺失；且没有 fixture/blocked 只读 E2E 证明边界表 D.1 行的四条关闭门。用户三裁决 R1（纯服务端）/ R2（并入删除）/ R3（双层 E2E）后实施本票。

## 决策

1. **D1 route 收口（main 唯一 owner）**：删除 Host 旧 `'sage'` 分支与 `src/adapter/` 三文件；`SAGE_APP_SERVICE` off 回退退场；谓词收敛为无开关 `isSageServicePath`；Host 对 `/.sage` 显式 `rejected`（绝不落到 asset 面）；传递性死代码 `src/product/state.ts` 随票删除；`HOST_LIB_FILES` 与对拍守卫同步。
2. **D2 matter 槽（公开 shape 冻结）**：`SageServiceState` 增 `matter: SageMatterViewState | null`；fixture 模式填 `createSageFixtureViewState()`（`projectionSource=fixture` 持续可见、全 blocked action）；production 稳定 `null`——**禁止 placeholder**（`matter` 必填字段不允许伪造空 matter）。
3. **D3 fixture 开关（显式、最小面）**：`SAGE_FIXTURE_PROJECTION=1` 启动读一次，只填 matter 槽，永不满足 production authority；renderer 零感知（payload 驱动渲染留 UI-01）。
4. **D4 单一装配点**：`src/main/app-service.ts` 的 `createSageAppServiceProviders` / `resolveFixtureProjection` 是 main 接线与实弹 probe 的共同消费面——被测装配即生产装配。
5. **D5 双层 E2E（零副作用含负控）**：服务级测试（fixture/生产两模式 + blocked 写路径）+ 真实窗口 probe（真实协议读 fixture payload、`data-projection-source` 可见、指定 Sage root 快照零写入）；负控 `SAGE_FIXTURE_PROBE_MUTATE=1` 证明零写入仪器能红。
6. **D6 门禁合同随票修订**：`sage-product-boundary` 四个退场文件 REQUIRED→RETIRED、`ctx.get(` 全域禁止；`sage-service-consumption` 为 Sage scope 增显式 `allowEmptyRegistry`（默认 false）；扫描器对「index 存、工作树删」的文件优雅跳过（陈旧条目由对账判红，不崩溃冒充红）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| renderer 一并 payload 驱动渲染 | 否决（R1）；UI 技术选型未定，留 UI-01。 |
| 保留 off 回退另票收口 | 否决（R2）；该路径实弹从未被真实验证，与单 owner 合同相抵。 |
| 只做服务级测试 | 否决（R3）；零写入与标识可见需真实窗口/协议读数。 |
| probe 复制 main 装配 | 否决；抽 `app-service.ts` 保单一事实之家。 |
| 清空 registry 并放宽 checker | 否决；改为显式按域开关 + 双向负例。 |

## 后果

- **读数（2026-10-01）**：54 files / 533 tests 全 PASS；typecheck 0；smoke PASS；gate 25/25。实弹：fixture payload 经真实协议全项达标、`POST /.sage/actions` 维持 `identity-unavailable@identity-policy`、Sage root 零条目；负控 canary 判红（failures 恰 1 条）。
- **部署面行为变化**：`SAGE_APP_SERVICE` 退场、`/.sage/*` 恒 main 处理（off 态不存在）、Host `/.sage` 404、新增 `SAGE_FIXTURE_PROJECTION` 本地开关。
- **边界**：fixture 槽不计入生产完成证据；live 投影、真实数据/action、renderer 渲染改造、插件/provider 接线不在本票。
- **遗留**：无新增 deferred。
