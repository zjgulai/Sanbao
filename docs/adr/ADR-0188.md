# ADR-0188 · WT-02B.2E 真实 Organization Policy Provider（本地 policy 文件）+ identity 会话端口 + Authority Runtime 组装

- 状态：accepted（2026-10-02）
- 日期：2026-10-02
- 决策者：用户（lute）
- 决策记录：[WT-02B.2E 本地 Organization Policy Provider 与 Authority Runtime](../notes/implemented/security/2026-10-02-wt02b2e-organization-policy-provider.md)
- 相关：[ADR-0163](ADR-0163.md)、[ADR-0164](ADR-0164.md)、[ADR-0186](ADR-0186.md)

## 背景

WT-02B.2D 内核迁移后（handle 索引 + 请求方组织线索 + provider 诚实性检查），生产链路仍缺真实 policy 源、identity 会话端口与 resolver 组装点——生产 `resolveIdentityPolicy` 恒 fail-closed。两约束限定形态空间：retention matrix 未批准前禁止持久化真实身份或身份映射（ADR-0164 §6）；identity handle 跨进程易失，持久化 handle-keyed 成员表无意义。用户四裁决（policy 源 = 本地 JSON 文件；membership = instance-operator 单成员；范围 = provider + identity 端口 + 组装；供给 = 手动配置 + 文档样例）后实施。

## 决策

1. **D1 本地 policy 文件合同**：`$SAGE_ROOT/organization-policy.json` 为实例级权威（与 `cordis.local.patch.yml` 同级，不进 generation）；每次 resolve 重读（文件即真相）；严格 exact-shape 校验（未知键拒绝、时间戳 ISO UTC 往返一致、roleRefs 非空去重、guards 五枚举、三元组去重、≤256 KiB）；`urn:sage:organization-policy:sha256:*` 由排序后 canonical 语义内容计算（version 作者维护、digest 不可伪造）；信号二分——读失败 throw → `policy-provider-unavailable`，坏内容 `null` → `policy-snapshot-invalid`。
2. **D2 instance-operator membership（精确如实）**：文件声明「本实例的操作者持有这些岗位」，resolve 时把请求方 identityHandle 绑到声明的 roleRefs；v1 无法区分多成员（任何通过已配置 IdP 验证的登录均视作操作者）——逐主体区分需持久化身份映射（retention 门禁止）与跨进程稳定引用（handle 易失），留未来形态；文件零身份材料。
3. **D3 会话契约与 Authority Runtime**：`VaultSession` 增 `issuer / authenticatedAt / expiresAt`（非秘密；authenticatedAt=本地接受时刻避开 IdP 时钟偏差；expiresAt=verified id_token exp）；`createTokenVault({ mintSessionRef })` 必填注入、signIn 被接受时铸一次；`identitySession()` 取代 2C 的 `identityHandle()`（main 内部访问器，snapshot 零泄漏不变）；adapter signIn 携带三新字段；`createSageAuthorityRuntime({ vault, policyPath, readFileBytes, now })` 组装内核（audience `sage-desktop`；identity 端口从活动会话构造 assertion，**sessionId 不回声调用方线索**）；失败码全走既有内核集合零新增；**不接 dispatch**（intent→请求组装属 WT-02D.2）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 内置内存默认 policy（代码常量） | 否决；改授权须改代码、无版本化 artifact、无管理员面。 |
| 按主体逐一指派的多成员表 | 否决；需持久化身份材料（retention 门禁止），handle 跨进程易失。 |
| 首启自动生成默认 owner policy | 否决；authority 凭空产生，产品语义须单独裁决。 |
| providers 直接接 dispatch | 否决；retry 的 availability-only 语义未定义，不猜。 |

## 后果

- **读数（2026-10-02）**：58 files / 568 tests 全 PASS；typecheck 0；tsc 构建通过；smoke PASS；gate 25/25；变异四组（绑定常量 / canonical 去排序 / sessionId 回声 / absent-invalid 混淆）均红、还原后绿。
- **golden**：policy digest `urn:sage:organization-policy:sha256:7d8a2ee1…393dd` 与 issuer digest `urn:sage:issuer-identity:sha256:482be97e…f81d` 手写对拍。
- **边界**：内核 / domain / store / v1 schema 零改动；零持久化 / 零日志 / 零网络；`main/index.ts` 仅 vault 构造一行。
- **遗留**：D.2 接线；candidate org claims（③）；refresh rotation / revocation（会话授权窗 ≤ id_token 寿命）；多成员 membership；供给自动化；WT-02B.3 持久化。
