# ADR-0189 · WT-02B.2F candidate org claims 提取：Logto organizations scope → registry candidateOrgRefs

- 状态：accepted（2026-10-02）
- 日期：2026-10-02
- 决策者：用户（lute）
- 决策记录：[WT-02B.2F candidate org claims 提取](../notes/implemented/security/2026-10-02-wt02b2f-candidate-org-claims.md)
- 相关：[ADR-0163](ADR-0163.md)、[ADR-0164](ADR-0164.md)、[ADR-0185](ADR-0185.md)

## 背景

WT-02B.2C 的 registry 条目含 `candidateOrgRefs` 但恒空（candidate 提取被显式留给 2B 后半）。2A 治理固定其语义：candidate 只是查找线索，**不是** membership / role / grant authority；retention 未确认前不得持久化真实身份。队列「3-1-2」的 ③ 落地真实 IdP（Logto）侧提取。

## 决策

1. **D1 scope + claim 合同**：`OIDC_SCOPES` 增 `urn:logto:scope:organizations`（Logto 事实：`organization_data` 默认进 ID token；userinfo 仅不透明 token 备选路径）。`extractCandidateOrgRefs`（oidc-adapter 导出纯函数）：**严格全弃**（非数组 / 条目非对象 / `id` 非 exact 非空 trim 串 / 条目 >64 / id >128 字符 → 整组为空，不部分信任）；去重保序；**只取 `id`**（最小子集）；**非阻断**（claim 坏不失败登录）。候选值为**原样 IdP org ID**（不发明前缀 / 规范化）。
2. **D2 registry 候选语义**：`resolve({issuer, subject, candidateOrgRefs})`——miss 铸 handle + 存候选；hit handle 复用、候选 replace（latest login = IdP 最新真相；数组等值保持 entry 对象同一性；detached 副本）。runtime-only 不变；候选仍仅查找提示，内核 / provider / resolver 零消费。
3. **D3 验证载体与边界**：新增可复用登录探针 `test/support/login-probe.mjs`（真 transport + 真 adapter + 真 registry，只打印非秘密读数）作为真实登录验收载体；不做 userinfo / access-token 路径、org-selection UX、IdP↔Sage org 映射；候选不进 renderer / Host / logs / 事件。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 坏 claim fail-closed 登录阻断 | 否决；提示数据坏形状不应升格为认证门槛。 |
| candidate 前缀规范形（organization:<id>） | 否决；前缀语义自造，映射留未来层。 |
| 仅 fixture 测试不做真实登录探针 | 否决；scope 接受性需真实读数。 |
| userinfo / access-token 路径 | 否决（本票）；JWT 路径 ID token 默认携带 claim。 |

## 后果

- **读数（2026-10-02）**：58 files / 573 tests 全 PASS；typecheck 0；tsc 构建通过；smoke PASS；gate 25/25；变异四组（部分信任 / 去掉重 / hit 不 replace / 去上限）均红、还原后绿。
- **Live 探针（真实 Logto + 浏览器登录）**：`login: ok`（**scope 被接受**）；`session: active`；`candidates: 0`（租户无 organization，空候选如实——用户裁决不造数）；`handle: minted`。
- **边界**：候选零 authority 消费；runtime-only；零持久化 / 零日志 / 零网络新增（探针为本地验收工具）。
- **遗留**：org-selection UX 与 IdP↔Sage org 映射；候选→`requestedOrganizationRef` 线索接线（WT-02D.2）；userinfo 路径（仅 ID token 缺 claim 时才需要）。
