# ADR-0333 · R17-B 模型设置壳批：编辑器结构复刻，凭证面零接触

- 状态：accepted（2026-10-12）
- 日期：2026-10-12
- 决策者：用户（2026-10-12 确认纯壳批口径与 R17-B 登记）＋ agent（装配设计）
- 决策记录：[Note](../notes/implemented/surface/2026-10-12-r17b-models-shell-batch.md)
- 相关：[ADR-0318](ADR-0318.md)（R17 波次划分：波 B 凭证裁决前置）、[ADR-0319](ADR-0319.md)（R17-C 成例）、T13（tickets 计划）

## 背景

R17 波 B：models 11 行 pending（P06 剩余最大组）。观测齐备（QB20-01..07：默认页、添加弹窗、供应商三组 17 项、DeepSeek 表单/模型/类型菜单、放弃确认；供应商菜单完整清单在 capture 尾注）。原型参照 `SettingsModelsPage`（200 行，覆盖全部变体）。

裁决前置项（ADR-0318 明文）已裁决：Sage 宿主凭据服务当前**无 Sage 面写入路径**（v10 走查实测：`DEEPSEEK_API_KEY` 只能从启动环境导出，`MISSING_CREDENTIAL` 错误回合实证）。BYO API Key 面在写入路径存在之前只能是壳。

## 决策

1. **D1 纯壳批口径延用 R17-A/C**：页面与弹窗结构逐字复刻（QB20-01..07），API Key 恒空只读占位、`校验并添加模型`禁用并具名「凭证写入路径独立成批」——零录入、零校验、零保存、零发送。
2. **D2 真实本地交互**（观测即合同，零伪造）：添加弹窗打开/取消（QB20-02）；供应商菜单展开，三组 17 项逐字、DeepSeek 可选（QB20-03/04）；类型/模型/API 类型面板展开、Escape 回（QB20-05/06）；放弃确认双出口、初焦继续编辑（QB20-07）。
3. **D3 凭证字段按观测边界落**：endpoint/Model ID 草稿只读占位；购买/获取 API Key 外链不渲染（capture 只记录存在与位置，未记录行为）；DeepSeek 表单不含「购买 Token Plan」（QB20-04 明文：链接消失）。
4. **D4 凭证写入路径独立成批**：宿主凭据写入是票级缺口（涉 main admission 面与凭证存储 owner），不入本批。retention/legal hold 未确认期间禁止持久化敏感经营数据（AGENTS.md 红线）继续约束任何后续 store。
5. **D5 迁移**：11 行 pending→implementing，evidenceRefs 挂 tracked-test；route 权威维度零改动；blockers 逐行具名凭证缺口。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 壳 + 本机模型偏好 store（非 key） | 否决：key 无写入路径，表单仍死；新增 store 属红线约束面，无收益。 |
| 接通宿主凭据写入路径 | 否决（超本批口径）：票级工作，需独立 admission 批与凭证存储 owner。 |
| 渲染购买/获取外链 | 否决：观测只记录存在，未记录行为；渲染即伪造可点击面。 |
| API Key 可编辑本地暂存 | 否决：伪造录入能力；retention 未确认期间不持久化敏感数据。 |

## 后果

- 矩阵 UI pending 66→55、implementing 132→143；P06 settings 剩入口行（波 D）与 scope 行。
- 后续批：宿主凭据写入路径（票级）→ 模型编辑器真校验/保存 → 已配置列表。
- 本批零 route、零写入、零 Host 面；gate 基线不变。
