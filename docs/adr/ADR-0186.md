# ADR-0186 · WT-02B.2D organization mapping 内核契约迁移：handle 索引 + 请求方组织线索 + Policy 独占证明

- 状态：accepted（2026-10-02）
- 日期：2026-10-02
- 决策者：用户（lute）
- 决策记录：[WT-02B.2D organization mapping 落地](../notes/implemented/security/2026-10-02-wt02b2d-organization-mapping.md)
- 相关：[ADR-0163](ADR-0163.md)、[ADR-0164](ADR-0164.md)、[ADR-0185](ADR-0185.md)

## 背景

2A 治理要求 raw subject 退出内核面、组织只由 Organization Policy Provider 独占证明（用户选择与 candidate 只是查找线索）。WT-02B.1 内核仍为 test-only 过渡形态（assertion 携带权威 subjectId/organizationId 且与 policy 组织强制相等）；WT-02B.2B 交付时登记为欠账。用户裁决 R1（纯内核迁移）/R2（请求方线索）/R3（handle 迁移本次完成）后实施。

## 决策

1. **D1 五面契约迁移（错误码集合不变）**：`ActionAuthorizationRequest` 增 `requestedOrganizationRef`；`IdentityAssertion` 的 `subjectId`/`organizationId` → `identityHandle`；`OrganizationRoleAssignment` 与 `AuthoritySnapshot` 以 `identityHandle` 索引；`PolicyProviderRequest` 改 `{requestedOrganizationRef, identityHandle}`；`authorize()` 组织检查改为 provider 诚实性语义（答非所问 → `policy-organization-mismatch`）。
2. **D2 请求方线索语义**：组织线索由调用方（未来 Application Service）注入，**非权威**；provider 必须为其作答；candidate 集不做解析主路径（保留给未来组织选择 UX）。
3. **D3 切片边界**：真实 Organization Policy Provider 形态与实现、candidate org claims、subjectRef、refresh / revocation、持久化、state / renderer / Host 面、命令管道接线均不在本票；fixture 与未来真实 provider 共用同一契约形态，无需二次迁移。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 本票一并做真实 Policy Provider | 否决；组织资源产品面须独立裁决（可能触及 retention 门）。 |
| candidate 集迭代解析组织 | 否决；现为空会全拒且多组织无法消歧。 |
| subjectId 双轨过渡 | 否决；两份身份索引、二次返工。 |
| 不设组织诚实性检查 | 否决；线索与作答不一致必须 fail closed。 |

## 后果

- **读数（2026-10-02）**：55 files / 542 tests 全 PASS（identity-policy 14，含 2 新用例）；typecheck 0；build 通过；smoke PASS；gate 25/25；变异三组（handle 绑定 / 诚实性检查 / snapshot 回填）均红。
- **行为面**：调用方自报 subjectId/organizationId/identityHandle 均 `invalid-request`；新键 accessor/Proxy 负例零 getter 执行。
- **边界**：真实 Policy Provider 为下一依赖；本票零持久化、零 renderer/Host 面变化。
