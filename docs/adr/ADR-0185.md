# ADR-0185 · WT-02B.2C 身份注册表 / identity handle（runtime-only）：登录链产出内部身份引用

- 状态：accepted（2026-10-02）
- 日期：2026-10-02
- 决策者：用户（lute）
- 决策记录：[WT-02B.2C identity registry 落地](../notes/implemented/security/2026-10-02-wt02b2c-identity-registry.md)
- 相关：[ADR-0163](ADR-0163.md)、[ADR-0164](ADR-0164.md)、[ADR-0183](ADR-0183.md)

## 背景

2A 治理链固定 Sage-owned identity registry 只产生内部 identity handle 与候选组织引用（不证明 membership）；scoped `subjectRef` 必须等 Organization Policy 证明 scope 后生成；禁止对 raw subject 做无密钥 deterministic hash；retention / legal hold 未确认前禁止持久化真实身份。WT-02B.2B 之后登录链止于「已验证 id_token → 纯内存 token vault」，identity handle 缺失，2B 后半无内部身份引用可消费。用户裁决 R1（最小切片）/R2（runtime-only）/R3（仅 main 内部）后实施。

## 决策

1. **D1 registry 内核（runtime-only）**：`createIdentityRegistry({ randomHandle })` —— 复合键 `issuer + '\u0000' + subject` 进程内映射；命中复用、未命中以注入随机性铸 opaque handle；零持久化 / 零日志 / 零 deterministic hash；条目形状含恒空 `candidateOrgRefs`。
2. **D2 vault 扩展（main 内部访问器）**：`VaultSession.identityHandle` 随 signIn 存入；`identityHandle(): string | null` 为 main 内部访问器（外部面 renderer / Host / 事件 / 日志 / 导出零暴露）；`snapshot()` 逐字段不变防泄漏。
3. **D3 adapter 接线（fail closed）**：deps 必填注入 `resolveIdentity`；verify 全链过后 guard `iss`/`sub` 为 string，缺失 → `token-verification-failed`（不新增错误码）→ resolve → signIn 带 handle；login 成功 ⇒ handle 必然存在；logout / 超驰路径无 handle 残留。
4. **D4 切片边界**：2B.1 内核接口迁移与 Policy-exclusive membership 并入 organization mapping 票；candidate org claims、scoped `subjectRef`、refresh / revocation、任何持久化不在本票。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 持久化稳定 handle | 否决；retention 红线；属 WT-02B.3。 |
| 本票迁移内核接口 | 否决；org 语义耦合，并入 organization mapping。 |
| handle 进 state / renderer | 否决；无消费方，扩大暴露面。 |
| deterministic hash 作 handle | 否决；治理红线。 |

## 后果

- **读数（2026-10-02）**：55 files / 541 tests 全 PASS；typecheck 0；smoke PASS；gate 25/25；变异三组（复用删除 / snapshot 泄漏 / sub guard 删除）均红。
- **链路面**：登录成功同时产出 main 内存 identity handle；renderer / state 零变化；重复登录（同进程同 `(issuer, subject)`）复用同一 handle。
- **边界**：handle 不计入持久化或产品完成证据；organization mapping 票为下一依赖。
