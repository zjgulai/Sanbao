# ADR-0246 · 任务分组：Sage 自有的组织对象（具名命令＋逐项回执；只改变列表组织）

- 状态：accepted（2026-10-03）

- 决策者：agent（取证并实施；FW-041、US-225/226 已定方向）

- 相关：[ADR-0227](ADR-0227.md)（029 归档/改名/逐项批量先例）、[ADR-0226](ADR-0226.md)（028 项目归属「只做分组与汇总」先例）、[ADR-0198](ADR-0198.md)（host 消费登记——本票零新增）

## 背景

工单 049（FW-041，US-225/226）：**任务分组是 Sage 自有组织对象：建立、改名、移除为具名命令
并逐项回执，不隐式产生**；**分组只改变列表组织方式，不改变事项事实、可见范围、责任或权限**。
原产品证据：O04 分组。Sage 侧已有同构先例：028 的项目归属（纯 refs＋trail）与 029 的逐项批量
（行级判定、无「整体成功」）。

## 决策

1. **D1 四个具名命令、各自回执**（`main/matter-groups.ts`）：`create`/`rename`/`remove`/`assign`
   各返回自己的回执状态（created/renamed/removed/batch）；**改名回读生效值**（trim 后存储值，
   请求字符串绝不冒充生效）；建立/改名/移除写 trail；`group-name-invalid`/`batch-size-invalid`
   （1–32）先验于任何写入。
2. **D2 不隐式产生**：对未知分组的任何操作（改名/移除/成员变更）=`group-unknown` 拒绝，
   **绝不静默建档**；成员目标先过 `knownItem` 门，未知目标逐项 `item-unknown` 拒绝（未知与无
   权同码，不做枚举）。
3. **D3 逐项回执、无整体成功**（US-225）：成员批量逐行判定 ok/unchanged/refused（计数随行），
   batch 键集封闭（spec 逐字断言）；「已在该分组」「不在该分组」是未变化行而非错误；空批量拒绝。
4. **D4 只改变列表组织**（US-226、同 FW-015 分区原则）：store 除自身成员集外**零写入**，唯一
   外部输入是 `knownItem`（读门）；**依赖面刻意不含任何授权/范围/责任端口**——没有可供推断的
   通道。断言：全生命周期分组操作前后 `matterList.derive()` **逐字节相等**；服务装配断言分组
   操作后 `matterList` 槽不变、权限邻近端口（archive/batch）零调用；未接线＝
   `matter-groups-unavailable` 具名缺项。
5. **D5 首版不做**：分组共享与协作语义、按分组批量授权、跨设备分组同步（工单边界）；分组记
   录为进程内组织记录，持久化后置。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 分组写入事项记录（成员字段） | 否决：会改变事项事实面；组织对象独立存放，「移除分组≠删除事项」。 |
| 成员批量给「整体成功」横幅 | 否决：US-225 要求逐项回执；行级判定＋计数，无总括字段。 |
| 对未知分组的成员操作自动建组 | 否决：US-225「不隐式产生」；`group-unknown` 拒绝。 |
| 改名直接显示请求值 | 否决：029 先例——回读值才是生效值。 |
| 分组参与可见范围/责任推导 | 否决：US-226 明令不改变；依赖面刻意不给推断通道（零端口）。 |

## 后果

- 验收两条机器断言：①建立/改名/移除各有回执与回读（四命令回执状态＋rename effective 断言）；
  ②分组不改变可见范围与责任（derive 逐字节相等＋装配零调用＋键集封闭）。
- 面/装配：`MatterGroupsStatus` 状态槽＋`createMatterGroup`/`renameMatterGroup`/
  `removeMatterGroup`/`assignMatterGroup`（route `/.sage/matter-groups`，精确成员解析）；名册
  +4；033 装配守护 +1（app-service 转发）；029 渲染切片端点改到新兄弟卡（deliberate）。
- §1.6：真产物两宽（1440/660）亲看——D12 卡「任务分组：建立、改名与移除（只改变列表组织）」
  ＋建立按钮、事项行分组标签（分组：交付跟进／分组：现金流专题）、分组行回读计数（2 项/1 项
  （回读））、四命令按钮、逐项批量行与 trail（`/tmp/wk049/049-1440.png`、`049-660.png`、
  `crop-1440.png`、`crop-660.png`、`crop-1440-flow.png`）；真实 Chrome DOM 读数：flow 页驱动后
  恰两条 POST——`{"action":"rename","groupId":"grp-1","name":"交付跟进v2"}` 与
  `{"action":"create","name":"交付跟进·副本","targets":["m-1","m-2"]}`——＋NOTE[请求「交付跟进v2」
  → 回读生效「交付跟进·财务口径」（显示的是实际生效值）。]＋BATCHROWS[4]＋GROUPS[2]。
- 已知未闭：真实持久化与跨设备同步后置；分组记录为进程内（重启即失）。
