# ADR-0208 · 后置四族只读呈现：只印已观察事实、安装证据与启动观察分开、版本标识取可核验来源

- 状态：accepted（2026-10-02）
- 日期：2026-10-02
- 决策者：agent（取证并实施；每族"能显示什么"是取舍）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-02-rear-readout-families.md)
- 相关：[ADR-0165](ADR-0165.md)/[ADR-0166](ADR-0166.md)（兼容权威）、[ADR-0167](ADR-0167.md)（安装时 attestation）、[ADR-0168](ADR-0168.md)（Host live 观察）、[ADR-0171](ADR-0171.md)（Registry 治理）

## 背景

工单 026 要把四族后置页面限定为**只读呈现**：可见范围（US-129/130）、知识与引用（US-131~133）、
插件与扩展（US-134~136）、关于与诊断（US-137~139）。三条验收全是"不许出现什么"：
不得有更新入口、不得由工具数量/连接成功推导可用结论、知识无创建/编辑/发布/退役入口。

取证当前 main 已持有的真事实：身份投影（`service.auth`）、实例策略文件（`organizationId`）、
事项投影槽（`matter.responsiblePartyRoleRef`，fixture 模式才有）、运行时清单
（`runtimeInventory.read()`：六组件 + 能力数组 + 摘要）、Host 快照（`dshVersion`/`manifestSha256`/
`profileGeneration`/`protocolVersion`/`loaderPhase`/`bootId`/`runtimeGeneration`）、数据根（`paths.root`）、
以及待办命令的 `code`+`correlation`。**没有**的知识：知识库 provider（不存在）。

## 决策

1. **D1 每族只印已观察事实，缺席带名**：可见范围只显示"已读到的组织与主责"，缺席分别给
   `policy-unreadable` / `projection-absent` 并配固定句；不发邀请、不给协作管理人或范围变更入口（US-129/130）。
2. **D2 安装证据与启动观察分两块印**：插件行来自运行时清单的**安装时**身份/版本/artifact 摘要；
   本次运行的观察（loader active、boot、世代）单独一块；两者**不合**成"已挂载"或"兼容/可用"结论（US-134~136）。
   清单缺席 → `未核验 + 原因码`，绝不写成停用（沿 ADR-0167/0168 边界）。
3. **D3 知识未接线就说未接线**：知识库没有 provider，所以"没有知识条目可列"与"没有来源"分开讲；
   引用条目只读呈现来源/版本/可达性，**取用（按需读取并重核）留在 013 的能力页卡上**，本族零控件（US-131~133）。
4. **D4 诊断版本标识取可核验来源**：运行时版本/协议版本/Profile 世代/manifest 摘要全部来自
   **Host 快照**（ready 事件按 pin 校验通过后才存在），界面自报的结构里根本没有这些字段；
   `manifestVerified` 只有活跃快照才为 true；数据根来自启动时解析的 `paths.root`（US-137/139）。
   本族不提供更新检查/一键更新，也不以旧发布链结果充当更新能力（US-138）。
5. **D5 零控件是结构事实**：这一族的面板里没有任何 `button`/`input`；判据直接对文档切片断言。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 插件页显示"已挂载/未挂载"两态 | 否决：安装时 attestation 不证明运行中挂载（ADR-0167），写两态就是合成结论。 |
| 可见范围页列出成员列表 | 否决：没有成员 provider，且"列表里出现某人"不得暗示读取权（US-130）。 |
| 诊断页做导出按钮 | 否决：导出的脱敏边界未定；本族只显示，不导出。 |
| 把知识条目做成"空列表" | 否决：没有 provider 与"确实没有条目"是两回事，空列表会被读成后者。 |
| 版本号从 renderer 侧常量或页面自报 | 否决：US-139 明文禁止；快照是唯一的版本家。 |

## 后果

- 四族全部只读：面板内零控件由文档级断言守着；"未核验/未接线"各有固定说法，不会退化成"停用/空"。
- 诊断块与 001 的命令槽共用同一份 `lastCommand`（经 provider 传入），命令事实仍只有一个家。
- 已知未闭：知识 provider、成员/范围 provider、更新能力都不存在——按工单备注"接入后另开票"；
  真机端到端未跑（本票不启动 Host）。
