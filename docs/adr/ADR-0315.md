# ADR-0315 · Sweep 消费规则：维度正交裁定（Q1–Q4）

- 状态：accepted（2026-10-11）
- 日期：2026-10-11
- 决策者：用户（2026-10-11 指令「并行可裁定治理 Q1–Q4」）＋ agent（按 C 线备忘推荐落定）
- 决策记录：[Note](../notes/implemented/process/2026-10-11-sweep-consumption-rulings.md)
- 相关：[pending-sweep-113](../notes/implemented/process/2026-10-11-pending-sweep-113.md)（警示 1/2/3 原文）、[ADR-0313](ADR-0313.md)（壳批成例）、[ADR-0310](ADR-0310.md)（adopt 装配取证）、[ADR-0283](ADR-0283.md)（t13a 裁定先例）

## 背景

C 线治理盘点（两线并行 + 裁定合成）证实：sweep 警示 1/2/3 的张力全部来自**维度混同**——「assemblable」（壳装配可行性）与矩阵 route `currentAuthority`（权威维度登记）是两个正交维度，被并置进同一句表述。仓内证据：O04 两 route bypass 属实；P15/S09 两行登记逐字段同构（「分类矛盾」不可复现、「S09 口径」无锚）；ADR-0310 从未声明 adopt compliant、从未触碰矩阵（只消费 adopt；mutate 消费方是 T03 旧工作区列表）。

## 决策

1. **D1 通用消费口径（Q4）**：以下固定式覆盖警示 1/2/3 原文的读法，供 16 条 direct-provider-bypass 家族后续成员入批直接引用——「**assemblable 只指壳可装配；route currentAuthority 是权威维度的唯一事实家；admission 收口一律独立成批；壳批不改变 violation 计数。**」
2. **D2 Q1（O04/P15/S09 入批口径）**：照 ADR-0313 成例——纯壳迁移（ui pending→implementing）、`applicationService` 保持 blocked 不虚升、blocker 照 S03 四要素样板改写（组展开状态/壳装配面/写路径当前态与具名拒绝/admission 收口具名独立批）、**矩阵一字不动**。方案 B（警示字面「批内收口」）否决：须先扩 protected-effect-admission family（今仅 session-core）、每条 route 独立 ADR，与成例矛盾且成本失当。
3. **D3 Q2（P13 权威冲突）**：裁「**正交**」——矩阵管 route 权威维度、ADR-0310 管装配维度，两者同时为真、互不推翻；adopt/mutate 的 violation **原样保留**，留待 workspace admission 独立批消除，不因 create 叶已取证而重议。方案 B（改写 compliant）会击穿门禁计数（bypass 恰 16 钉死）；方案 C（认定取证假绿）与真实运行证据冲突——均否决。
4. **D4 Q3（P13 扩叶前置）**：归档确认叶/远端工作区叶仓内无真实机器（route/operation 均不存在）——**从 P13 伞的 assemblable 声明中剔除**，待 workspace route 设计批另行立项；编辑叶先补 WorkspaceEditorDialog 字段级观察再定（rename 是否足够覆盖未定前不扩叶）。
5. **D5 落点**：sweep 警示 1/2/3 原文保留（历史事实），消费规则以本 ADR + 配套 Note 为准；sweep 记录加注记链接。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| Q1/Q2 按警示字面「admission 改造在批内」 | 否决：与仓内唯一成文口径（ADR-0313）矛盾；壳批变收口批，收益（16→15）与成本不成比例。 |
| Q2 改写 adopt 为 compliant | 否决：击穿门禁计数；ADR-0310 亦从未如此声明。 |
| Q2 认定 ADR-0310 取证假绿 | 否决：与请求恒 1 断言、65/65、全量运行证据正面冲突。 |
| Q3 归档/远端叶先立 workspace route 设计批 | 推迟：无观察动机前不立项（无叶可装、无产品信号）。 |
| 不落通用口径（每次逐条裁定） | 否决：16 条同族将重复同一裁定。 |

## 后果

- 16 条 bypass 家族后续入批有可引用口径；sweep 警示引用时必须按 D1 改写读法。
- P13 批范围收缩（扩叶前置具名）；O04/P15/S09 批形状定型（纯壳 + 具名推迟）。
- 矩阵与 route-authority-matrix 计数零改动（本裁定不产生数据变更）。
