# ADR-0212 · 会话通道：ack 只表示受理、执行只看日志里未结束的一轮、最终文本以历史为准

- 状态：accepted（2026-10-02）
- 日期：2026-10-02
- 决策者：agent（取证并实施；三条判据来自基座自己的契约）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-02-session-channel.md)
- 相关：[ADR-0205](ADR-0205.md)（服务面取自声明）、[ADR-0206](ADR-0206.md)（流式读收束）、[ADR-0211](ADR-0211.md)（建项三态）

## 背景

工单 005 要打通最窄执行路径，三条验收：**ack 出现时不显示"模型已开始工作"**、**流断后重新对账得到与历史一致的最终文本**、**重开不重复发送**。
取证基座 `sessionController`（`@deepseek-ai/dsh-api-session-controller`）：`prompt` 的返回值就叫"Receipt after one prompt enters the target Agent inbox"（`{accepted:true}`）；
执行与否只写在会话日志里（`turn/start` / `turn/end`）；`assistant/message` 的注解明确"derived history uses this"；
`page` 是"cold-safe"历史读；`create` 是"create or idempotently adopt"。

## 决策

1. **D1 ack 只表示受理**：桥新增 `session/create|prompt|page` 端点与 `session/follow` 流；`prompt` 回执按基座原样投影为"已受理（进入队列）"，
   界面文案明说"执行与否看下一行"，**任何地方不得把 ack 写成"已开始工作"**。
2. **D2 执行态只从日志来**：`turn/start` 未配对 `turn/end` = 执行中；已配对则显示结束原因（`reason`）。accepted 与 executing 是两个字段、两句话。
3. **D3 最终文本以历史为准**：`assistant/message` 事件的消息文本是唯一的"最终文本"来源；live `assistant-stream` 帧对最终文本**零贡献**（只作过程展示位）。
   流断（或本次读取拿不到最终文本）时自动走 `session/page` 重读并标记 `reconciled`；对账本身失败则如实报 `streamBroken + code`，**不拿半截流文本充当最终态**。
4. **D4 重开只读、绝不重发**：matter→session 绑定持久化（`sessions/bindings.json`，0600）；`read` 复用会话且只开流/读历史；
   没有绑定就回 `no-session`，**打开页面不会创建会话、不会发提示**。发送是独立动作（`/.sage/session/send`，仅 POST+JSON）。
5. **D5 载荷与错误面**：`prompt` 只接受 `{requestId, sessionId, mode, text}`（文本非空且 ≤32K）；`page` 只接受 `{sessionId, throughSeq[, maxMessages]}`；
   基座 `session/*` 拒绝码映射为 `bridge-session-*`；流沿用 ADR-0206 的静默窗口收束（每次读取是有界窗口，长订阅留给 006）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 把 prompt 回执当成"开始执行" | 否决：基座自己的注解就是"enters the inbox"，US-012 的反例正是这条。 |
| 用 assistant-stream 帧拼最终文本 | 否决：帧是进程内展示（cursorless），历史才是 durable 的最终态。 |
| 打开事项时 `create` 一次会话以便"准备就绪" | 否决：会激活/创建会话；US-024 要求冷读不促发 Agent，`no-session` 是更诚实的状态。 |
| 重开时重发上次输入以便"续上" | 否决：US-013 的"重开不重复发送"。 |
| 为 005 建长订阅通道 | 否决：长订阅与停止/待继续语义是 006 的范围，本票用有界窗口读。 |

## 后果

- 三条验收各有机器断言：ack 句不含"已开始工作"（含卡片级反例断言）、断流后 transcript 的助手行来源标 `history` 且文本等于历史事件文本、
  重启后的新通道只发过一次 `session/prompt`（计数断言）。
- 已知未闭：真机端到端未跑（不启动 Host、不发真实模型调用）；本票不覆盖工具审批、预算与取消续跑（006）；`assistant-stream` 帧目前只被计数不展示（过程展示位留给后续票）。
