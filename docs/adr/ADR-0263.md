# ADR-0263 · 本地开发与调试环境：一键 `dev:debug`（隔离 dev 根＋inspector/CDP＋日志 tee）

- 状态：accepted（2026-10-05）
- 日期：2026-10-05
- 决策者：用户（lute，2026-10-05「按方案 A 先搭建本地开发和调试环境」——打包决策包 `docs/notes/proposed/process/2026-10-05-sage-packaging-decision-package.md` 选定 A 档并以本环境为第一步）
- 决策记录：[Note](../notes/implemented/process/2026-10-05-local-dev-debug-environment.md)
- 相关：[ADR-0160](ADR-0160.md)（本机活动仓基线）、[Sage 自有桌面端执行方案](../plans/2026-09-24-sage-self-owned-desktop-execution-plan.md)（P1/A 档）、[ADR-0261](ADR-0261.md)（renderer 构建链）

## 背景

Sage 壳的既有开发循环是手工组合：`tsc && build-renderer` → `SAGE_ROOT=… node scripts/materialize.mjs` → `electron .`，其中「先 materialize 再重启」是散落在会话经验里的纪律；没有默认隔离的 dev 数据根（`pnpm dev` 缺省直指生产根 `~/Library/Application Support/Sage`）、没有成文的调试端口/日志路径。方案 A（本机自用 app）要求先有一个可靠的本地开发与调试环境，否则后续装配与会话调试都在高摩擦路径上进行。

## 决策

1. **一键入口**：新增 `apps/sage-shell/scripts/dev-debug.mjs` 与 `pnpm dev:debug`，顺序固定为 **构建（tsc＋renderer bundle）→ materialize → 启动 Electron**——把「先 materialize 再重启」从会话纪律固化成命令语义；`--no-build` 供纯重启循环。
2. **根隔离（默认安全）**：dev 数据根默认 `~/Library/Application Support/Sage Dev`（与生产 `Sage` 根分离；既有 path 守卫仍拒绝 `~/.dsh` 及包含关系）；首次使用写 `.sage-dev-root` 标记；`--reset` 仅在标记存在时允许删除，否则拒绝（退出码 2）。`SAGE_DEV_ROOT` / `--root` 可覆盖。
3. **调试姿态**：main 进程 Node inspector（默认 `--inspect=9229`）＋renderer CDP（默认 `--remote-debugging-port=9222`）＋ `SAGE_DEVTOOLS=1`（既有开关，打开 detached DevTools）；端口可用 `--inspect-port` / `--cdp-port` / env 覆盖。stdout/stderr 全量 tee 到 `<dev 根>/logs/dev-session.log`。
4. **投影可切**：默认注入 `SAGE_FIXTURE_PROJECTION=1`（可见 fixture UI）；`--unavailable` 切到生产形态（unavailable-first 诚实面）。两者都只是开发面选择，不改变生产装配。
5. **边界**：本环境纯属开发工具；不构成发布、签名、DMG 或实机验收证据；不触碰生产根、真实 profile、凭据；不改变 Host、route authority、CSP 与任何运行时合同。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| A. 维持手工三步（现状） | 否决：摩擦高、易误用生产根、无成文端口/日志，且「materialize 纪律」靠人记。 |
| B. 一键 `dev:debug`＋隔离 dev 根＋调试姿态（采纳） | 一条命令、默认安全、可复现读数；为 A 档装配与后续会话调试提供固定入口。 |
| C. 直接复用生产根做开发 | 否决：违反隔离纪律（生产根只由真实产品装配使用）。 |
| D. electron-builder dev server / 热重载框架 | 暂不引入：当前单文档私有协议架构无需 dev server；热重载另行评估。 |

## 后果

- 开发循环收敛为 `pnpm dev:debug`（构建+materialize+启动）与 `--no-build` 重启；devtools、inspector、CDP、日志路径全部有文可查。
- dev 根可整体重建（`--reset`），与生产根、恢复集、旧链物理隔离；P1/A 档的装配链后续可直接消费同一 dev 根验证产物。
- 本环境与发布链无关：不影响 gate 组合，不进入 `packaging-sage/`（尚未建立）的判定。
