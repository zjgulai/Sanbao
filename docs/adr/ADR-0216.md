# ADR-0216 · 外观八项：一条 v2 记录、两入口同值、失败回退在各入口、清单外项零控件

- 状态：accepted（2026-10-02）
- 日期：2026-10-02
- 决策者：agent（取证并实施；值域与两入口写行为是取舍）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-02-appearance-eight-items.md)
- 相关：[ADR-0214](ADR-0214.md)（偏好单一权威值）、[ADR-0215](ADR-0215.md)（叶子页只读——D5 的面板级零控件断言由本 ADR 重划到叶子组切片）

## 背景

工单 047（FW-039 / US-220~222）把 020 的三项显示偏好**扩为八项**：主题（含跟随系统）、语言、密度/缩放、
字体风格、内容宽度、终端主题、文件图标、图标外观；仍由同一偏好端口（S9）持有。原型证据：
`SettingsAppearancePage.tsx` 六个下拉（主题模式/终端主题/语言/字体风格/内容宽度/文件图标）+ 应用图标区的
图标外观（跟随系统/浅色/深色），`UserAppearanceMenu.tsx` 的快捷外观选项（语言/明暗/主题/字体风格/字号/界面缩放/内容宽度）。
US-221 要求每个外观项**在设置页与快捷菜单读写同值并订阅变更**，任一处保存失败不得显示为已生效；
US-222 要求快捷键/语音/监控浮层布局继续后置并显式标注，不留"看起来能改"的控件。

## 决策

1. **D1 一条 v2 记录、八项封闭值域**：`DisplayPreferenceValues` 是唯一形状（contracts 单一 home），
   存储升 `sage.preferences.v2`；路由校验器、存储 `readValues` 用同一份键/值白名单（8 键、逐值校验）。
   旧 `v1` 三值记录**不半采纳**：读回默认值且 `savedAt: null`，不把三项旧值伪装成八项已保存记录。
2. **D2 两入口同权威值、写行为分工**：设置页外观段（`#settings-appearance`，唯一可保存面）一次提交
   八项 patch；顶栏快捷外观菜单逐项即时保存（每个 change 一个单键 patch）。两处都只读 `state.preferences`、
   只写 `/.sage/preferences`。任一处失败＝该入口重写回已保存值并挂本地提示句（本地提示门不被 2s 轮询覆盖）——**回退以入口为单位**。
3. **D3 重启一致性**：重启后 `requested` 读回八项已存值；`effectiveTheme` 由**重启时**的桌面观察解析
   （`system`→观察值，无观察→null 不猜）。设备密钥文件复用，不因重启重造记录。
4. **D4 清单外项显式不可配置**：外观卡内「不在本版清单」块列三行（快捷键/语音/任务监控浮层布局）
   各带 `不可配置` 标；另列「终端链接使用内置浏览器」为 `不迁入`（D-036 已定系统浏览器）。
   该块零控件；全文档控件 `aria-label` 不得出现这些词（US-222/112/113）。
5. **D5 设置面板重新划界**：`panel-settings` 从"设置（只读）"改为两段——顶部外观段（可保存、明确标注
   `data-settings-writable`）＋`#settings-leaf-section` 叶子页只读组。046 的"面板切片零控件"断言
   **重划到叶子组切片**（046 的逐页来源/零写入口断言不变）；nav 标签改"设置"，pill 写"外观可保存 · 叶子页只读"。
6. **D6 默认值单一 home**：`DEFAULT_DISPLAY_PREFERENCE_VALUES`（contracts）同时供存储默认与
   unavailable-first 回退快照，杜绝两处默认字面量的漂移。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 保留 v1 版本号、字段直接加宽 | 否决：文件形态变了却不换版本，旧记录会以"部分已知"混进新读路径；换版本 + 拒绝旧版才符合"未验证不冒充"。 |
| v1→v2 迁移（三项旧值 + 五项默认） | 否决（本票）：迁移语义是新决策，本票未要求；拒绝旧记录读回默认是更小的诚实面。 |
| 快捷菜单也做"一次八项 + 保存按钮" | 否决：快捷入口的语义是"改一项即时落一项"；与 020 已演示的 menu 即时保存一致。 |
| 外观卡留在个人资料面板 | 否决：US-221 点名"设置页与快捷菜单"两入口；外观是设置页的页面（U01），个人资料只留身份。 |
| 046 面板级零控件断言原样保留 | 无法保留：面板里现在有了按规格可保存的外观段。重划到叶子组切片，且 047 用 US-222 断言补上"外观段是唯一可保存面"。 |

## 后果

- US-220/221/222 各有机器断言：八项默认与重启回读（含 followed theme 的观察解析）、两入口逐项同值/同变、
  设置页 8 键 patch 与菜单 8 次单键 patch、成功才出现"已保存"、失败在两入口各自回退、清单外三行标注 + 零控件。
- 046 的既有断言只动一处（切片起点 `id="settings-leaf-section"`），逐页来源与零写入口断言未动。
- 已知未闭：真机 Electron 未跑（`nativeTheme` 仍以注入值证明）；八项的视觉应用（token 重绘）与对比度验收
  属 §7.10，不在本票。
