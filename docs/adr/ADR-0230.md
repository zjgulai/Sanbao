# ADR-0230 · 成果补全：受控外链、typed 工具结果、只读网页成果目录与全屏预览（含生产装配断链修复）

- 状态：accepted（2026-10-03）
- 日期：2026-10-03
- 决策者：agent（取证并实施；D-034/036/037/047/048/059/070 与 FW-033 已定方向）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-03-deliverable-completeness-external-link-tool-results.md)
- 相关：[ADR-0219](ADR-0219.md)（015 预览容器）、[ADR-0224](ADR-0224.md)（执行前确认）、[ADR-0229](ADR-0229.md)（032 外围流程）

## 背景

工单 033（FW-033，US-172~176）：图表全屏与链接预览走**离线资源与受控显式外链入口**、
**不自动联网**、全屏退出**恢复焦点**；图片查看支持缩放与平移（纯 UI），**批注后置**；
网页成果目录只读并显示**同源版本与访问限制**——**已托管交付不等于网站上线**（OBS03）；
专用工具结果按 **typed 数据由 Sage 自有组件呈现**、不支持的类型**明确拒绝**、结果内不执行
脚本、不接受权威动作输入（M04）；工具详情脱敏、结果图片按权限加载、**raw payload 不透传**
（M05，D-048）。

实施中发现**既有的生产装配断链**：`main/index.ts` 把五族 wiring（附件/产物/搜索/事项列表/
侧聊）spread 进 `createSageAppServiceProviders`，但 `main/app-service.ts` 的装配点从未声明与
转发这些键——TS 的 spread 不做过剩检查、函数级测试又都直接接 `createUnavailableFirstService`，
于是**真实窗口下这些 route 恒 unavailable 而所有测试全绿**（P-20「归位不等于接线」的又一实
例）。033 自身的产物依赖（目录/预览/全屏）正落在这五族上，故一并修复并以守护 spec 拦住。

## 决策

1. **D1 受控外链（US-172，D-036）**：新纯模块 `main/external-links.ts`——唯一入口是具名
   `open` 动作（渲染端只有一次显式点击会发出）；**只有 http/https 过门**（`javascript:`/
   `file:`/`data:`/自定义 scheme=`link-scheme-refused`，内嵌凭据=`link-credentials-refused`，
   超长=`link-too-long`，不可解析=`link-invalid`）；校验后交**注入的 opener**（生产接
   `shell.openExternal`），未接线=`external-open-unavailable`、抛出=`external-open-failed`
   （都不算成功）；投影**只回 scheme+host**——路径/查询/凭据永不回传。模块本身**没有任何读取、
   抓取或探测路径**——"外链仅在显式动作下打开、不自动联网"是结构事实。
2. **D2 全屏=同一文档的布局切换（US-172）**：预览就绪态增加 `expanded`；`/.sage/artifacts/
   fullscreen {on}` 走 `preview.setExpanded`——**不重新加载、不重读版本**（容器只改几何：
   `preview-window.ts` 侧栏↔整窗）；渲染端按钮随投影翻转（全屏查看（离线）/退出全屏（返回
   侧栏）），**退出全屏把焦点还给触发器**（有断言）；未打开时拒绝 `artifact-preview-not-open`。
3. **D3 图片缩放/平移=纯查看 UI（US-173）**：`buildImageDocument` 增加 **CSS-only** 缩放
   （radio 组 100/150/200%，`:checked ~ .stage img` 定宽）＋ stage `overflow:auto` 原生滚动
   平移；**文档零脚本**（CSP 不放行 script）——"纯 UI"是机器事实；**批注入口缺位**（文案声明
   没有入口，正文无任何批注控件）。
4. **D4 typed 工具结果=Sage 组件（US-175/176，D-048）**：新纯模块 `main/tool-results.ts`——
   声明按**严格解析**过门：支持 `text/key-values/table/link/image`，各自有界（文本 ≤8192、
   键值 ≤32、表 ≤100×12、计数 ≤32）；**敏感字段以「（已脱敏）」呈现、原始值不出投影**；
   **不支持的类型按名拒绝**（`state:'unsupported'`＋declaredType，**不用替代内容渲染**）；
   链接条目复用 D1 校验（坏 scheme=条目级 `refused` 码）；图片条目**只认本运行的就绪 image
   产物**（015 store 为权限家），否则 `tool-result-image-not-permitted`。视图只含组件数据：
   无脚本、无权威动作字段；渲染面可交互的只有两枚显式按钮（外链打开/按版本预览）。生产
   provider 不存在 ⇒ 槽如实 `unavailable`（不用空列表冒充）。
5. **D5 网页成果目录=只读筛选（US-174，OBS03）**：渲染面从 015 同一份观察卡中筛出
   `kind:'html'`——显示**同源版本**与「访问限制：仅本机离线预览（无发布/托管入口）」；
   文案钉住「**已托管/可预览不等于网站上线**、本版没有发布、部署或托管入口」；唯一控件是
   「预览（离线）」（走既有按版本打开）。不新建事实源、不出现发布类动词（名册断言）。
6. **D6 生产装配断链修复（跨票）**：`main/app-service.ts` 补齐**附件/产物/搜索/事项列表/
   侧聊**五族的键声明与转发（并含 033 的 `artifactFullscreen`/`externalLinkOpen`/
   `toolResults`）；新增守护 spec `test/app-service-wiring.spec.ts`——每族一枚独有标记穿透
   **生产装配函数**，任何一族再被丢键即具名红（「知道」升级为「拦住」）。已知未闭：五族
   此前只经过函数级验证，其真实窗口行为仍待真机复跑（§1.6 真机未跑口径不变）。
7. **D7 首版不做**：图片批注（绑定版本与权限后置）、真实发布/托管与站点上线、图表编辑
   （沿工单边界）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 预览允许外链点击/内置浏览器 | 否决：D-034/036——外链只走可信显式入口→系统浏览器。 |
| 外链由渲染端直接打开 | 否决：校验必须在 main（协议/目标/凭据），渲染端只发具名动作。 |
| 全屏=重新加载到全宽容器 | 否决：US-172 要求全屏退出恢复焦点、走离线资源；重复加载=可观测副作用。 |
| 图片缩放用脚本 | 否决：「纯 UI」+ 现有预览文档零脚本纪律；CSS 切换足够表达。 |
| 不支持类型近似渲染（如把 json 当文本） | 否决：US-175 点名"明确拒绝"；M04 教训=替代渲染制造假能力。 |
| 结果里透传 raw payload 供调试 | 否决：US-176/D-048——脱敏投影是合同，raw 不进 UI。 |
| 装配断链只登记不修 | 否决：033 的目录/预览/全屏即依赖该装配；且先例（P-20）要求"知道⇒拦住"。 |

## 后果

- 验收三条的机器断言：①外链仅在显式动作下打开（boot 零请求；恰一次具名 POST；坏 scheme 拒
  于 opener 之前；opener 未接线诚实）；②网页成果目录不把已托管说成已上线（筛选+文案+控件
  名册）；③批注入口缺位（文档零脚本、无批注控件、文案声明）。
- 装配守护：五族＋033 两端口＋toolResults 槽经生产装配函数往返；丢键即红。
- §1.6：D4 全屏态、D10 五行结果（含脱敏/拒绝）、D11 目录行以真实页面两宽实测；交互读数由
  dump-dom 逐项核对。
- 已知未闭：工具结果生产 provider 不存在（槽如实 unavailable）；外链真实系统浏览器行为待
  真机；五族断链修复的真实窗口复跑挂在真机批；批注/发布后置。
