# ADR-0316 · R16 壳批：事项名册/管理读回、事项分组与侧聊（O04/P15/S09）

- 状态：accepted（2026-10-11）
- 日期：2026-10-11
- 决策者：用户（Loop-Q 连续性授权）＋ agent（侦察＋实施）
- 决策记录：[Note](../notes/implemented/surface/2026-10-11-r16-shell-batch.md)
- 相关：[ADR-0315](ADR-0315.md)（纯壳口径 D1/D2）、[ADR-0313](ADR-0313.md)（壳批成例）、[ADR-0310](ADR-0310.md)（adopt 装配先例）

## 背景

R16 = sweep 剩余壳家族的成例批。O04（matter-admin/matter-groups）、P15（侧聊半）、S09（后台半）三伞在账本中全无叶；三族机器均已装配进 `/.sage/state` 信封（matterList/matterAdmin/matterGroups/sideChats），desktop 零消费；三条 route 均为 violation/direct-provider-bypass。ADR-0315 已裁：纯壳迁移、appsvc 保持 blocked、矩阵 violation 一字不动、admission 收口独立成批。

## 决策

1. **D1 纯壳装配（三槽闭合解析）**：desktop `client.ts` 增 matterList/matterAdmin/matterGroups 三槽、`session.ts` 增 sideChats 槽——逐字段闭合解析、畸形整槽省略（parseSettingsLeaves 纪律）；面板只渲染事实。
2. **D2 零动作入口（与本仓 S03 成例的关键分野）**：S03 的审批路由 compliant 故壳批直接接通；本批三族写路径（archive/restore/batch/rename、groups create/rename/remove/assign、sideChat create/send/return/read）骑 **violation** 路由——接通即深化 bypass。因此：**读回面全装**（名册/计数/触发/归档标签/重命名回读/批量逐项/轨迹/分组与成员数），**动作面零入口**——卡内以一条具名说明行声明「尚未接通（写路径 admission 收口在独立批——本版不提供动作入口）」。**选择态（多选 checkbox/单选 pick）同批不装**（无动作消费方的选择即死控件）；随 admission 批一并装。
3. **D3 侧聊壳**：会话页侧聊名册（读侧行 + 执行态徽标 + 派生来源/锚点）＋ 新建/发送/带回/单独回看四动作按钮——点击给出具名说明、**不提交任何请求**（violation 路由零接触）；transcript 回看（sideChatRead 亦在 violation operations 内）同批具名未接通。
4. **D4 P15 多窗格半剔除**：仓内无机器（无 route/wiring/分栏实现，static-only）——不装配、不占位，blocker 具名；S09 后台 Agent/进程展开面同判（runMonitor.background 轴维持 named unknown）。
5. **D5 S09 对齐**：MonitorPage 后台轴沿用既有 named unknown；清理 page 路由中 `运行模式` 的陈旧 outstanding 死条目（该页自 ADR-0304 起为真实页）。
6. **D6 迁移**：O04/P15/S09 三伞行迁 `ui` `pending→implementing`（tracked-test 证据：desktop-matter-admin.spec.tsx / desktop-side-chats.spec.tsx / desktop-client.spec.ts）；`applicationService` 保持 blocked；ownerTicket 维持 T08（范围票据不变）；blocker 照 S03 四要素改写（含 violation 语义）。summary 重算。
7. **D7 用户裁定采纳**：O04 名册容器落点采纳侦察建议——并入**工作区页「事项」分区**（不开新导航项）；P15 多窗格半正式剔除记录入本 ADR。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 接通 violation POST（照 S03 形） | 否决：S03 路由 compliant 故直连；本批接通即加深 bypass，违反 ADR-0315 D1/D2。 |
| 装多选/单选选择态 | 否决：无动作消费方即死控件；随 admission 批装。 |
| 事项管理开新导航页 | 否决（裁定）：并入工作区页分区，不开新导航项（Q4 建议已采纳）。 |
| 多窗格/后台 Agent 静态占位 | 否决：无机器不占位，防假入口。 |

## 后果

- 工作区页获得事项名册与两卡读回；会话页获得侧聊名册；矩阵 108→111 implementing。
- 余量具名：三族写动作 + 选择态（admission 批）、侧聊 transcript、多窗格、后台 Agent/进程。
- 真机验证项：三族真实读数（空态/真实行）——走查手册第 18 步记录所见。
