# ADR-0154 · 验收入口显式准备依赖、全量收集测试与沙箱失败停止

- 状态：accepted（2026-09-21）
- 决策者：用户批准 full CI 仅补更新包锁文件安装；agent 负责测试收集与沙箱失败保护
- 决策记录：[Note](../notes/implemented/contract/2026-09-21-acceptance-entrypoints.md)

## 决策

验收必须核对实际执行的对象，而非只比较失败检查名。full CI 在运行门禁前为更新包安装锁定开发依赖；发布自测在临时根创建失败时立即停止；LoopX 默认套件收集两种已有测试后缀。均须有可执行反例，不放宽生产隔离或锁定保证。
