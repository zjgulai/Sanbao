# ADR-0260 · UI-01B：导航六项目标与支持卡文案收口

- 状态：accepted（2026-10-04）
- 日期：2026-10-04
- 决策者：用户（lute，指示视觉 CSS 层优先推进；本票由 Qoder 会话执行）
- 决策记录：[Note](../notes/implemented/surface/2026-10-04-navigation-six-item-and-support-copy-batch-13.md)
- 相关：[ADR-0259](ADR-0259.md)、[UI 一致性合同](../specs/2026-09-27-sanbao-to-sage-ui-consistency-contract.md)

## 背景

UI-01A（批次 12）已把工作台外壳收敛到运营级标度，但左侧导航仍是七项旧集合（经营事项/总览/能力/治理/个人资料/只读呈现/设置），与用户确认的六项目标（经营事项、搜索、自动化、知识、能力、设置）不一致；搜索与知识虽有已接线的只读卡，却埋在「经营事项」支持区与「只读呈现」面板里；「已接线操作面」多张支持卡仍带超长解释段落。

## 决策

1. 左侧一级导航收敛为固定六项：经营事项、搜索、自动化、知识、能力、设置；tab/panel 对为 view-matter、view-search、view-automation、view-knowledge、view-capabilities、view-settings，ARIA 互引、单一 tab stop 与窄宽 accessible name 全部保留。
2. 搜索升为一级页面：原搜索卡（含 `#search-input`/`#search-run` 等全部 id）从「经营事项」支持区迁入 `panel-search`，客户端零改动。
3. 知识升为一级页面：原「知识与引用」卡从只读呈现迁入 `panel-knowledge`。
4. 自动化以诚实未接线呈现：明确「本版没有定时、周期或事件触发的自动化入口」，零控件、无创建/启停/记录入口；「没接线」不写成「已停用」。
5. 被置换面板内容归并到设置：运行状态卡（含 `#state-title`/`#retry`/`#login` 等）与身份卡、行动边界、退出检查/引导/环境、可见范围、插件与扩展、关于与诊断全部迁入 `panel-settings`；总览的事项卡与 trace 说明条退役（工作台同源呈现）；能力面板不变。所有既有元素 id 保留。
6. 支持卡文案收敛（4 处）：事项列表卡、草案卡、搜索卡、附件卡的长段落压缩为短句；fail-closed 断言（「不会自动写入交付或责任」「上传成功不等于模型已读取」「不打开会话、不激活执行、不加载正文」等）逐字保留。
7. 守护升级：新增源合同 spec `test/ui-navigation-contract.spec.ts`（六项顺序、退役面板缺席、归并 id 存在、automation 零控件、客户端无 `#matter-overview` 钩子）；两套 Electron 探针的 documentFacts 以 `activeTabId` ＋ `navItemCount`/`navItemIds` 取代 `overviewVisible`，键盘遍历断言从 view-overview 改到 view-search。
8. 不引入 React/依赖；不改路由、provider、authority、token 与各卡的行为与请求形状。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 保留七项、仅改名 | 否决：与用户确认的六项目标直接冲突。 |
| 六项但自动化留空面板 | 否决：空白会被读成加载失败；诚实未接线文案是 fail-closed 基线。 |
| 删除被置换面板内容 | 否决：会丢失已接线的登录/重试/退出检查/可见范围/诊断入口；归并到设置并保 id。 |
| 同步调整能力面板或引入新控件 | 否决：超出本票边界，能力面板保持原样。 |
| 复制 Qoder / Sanbao CSS | 否决：外部原型只作只读证据。 |

## 后果

- 首屏导航与目标 IA 一致；搜索、自动化、知识成为一级入口；设置承担系统与控制台归并。
- 所有既有 wired id 保留；客户端脚本仅移除 Overview 卡引用；六项导航与归并结构被源合同 spec 与两套 Electron 探针钉死为可失败断言。
- 未决：UI-DECISION-01、真实 provider/mutation、完整 Qoder UI/UX 状态迁移（一致性合同 13 adapt 状态的后续逐条迁移）。
- 改动写入 `main` 工作区，未 stage、未 commit、未 push。
