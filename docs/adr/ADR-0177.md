# ADR-0177 · Electron 43.3 single-frame caller-binding 预检（帧禁用候选不变量）

- 状态：accepted（2026-09-30）
- 日期：2026-09-30
- 决策者：用户（lute）
- 决策记录：[Note](../notes/proposed/architecture/2026-09-30-electron-single-frame-caller-binding.md)
- 相关：[ADR-0174](ADR-0174.md)、[ADR-0175](ADR-0175.md)、[ADR-0176](ADR-0176.md)

## 背景

[ADR-0176](ADR-0176.md) 以 revision 39 证明 IPC/preload candidate 的 top-bridge bypass：same-origin child 可借用 top frame 公开的 bridge，而 `event.senderFrame` 只能证明实际发送 IPC 的 preload frame，不能证明 JavaScript caller 是 top document。ADR-0176 第 6 条要求下一候选必须另票决定 same-origin caller principal、frame 禁用、bridge / renderer 拓扑或替代 transport。

用户于本票确认 revision 40 按八文件 single-frame preflight 执行，并接受候选不变量：**Sage privileged renderer 禁止 nested browsing context；出现 child 即污染当前 document generation，直到 clean top cross-document reload**。

## 决策

1. **revision 40 的结论为 PASS（预检局部）。** 真实 Electron browser-process probe 以 `outcome=pass`、`passed=true`、exit 0 结束。在 pinned Electron 43.3.0 下，main-owned frame 观察（`frame-created`、非 main 导航、webview attach、非 owned 顶层导航、load 失败、render-process-gone、destroyed）+ document generation 状态机 + IPC entry 与 durable barrier 双重核验，对 revision 39 的全部 child 形态（parser / dynamic / about:blank / srcdoc / data / blob / sandbox-opaque / nested / early-call-remove）fail closed；干净单帧 baseline 的 read / action 正常完成；唯一恢复路径是 main-owned clean top cross-document reload。
2. **帧禁用不变量确认为本票候选不变量，不是已采纳的 production 合同。** 该不变量将 same-origin descendant 一律视为污染而非合法 caller principal，比 ADR-0174 的 main-frame-only caller 合同更保守；production 采纳要求 production 页面 CSP、导航图、embedding 政策与 UX 影响一并落地，属独立决策。
3. **sticky contamination 是必要组成，tree-only 检查不充分。** child 移除后 frame tree 回到单帧，但被移除 child 的 generation 保持拒绝；same-document navigation 同样不洗白。只做即时 frame tree 检查会在 child 移除后重新放行，不得写成等价实现。
4. **control 窗口反例复现是本批 harness 自证。** 同一 probe 内不启用 single-frame 判定的 control 窗口仍复现 revision 39 的 top-bridge allow，证明本批 PASS 来自帧禁用判定本身，而不是环境差异悄悄消除了反例。
5. **WT-02D.0.1、`.1` 与 `.2` 继续 blocked。** 当前 Host-owned `GET /.sage/state` / `POST /.sage/actions` 保持不变；不迁移 production route、不增加 production preload / IPC handler、不接 Host narrow port、Application Service、provider、store、Adapter、UI action 或真实副作用。预检 PASS 只解除 transport 候选层面的一个反例，production 采纳（含 production CSP / frame policy）必须另建 Birdview 计划、决策与用户确认。
6. **绿色测试只表示 PASS 可重复且可证伪。** 外层 test 独立断言 raw child exit 0、空失败清单、完整事件矩阵、effect 计数、sequence 唯一性与 cleanup；`no-go` / `harness-fatal` 仍独立编码为 exit 2 / 1。变异验证证明污染不粘滞时该测试会红。
7. **本批射程严格为八文件。** 三份 test-only 文件（probe、preload、外层 spec）、本 ADR、对应 Note、ADR 索引、派生 ledger 与执行计划；production `src/**`、package / lockfile、Electron pin、vendor、legacy 与 release 均不修改，也不暂存、不提交、不推送。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 将 same-origin child 归为与 top 相同 caller principal | 本票不采纳；帧禁用更保守，principal 合并仍需独立决策。 |
| 只靠 production CSP `frame-src 'none'` 防嵌 frame | 否决为充分条件；CSP 只能作为并积层，blob / data / 移除后重嵌入等路径仍需 main-owned generation 状态机。 |
| 只在 entry / barrier 即时检查 frame tree | 否决；removed-child 读数证明移除后 tree-only 检查重新放行，必须 sticky contamination。 |
| 让 same-document navigation 重置 generation | 否决；same-document 不产生新 document，且该放松属 SPA entitlement 治理另票。 |
| 回到 browser-fetch（ADR-0175）或升级 Electron pin | 不在本票射程；均为独立决策与验证。 |
| 以本批 PASS 直接进入 production route migration | 否决；production CSP、导航图、embedding 政策与 UX 影响未决，预检证据不能替代。 |

## 后果

- single-frame candidate 取得完整正读数：所有 child 形态 fail closed、干净 baseline 可用、恢复路径唯一且 main-owned；这解除了 transport 候选层面 revision 39 反例的阻断，但不解除 WT-02D.0.1 的 production 阻断。
- 已证明的仍是 test-only transport / synthetic state-machine 语义与 main-owned frame 观察；真实 Adapter cancel、receipt、reconciliation、outcome recovery、production authorization 与 production frame policy 均未证明。
- ADR-0174 继续拥有 Application Service 总体合同；ADR-0175 / 0176 继续拥有前两候选 NO-GO；本 ADR 只拥有 single-frame preflight PASS 与候选不变量。
- production runtime、当前 route、Host、UI、provider、Adapter、store、真实数据和外部动作保持原状。
