## 背景

ADR-0333 把「模型编辑器真校验/保存 → 已配置列表」登记为具名后续。审计确认：settings 栈自接线起**恒关闭**——`dsh-settings`/`dsh-config-editor` 行挂 `!ctx.get('profileContext')` 门，Sage 自组启动器从不提供，`modelConfig` 恒 `bridge-refused`（ADR-0249 时代的定位记录逐字命中）。基座本身有完整的自定义模型机制：llm-pi-ai 手写路由（`providers.<route>` 画像）、settings 路径写三件套（update/replace/mutate，mutate.unset 是唯一移除路径）、`discoverModels` 真实端点探询（GET {baseURL}/models，零业务内容）。

## 决策

1. **D1 settings 栈解锁**：host `prepare` 提供 `profileContext`（name=`sage-shell`、patchPath=`<Sage root>/cordis.settings.patch.yml`——**代外**，代内 `cordis.patch.yml` 收据逐文件哈希封印、写一字节即下代 fail closed、home=`$DSH_HOME`、overlays=壳+实例本地平铺行）。**组合等式为构造性**：`composeShellPatches = readProfilePatches(同一 context)`，启动补丁与 config-editor 每次重算同源；generation 用户层退出组合且非空 fail loud；壳 overlay 显式 disabled hmr。
2. **D2 保存 = 路径写**：`modelConfig/save` 以 `mutate set ['providers', route]` 落 llm-pi-ai 用户层（整段 merge 会抹兄弟路由）；`modelConfig/remove` 只走 `unset`。语法封闭：route 名文法、api 三枚举、http(s) URL 无凭据/查询/片段、models 1..64 精确键——未知成员拒（不能走私 headers 等部署域字段）。
3. **D3 测试只测已保存路由**：`modelConfig/test` 由宿主从 settings **读**端点事实后调 `llm.discoverModels`——渲染端只传路由名，注入 baseURL 的钥匙外泄路径在 400/缺省即死；宿主 20s 自有钟、不重试、abort→unknown；请求即 GET {baseURL}/models，**零事项/会话/附件内容**。裁决结构化（ok:true 携 state + 绑定事实）；`credential-missing`/`unsupported` 具名。
4. **D4 结果绑版本**：记录臂 = namespace revision + 凭据 configured 快照；`current` 由**当下的**事实判定——保存移动 revision 后旧成功自动降「仅历史」。端口持有 in-flight 单槽与记录（**main 生命期单例**）；每路由不并行重复测试。
5. **D5 渲染面**：兼容供应商（OpenAI/Anthropic Compatible）表单真录入（Base URL、Model ID 添加/移除、API Key）；「校验并添加模型」= 结构校验→保存配置→保存凭据两步分开（部分失败具名、不显示整项完成）；行内「测试连接/删除」；行 = 路由名+供应商形态+端点+凭据状态+绑定结果标签。**保存不触发任何供应商请求**；「已保存、未测试」与调用状态是两个字段。路由名与凭据引用由端点主机确定性派生（`openai|anthropic-<host-slug>` → `*_API_KEY`），凭据可寻址名 = 固定应用名 ∪ 已声明引用（未声明名宿主仍拒）。
6. **D6 实测披露的基座口径差**：settings 的 `user` 层读**代内** patch 文件（Sage 布局下恒空）——有效配置在 `value`；全部读取统一 **value 优先**（写路径不受影响：config-editor.edit 以 readProfilePatches(profileContext) 重算）。该差异与 018 未闭项（unset UX/pi-ai 段表单/baseURL 回填）一并登记。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| patchPath 放进 generation | 否决：收据封印会因一次保存报废整代（下代 fail closed）。 |
| update（整段 merge）写 providers | 否决：合并语义会抹掉兄弟路由；mutate 路径写是基座自己的先例。 |
| 渲染端传 baseURL 给测试 | 否决：已保存凭据会被发往任意端点（钥匙外泄缝）。 |
| 测试=真实补全调用（ADR-0249 草图） | 改为列目录探询：同样证明「端点+凭据被供应商接受」，零业务样本、更小面。 |
| 直接读 user 层 | 实测否决：恒空（D6）；value 即有效事实。 |

## 后果

- 模型编辑闭环：录入→保存（两步）→列表「已保存、未测试」→显式测试→绑定结果；重启后配置与凭据持久（测试记录随进程，属登记边界）。
- 路由 64 行（+.sage/model-config = protected-effect bypass 第 12 条）；桥 +3（modelConfig/save|remove|test）；矩阵/gates/消费登记（+llm）同步。
- 真机实证：真实 DeepSeek 端点 200、147–189ms、modelIds 回读；UI 行渲染核对。
- 后续票：018 未闭项（unset UX、pi-ai 段表单、baseURL 回填、inventory overlayPolicyDigest）；019（事项级改选）另票；DeepSeek 默认供应商表单写入面另票。
