# ADR-0329 · 运行时失效只听**根 fiber**：会话级子 fiber 的正常拆除不再是失效

- 状态：accepted（2026-10-12）
- 日期：2026-10-12
- 决策者：用户（授权修复实测问题）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-12-root-fiber-invalidation.md)
- 相关：[ADR-0327](ADR-0327.md)（第一层过滤）、[ADR-0294](ADR-0294.md)

## 背景

ADR-0327 落地后（v10 装机实测）：回合走完 + 稍后，桥再次整体死亡（折叠 `bridge-host-not-ready`，Host 进程活着）。装版探针链：`fold-catch: bridge-host-not-ready`；Host 侧失效路径只能来自 `internal/status` 监听——ADR-0327 的状态过滤（3/4/5）**放行了会话级子 fiber 的正常拆除**：回合/会话收尾时 cordis 拆除 scoped 子 fiber（DISPOSED=4/UNLOADING=5）→ 判运行时失效 → 桥死。与 ADR-0327 同类误报的第二层：`internal/status` 覆盖**所有** fiber，而「运行时失效」只应由**根 fiber**（整个已认证组合）的劣化触发。

## 决策

1. **D1 根 fiber 身份闸**：监听器在注册时捕获根 fiber（`hostCtx.fiber`）；仅当事件 fiber === 根 fiber 时才考虑失效（cordis 子 fiber 携带 `.parent` 链，scoped 拆除属常规生命）。
2. **D2 状态过滤保留**：根 fiber 上仍只认 FAILED=3 / DISPOSED=4 / UNLOADING=5（boot/懒激活 1/2 静默）。
3. **D3 既有判据不变**：`runShellHost` 生命期 spec（arm 后 dispose → 恰一次失效）不改判据仍通过（根 dispose 走根 fiber 的 5）。
4. **D4 验证**：spec + v11 装机实测（失败/成功回合之后的连续读取面保持可用）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 只认 3（FAILED） | 否决：根拆除（5/4）是既有 spec 的失效事实，且是真实生命周期。 |
| 看 fiber.parent 链判断深度 | 脆弱：根身份直接可比，无需启发式。 |
| shell 侧对失效做宽限重试 | 否决：拆证据链；根因在判据不在消费端。 |

## 后果

- 回合收尾（成功或失败）不再打死桥；连续读面（折叠/state/会话通道）保持可用。
- 根级异常（真拆除/失败）仍恰一次失效。
