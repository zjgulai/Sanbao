# ADR-0192 · deepseek-harness 0.2.0-rc.2 内核跟进：单步换装、帧常量自有权与最小 seed 演进

- 状态：accepted（2026-10-02）

- 决策记录：[harness 0.2.0-rc.2 内核换装](../notes/implemented/architecture/2026-10-02-harness-0.2.0-rc.2-kernel-upgrade.md)
- 相关：[ADR-0006](ADR-0006.md)（观察窗——本轮立场）、[ADR-0008](ADR-0008.md)（pin 只读参照与分离提交）、[ADR-0139](ADR-0139.md)（薄壳骨架）、[ADR-0168](ADR-0168.md)（Sage lifecycle v4 自有方向）、[research/20 差异总账](../research/20-harness-0.2.0-rc.2-delta.md)、[升级设计 spec](../superpowers/specs/2026-10-02-harness-0.2.0-upgrade-design.md)、[实施计划 K 票](../superpowers/plans/2026-10-02-harness-0.2.0-upgrade.md)

## 背景

上游 deepseek-harness 于 2026-09-29 发布 **0.2.0-rc.2**（间隔跨 0.1.6/0.1.7 三条线、约 3 周）：包面 289→338（59 新增/10 移除），发布纪律改为包间**精确版本**；**FD3/FD4 字节管道传输被整体删除**（desktop 换轨到共享 Web 应用 + Node IPC，`apps/desktop-host/src/wire.ts` 不复存在）；`settings.yaml` 退场改 profile 级配置；session 数据格式 **v3→v4**；且 0.1.5→0.1.7 窗口**没有官方 upgrade guide**。Sage 薄壳的程序性 pin 停在 0.1.5-rc.2，运输协议、host 移植与全量 fixtures 都建立在该参照上（[research/20](../research/20-harness-0.2.0-rc.2-delta.md)）。

用户于 2026-10-02 立项：**以当前 Sage 骨架为第一性原理直接跟进 0.2.0-rc.2**（三件套评审通过后开工；7365c577 会话已收口、ddd80099 会话在独立 worktree，主树无冲突面）。

## 决策

1. **D1 目标与立场**：单步换装到 `0.2.0-rc.2`（不取 0.1.7 两步式——与 0.2.0 相隔 4 天，重复安装/验证无可证收益）。ADR-0006 观察窗立场显式记录：本迁移属「客户需求驱动的大版本迁移」；目标为 3 天新鲜的 pre-release；Sage 尚未出货、爆炸半径限开发环境；保留 pin+lock 一键回退。rc.3/正式版发布后做一次增量核对。
2. **D2 帧常量自有权**：上游删除 wire 参照后，Sage 协议 v4 的六个 FD3/FD4 framing 常量**值不变、所有权归 Sage**；`sage-shell-pin` 从「对齐上游 wire.ts」改为「冻结字面量断言（空白归一）+ 变异自测」，删除 submodule 参照输入与 degraded 路径；检查强度不降级——从会漂移的对照变成不能被静默改动的冻结值（承接 ADR-0168 的自治方向）。
3. **D3 seed 最小演进**：`dsh-code-runtime`（上游删除）→ `dsh-ptc-runtime`（worker 由 base bundle 传递）；其余 37 个 `dsh-*` 原位升 `0.2.0-rc.2`；cordis 族 4.0.4/include 1.0.9/group 1.0.4；`dsh.profile.patchReload` 字段删除（0.2.0 app-boot 不再消费；自定义 profile 缺省即 `live` 语义等价）；`bundles` 与两个 override 不动；**不主动纳入任何新包**。
4. **D4 唯一行为适配 + fail-loud 重建**：0.2.0 把不可装载的 bundle 从「抛错」改为「跳过并记 `skippedBundles`」；Sage 在 `composeShellPatches` 层重建 fail-loud（任一声明 bundle 被跳过即中止启动、原样携带上游 reason），保住薄壳的组合合同；host/协议/overlay 其余面零源码改动。
5. **D5 证据与回退**：全部验收在 `SAGE_ROOT` 隔离实例完成（共享数据根零接触）；回退 = pin/seed/devDeps/lock 回撤 + 重物化（旧 generation 留盘）。legacy 链（fork、旧 DMG、`harness-runtime-source` 物化）不联动。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 两步换装（先 0.1.7-rc.2） | 否决；与 0.2.0 相隔 4 天，双倍安装/验证成本无可证收益。 |
| 走 ADR-0006 观察窗/等正式版 | 否决（用户立项）；Sage 未出货、仅开发环境，观察收益低于停滞成本；立场已显式记录并保留回退。 |
| 跟随上游新桌面架构（共享 Web 应用 + URL 注入） | 否决；等于重做壳的传输层，产品范围外，且与 ADR-0139/0168 的薄壳形态冲突；登记为独立评估项。 |
| 保留 vendor 旧 commit 作 wire 参照 | 否决；参照系与运行时线脱钩（pin 腐化），违反「一份事实一个家」。 |
| 手改 golden 字面量 | 否决；golden 一律用真实生产者重算后重冻结（K5 实证：6/13 独立未变、7+2 随语义变化重冻结）。 |

## 后果

- **读数（2026-10-02）**：提交链 `d496953`（三件套）→ `d31cfa1`（K1 pin）→ `9d42a5d`（K2 门禁）→ `01ceb2c`（K3+K4 换装）→ `70c0bcc`（K5 golden）；`pnpm run gate` 每步 25/25；全量套件 **611 pass + 1 opt-in skip（62 文件）**；隔离根 materialize 两次成功（598 解析/600 包、frozen-lockfile）；smoke **16/16**（`protocolVersion=4`、`dshVersion=0.2.0-rc.2`、generation/manifest 绑定、loaderPhase=active、`/.sage` 404 拒面、traversal 403、shutdown code=0、零告警）；overlay 探针 10/10（7 disable 行 + 2 insert + connection inject）。
- **行为面**：内核 = 0.2.0-rc.2（seed 41 依赖 + 壳 devDeps 同版）；Sage 协议帧值不变；bundle 准入 fail-loud 保留；`/.sage` 面归 main、host 恒拒面不变；编译面 typecheck/build 0 错（窄接缝判断命中）。
- **边界**：未动 legacy 链、未消费上游新面（账号/插件管理 UI/settings 表单/client 新 primitives）、未挂任何 Sage 插件（用户层仍 `[]`）、未动共享数据根与 `~/.dsh`。
- **遗留（登记见 spec §8）**：PMAP 源面（`dsh-agent-presets` 路径失效 + `settings.yaml` 改名）；C2C 面 MCP SDK 2.0/`projectContent` 改名评估；插件 manifest peer 规则体检；optional bundles 决策；client 栈消费研究；rc.3/正式版增量核对。
