## 背景

WT-02C.2E.3 验收发现（ADR-0196 D6）：host 面 4 行（`llm-deepseek`＝`@deepseek-ai/dsh-llm-deepseek-api-key`、`llm-deepseek-account`、`deepseek-account-platform`、`account-controller`）在全新与 K 世代隔离根共同 `failed to import`。本票全量审计定性：

- 对隔离 generation（`4b8e7dfb`）hoisted 树逐包核对 **600 包 / 1060 条非可选 peer**：未满足**恰为 4 条**，全部 dsh 家族；二号位 peer（`dsh-timeout` 等 7 包）全部在位，**零级联**；非 dsh 未满足为 **0**。
- 根因：0.2.0 系把家族内依赖收窄为**非可选 peer**（两包 `0.2.0-rc.2` 在 npm 存在）；seed 沿用的 `autoInstallPeers: false` 来自 **0.1.x rc 生态纪律**（ADR-0005 语境：当时 rc 区间在 npm 不可解析），对 0.2.0 exact-pin peer 只产生「警告 + 静默跳过」，消费者仍入图、运行时导入失败。
- K6「stderr 零告警」为模式受限读数（不覆盖 `did not activate`），真机 smoke 是唯一咬住该缺陷的仪器。

## 决策

1. **D1 修法 = seed 开关翻转 + 锁最小增量重生成**：`apps/sage-shell/seed/pnpm-workspace.yaml` 置 `autoInstallPeers: true`；锁在隔离临时目录以**现有已提交锁为起点增量重生成**（不换 pnpm、不动 registry）。增量结果恰为：`packages +2`（`@deepseek-ai/dsh-llm-deepseek` / `@deepseek-ai/dsh-deepseek-account`，均 exact `0.2.0-rc.2`）、**已锁 600 包零版本漂移**、importers 成员零变化（仅 peer-suffix 重哈希）；frozen 安装验证 + 全树复审计 0 未满足 0 版本错配。
2. **D2 拒绝全量新鲜解析**：同日新鲜 `--lockfile-only` 会把 ~68 个 ranged 三方包拉高（aws-sdk / sharp / mcp-sdk / undici 等）——属换装票外的版本漂移，违反「最小增量、既有验收读数有效」纪律，本票不取。
3. **D3 再生门 = `strictPeerDependencies: true`（同批入 workspace）**：定性实测——它**不**门槛 `--frozen-lockfile`（冻结安装跳过解析，旧锁带 4 条未满足仍 exit 0），只门槛**重生成**：同题无锁再生，关（baseline）exit 0 + 警告，开 exit 1 列出缺失 peer；正控（闭包后配置）exit 0。即：未来 K3 式换装 recipe 若引入不可自动闭包的 peer，再生即红，不再静默落盘。
4. **D4 机制守护 = smoke 激活断言（永久）**：`apps/sage-shell/scripts/smoke.mjs` 新增「`stderr` 含 `did not activate` 即失败」（上游 loader 对失败/挂起 entry 的唯一告警文案，required 失败走 `startup failed` 同含该串）。红证：旧根 `4b8e7dfb` 19 PASS + **1 FAIL** 点名 4 条；绿证：新根 **20/20**、exit 0。这是「静默降级」类缺陷第一次有机器守卫。
5. **D5 0.1.x 纪律边界入档**：`autoInstallPeers: false` 的历史要求（ADR-0005 与 `docs/research/*`）属 legacy 0.1.x 上下文；对 Sage seed（0.2.0 exact-pin peer 生态）由本 ADR 取代。legacy 文档保持历史原样，不追改。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 只把 2 个 peer 包手写进 seed `dependencies` | 否决：治标——peer 闭包语义应交给解析器；漏一个 peer 复发同病。 |
| 保 `autoInstallPeers: false` + `strictPeerDependencies: true` | 否决：strict 只让再生失败，不闭合图；换装 recipe 会直接不可用。 |
| 全量新鲜解析新锁 | 否决：~68 包版本漂移出票外，毁既有验收读数（D2）。 |
| 仅在 K6 记录里更正告警读数 | 否决：记录不能替代机制；smoke 断言才是守卫（D4）。 |

## 后果

- **读数（2026-10-02）**：隔离根 `sage-e3-accept.qbcmtXWANV` 新 generation `210d6ea0-d107-4692-b418-74c2bd2a9af4`：安装 601 包（新增 2）；smoke **20/20**（含新断言「host boot activates every bundled entry」），四行激活、零 `did not activate`；新树复审计 0 未满足 / 0 版本错配；无凭据激活（隔离根无任何凭据库）；typecheck 0；套件 **621+1skip**；三层 gate **25/25**（quick/full/strict）。
- **锁状态**：`settings.autoInstallPeers: true`；`packages` 668 key（旧 666 + 2）；增量 recipe 幂等（复跑 `Already up to date`，字节不变）。
- **遗留**：官方 DeepSeek route 的运行时可用性仍待真实模型调用功能探针实证（本票只保证 entry 激活，不证明 route 端到端可用）；行级 enablement 全矩阵与 matrix 物理重发仍按 ADR-0196 D3/D5 登记。
