# ADR-0346 · EP-1 专家列表 UI 与资源面（3 MGT + 50 AGT 目录卡片页）

- 状态：accepted（2026-10-13）
- 日期：2026-10-13
- 决策者：用户（EP 票链批准；2026-10-13「接管其待完成的任务」）＋ 并行会话（restore-expert-directory 实现）＋ agent（本会话核验与收口）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-13-expert-catalogue-ui.md)
- 相关：集成票 [EP-1](../plans/2026-10-13-expert-system-tickets.md)、[ADR-0341](ADR-0341.md)（EP-0 投影）、[ADR-0258](ADR-0258.md)（density token）

## 背景

EP-0 已入仓 3 MGT + 50 AGT 静态投影（ADR-0341）。EP-1 = 「专家」页：卡片网格 + 计数 tabs + 搜索 + 新建虚线卡（复刻 0.24.1 形态）；数据=EP-0 投影；创建/对话按钮具名禁用。资源面难点：53 头像要在**不改 CSP、不开文件系统路径面**的前提下同源可加载。票明文：Expert 属新产品面，矩阵登记走独立「catalog 扩展批」，不冒充现有 206 行。

## 决策

1. **D1 目录页（design-only）**：新增「专家」nav 与页面（`experts.tsx`）：3 管理身份 + 50 岗位设计卡片网格、MGT/AGT 计数筛选、大小写不敏感搜索、空态恢复、新建虚线卡；创建/对话按钮**具名禁用**并说明未接线——目录是设计内容面，不创建运行态、不建会话。
2. **D2 头像资源面（build 期封存）**：53 头像在 renderer 构建时封入 `SAGE_EXPERT_AVATARS`（base64 静态表，`renderer-assets.mjs` 校验：符号链接拒、大小界、stale generated 模块拒、缺图拒）；main 按**构建封存路径白名单**伺服（`/assets/experts/...`，仅命中封存表；请求路径永不成为文件系统路径；GET/HEAD、nosniff、CSP 不变；遍历/编码变异/多余段全部 404）。
3. **D3 投影生成**：`expert-registry.generated.ts` 由 `renderer-assets.mjs --write` 生成（design-only：无运行身份、授权或可执行 Preset）；`build-renderer.mjs` 引用 `assertExpertProjectionCurrent()` 保证构建期一致。
4. **D4 边界**：不触碰 `/.sage/*` 分支；矩阵登记不在本批——按票划归独立「catalog 扩展批」（如实记为后续）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 运行时从文件系统读头像（或 file://） | 否决：请求路径变文件系统面，且与 CSP/同源模型冲突。 |
| 头像内联进 DOM（data URL 直接进文档） | 否决：53 图撑大文档、无缓存边界；build 封存 + 按路径伺服更窄。 |
| 专家页先接真实创建/会话 | 否决：EP-2/EP-3/EP-4 依赖未到；伪接线=假完成。 |
| 本批内做矩阵登记 | 否决（本批范围）：登记机制（Sage 原生面 schema + 门支持）是独立设计，票已划为「catalog 扩展批」。 |

## 后果

- 「专家」页进入导航；内容=设计目录，动作全具名禁用（诚实边界与 EP 票一致）。
- 资源面获得一条可复用的构建封存伺服路径（同源、CSP 不变、零文件系统面）。
- 后续：EP-2 ExpertProfile 存储面；矩阵「catalog 扩展批」（登记 Sage 原生面）；EP-1 视觉验收随实机批。
