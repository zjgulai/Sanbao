# ADR-0321 · L1-B 事项分组四 op：同家族收口 + 真实分组动作入口

- 状态：accepted（2026-10-12）
- 日期：2026-10-12
- 决策者：用户（2026-10-12 确认 L1 计划与并行执行）＋ agent（装配设计）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-12-matter-groups-admission-batch.md)
- 相关：[ADR-0320](ADR-0320.md)（家族与成例）、[ADR-0315](ADR-0315.md)、T13/T04（票据）

## 背景

matter-groups 路由（create/rename/remove/membership 四 op）仍为 direct-provider-bypass violation；R16 读面与 GROUPS_UNWIRED_NOTE 在位、零动作入口。L1-A 家族机制齐备，本批为同型机械扩展。

## 决策

1. **D1 同家族扩展**：四 op 入 matter-governance 家族（表四行 scope `matter.groups` local-write；四个 detail kind 各带 provider 读回 status）；不新开家族面。
2. **D2 dispatch 单家族多路**：family dispatch 按 operation 前缀多路复用（admin/groups 各自 provider 绑定；未接线族仅自身 op not-dispatched）。
3. **D3 成员变更保持逐行**：membership 收据携批量 status（行级裁定，无整体成功横幅）；路由身份配对 groupId+operation。
4. **D4 UI 最小真入口**：分组建立/改名/移除真按钮（创建草稿仅成功时清空）；成员变更选择态具名留后续批。
5. **D5 门禁有意翻转**：matter-groups violation→compliant（20 bypasses / 14 direct / 15 admitted）；selftest 与矩阵 spec 同步。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 为新 op 组开第二家族模块 | 否决：同族五步面等价，仅多路 dispatch 差异。 |
| membership UI 与后端同批 | 否决：选择态属独立件；后端先行、UI 具名。 |
| 保持路由直连 | 否决：深化 bypass，违反治理红线。 |

## 后果

- 分组四命令全链收口；violation 面余 20（L1-C..L1-G 五波已规划覆盖 19 条）。
- UI：分组真入口上卡；成员变更具名随选择态批。
