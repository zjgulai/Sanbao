# ADR-0228 · 运行监控四轴与只读运行日志：不合成单一状态、游标式有界读取

- 状态：accepted（2026-10-03）
- 日期：2026-10-03
- 决策者：agent（取证并实施；D-012/013/031/032/039/056/071 与 FW-032 已定方向）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-03-run-monitor-four-axes-log.md)
- 相关：[ADR-0212](ADR-0212.md)（会话通道）、[ADR-0213](ADR-0213.md)（暂停语义）、[ADR-0225](ADR-0225.md)（S5 内容读取）

## 背景

工单 031（FW-032，US-159~164）：监控按步骤/预算/设备/后台**四轴分别呈现、不合成单一"运行
状态"**；折叠或关闭面板不取消运行、详情与列表读同一投影（R12 教训：详情"已停"而列表"运行中"
不可共用局部状态）；设备离线≠运行取消≠被接管（D-071）；用量分预留/消耗/最终账单、子执行与
重试归集同一事项、共享预算不重复占用（D-031/032/056）；上下文用量与压缩只读、压缩显式提示、
不泄漏私有侧聊或扩大外传（D-039）；运行日志只读、不进普通对话同步、导出独立核权（P14/D-033）。
验收：①四轴各自独立显示、无合成单一状态；②压缩前后差异与提示可见、未确认不压缩。明确不做：
预算预留与结算合同、后台执行主体、设备接管协议。

基座事实：无用量/预算/设备绑定/压缩读数；会话侧可核验的=打开轮（executing）与事件计数；
S5 内容读取端口（workspaceFiles）可读工作区内任意文件（含日志），版本令牌不透明。

## 决策

1. **D1 四轴各自为事实（US-159/161）**：新纯模块 `main/run-monitor.ts`。步骤轴=**会话通道的同一
   投影**（executing/idle 来自未结束轮；observedRecords/lastTurnEnd 直取）——生产接线两槽同源一读，
   "已停/运行中并存"在结构上不可能；预算轴=预留/消耗/最终账单**三个分开的 unknown**（各自
   reason `usage-provider-unavailable`，**不许出现数字 0 冒充**）；设备轴=unknown
   （`device-binding-unavailable`，文案明说离线≠取消≠接管）；后台轴=unknown
   （`background-host-unavailable`）＋文案"面板开合不影响运行"。**视图里没有任何 overall/
   runStatus/total 字段**（形状钉住＋扫描断言）——"不合成单一状态"是机器事实。
2. **D2 面板开合=本地视图状态（US-160）**：收起/展开只改本地 hidden（零请求、零会话动作）；
   renderer 断言：开合前后 requests 为空、刷新后仍收起；面板代码里没有任何 stop/cancel 调用。
3. **D3 上下文与压缩只读（US-163）**：context 轴=unknown（`context-usage-unavailable`）＋
   `compaction:'unknown'`；**无压缩触发入口**（控件名单钉住）；文案明说"压缩由执行侧决定、本版
   无压缩读数；任何压缩不得把私有侧聊带入主对话或扩大外传"（沿 024 分别投影合同）。"未确认
   不压缩"在首版成立的方式：根本不存在压缩命令面（负空间断言）。
4. **D4 运行日志=游标式有界只读（US-164，S5）**：新模块 `main/run-logs.ts`——stat 取版本/字节，
   `workspaceFiles/read` 逐页（≤200 行/页、单行>2000 字符截断并计入 truncatedLines）；游标
   {fromLine, expectVersion, expectBytes}：**追加（文件变大）不失效游标**（版本令牌含 mtime，
   每次追加都变——所以旋转判定用"变小"而不是"变了"）；**变小=轮转/截断**→ `rotation:
   'file-rotated'` 置空游标、明确提示"从头再读；不重复、不漏标"；同尺寸重写不可检测（登记为
   已知局限）。缺文件=`bridge-file-not-found`（**不存在≠空日志**）；越界路径/坏游标各有自码；
   权限=活会话作用域（无会话即 `bridge-file-scope-unavailable`，沿 013/027）。**日志读取不触
   会话/转录**（读前后 sessionChannel 逐槽 byte-equal）；**无导出入口**（导出独立核权后置）。
5. **D5 首版不做**：预算预留/结算合同、后台执行主体、设备接管协议、日志导出（均按工单边界）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 合成单一"运行状态"字段 | 否决：US-159 点名不合成；R12 的"已停/运行中并存"正是合成本地状态的后果。 |
| 预算未知处填 0 | 否决：D-031 点名"缺少可核验的价格或用量时不能以零代替未知"。 |
| 监控另建事件缓存 | 否决：US-160"详情与列表读取同一投影"；缓存必然分叉。 |
| 日志用定时 tail/监视器 | 否决：首版按需有界读取；watcher 另属 015 的 changes 观测面。 |
| 旋转判定=版本变化 | 否决：版本令牌含 mtime，追加日志每次都在变——用"变小"判旋转（追加不失效游标）。 |
| 日志导出入口 | 否决：D-033/059 独立核权后置；出口即泄漏面。 |

## 后果

- 验收两条的机器断言：四轴形状钉住（无 overall/status/total、预算无 0 数字、每轴独立 reason）；
  上下文/压缩只读＋无触发控件＋侧聊不混入（024 合同继续在守护）；折叠测试零请求。
- S5 真字节：临时目录＋真文件证明分页游标、追加不失效、变小即轮转、超长行有标记、缺文件≠空日志。
- 已知未闭：用量/设备/后台/上下文读数全部未接线（各轴如实 unknown）；同尺寸重写的轮转不可检测；
  真机未跑。
