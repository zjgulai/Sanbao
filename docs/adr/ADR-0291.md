# ADR-0291 · 选择流前置 ensure：全新 matter 全流程闭合与「先判后栅」写入核心

- 状态：accepted（2026-10-11）
- 日期：2026-10-11
- 决策者：用户（lute：同意推荐）＋ agent（取证与实施）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-11-selection-ensure-step.md)
- 相关：[ADR-0290](ADR-0290.md)、[进入 revision 流裁决](../notes/proposed/architecture/2026-10-11-revision-entry-flow.md)、[ADR-0289](ADR-0289.md)

## 背景

ADR-0290 D5 登记：context 激活绑定既有 revision，send 时 prepare 无法修复已激活 context。本刀把 ensure 前移到选择内核（active-matter-selection），CAS 因此绑定被 ensure 的修订。实施中又被 step-10 端到端抓到第二处缺陷：send 时钩子先跑四栅后判 not-needed——已备 matter 也被索要 prepare grant（dispatch E2E 拒绝暴露）。

## 决策

1. **D1 选择内核新序**：可选端口 `ensureRunnableRevision({matterId})` 位于 read-authorization 之后、`resolveCurrentRevision` 读取之前——CAS 绑定被 ensure 的修订。结果三态 `ready|not-needed|refused`；refused 或形状非法 → 新拒绝码 `revision-ensure-refused`，CAS 不跑（既有常驻 context 不被触碰）。端口缺省 = 旧行为（既有 fixture 不受扰）。重复选择天然幂等：已备 matter 判 not-needed。
2. **D2 写入核心拆为两半（先判后栅）**：`decideRunRevision`（读库 + current-policy 判——**先于一切 authority 检查**，与链内 context 步「先读后策略」先例一致；已备 matter 不因选择或发送被索要 prepare grant）→ 需要写入时 `writeRunRevision`（域 authored `revision-entered` + 普通幂等 append）。两个入口共用：send 时 runner（四栅后写）与 selection ensure（identity 栅后写）。
3. **D3 见证**：selection ensure 的见证 = 用户显式选择（`source: 'user-selection'`）；send 时 = `user-input`。
4. **D4 装配**：index 以同一身份端口工厂构造 ensure 并接入选择端口（correlation 为 caller binding）。
5. **D5 门禁**：ensure 顺序 pin（先于 current-revision 读）+ ensure 拒绝停选择 pin + **decide 先于栅序 pin**（过栅缺陷的回归钉）+ 三条新突变；上一刀 pin 随拆分复绿。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| ensure 放在 CAS 前最后（frame 后） | 否决：current-revision 读在 frame 之前，CAS 会绑陈旧修订；或需二次重读（多一读无益）。 |
| 把写藏进 `resolveCurrentRevision` 端口 | 否决：读端口隐藏写；选择内核显式序列是本模块的纪律。 |
| 维持「先栅后判」 | 否决：E2E 抓到过栅——已备 matter 的选择/发送被无端拒绝。 |
| send 时静默重激活 context | 仍在否决（ADR-0290）——选择流是 context 的治理面。 |

## 后果

- **全新 matter 全流程首次闭合**：custody 形态 matter → 选择（真内核 + 真 ensure + CAS 绑定新修订）→ send 走完十步链 → `accepted{sessionId, requestId, mode}`；store 复核两修订（出生 + 工作）+ 一条 attempt。
- 两处本批发现的缺陷（过栅、以及此前 0290 D5 的排序）都有测试与门禁钉住。
- 未闭：回合收口流（侦察已呈报，粒度裁决待定）；真实模型调用验收；WT-02B.3、host-lifecycle、撤销运营。
