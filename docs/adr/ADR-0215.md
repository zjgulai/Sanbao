# ADR-0215 · 叶子设置页只读注册表：来源可追、写入口在契约上就不存在、索引读观察不扫描

- 状态：accepted（2026-10-02）
- 日期：2026-10-02
- 决策者：agent（取证并实施；"写入口长什么样"是取舍）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-02-readonly-leaf-settings.md)
- 相关：[ADR-0208](ADR-0208.md)（后置只读族）、[ADR-0214](ADR-0214.md)（偏好权威值）

## 背景

工单 046 要把 11 张叶子设置页（桌面宠物/记忆/数据导入/钩子/电脑操控/移动端/连接/安全/网络/工作区索引/任务监控）
首版做成**只读呈现**：每页标来源、标不可用原因、无任何写入口，且工作区索引页**不得触发全量扫描**（D-090/US-219）。
其中只有三项的"来源"在 main 手里有真事实：Host 启动观察（连接）、实例策略文件（安全）、工作区登记观察（索引）。

## 决策

1. **D1 注册表即表面**：`SETTINGS_LEAF_IDS` 是这 11 页的唯一名单；没登记就没有页面。每行必须带 `title/source/note`，
   且 `state:'unavailable'` 的行必须以 `未接线` 起句并给原因——**没接线不改写成停用**（US-212 余部 + 026 同款纪律）。
2. **D2 写入口在契约上就不存在**：`SettingsLeaf.writeEntry` 恒为 `null`，本版**没有任何写端口**；
   将来要加启用/导入/连接入口，必须先改这个契约（及其断言），不允许"顺手"长出来（US-210/213~218）。
3. **D3 来源可追到真事实**：连接＝`host.readSnapshot()` 的活跃世代；安全＝实例策略文件的 `organizationId`；
   索引＝**follow 折叠**的工作区登记观察（`lastWorkspaceFold`）。三者缺席时各给自己的"未核验"句子，
   "折叠没读到"不得显示成"0 个工作区"。
4. **D4 索引不扫描**：索引页只读折叠观察；源码级断言该模块与 wiring 切片里不出现 `workspaceFiles`/`readdir`/`scandir`，
   且 wiring 的 fold 就是那条 `workspace/follow` 读取（D-090/US-219）。
5. **D5 面板放在"设置（只读）"独立页**：11 张卡零控件（面板级断言：该面板切片里没有 button/input/select）；
   与 026 的后置只读族并排但不混同（后者是事实呈现，这里是设置族的状态级补漏）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 每页给一个禁用（disabled）开关以示"将来能用" | 否决：禁用控件就是"看起来能改"；US-210 要求入口缺位而非置灰。 |
| 索引页扫一次目录树给出真实数量 | 否决：正是 D-090/US-219 禁止的全量扫描。 |
| "未接线"写成"暂不可用/已关闭" | 否决：把没有来源写成产品状态（026 的同类反例）。 |
| 把 11 页并进 026 的后置只读面板 | 否决：设置族与事实族的来源与后续治理路径不同，混同会让 026 的"零控件"断言失去边界。 |

## 后果

- 三条验收各有机器断言：逐页来源标注（11/11）、每页/整面板零写入口、索引页零扫描词汇 + fold 同源。
- 已知未闭：8 页没有真实 provider（按工单"治理写面保持 §7 后置"）；真机端到端未跑。
