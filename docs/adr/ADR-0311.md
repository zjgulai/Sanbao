# ADR-0311 · 弹层族第三刀：工作区文件上下文菜单（真实 T03 候选）

- 状态：accepted（2026-10-11）
- 日期：2026-10-11
- 决策者：用户（lute：同意 Loop-Q R13）＋ agent（实施与对抗评审）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-11-files-menu.md)
- 相关：[ADR-0309](ADR-0309.md)（同族）、T03 票据（workspace/files routes）

## 背景

`QDR.O02.files.menu.open`（输入区「工作区文件」菜单：搜索当前项目文件的输入框 + 文件行；按 Left 返回上下文根；未选文件；**未证明**搜索过滤语义）：desktop 的上下文菜单此前对所有项出「不可用」通知。真实数据源已存在——`/.sage/workspace/files/candidates`（T03 链，projection-read admitted，走查 grants 在列）。装上它即可使 O02 组 6/6 叶全部 implementing（伞行随之可核销）。

## 决策

1. **D1 真实候选消费**：新模块 `desktop/files.ts` 调真实 route（POST `{workspaceRoot, path:''}`）；工作区根来自会话上下文的默认链接（`session.context.workspaceRoot`）；无会话 → 保留旧「不可用」诚实通知（packaged live check 与既有 spec 恰在该状态运行，两仪器不变）。
2. **D2 子菜单形态**：菜单项「工作区文件」展开子菜单——搜索输入（获焦）+ 候选行（观察三行同名）；**本地过滤为本人实现之推断**（观察行未验证任何过滤行为——服务端或本地皆未证）；`truncated` 如实披露「仅显示前 N 项」；loading 状态具名。
3. **D3 选择与退出**：行点击 → 具名拒绝「选择文件作为上下文尚未接通；未附加任何内容，草稿已保留。」（观察未证选择行为——不装假附加）；空查询下 Left → 返回上下文根（焦点回「工作区文件」项）；根层再按 Left → 关闭并回输入入口（观察 exit 后半段「AX 恢复到输入入口」）；输入框内非空查询的 Left 保留原生光标语义（stopPropagation，不得劫持）；Escape 全程关闭；子菜单打开时根级上下键循环静默。
4. **D4 路由拒绝透传**：`refused` → 「文件候选未接通（{code}）」，零行（不伪造）；请求纪元守卫保证慢的旧请求不得覆盖新请求结果；一切关闭路径（Escape/再点/外击/blur）走同一重置，重开必新鲜。
5. **D5 迁移**：`O02.files.menu.open` 迁 implementing，O02 伞行（组内 6/6）随之核销（第二批伞行迁移并入本批）。summary 生成器重算。
6. **D6 对抗评审与几何仪器（本批内）**：提交前经 4 透镜对抗评审（18 原始发现 → 去重 8 → 逐条反驳验证）；确认缺陷全部修复：Left 劫持非空查询光标（high）、慢请求覆盖新结果（high）、外击/blur 不重置子菜单（medium）、exit 后半段未复刻（medium）、注释把推断表述为事实（low）、role=menu 直接子节点含 input（low，已按 combobox 邻接结构分离）。**CSS 几何缺陷由完备性批评以真实浏览器探针实证并修复**：根菜单 `overflow:auto` 裁剪绝对定位 flyout（修复前 elementFromPoint 三行全 miss，修复后全命中）；flyout 继承基类 `bottom:100%` 且未清（修复前 143px 塌缩至 10px，修复后 143px）——两对红/绿均在 Chrome 真引擎测得。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 无会话时也装子菜单 | 否决：无 workspaceRoot 即无查询键——保留旧诚实通知，且两处既有仪器（live check/spec）在该状态断言旧行为。 |
| 声称服务端过滤 | 否决：观察未证明；本地过滤 + 注释 + blocker。 |
| 行点击静默或假附加 | 否决：具名拒绝是唯一诚实回应。 |
| 页面级挂载候选列表 | 否决：行断言是菜单内展开。 |

## 后果

- O02 组 6/6 叶闭环；上下文菜单不再有「工作区文件」占位项（有会话时）。
- 选择/附加的真实路径、过滤语义、file bytes 显示登记 blocker。
