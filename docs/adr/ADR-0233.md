# ADR-0233 · 冷历史与运行历史：纯历史接点、逐运行详情与当时实际模型

- 状态：accepted（2026-10-03）
- 日期：2026-10-03
- 决策者：agent（取证并实施；FW-021、US-024 与 US-097~101 已定方向）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-03-cold-history-runs-and-detail.md)
- 相关：[ADR-0212](ADR-0212.md)（005 会话通道）、[ADR-0213](ADR-0213.md)（006 停止/待继续）、[ADR-0230](ADR-0230.md)（004 会话续读）

## 背景

工单 009（FW-021/US-024、US-097~101）：在**不激活、不重发、不触发运行**的前提下回看既有
会话——列出运行（含进行中与已结束）、按需展开某次运行详情，并**如实标注该次运行当时实际
使用的模型**（US-099：与当前选择分开显示，不得用今日默认冒充历史）。基座已具备：
`session/page({address?,throughSeq,beforeSeq?,maxMessages?})→{records,hasMore}`（records 为
`{type:'event',event:{seq,type,data}}`）；`request/header` 事件的 `data.header.config.{provider,
model}` 即该运行**当时**请求头快照；`turn/start`/`turn/end` 组出运行边界（未闭合 end=进行中）。
US-024 明令历史接点**不得**激活会话、重发消息或重跑上传；US-100：读不到时保持缺失、不得
呈现空白成功。

## 决策

1. **D1 纯历史接点（US-024）**：`main/session-history.ts` 的 `list` **只调 `session/page`**
   （`{sessionId,throughSeq:-1,maxMessages:400[,beforeSeq]}`），test 断言调用表恰为该一种
   请求——不 `create`、不 `prompt`、不重发上传；`no-session` 绝不建会话，直接
   `{state:'missing'}`。
2. **D2 运行列表倒序＋游标分页（US-097）**：`runsOfRecords` 由 turn/start|end 组运行、
   未闭合 endSeq=null（进行中）；`list` newest-first、`MAX_RUNS=50`，返回
   `{state:'read',runs,hasMore,nextBeforeSeq}`（hasMore 时携带下一 `beforeSeq` 游标）；
   渲染面「加载更早」按需再调 list（同一种 page 读）。
3. **D3 逐运行详情＋窗口过滤（US-098）**：`detail` 做**一次有界页**（maxMessages 有界）后
   按 `seq ≥ runSeq` 且 `< 下一运行起点` 过滤，绝不把整段会话透传；输出预览
   `outputPreview≤2000`（超限携 `outputTruncated:true`）、用户输入 `userTexts` ≤4 条×300
   字符；运行不在场/页读失败 → `{state:'missing',runSeq,code}`。
4. **D4 当时实际模型（US-099）**：模型取自该运行 `request/header` 的
   `data.header.config.{provider,model}` 快照（provider/model 拼接显示）；**取不到时为 null，
   不得回退到本事项当前默认**；渲染句「当时实际模型（本运行请求头快照）：…——与本事项当前
   选择分开显示（当前默认见模型卡）。」把两侧绑定分开呈现。
5. **D5 不可读保持缺失（US-100）**：`missing` 语义贯穿通道与渲染——渲染句「…保持缺失
   （不显示空白成功）。」，空态（从未读取）与缺失（读取失败）分开；`status(matterRef)` 供
   槽呈现（空 runs=从未读取）。
6. **D6 首版不做**：两次运行并排对照（US-101 后置）、跨会话历史、历史搜索、导出、重跑入口；
   不做自动轮询刷新（历史区只在显式动作时读取）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 用当前模型配置渲染历史模型 | 否决：US-099 点名"当时实际"，历史快照与该次请求头绑定。 |
| list 一次拉全量会话再本地切运行 | 否决：无界读与 US-024 有界纪律冲突；分页游标（hasMore/nextBeforeSeq）才可续读。 |
| detail 透传整段会话记录 | 否决：按 runSeq 窗口过滤是 US-098 的"逐运行"语义；原始载荷不跨界。 |
| 读取失败显示空白/空列表 | 否决：US-100；缺失必须自报，空态另义（从未读取）。 |
| 打开历史时自动激活会话续读 | 否决：US-024——纯历史接点零副作用。 |

## 后果

- 验收三条机器断言：①调用表仅为 `session/page`（不激活/不重发/不重跑上传）；②模型取
  运行请求头快照且 null 保留（不借今日默认）；③missing 语义贯穿（失败不显示空白成功）。
- 端口名册 deliberate +2（sessionHistoryList/sessionHistoryDetail）；
  `SessionRunListOutcome/SessionRunDetailOutcome/SessionHistoryStatus` 进 contracts。
- §1.6：历史区文案、倒序行、当时模型徽章、展开详情、missing/空态句以真实页面两宽实测；
  DOM 读数逐项核。
- 已知未闭：两次运行对照（US-101）后置；真机 Electron 未跑；跨会话历史后置。
