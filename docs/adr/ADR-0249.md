# ADR-0249 · UI 接线第二批：main-owned active context 与 session protected-effect admission

- 状态：accepted（2026-10-03）
- 日期：2026-10-03
- 决策者：agent（用户确认从第一批断点继续）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-03-active-context-and-session-admission-batch-2.md)
- 相关：[ADR-0248](ADR-0248.md)、[ADR-0174](ADR-0174.md)、[ADR-0184](ADR-0184.md)、[Sanbao → Sage UI 一致性合同](../specs/2026-09-27-sanbao-to-sage-ui-consistency-contract.md)

## 背景

第一批已把 57-route authority 与 exact nested matter wire 固定为可门禁事实，但 session send/stop/resume 仍直接调用 raw provider，当前事项又由 draft recency 与 renderer body 隐式决定。现有同步 `runCommand` 不能表达异步 effect 的 durable-before-dispatch、request-scoped freshness 与 dispatch 后 outcome-unknown/no-retry 边界。

## 决策

1. 建立 Electron main 独占、generation-bound 的 active matter context kernel；不从 renderer、Host 或最新 draft 推断，不新增 activation route，默认 inactive。
2. 建立独立异步 `admitProtectedEffect`，固定 caller→context→candidate→identity/policy→target→compatibility→Registry→preflight→persistence→dispatch 顺序；dispatch 后未知永不自动重试。
3. `/.sage/session/send`、`stop`、`resume` 先进入 admission，renderer 的 workspaceRoot 不成为 authority；缺真实 authority provider 时明确 unavailable，raw session provider 调用数必须为 0。
4. route truth 更新为 2 条 `runCommand`、3 条 protected admission、32 条 remaining bypass；gate 同时核对 source fact，不把 unavailable 冒充产品功能可用。
5. 本批 UI 只加固 Sage-owned shell 的 ARIA、键盘焦点、CSP、品牌隔离与 wire→DOM 同源测试；不选择新 UI 栈、不吸收 Qoder 018/019、不声明视觉迁移完成。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 继续使用最新 converted draft | 否决：顺序事实不是 active context authority。 |
| 信任 renderer 的 matter/workspace 字段 | 否决：UI 只能提交 candidate，不能提交可信上下文或 target。 |
| 复用同步 `runCommand` | 否决：无法保持异步 effect 的顺序、持久化与 outcome-unknown 边界。 |
| admission 后直接调用旧 provider | 否决：真实 Identity/Policy、Compatibility、Registry、preflight 与 persistence 仍缺。 |
| 复制 Qoder 018/019 dirty | 否决：独立回放绿色不消除其 authority、credential 与假 apply 风险。 |

## 后果

- 三条 session core route 从 direct-provider bypass 收口为 secure-but-unavailable；真实功能恢复必须另票补齐 active selection owner 和全部 authority provider。
- protected bypass 从 35 降为 32；read policy、partial CB1 与其余 session-family effect 保持显式未完成。
- active context 在 Frame contamination 时失效，公开 projection 不泄露 actor、session 或绝对路径。
- UI 合同更严但视觉/IA 未迁移，UI-01 仍是后续硬前置。
