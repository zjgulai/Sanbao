# ADR-0340 · 模型可用面：实时目录、默认模型切换与 composer 选择器

- 状态：accepted（2026-10-13）
- 日期：2026-10-13
- 决策者：用户（2026-10-13「下一批执行哪个方向」裁决 D 模型可用面）＋ agent（装配设计）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-13-model-availability-surface.md)；重发布配套记录：[第二次跨代重发](../notes/implemented/architecture/2026-10-13-second-cross-generation-republish.md)
- 相关：[ADR-0339](ADR-0339.md)（保存路由；本批闭合其「可用」缺口）、[ADR-0326](ADR-0326.md)（重发布程序）、[ADR-0278](ADR-0278.md)/[ADR-0284](ADR-0284.md)（sealed 模型面精确钉）

## 背景

ADR-0339 建成保存/列表/测试闭环后，自定义路由无途经被会话使用：会话固定跑 `agent-default-model` 的出厂默认。基座接点已核验：`sessionController.modelCatalog`（实时目录，自定义路由自动入围）、`agentDefaultModel.saveSelection`（公开写，但**盲写无目录校验**——基座明文「可用性诊断归消费者」）。Qoder 的 composer 模型选择器为 **static-only 观测**（`data-chat-model-selector-menu`，任何 capture 从未展开）——菜单解剖须诚实自建。

## 决策

1. **D1 读面**：桥 +`modelConfig/catalog` 直读 `sessionController.modelCatalog`（分组/失败条/默认选择；防御映射）。目录天然含已保存自定义路由（llm-pi-ai 注册 → `listProviders/listModels`）。
2. **D2 写面**：桥 +`modelConfig/default`：**先对活目录校验** provider/model/effort（未知具名拒 `bridge-model-selection-unknown` / `-effort-unknown`）再 `saveSelection`；config-editor 的 home-patch 覆盖拒绝具名 `bridge-model-default-overridden`。默认值经 patchPath 落 settings 文档；与基础值相同的写入被编辑器规范化剔除（正确语义）。
3. **D3 路由**：`/.sage/model-config` 动作扩至六枚（catalog/set-default 键集精确、界长）；矩阵 operations 同步；保护级别/计数不变（同路由）。
4. **D4 渲染面**：composer 模型选择器——**懒加载**（开菜单才读目录；composer 每页挂载，不在挂载打请求）；分组 + 当前 ✓ + failures 条 + 「切换影响下一次请求；已有回合的会话保持其首次使用的模型」（与基座 `selectionFor` 的 logged-header 语义一致）；拒绝就地具名；旧「模型未知」占位 chip 退场。static-only 观测下的诚实边界：菜单解剖（组头/选中/失败条）自建，不冒充观测。
5. **D5 组件集纪律**：settings 栈激活改变活动组件集 ⇒ sealed 三件必须重发布（本批执行 ADR-0326 程序第二次，见配套记录）；发送在重发布前全域被 compatibility 拒——该程序即本批的承重配套。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 直接 `saveSelection` 不校验 | 否决：基座盲写+明文归责消费者；不可用默认会写进文档并污染下一次请求。 |
| 挂载即读目录 | 否决：composer 每页挂载=每页一次宿主往返；懒加载+开菜单刷新等价且安静。 |
| 会话级改选（`selectModel`） | 不做（019 域）：公开请求必写默认（ADR-0248 核验），无受支持会话级接点。 |
| 菜单解剖复刻观测 | 不可能：观测为 static-only；按实建+注明边界。 |

## 后果

- 目录/切换/选择器闭环；默认切换持久（`agent-default-model` 行）；发送回归验证（重发布后）。
- **边界（新票候选）**：自定义模型可选为默认，但其模型面不在 sealed prompt 语义内 → 发送被 compatibility 拒。让自定义模型真实可发需要受治理的运行时声明路径或发布面扩展。
- 后续：019 事项级改选；018 未闭项；「自定义模型可发」治理票。
