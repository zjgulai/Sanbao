# ADR-0187 · WT-02C.2E-PMAP/E.0 PMAP 静态层 runtime inventory producers：五面观测矩阵 + 合法空集/缺输入二分 + 候选证据（非 descriptor）

- 状态：accepted（2026-10-02）
- 日期：2026-10-02
- 决策者：用户（lute）
- 决策记录：[WT-02C.2E-PMAP/E.0 PMAP 合同与静态层 producers](../notes/implemented/security/2026-10-02-wt02c2e-pmap-runtime-inventory.md)
- 相关：[ADR-0165](ADR-0165.md)、[ADR-0166](ADR-0166.md)、[ADR-0168](ADR-0168.md)

## 背景

C 链 `RuntimeDescriptorBodyV2` 的 provider / model / agent / preset 四面（PMAP）此前无受信 producer：C2B（ADR-0168）只交付 boot 层 `HostLiveInventoryProjectionV1` 并明确不构造完整 `RuntimeInventoryEvidenceV2`；PMAP 面若用 placeholder、自报值或登录期 boot 观测补齐，即违反 ADR-0165（复合证据）与 ADR-0166（stable/full 分层）。C2E 汇合（`RuntimeDescriptorV2` 组装 + 与 C2B 合并，C2E.2）依赖四个组件的五面证据先存在且来源诚实。

## 决策

1. **D1 五面观测矩阵合同（E.0）+ 静态层语义域**：逐组件钉死 identity / version / artifactDigest / contractDigest / behaviorConfigurationDigest 的覆盖主体、canonical 规则与来源 provenance（带 dsh 包源码锚点：`dsh-agent-presets` / `dsh-settings-file` / `dsh-agent-default-model` / `dsh-agent`）；digest 统一 `urn:sage:pmap-<面>:sha256:*`；evidence 显式标注 `observationScope: 'materialized-static'`——运行态 effective 配置（env 层合并、实际 mount enablement、default preset 标记）不在静态层语义域，需 Host protocol 扩展另票。
2. **D2 静态层 producers 实现**（`src/main/runtime-inventory-pmap.ts`）：main-owned、只读；注入 `{ harnessHome, profileDir, fs 三端口, now }`（零模块级 I/O）；preset 双 root 按序扫描 + first-root-wins per id（dsh discovery 语义）；settings 只读 `agent-default-model` 命名空间白名单三字段（provider / model / reasoningEffort），绝不整档透传；provider 由 route 解析 `@deepseek-ai/dsh-llm-<route>` 包；所有包树 digest 强制 realpath containment（逃逸 → broken），symlink 不展开（安装时拓扑归 C2A）；证据形状 `sage.pmap-component-evidence.v1` candidate（deep freeze、路径零机器泄漏、每行 evidenceDigest），**不是** `RuntimeComponentDescriptorV2`。
3. **D3 空态语义二分与零依赖纪律**：合法空集（settings 文档缺失、命名空间缺失、user preset root 缺失）→ 显式 `absent`；缺输入（shipped root 缺失、composition 不可读、包不可解析/逃逸）→ `broken` + 稳定原因码（C2E.2 汇合映射 composition unavailable）。YAML settings 在 `deps: {}` 纪律下不解析，字段级选择如实 absent（reason `settings-not-statically-parsed`），解析通道另票；汇合、capabilities、Registry、Matrix、UI、任何写入均不在本票。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 本票解析 YAML settings（引依赖或手写解析器） | 否决；零运行时依赖是包纪律，手写 YAML 是长期 footgun；以稳定 reason 如实 absent。 |
| 本票做运行态 effective 观测 | 否决；需 Host protocol 扩展（独立票），静态层猜测 effective 值违反「不是权威不冒充」。 |
| producers 直接产出 `RuntimeComponentDescriptorV2` | 否决；组装与 C2B 合并属 C2E.2 composition，本票只输出 candidate evidence。 |
| 展开 symlink / 重新 attest 安装拓扑 | 否决；安装时 attestation 归 C2A，静态层重复 attest 制造第二个家。 |
| settings 整档进 evidence 或落盘 sample「让 provider observed」 | 否决；白名单字段纪律 + 只读纪律，不伪造观测。 |

## 后果

- **读数（2026-10-02）**：spec 单跑 9/9；全量 56 files / 551 tests 全 PASS；typecheck 0；tsc 构建通过；smoke PASS；gate 25/25；变异三组（artifact digest 名空间 / first-root-wins / absent-broken 二分）均红。
- **真实 root 读数**（active generation `ae615ae9` 实读，零写入）：provider / model absent（`settings-document-absent`）；agent observed（`@deepseek-ai/dsh-agent@0.1.5-rc.2`）；4 system presets observed；user preset 零行（合法空集）。
- **边界**：不写 harness / profile / settings；不读 `.credentials.yaml`；零持久化、零 renderer / Host 面变化。
- **遗留**：C2E.2 汇合（PMAP + C2B）为下一依赖；运行态 effective 观测（含 default preset 运行时求值）需 Host protocol 扩展；YAML settings 字段级解析通道待裁决。
