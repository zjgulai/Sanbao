# ADR-0244 · 产物独立预览窗口：同版本引用、显式打开与「关窗不动运行」

- 状态：accepted（2026-10-03）
- 日期：2026-10-03
- 决策者：agent（取证并实施；FW-037、US-205 已定方向）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-03-artifact-window.md)
- 相关：[ADR-0178](ADR-0178.md)（015 预览容器合同）、[ADR-0230](ADR-0230.md)（033 全屏与版本冻结）、[ADR-0198](ADR-0198.md)（host 消费登记——本票零新增）

## 背景

工单 044（FW-037，US-205）：**产物独立预览窗口仅在用户显式动作下打开，与侧面容器共用同一
版本引用；迟到结果不覆盖当前选择，关闭不取消运行**。验收：①显式动作前不创建窗口（有断言）；
②窗口与侧面板同时存在时**不出现两份权威版本值**；同版本重开不重跑生成。原产品证据：P12。
既有面（015/033）：`artifact-preview.ts` 状态机＝单一侧面板容器（非持久 session、仅内存
`sage-preview://`、generation 守卫、版本冻结 open/retry、033 全屏＝同文档布局切换）。

## 决策

1. **D1 独立窗口=同合同的第二表面，显式动作才创建**：`createWindowContainer`（注入；生产＝
   `createPreviewWindowContainer`——真实非特权 BrowserWindow，同 partition/无 preload/navigation
   与 window.open 拒绝）；`openWindow()` 仅在 `state==='ready'` 且存在已备文稿时可调用；卡片
   渲染、boot、面板 open 一律不触窗口（工厂计数=0 的断言）。
2. **D2 同一版本引用=同一份已备文稿**（验收 ②的机器面）：store 保存 `lastLoad`（选中时准备的
   唯一文稿引用）；`openWindow` **零桥调用、零重生成**，把**同一引用**交给窗口容器——面板与
   窗口即使并存也只有一个版本值来源；spec 断言 `windowLoads[0] === panelLoads[0]`（同引用）。
3. **D3 迟到结果丢弃**：窗口加载带 generation 守卫——加载期间发生新选择（generation 改变或
   状态离开 ready）→**销毁该窗口**并拒 `artifact-superseded`，绝不让旧版本成为第二权威。
4. **D4 关窗不动运行**：`closeWindow` 只销毁窗口容器并把 `window:false`；面板容器不动、产物
   记录不变；本模块桥面只读（workspaceFiles/*），调用表里**不存在** session/cancel 等写路径
   ——「关闭不取消运行」是结构事实；`close()`（关预览）同时释放两个表面。
5. **D5 首版不做**：多窗口标签管理、窗口内编辑与回写、窗口级权限策略（工单边界）；
   真实 Electron 窗口的真机验证后置（工厂注入、替身全测）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 窗口独立重读版本/另开生成 | 否决：验收②「不出现两份权威版本值」；同一引用是唯一布防点。 |
| 卡片渲染即建窗（更快） | 否决：验收①显式动作前不创建。 |
| 关窗连带取消运行 | 否决：US-205 明令关闭不取消运行；且本模块无任何取消路径。 |
| 面板与窗口互斥（移窗不并存） | 否决：验收②以「同时存在」为条件；并存+单权威已足够。 |
| 复用 `served.clear()` 的一刀清 | 否决：会把另一表面的文档一起清掉（面板/窗口各自只回收自己的令牌）。 |

## 后果

- 验收两条机器断言：①显式动作前不创建窗口（工厂计数 0；面板 open 请求不含窗口动作；未点击
  零请求）；②窗口与侧面板并存时一份权威版本值（同引用加载、零桥调用、迟到销毁）。
- 面/装配：`ArtifactWindowOutcome`＋`ArtifactPreviewState.ready.window`；ServiceProviders
  +`artifactWindowOpen/Close`；路由复用 `/.sage/artifacts/window`（`{action:'open'|'close'}`）；
  名册 +2；033 装配守护 +1。
- §1.6：真产物两宽（1440/660）亲看——就绪态「已在右侧容器打开：page.html（v3）。」＋
  [全屏查看（离线）][在独立窗口打开（同一版本）][关闭预览]；window:true 态按钮变[关闭独立窗口]
  且句尾带「（独立窗口已打开：同一文档、同一版本引用；关闭独立窗口不改产物记录）」；flow 页
  点击后 DOM 恰一条 `POST {"path":"/.sage/artifacts/window","body":{"action":"open"}}`＋注记
  「已在独立窗口打开（同一版本引用；未重读、未重跑生成）。」。
- 已知未闭：真实 Electron 窗口真机未跑（本机不启动应用；工厂注入/替身全测）；窗口内滚动/缩放
  等窗口级交互后置。
