# ADR-0145 · 全站三主题身份与语义颜色单一源

- 状态：accepted（2026-09-20）；实施和实机验收未完成
- 决策者：用户（lute）
- 取代：ADR-0132 D2 的双色道限制；ADR-0132 D5 的标题紧缩签名由已批准的[规格 §0.2](../specs/2026-09-20-qoder-visual-language.md#02-统一排版标准)更新（保留用户字体选择与 Inter 回退，排版实施归另一会话，本次不改排版代码）；ADR-0144 D1 的重复色值源与不合格强调色回采规则、D2 的亮色强制压暗规则、D3 的仅主题包与分批交付范围。
- 保留：ADR-0008 基座只读、ADR-0019 官方 UI 锚禁钉哈希、264px 左栏水平轴、品牌名称与资产身份。
- 规格：[全站三主题与统一排版](../specs/2026-09-20-qoder-visual-language.md#0-已确认的扩展范围)
- 决策记录：[Note](../notes/features/contract/2026-09-20-global-theme-triad.md)

## 背景

用户要求所有页面与子页面只保留亮色、暗色、暖粉白，并明确批准继续实施。原仅换默认色的方案无法消除旧存储回灌、局部色板和独立文档断链，亦不能保证第三主题的持久化身份。

## 决策

**D1 三主题是产品身份，不是三个预设。** 身份固定为 `light | dark | warm-pink`。官方模式与 CSS color-scheme 只是二态适配，暖粉白投影为 light，不从 light 反推为普通亮色。身份通过 Host 的 `sanbao-appearance` 设置命名空间保存与广播；客户端仅缓存已接受的状态与迁移候选，不形成另一个权威来源。

**D2 颜色只有一个可编辑源。** 三套只读语义色板放在 `shared/client/sanbao-tokens.ts`，主题包副本通过现有共享生成器同步。`--sanbao-*` 为源，官方 `--dsw-*` 与独立文档 CSS 单向生成；材质别名不得反向闭环。页面不得另存粉色、暗色或亮色字面色板。所有必要状态颜色、代码与图表角色也必须登记，不用品牌色掩盖错误/警告/成功的区别。

**D3 字体偏好与颜色身份独立。** 保留合法的 `uiFont/codeFont/uiFontSize/codeFontSize` 与减弱动态等非颜色偏好；v1 即使颜色损坏也不能导致合法字体丢失。新版存在后不再消费旧颜色。配色重置仅改变 themeId，不重置字体、不清空 localStorage。

**D4 参考色按用途验证。** 亮暗结构面参考归档 Qoder 截图，文字与状态色按可读性设计并标清来源。参考灰绿不能被当作所有用途的通用合格颜色；强调文字、按钮填色与按钮前景分开。小字至少4.5:1，主体正文目标7:1，必要控件图形与焦点至少3:1；不以回采直到合格或放宽阈值制造通过。亮色和暖粉白采用各自明晰的浅色层次，不套用暗色压暗公式。

**D5 一次性交付所有可达面。** 全部设置子页、弹层、插件页、独立管理页、自有 iframe/原生窗口按唯一叶 ID 建立三主题状态矩阵。源码注册、安装组合和实际注册清单交叉核验分母；缺失与不可访问计 blocked，不计 pass，不通过删功能缩小分母。组件浏览器测试与纯 token 解析仅是局部证据，不能替代真实运行时逐页验收。

**D6 不越过内容和环境边界。** 系统控件遵循平台亮暗能力，用户图片/PDF/HTML和第三方网页不重染，iframe sandbox 不放宽。不可修改 pin/vendor 源码；独立窗口需要产物适配时先验证可审计重放与复制产物，再协调装机。开发使用隔离工作树，未经明确授权不提交、推送、修改实际 profile 或重启桌面。

## 备选方案

| 未采用 | 原因 |
| --- | --- |
| 仅替换默认颜色 | 已保存旧颜色仍优先生效 |
| 暖粉白作为亮色下的新预设 | 官方亮态回灌会丢失第三主题身份，旧预设仍可混色 |
| 每页独立覆盖颜色 | 色值多源，无法保证全局切换一致 |
| 整屏滤镜统一色调 | 污染用户内容、状态和品牌图像 |
| 首页先交付，子页面后补 | 与用户明确的一次性全站要求冲突 |

## 后果

主题核心、同文档兼容面和独立文档适配可分任务开发，但验收必须汇总所有叶面。旧任意配色编辑入口退役，非颜色偏好继续可调；系统原生内容不承诺粉白像素。任何未接入或未测页面都阻止完整交付声明。
