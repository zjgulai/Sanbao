# ADR-0195 · 帧名称表单源化与冻结面扩展 + WT-02C.2E.2 遗留合并清点

- 状态：accepted（2026-10-02）
- 日期：2026-10-02
- 决策者：用户（lute）+ agent（遗留合并执行与实测）
- 决策记录：[WT-02C.2E.2 遗留合并清点 Note](../notes/implemented/architecture/2026-10-02-wt02c2e2-leftovers-consolidation.md)
- 相关：[ADR-0187](ADR-0187.md)（E.0）、[ADR-0191](ADR-0191.md)（E.2）、[ADR-0192](ADR-0192.md)（帧常量冻结起源）、[ADR-0194](ADR-0194.md)（PMAP.1 换装适配）、[E.2 设计](../superpowers/specs/2026-10-02-wt02c2e2-runtime-inventory-composition-design.md)

## 背景

会话 7365c577（WT-02C.2E.2）收口时登记 ①–⑧ 遗留，其中 ③ 指出「policy 文档字段级语义与 `runtime.ts`/`protocol.ts` 常量同步靠 golden 与评审守」。实测证实其风险：E.2 provider 的 `FRAME_KINDS` 是 protocol.ts 的手工副本，却被发布进 stable `protocolContractDigest`（matrix 规则键的一部分）——协议侧改名/增减帧 kind 时 golden 不跟动，仅靠评审。同形态的还有 `HOST_VERSION = '4.0.0'`（协议版本的手工派生，注释要求"协议变更必须同步它"）。其余遗留多数阻塞于外部依赖（Host protocol 扩展、C2C 真实 provider、C2D.2A），需明确分诊而非悬空。

## 决策

1. **D1 帧名称表单源化**：`SHELL_REQUEST_FRAME_KINDS`/`SHELL_RESPONSE_FRAME_KINDS` 由 `protocol.ts` 导出，成为唯一事实源；E.2 provider 导入构造 policy 文档（逐字节等价由既有 golden 证明）。
2. **D2 冻结面扩展**：`sage-shell-pin` 的 `FROZEN_FRAMING_CONSTANTS` 自 6 行增至 8 行（新增两枚名称表，空白归一比较）；改值/改名/删除导出均判红；selftest 增判红与不误报用例。
3. **D3 `HOST_VERSION` 派生**：`'4.0.0'` 改为 `` `${SHELL_HOST_PROTOCOL_VERSION}.0.0` ``——协议升级不再依赖人工同步该常量。
4. **D4 遗留合并清点**：③ 本批执行；⑤（capability canonical 与 C2D.1 重叠）核查为**无重叠**并关闭（内核 canonicalize registry 治理 v1 文档，E.2 是 compatibility V2 投影换形，无收敛对象）；④ 被 ADR-0194 覆盖；①（default preset 运行时判定）阻塞于 Host protocol 扩展票；②（host/harness 分包 artifact 粒度）待用户语义裁决；⑥（health/liveness 增强）阻塞于 C2C.4/.5 真实 provider；⑦（`runtimeInventory` 消费者）移交 D.2 接线车道；⑧（registrySnapshot 变更检测）阻塞于 C2D.2A。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 保留副本 + 测试对照 protocol.ts | 否决；单源导入优于双写对照，测试只能覆盖已写下的变体。 |
| TS 类型层断言替代门禁冻结 | 否决；类型对运行时表无约束力，表与 union 仍可各自漂移。 |
| launch/overlay policy 语义串一并单源化 | 否决；语义描述非常量引用，强行导出污染运行时词汇；维持 golden + 评审。 |
| ①（Host protocol 扩展）并入本批 | 否决；新消息面 + 版本升级 + matrix 重发属独立决策票。 |

## 后果

- **读数**：扩冻表先红（`SHELL_REQUEST_FRAME_KINDS = undefined`）→ 单源化后门禁 **25/25**、selftest **24/24**；provider spec **12/12**（13 golden 字面量未动 = 零行为漂移的证明）；全量 **613 pass + 1 skip**；typecheck 0 错。
- **语义面**：现行 `protocolContractDigest` 与 matrix 键不变；未来任何帧名称/数值变更将同时触发门禁红与（若语义变更）goldens 红——不再依赖评审记忆。
- **遗留去向**：① 建议独立立票（Host protocol 扩展：默认 preset 标记 + enablement 求值）；② 待裁决；⑥⑧ 随 C2C/C2D 真实 provider 重审；⑦ 归 D.2 车道。
