# ADR-0213 · 停止＝暂停＋取消＋收回：暂停期输入不进 inbox，竞态结果如实分账

- 状态：accepted（2026-10-02）
- 日期：2026-10-02
- 决策者：agent（取证并实施；"暂停在 Sage 侧"与"竞态分账"是取舍）
- 决策记录：[Note](../notes/implemented/architecture/2026-10-02-stop-and-pending-inputs.md)
- 相关：[ADR-0212](ADR-0212.md)（会话通道）、[ADR-0209](ADR-0209.md)（设备密封）、[ADR-0211](ADR-0211.md)（三态）

## 背景

工单 006 的三条验收：**停止后无后续输入被自动执行**、**切页/重连/重开应用不自动续跑**、**编辑待继续项不改写已消费输入**；
备注点名要实测"cancel keepInbox 与 kick 续跑竞态"。取证基座：`cancel` 的注解是 "Cancel one active Agent turn **without dropping its pending inbox**"——
也就是说取消后队列里的条目可能被后续一轮消费（"kick 续跑"），这正是竞态本体；`updateQueue` 的 `{kind:'remove'}` 是唯一能移除"仍待处理队列条目"的手段；
权威队列快照在 `control` 流（每代先 baseline，含 `queues[sessionId]` 与 `rpcId`）。

## 决策

1. **D1 暂停在 Sage 侧、发送不过桥**：`stop` 先把 matter 置为 paused；暂停期间 `send` 只把文本存成 Sage 自己的待继续项（`state:'pending'`），
   **不调用 `prompt`**（断言：桥调用计数为 0）。"输入不进会自动唤醒的 inbox"因此是结构事实。
2. **D2 停止＝取消＋收回**：paused 后调 `session/cancel`；再用 `control` 读权威队列快照，对**仍属我方已提交项**的 occurrence 调 `updateQueue{remove}`，
   并把这些项 `returnToPending('drained-at-stop')`——队列里不留可被 kick 消费的孤儿。
3. **D3 竞态如实分账**：快照里已经消失的已提交项 = 被那一轮消费了 → 冻结为 `consumed('consumed-by-race')`，
   **不回到可重发队列**（备注要求的核验项：测试注入"cancel 后 B 已被消费、A 仍在队列"，断言 drained=[A]、consumed=[B]）。
   拿不到队列快照时如实报 `stopped + code`（drained 为空），不假装已收回。
4. **D4 继续是唯一的派发路径且按序**：`resume` 先解除暂停，再按 pending 列表顺序逐条 `prompt` 并转 `submitted`；
   没有会话绑定但有 pending 时，这次显式继续才创建会话（读路径仍不创建，沿 ADR-0212）。
5. **D5 冻结已接受项**：`edit/remove` 只对 `pending` 生效；`submitted/consumed` 一律 `item-frozen`（US-018；
   断言：被拒编辑后文本不变）。待继续记录与草案同族——**同一设备密封**（`createDeviceSealer`，0600 密钥），
   重开只读回状态，不自动续跑（断言：新通道只 read 时零调用）。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 暂停期仍 `prompt` 进队列，等恢复再"放行" | 否决：inbox 条目会被后续轮次消费，"停止后不自动执行"无法守住。 |
| 停止时只 cancel，不收回队列 | 否决：正是备注点名的 kick 竞态；队列里留下可被消费的孤儿。 |
| 把被竞态消费的项也标回 pending | 否决：它会二次派发已执行的内容（US-018 的反面）。 |
| 恢复时用新会话重发全部 pending | 否决：新会话会丢历史连续性，且"未执行"与"已执行"必须分账。 |
| 编辑 submitted 项（改写队列内容） | 否决：`updateQueue{edit}` 属队列语义的后续票；本票把已接受项视为冻结。 |

## 后果

- 三条验收各有机器断言：暂停期零 prompt、竞态 drained/consumed 分账、重启零调用、冻结项不可改。
- 待继续记录与草案共用 `createDeviceSealer`（本票顺手把密封抽成单一实现，草案行为不变、其 spec 全绿）。
- 已知未闭：真机端到端未跑；`steer` 语义与队列内编辑（US-025/027）另票；`control` 流按有界窗口读，长订阅不在本票。
