# ADR-0137 · 品牌 token 命名空间改判为 `--sanbao-*`；并记录一次「pivot 后未审计已落盘文档」的自伤

- 状态：accepted（2026-09-19）
- 决策者：用户（lute）+ Sanbao 全维度换皮轮
- 取代：ADR-0132 D4 中的命名空间名（`--wp-*` → `--sanbao-*`）；ADR-0132 D3 中的测试新名（「遵循 WorldPilot 材质契约」→「遵循 Sanbao 材质契约」）
- 相关：ADR-0009（一份事实一个家）、ADR-0122（机读决策账本）、ADR-0132、ADR-0136；总账 P-02（仪器假绿）、P-07（一条事实多个家）

## 背景

ADR-0136 把产品名从 WorldPilot 改为 Sanbao 之后，我回去审计已落盘的六篇 ADR 与两份射程/计划文档，
发现 pivot 之前的产物里有六处仍按「品牌 = WorldPilot」写死。其中两条是**实质自相矛盾**：

1. **`--wp-*` 命名空间**（22 处）。`wp` 即 WorldPilot，而 ADR-0132 D4 让它做品牌色的唯一源，
   token 会编译进出货 CSS bundle。讽刺的是我在 ADR-0132 自己的备选方案表里用**逐字相同的论证**
   否掉了 `--lute-*`：「`--lute-brand` 里装着钛银，与 ADR-0131 D1 在代码层自相矛盾」。
   同一个论证现在判我自己出局。
2. **ADR-0132 D3 把测试名改判为「遵循 WorldPilot 材质契约」**。我改这条测试的原始理由正是它旧名
   「遵循 Codex 视觉基线」的前提是个已退役品牌——照那写法我只是把一个过期品牌名换成另一个。

另有四条是**传染面没跟上**：ADR-0131 的 `## 机器可读决策` 块仍写「射程 16 处」（正文上一轮已改 20）、
仍写「出货产品即 WorldPilot」；`docs/adr/README.md` 的 ADR-0131 索引行仍写改名 WorldPilot 且仍写 16 处；
`.scratch/worldpilot-reskin/` 目录名被六处当作「唯一权威射程表」路径引用。

**其中「16/20 分叉」这一条值得单独记。** 我上一轮把射程从 16 改判为 20 时只改了正文，
没改机器可读块，于是 `decisions.json` 里也是 16——**两边同错，`adr-agent-records` 门禁照样绿**。
该门禁比对的是「账本 vs ADR 源」，它没有能力发现「源自己内部不一致」。
这正是总账 P-02「仪器假绿」的形状，而它是我在这一轮亲手复现的。

## 决策

**D1 品牌 token 命名空间定为 `--sanbao-*` 全拼**，取代 `--wp-*`。
`theme-tokens.mjs` 的 `NAMESPACE` 相应扩为含 `sanbao` 而非 `wp`。
选全拼而非 `--sb-*`：`sb` 是常见缩写、可读性弱；选全拼而非 `--brand-*`：`brand` 与官方
`--dsw-alias-brand-primary` 里的 `brand` 字面重叠，grep 时易混。

**D2 材质测试的新名定为「遵循 Sanbao 材质契约」。**

**D3 被取代的 ADR 不静默改写，用前向标注。** ADR-0131 的机读块保留「出货产品即 WorldPilot」的
历史原文，在其后追加 `〔已被 ADR-0136 D1 取代：…〕`；索引行同样加标注。
理由：账本是 agent 开工前的必读面（ADR-0122 的立账初衷），只改正文头部一行 supersession 指针
**不足以**让读账本的人知道真相；但直接改写历史决定文本会让「当时怎么定的」永久失传。

**D4 改一处事实必须扫它的传染面，且不能只信门禁。** 一条品牌事实至少有四个面：
ADR 正文、`## 机器可读决策` 块、`docs/adr/README.md` 索引行、派生的 `decisions.json`，
外加文档间路径引用。`adr-agent-records` 只保证「账本 == 源」，不保证「源内部一致」。
本 ADR 之后，改 ADR 正文里的**数字或名字**时，必须同一次提交内 grep 该值在
`## 机器可读决策` 与索引行里的出现并一起改。

## 后果

- **正面**：命名空间与产品名重新对齐；六处 pivot 残留清零；P-02 的形状被记录成可操作的四条传染面清单。
- **负面 / 需跟进**：
  1. `vendor/worldpilot.pin` **刻意保留原名**——它 pin 的确实是 WorldPilot 仓库，名字准确，
     且 ADR-0136 已澄清其语义为「视觉语言上游」而非「品牌目标」。
  2. ADR-0131 的**标题**仍是「改名 WorldPilot」，未改。ADR 是不可变记录，靠状态行的取代指针 +
     机读块前向标注 + 索引行标注三层提示。若未来读者仍被误导，说明这三层不够，应改判 ADR 状态字段
     的用法（ADR-0122 已点名「121/121 全部 accepted，状态字段不承载信息」）。
  3. 「改一处事实要扫四个面」目前**没有门禁**，仍是纪律。要真正守住，需要一条新门禁断言
     「ADR 正文与它的 `## 机器可读决策` 块在关键数字/名字上不得互相矛盾」——但这条很难写对，
     因为「关键值」没有通用判据。留作待评估，不在本 ADR 里承诺。
