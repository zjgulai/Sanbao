# ADR-0178 · Sage privileged renderer 帧禁用不变量 production 采纳

- 状态：accepted（2026-09-30）
- 日期：2026-09-30
- 决策者：用户（lute）
- 决策记录：[Note](../notes/implemented/security/2026-09-30-sage-frame-policy.md)
- 相关：[ADR-0174](ADR-0174.md)、[ADR-0176](ADR-0176.md)、[ADR-0177](ADR-0177.md)

## 背景

[ADR-0177](ADR-0177.md) 在 pinned Electron 43.3.0 的 test-only preflight 内证明帧禁用候选不变量成立（revision 40 PASS），但明确 production 采纳必须另票决定：production CSP、导航图、embedding 政策与 UX 影响都要一并考虑。revision 39 的 top-bridge bypass 证明不解决 nested browsing context，Electron IPC sender 事实不能证明 JavaScript caller 是 top document。

用户于本票逐项拍板：采纳不变量为 production 合同；射程为骨架票（防御层先落地，不引入 preload / IPC bridge）；strict CSP 随票下发；未来嵌内容场景定为合同。

## 决策

1. **帧禁用不变量成为 production 合同。** Sage privileged renderer 禁止 nested browsing context：出现任何 child 即污染当前 document generation，直到 clean top cross-document reload；child 移除与 same-document navigation 均不洗白。revision 41 将其落地为 `apps/sage-shell/src/main/frame-policy.ts`（纯状态机）+ `src/main/window.ts`（唯一 privileged 窗口工厂与事件接线）+ `src/main/index.ts`（stdout tripwire）。
2. **privileged 窗口只能经 `createSageWindow` 创建。** 显式 `webviewTag: false`、`nodeIntegrationInSubFrames: false`（不再依赖默认值）；window-open deny 与 `will-navigate` scheme 栅栏保留；非 main 导航与 unowned 顶层导航在 `will-frame-navigate` 被 `preventDefault`。真实读数证明 renderer 发起的顶层导航被就地拒绝（URL 不变）。
3. **strict CSP 随文档下发，但只是并积层。** `SAGE_DOCUMENT_CSP` 由 asset handler 对 Sage 自有文档下发（`default-src 'none'`，仅 inline script/style 与 same-origin fetch）；真实读数证明被 CSP 拦截加载的 iframe 仍触发 `frame-created` tripwire，CSP 不能替代 main-owned generation 状态机。
4. **嵌内容出路定为合同。** privileged renderer 永不嵌 frame；未来 HTML 预览、外部网页等嵌内容场景必须走独立非特权 WebContentsView（独立 session、无 preload、无 privileged IPC 通道），实现后置到具体 UI 票。
5. **本票不引入 preload / IPC bridge。** WT-02D.0.1 的 route 迁移、Application Service composition、Host narrow port 仍 blocked；`isTrustedGeneration()` 是未来 privileged IPC 入口的必要检查项之一，不是充分条件。
6. **验证边界。** 单元 spec（12 例）、assets CSP 断言与真实窗口 probe（先 `tsc --build`、后独立 Electron 对编译产物取证）全绿；负控变异（污染不粘滞）下外层 spec 红。已证明窗口/文档/CSP/状态机行为；未证明 bridge、Application Service、真实 adapter cancel / receipt、身份授权。
7. **本批射程。** production 新增 `frame-policy.ts`、`window.ts`、窗口 probe；修改 `index.ts`、`contracts.ts`、`assets.ts`、`assets.spec.ts`；新增 ADR、Note、索引、ledger 与执行计划。未提交、未推送。

## 备选方案

| 方案 | 结论 |
| --- | --- |
| 只靠 CSP `frame-src 'none'` | 否决；被拦加载的 iframe 仍触发 frame-created，且覆盖不了移除后重嵌入等路径，只作并积层。 |
| tree-only 即时检查 | 否决；removed-child 读数证明移除后重新放行，必须 sticky generation。 |
| 骨架票同时引入 preload/IPC bridge | 否决；ADR-0174 production composition 仍缺多项真实 authority，bridge 属后续票。 |
| 嵌内容留在 privileged renderer 内 | 否决；与本不变量冲突，定为独立非特权 WebContentsView 合同。 |
| same-document navigation 重置 generation | 否决；不变量要求不洗白，SPA entitlement 治理另票。 |

## 后果

- 任何后续 privileged 窗口/文档改动必须维持：单帧窗口工厂唯一入口、CSP 下发、污染粘滞与 main-owned reload 恢复语义。
- 产品 UI 引入 SPA 路由时须保持 same-document 不洗白语义；需要恢复信任时走 main-owned reload。
- WT-02D.0.1 后续 bridge 票的 IPC entry / durable barrier 必须检查 `isTrustedGeneration()` 并在 durable boundary 前重验。
- 嵌内容 UI 票必须按第 4 条合同实现独立 WebContentsView，不得在 privileged renderer 内开 iframe/webview 例外。
