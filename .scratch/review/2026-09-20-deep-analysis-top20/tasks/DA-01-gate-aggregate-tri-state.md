# DA-01 · gate.mjs 聚合层三态收口：skip 显式渲染 + --strict 开关

- 优先级：P0
- 状态：`local-done`（2026-09-21，批次 A 落地，待提交）
- 依赖：无
- 估算：M
- 来源：docs/pitfalls-playbook.md P-17；报告 TOP20 #1

## Problem

P-17 诚实划界原文：「拦住聚合层的那一步尚未落地——只有 skip 时退出码仍为 0，`scripts/gate.mjs` 里没有 `--strict` 或「跳过即失败」之类开关……两处尚未落地，下次同族复发前做掉。」
现状：`skip` 在单项层已诚实（不计入通过数、note 必渲染），但**聚合层输出对逐项状态做有损投影**——「射程为空 / 环境读不到」与「逐项全过」在退出码与汇总行上同形。发布 2.4.0 时 54/55 通过、RC=0 的同一份输出里藏着一句「本项未核对任何版本」。

## 动作

1. 汇总行改写：`skipped > 0` 时显式输出「N 项未核对」，与「通过」句分离；
2. 给 `scripts/gate.mjs` 增加 `--strict`（或等价开关）：skip 计为非 0 退出，供**发布前那次运行**使用；日常开发保留宽容语义（否则断网环境门禁不可用）；
3. 两项同步配反向自测（恒真桩突变下必须变红），并更新 pitfalls-playbook P-17 的「已落地机制」段。

## 验收

- 构造一个 skip>0 的场景：默认模式汇总行含「未核对」字样且与原「通过」句可区分；
- 同场景加 `--strict`：退出码非 0；
- `gate --list` 自测项覆盖两态（默认宽容 / strict 严格）；
- `pnpm run gate` 日常语义不变（本次全绿基线不得回退）。

## 注意

日常与发布两种语义必须分开说清，写在开关的 help 文本里；不要用「放宽阈值」消掉 skip。
