# DA-13 · .scratch 42 个工作流清场（按「先承诺后体积」的顺序）

- 优先级：P1
- 状态：`open`
- 依赖：DA-04
- 估算：L
- 来源：本次图谱（historical-artifacts 层 205 节点）；P-49；报告 TOP20 #13

## Problem

`.scratch/` 下现存 **42 个工作流目录**（acceptance / 研究 / 卡片 / 一次性诊断混杂），图谱层统计 205 个节点。
P-49 的教训：清场清单若按体积/引用排序会**先盯上证据面**（历史发布产物 5.7 GB 被列「无用垃圾」）；这些工作流里同样混着在飞工作、证据面与已完成品。

## 动作

1. 逐工作流判三档：**已完成归档 / 在飞保留 / 证据面不动**；
2. 在飞的收敛进 `docs/notes/`（或本目录），完成品按 ADR-0013「归档出工作树」移出；
3. 顺序严格按 DA-04 的三步（先承诺 → 再引用 → 后体积）；
4. 处置结果写一张清单（每项一句话去向）。

## 验收

- 清单化处置（42 项逐条，无遗漏）；
- `.scratch/` 仅剩在飞工作流与证据面；
- 被移动/归档的对象仍可从归档索引回溯（ADR-0013 要求）。

## 注意

有人正在用的工作流不要动（先归因 P-43：git status 看最近改动）；证据面的判定进清单。
