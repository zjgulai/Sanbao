# 018 名字迁移批 4：favicon + PWA 清单（补既有射程缺口）

**类型**: 宽重构·迁移
**Blocked by**: 003, 016

## 目标
处理**从未被品牌化过**的两处：`brand-replay.sh` 里没有任何 favicon 命中，PWA 清单至今写着基座名。

## 涉及层
- [ ] S-C：新增 favicon 与 `manifest.webmanifest` 的重放声明
- [ ] S-A：`name` 取 `bundleDisplayName`、`short_name` 取 `shortName`（=`SB`）、icon 接 app-icons
- [ ] 资产层：`worldpilot-favicon.svg` 的**同配方产品版**由名源生成（随系统明暗变色）
- [ ] 测试：清单字段与名源一致性断言

## 验收标准
- 真机浏览器标签：favicon 是产品自己的且随明暗变色
- `manifest.webmanifest` 不再含 `DeepSeek Harness`/`DSH`
- `short_name` 与 app-icons 的命名族一致
