# 013 排印：Inter 默认 + mono 元标签原语 + 列轴实测复核

**类型**: 宽重构·迁移
**Blocked by**: 007

## 目标
换默认 UI 字体并引入两个排印签名，同时**实测**（非推断）字体宽度变化对侧栏几何的影响。

## 涉及层
- [ ] S-B：`uiFont` 默认 `system`→`inter`（基座已内置 6 个 woff2 子集，零新资产）
- [ ] 共享层：`.tiny`（mono 11px/字距 1.3px/大写）与 `.eyebrow`（11px/字距 2.5px/650/主色 + 前导 27px 短横）提为共享原语
- [ ] 排印：标题字距 h1 `-.055em`、h2 `-.045em`
- [ ] 判据层：`sidebar-row-axis` 列轴与 `TARGET_SIDEBAR_WIDTH=264` **实测复核**
- [ ] 测试：Law C 断言不破——所有 UI 规则仍走 `font: var(--dsw-font-…)`

## 验收标准
- 真机明暗两主题下正文渲染为 Inter，拉丁字形与字标一致
- `sidebar-row-axis` 绿，且给出换字体前后的实测 x 坐标对照（不能只报「绿」）
- 不采纳供体官网的 `Arial` 字体栈（那是零依赖静态页的妥协，非品牌裁决）

## 备注
改字体会改字宽。这条被明确列为「不得推断为应该没事」。
