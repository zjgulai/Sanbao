# 029 视觉基线入仓，使其可从仓库重建

**类型**: 收口
**Blocked by**: 012, 020, 023

## 目标
把「视觉基线」从不可复现的未跟踪目录搬进受管面——现状它由 headless Chrome 现跑现生成，仓库里没有。

## 涉及层
- [ ] 资产层：基线截图迁入受管目录
- [ ] 工具层：`visual-gate.sh` 的生成路径改指受管位置，且可从干净 checkout 跑通
- [ ] 判据层：基线缺失即判红（不得静默跳过）

## 验收标准
- 从干净 checkout 跑一次基线生成，产物与入仓基线一致
- 删掉基线文件后门禁判红（证明它真的在管事，不是可选步骤）
