# 001 开工基线与并发会话文件所有权交集

**类型**: 预重构
**Blocked by**: 无

## 目标
让后面 31 张工单的「gate 绿」具备可归因性——没有基线读数，红到底是自己改的还是别人在制品，无法分辨。

## 涉及层
- [x] 判据层：跑一次 `pnpm run gate` 与 `gate:full` 并存原始输出
- [x] 协作层：列出并发会话当前在改的文件，与本计划落点求交集
- [x] 记录层：把基线与交集写进 `.scratch/sanbao-reskin/baseline.md`
  → **实际落在 `baseline/README.md`**（目录形态）。卡面写的单文件名放不下三份原始 JSON，
  而结论必须与读数同处一地才可反查。偏差已在该文件 §5 记明。

## 验收标准
- [x] 基线读数存档，含每个 gate 项的通过/失败/跳过三态计数
- [x] 交集清单为空集，或非空项已排序等待——两者都要有书面结论
- [x] 确认 worktree 不适用的三条理由仍然成立（vendor/、.app-cache/、lute-brand-icons 均不在版本管理内）
