# 003 生成机制：名源 → 派生物 + 一致性判据

**类型**: 预重构
**Blocked by**: 002

## 目标
让「改一个源、重跑生成」成为真实可执行的路径，并立一条判据保证派生物不得与源分叉。

## 涉及层
- [ ] S-A：名源读取
- [ ] 生成层：派生物清单 + 生成器（本张只接 `<title>` 一个派生物作为最小贯穿）
- [ ] S-G：新增门禁「派生物与名源不一致即判红」，带反向自测
- [ ] 测试：突变测试——手改派生物一个字符，门禁必须红且点名两处路径

## 验收标准
- 改 `nameLatin` 后重跑生成，`<title>` 随之改变，无需碰第二处
- 新门禁的反向自测能举出反例并判红（写不出反例即视为恒绿，不予合入）
- `pnpm run gate` 绿
