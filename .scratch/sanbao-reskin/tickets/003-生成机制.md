# 003 生成机制：名源 → 派生物 + 一致性判据

**类型**: 预重构
**Blocked by**: 002

## 目标
让「改一个源、重跑生成」成为真实可执行的路径，并立一条判据保证派生物不得与源分叉。

## 涉及层
- [x] S-A：名源读取
- [x] 生成层：派生物清单 + 生成器（本张只接 `<title>` 一个派生物作为最小贯穿）
- [x] S-G：新增门禁「派生物与名源不一致即判红」，带反向自测
- [x] 测试：突变测试——手改派生物一个字符，门禁必须红且点名两处路径

## 验收标准
- 改 `nameLatin` 后重跑生成，`<title>` 随之改变，无需碰第二处
- 新门禁的反向自测能举出反例并判红（写不出反例即视为恒绿，不予合入）
- `pnpm run gate` 绿

### TDD 红→绿
- 先写自测（红）→ 实现判据（绿）：5/5 pass（含突变判红且同时点名 `dsh-patches/brand-replay.sh` / `sanbao-brand-source.ts` / `nameLatin`；空扫描面判红 P-15；write 回路回绿；mode 保留）
- 自测自身的两次修复：async 回调漏 await（`ERR_ASSERTION actual: undefined`）；`computeExpected` 缺省 brand 未加载 → 改为缺省时自动加载名源

### 实现中发现并修掉的两个真实缺陷
1. **Promise 被 gate 同步化误读**：`runGateChecks` 同步调用 `run()` 不 await，异步判据返回 Promise 被归一成 fail-close schema 错（实测 gate 报「legacy violations must be an array of strings」）。修法：判据拆 `checkDerivativesSync(repoRoot, brand)`，壳模块顶层 await 预载名源，gate 走同步形态。
2. **tmp+mv 抹掉可执行位**：可证伪演练实测 brand-replay.sh 100755→100644。修法：`writeDerivativeFile` 在 rename 前回填原文件 mode，并进反向自测（fixture chmod 0o755 → 写回后断言 mode 不变）。
