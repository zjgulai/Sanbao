# 014 主题收敛：1 套品牌 × 明暗双色道，legacy 降档

**类型**: 宽重构·收缩
**Blocked by**: 007, 013

## 目标
预设墙从 15 条收为 2 条，`codex`/`graphite`/`midnight` 降 legacy 但历史分享串仍可解析。

## 涉及层
- [ ] S-B：`presets.ts` 墙内只留 WorldPilot Dark/Light；三条降 legacy（不进墙）
- [ ] S-B：`accent-swatches.ts` 8 组→1 组
- [ ] 兼容：legacy 串解析路径保留，提示迁移而非 404
- [ ] 测试：`presets.test.ts`、`accent-swatches.test.ts` 重生成并逐条人审
- [ ] 文档：`docs/plans/2026-09-19-capability-hub.md` D3 处标注「已被 ADR-0132 D2 取代」

## 验收标准
- 预设墙条目数 == 2（不得残留第三套深色）
- 拿一个 `codex` 时代的历史分享串实测：可解析 + 提示迁移，不报错
- 被取代关系写进被取代文档（同一事实不留两个版本）
- `pnpm run gate` 绿
