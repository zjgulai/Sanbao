# 004 示踪弹 A：一位数字员工头像端到端（AGT-001 衡远）

**类型**: 示踪弹
**Blocked by**: 001

## 目标
用**一位**头像把整条头像路径穿通一次：资产入仓 → pin 校验 → 生成 → preset.yml → 官方卡 + 自研面板双色道。完成后能演示「一人是新形象、其余 49 人不变」。

## 涉及层
- [x] 资产层：AGT-001 双色道 × 选定档入仓 + `vendor/worldpilot.pin` + 逐档 sha256
- [x] 逻辑层：`generate.mjs` 的 `ICON_MANIFEST` 支持受管源；单点产出 `data:image/webp;base64,…`
- [x] S-D：`preset.yml: icon` → 官方 loader → `<img src>`（data URI 直出，离线可用；官方 loader 侧零改动）
- [ ] UI 层：`RoleMatrixPanel.tsx` 按主题选色道、按场景选尺寸 → **延后到 023**（见下「延后项」）
- [x] 判据层：`verify-lossless` L10 改判（MIME 与字节头一致 + 全员互异 + 与 manifest 同串）
- [x] 测试：L10 的反例（伪造 SVG 包位图必须判红）
