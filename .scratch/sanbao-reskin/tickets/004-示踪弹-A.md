# 004 示踪弹 A：一位数字员工头像端到端（AGT-001 衡远）

**类型**: 示踪弹
**Blocked by**: 001

## 目标
用**一位**头像把整条头像路径穿通一次：资产入仓 → pin 校验 → 生成 → preset.yml → 官方卡 + 自研面板双色道。完成后能演示「一人是新形象、其余 49 人不变」。

## 涉及层
- [ ] 资产层：AGT-001 双色道 × 选定档入仓 + `vendor/worldpilot.pin` + 逐档 sha256
- [ ] 逻辑层：`generate.mjs` 的 `ICON_MANIFEST` 支持受管源；单点产出 `data:image/webp;base64,…`
- [ ] S-D：`preset.yml: icon` → 官方 loader → `<img src>`
- [ ] UI 层：`RoleMatrixPanel.tsx` 按主题选色道、按场景选尺寸
- [ ] 判据层：`verify-lossless` L10 改判（MIME 与字节头一致 + 全员互异 + 与 manifest 同串）
- [ ] 测试：L10 的反例（伪造 SVG 包位图必须判红）

## 验收标准
- 真机：AGT-001 在自研面板明暗两主题下头像底色各自协调
- 真机：官方预设卡离线（关停 loopback 服务）仍渲染出头像
- `verify-lossless` 全层绿，且除 AGT-001 外 49 个 preset 的 icon 字段逐字节未变
- pin 校验：篡改任一入仓资产字节，构建失败

## 备注
选 AGT-001 是因为它与本仓 role-catalog 的对应关系已逐条验证（职责、花名全等）。
