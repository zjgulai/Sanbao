# 032 终验：改名可证伪演练 + 干净机器三件套 + `gate:full`

**类型**: 收口
**Blocked by**: 031

## 目标
证明整件事真的成立：改名只需改一个源、装机首启无异常、全量门禁绿。

## 涉及层
- [ ] 演练层：把名源 `nameLatin` 临时改成假名 → 重跑生成 → 确认 20 处可见面全部生效且 `git diff` 只落在派生物 → 改回
- [ ] 真机层：干净机器安装 → 三件套读数（启动 attempt=1、看门狗零告警、CPU 归零）
- [ ] 判据层：`pnpm run gate:full` 全绿；`exemptions.json` 仍为 `[]`
- [ ] 发布层：ΔE 8.7 的选中态可辨性读数——不达标则走材质派生升级路径，**不得**回退为另留饱和色

## 验收标准
- 改名演练的 diff 证据在案，且 20 处全部随假名改变（这是 ADR-0136 D2 的唯一真实验收）
- 真机三件套三项读数齐全
- `gate:full` 绿且零豁免
- 可辨性有实测结论，不是「看着还行」

## 备注
S6 之前不得发版（ADR-0135 D6）——中途停会留下「源已改、复述未清」的中间态。
