# 002 接缝骨架：`--sanbao-*` 定义文件 + 品牌名源模块（值 = 现状）

**类型**: 预重构
**Blocked by**: 001

## 目标
立起两个新接缝的**形状**，但值仍等于现状（绿 `#58b848`、名 `LUTE Agentic System`），因此全库零行为变化、gate 仍绿。

## 涉及层
- [ ] S-B：`--sanbao-*` 定义文件，逐条列全供体契约的键名，值先填现状
- [ ] S-A：品牌名源模块，字段 `nameLatin`/`nameZh`/`shortName`/`sloganZh`/`sloganEn`/`signingIdentity`/`bundleDisplayName`，值先填现状
- [ ] 派生层：`shared/client/` 同步机制接上，生成物带 `generated-marker`
- [ ] 测试：两模块的形状单测（键齐全、无 undefined）

## 验收标准
- `pnpm run gate` 绿，且装机产物字节与 001 基线逐字节一致（证明纯骨架无行为变化）
- 两个模块各自是唯一可编辑面，无第二处重复定义
- `theme-tokens` 门禁的 `NAMESPACE` **本张不动**（扩列必须与真实值迁移同片，否则全仓判红）

## 备注
刻意让值等于现状：这样「建接缝」与「换值」是两张可独立回滚的工单。合并做会让归因变成一团。
