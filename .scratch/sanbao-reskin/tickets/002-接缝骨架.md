- [x] S-B：`--sanbao-*` 定义文件，逐条列全供体契约的键名，值先填现状
- [x] S-A：品牌名源模块，字段 `nameLatin`/`nameZh`/`shortName`/`sloganZh`/`sloganEn`/`signingIdentity`/`bundleDisplayName`，值先填现状

- [x] 测试：两模块的形状单测（键齐全、无 undefined）

- **测试**：`packages/platform/dsh-theme-local/src/client/sanbao-seam.test.ts`，7 条（S-A 键齐全/现状锚、S-B 21 键无多余/无 undefined/命名空间纪律/现状锚/选择器约定）。TDD 红绿：先红（模块缺失 resolution fail）后绿。全包 `vitest run` 57/57、`tsc --noEmit` 干净。
