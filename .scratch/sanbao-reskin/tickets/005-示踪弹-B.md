# 005 示踪弹 B：macOS app 图标端到端

**类型**: 示踪弹
**Blocked by**: 003

## 目标
把「占位字母标 → squircle 生成器 → 门禁 → 装机 → Finder」一条窄路径穿通，并补上那条**缺失的形状判据**——旧 `brand-icons` 只校 IHDR 尺寸，硬边方块会静默出货且照样绿。

## 涉及层
- [ ] 资产层：中性几何占位字母标（显式标注为占位，不含 W/P 语义）
- [ ] 生成层：`build-app-icon.sh` 新增可复现 squircle 生成器（深底 `#0b1521` + 透明四角），删除废弃的 `LUTE_ICON_ENGINE` 分支
- [ ] S-C：`ICON_PAIRS` 与资产集合同片改
- [ ] S-G：`brand-icons` **扩展 alpha/形状判据** + 反例自测
- [ ] 装机层：`icon.icns` 落进 bundle，`icns` 哈希回退常量重算

## 验收标准
- 真机 Finder/Dock 里图标是圆角、四角透明；`sips -g hasAlpha` 为 yes
- 反例测试：喂一张无 alpha 的硬边方块，`brand-icons` 必须判红（证明新判据真的在管事）
- `brand-icons-selftest`、`brand-replay-selftest` R1–R6 全绿
- `icns` 的 sha1 回退常量已重算，`brand-replay.sh --check` 不误报

## 备注
这颗弹的额外价值：它把「门禁看不见但客户看得见」这个盲区补上了。
