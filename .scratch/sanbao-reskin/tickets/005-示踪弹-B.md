# 005 示踪弹 B：macOS app 图标端到端

**类型**: 示踪弹
**Blocked by**: 003

## 目标
把「占位字母标 → squircle 生成器 → 门禁 → 装机 → Finder」一条窄路径穿通，并补上那条**缺失的形状判据**——旧 `brand-icons` 只校 IHDR 尺寸，硬边方块会静默出货且照样绿。

## 涉及层
- [x] 资产层：中性几何占位字母标（显式标注为占位，不含 W/P 语义）
- [x] 生成层：`build-app-icon.sh` 新增可复现 squircle 生成器（深底 `#0b1521` + 透明四角），删除废弃的 `LUTE_ICON_ENGINE` 分支
- [x] S-C：`ICON_PAIRS` 与资产集合同片改
- [x] S-G：`brand-icons` **扩展 alpha/形状判据** + 反例自测
- [x] 装机层：`icon.icns` 已落进 bundle，哈希回退常量同值；用户授权退出 DSH 后重放、重签、重启并完成目视验收

## 验收标准
- [x] 真机 Finder/Dock 外观由用户目视确认正确；安装后的 icns 与 Dock PNG 均 `hasAlpha: yes`
- [x] 反例测试：无 alpha RGB 方块、RGBA 不透明方块、仅四角单点透明、错误深底均判红
- [x] `brand-icons-selftest`、`brand-replay-selftest` R1–R6 通过
- [x] `icns` sha1 回退常量同值，真机 `brand-replay.sh --check` 返回 `BRAND ALL VERIFIED`

用户最终裁决：005 只完成图标；不改显示名、bundle 路径、可执行文件或 bundle id。

## 验收证据（2026-09-19）

### 生成与资产
- `brand/logo/placeholder-mark.svg`：三个独立菱片，显式 `data-status="placeholder"` / `data-semantic="neutral-geometric"`，无 W/P 语义；正式字母标仍归后置 T1。
- `build-app-icon.sh`：唯一输入为受管 mark，标准库确定性栅格化 power-5 superellipse（深底 `#0b1521`、钛银 `#c4d0dc`）→ 1024 PNG / 6 档 mark PNG / iconset / icns；删除仓外技能依赖和 `LUTE_ICON_ENGINE` 分支。
- 连跑两次：`icns` 与 7 张 PNG sha256 全同；入仓副本与现跑产物全同。当前 `icon.icns` sha1=`7679eaf58b6a45ebfb5bb34b7383f916149778f5`，回退常量同值。
- `sips`：`app-icon.icns` 与 7 张 PNG 均 `hasAlpha: yes`，尺寸分别为 1024 与 `ICON_PAIRS` 声明值。
- 输入 + 8 个生成输出均登记进 `vendor/worldpilot.pin`；`brand-avatars-pin` 真仓复算绿。

### 判据与反例
- `brand-icons` 直接解析真实 IHDR/IDAT，支持 PNG filter 0–4；限制边长 ≤4096、解压后 ≤64MiB，判不出 fail-close。
- 形状规则：有 alpha；四个 5% 边角区域全透明；透明像素占比 ≥5%；有非透明主体；app squircle 中心深底必须为独立规格字面量 `#0b1521`。
- 反例：无 alpha RGB 方块红；RGBA 全不透明方块红；只挖四个角点红；错误深底红；尺寸错/非 PNG/缺件/多件/重复目标/空表仍红。
- 聚焦 Node 测试 25/25 绿；`brand-replay-selftest` 8/8 绿，并证明 icon.icns + 8 个运行时目标的 DRIFT→写入→逐字节同值→幂等；尺寸错时 8/8 全拒绝、0 写入且前后 sha256 同值。
- 实际执行 assemble 的复制段：完整七张资产复制成功，逐个删去任一必备 PNG 均失败；实际执行 refresh 备份段：备份失败退出且不得打印成功。
- `assemble.sh` 改为 fail-closed：缺 app icns 或 `ICON_PAIRS` 任一 runtime 资产均中止，不再保留官方原样继续出货。
- `bash -n`、`node --check`、`git diff --check` 通过。形状规则不是整条超椭圆曲线的逐像素认证；跨 macOS 工具链的二进制编码同值未承诺。
