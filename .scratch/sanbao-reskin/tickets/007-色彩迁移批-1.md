# 007 色彩迁移批 1：换源值 + 测试改读源（不可拆）

**类型**: 宽重构·扩展
**Blocked by**: 002

## 目标
把 `--sanbao-*` 的定义值换成供体真实值，并**在同一次提交内**把复述字面量的测试改为 import 源做断言。

## 涉及层
- [ ] S-B：暗 `#0b1521/#142332/#1b3042/#eef4fa/#b0c1d1/#2b4256/#8adac4/#c4d0dc/#122337`，亮 `#ffffff/#f6f8fc/#edf2f8/#16283c/#526578/#dce5ee/#176c57/#3d566e/#ffffff`，`--radius 8px`，材质 `--sanbao-metal-*` 七项双色道，动效 `--sanbao-{fast,base,slow,ease}`
- [ ] S-C：`theme-tokens.ts` 的 `--dsw-alias-brand-primary`、`--dsw-alias-state-business-*`、`--dsw-static-deepseek-{500,450,200}` scale 改指 `--sanbao-accent`
- [ ] S-G：`theme-tokens.mjs` 的 `NAMESPACE` 扩为含 `sanbao`（**与定义之家同片**，否则全仓判红）
- [ ] 测试：`stylesheet.spec.ts:85`、`layer-icons.spec.ts:61`、`theme-tokens.test.ts`、`accent-swatches.test.ts` 等改为 import 源
- [ ] 判据层：`brand-css.test.ts` 拆分——材质渐变合法、带色相 `box-shadow` 仍禁；测试名改判「遵循 Sanbao 材质契约」

## 验收标准
- `pnpm run gate` 绿；`theme-tokens-baseline.json` 条目数不增；`exemptions.json` 仍为 `[]`
- 真机暗/亮两色道各一张全窗口截图
- WCAG 实测读数：暗 accent on bg ≥ 11.72:1、亮 ≥ 7.62:1、accent 填充上文字 ≥ 10.14:1
- `brand-css.test.ts` 反例：加一个彩色 `box-shadow` 必须判红；加材质渐变必须判绿
- 确认 `LEGACY_EDITORIAL_SIGNATURE` 的按十六进制分支不会把新默认误判为旧 editorial

## 备注
- **不依赖 004（头像示踪弹）**：色彩迁移不需要头像先落地。曾把 004 列为前置，理由是「先跑示踪弹」——那是排序偏好，不是阻塞关系。`Blocked by` 的语义是「没有它就干不了」，假边会无谓砍掉并行度。
**拆不到更细**：测试钉的就是字面量本身，「只换值不改测试」会让 gate 立刻红。这是拆切片时才暴露的事实，规格 §5 已补记。
